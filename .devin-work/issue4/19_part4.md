## 6. 楽曲方針

楽曲の SoundEvent ID は `understory.music.*`（MUSIC 領域）。楽曲は §3 の SE 表には登録せず、本節の表が楽曲台帳（SoundEvent ID ⇔ 素材 ID の突合は §7.1）。

### 6.1 次元環境楽曲

- **バニラ抑制**：本 MOD の次元内ではバニラ楽曲を抑制し、独自楽曲のみを常時化（次元全体の音楽言語を統一）
- **独自常時化**：環境床に 30〜90 秒間隔の無音を挟む間欠型の楽曲を薄く重ねる（常時音楽にしない——「静けさの中に時々音楽が漂う」設計）
- **05 楽曲なし特例**：汀には楽曲を配置しない（歌姫の歌のみ——§6.6）
- **ダッキング**：幕切れ・結末・救出などの重要イベント音の発生時、楽曲を一時的に下げる（バスダッキング）

## 7. 素材要件・権利

### 7.1 素材仕様

- **形式**：OGG 44.1kHz（バニラ標準）。mono＝定位音、stereo＝非定位（§2.3）
- **規模**：全体で 120〜180 素材（SE 群＋楽曲群＋環境床群）
- **疑似ループ対応**：環境床・周期音はループ用の切り出し設計（§2.1.2——head/tail フェード点の明確化）

### 7.1.1 素材 ID ↔ SoundEvent ID 突合

素材表の `SE-*`/`MU-*` ID と §3 の `understory.*` SoundEvent ID の対応は §3 各行の「素材ID」列に記す。実装では SoundEvent ID のみが存在する。

### 7.2 権利方針

- **自作本線**：独自楽曲・SE は自作を本線とする
- **CC0 限定**：外部素材は CC0 のみ採用可
- **CC-BY 原則不採用**：帰属表記が要る素材は原則不採用（例外的に採る場合のみ帰属表記を整備）
- **生成 AI 受入条件**：生成 AI 素材は「権利クリーン確認＋修正・加工の自由があること」を条件に限定受入
- **台帳**：`LICENSES-AUDIO.md` に素材単位で権利情報を記録（発注・収録・加工履歴を管理）

### 7.3 配信対応

- **Content ID 非登録**：自作楽曲は Content ID に登録しない（配信者の動画が著作権ヒットしない設計——17 §5）
- **音量推奨**：配信での聞き取りやすさを意識した音量バランス（楽曲は控えめ・SE は明瞭）
- **クリップ映え**：幕切れ・鐘・救出の一瞬の「映える一音」を意識した設計

### 7.4 制作体制・P0 最小音セット

優先度 P0 の最小音セット（プロトタイプ段階で必須の 14 項）：

書物器 3 音（頁めくり・開閉・綴じ）・拾得通知・ゴミ箱着弾・環境床（序章・01・03・04 各 1）・幕切れ・鐘（径・大鐘・結末）・打鍵・転移音・歌姫攻撃・音消える
