## 0. 位置づけ

### 0.1 本書の役割——名前の唯一の台帳

本書は The Understory の**名前（用語・読み・英語名・識別子）の唯一の台帳（正本）**である。設計書・実装・配信素材が名指しに使う語の「どれが正しい名か・どこがその定義の権威か」を一括で引く場所であり、「この語は何を指すか」の**定義・数値・仕様の正本は各正典書に残る**（G-GL-01——引用のみ原則。本書は名を持ち、正本節を指す）。

- **TBX termEntry 型**（docs/61 §1.1）：1エントリ＝1概念。同じ概念を指す複数の表記は別行にせず、1エントリ内に「主語（preferred）／異表記（admitted）／旧称・廃止語（deprecated）」の**格付けで束ねる**（P-GL-01）。
- **本書が担わないもの**：値・仕様・設計判断そのもの（各正典が正）。本書は「どの正典節が権威か」の索引に徹し、矛盾や衝突を検出した場合は黙って修正せず `44-U{n}-Q{m}` の要承認として報告する（P-GL-09——用語集は消去装置でなく報告装置）。
- **なぜ必要か**：正典約60ファイルに世界観語・システム語・工程語・識別子が混在し、独立検証のたびに表記ゆれ・定義ずれが検出される現状がある（docs/61 §1.3）。Issue #9 の完了条件「棄てられたものの国関連用語の日英統一」は、名の正本を一本化することで達する。
- **権威の分界**（G-GL-11）：リスクは docs/42、公開工程は docs/43、**N-系 ID 採番は docs/38 系**（他系列の採番権威——F/T 系＝docs/36 §0（命名規則 `F-<主題>-nn`・`T` 系名前空間）・§5（旧ID→正番号の対応表）・判定票 GT-*＝docs/43 §2.8・記録イベント名＝docs/41 §3.2-2——は §7.6 分界表を参照）、字幕名は docs/19 §3.6、音名（SoundEvent ID）は docs/19 §3（命名規格＝§2.1.1）、記録イベント名（プレイテスト計測）は docs/41 §3.2-2 がそれぞれ唯一の正本。本書はこれらを**再管理せず**、読み・格・対応する正本節を索引化するだけとする。

### 0.2 収録基準と除外基準

**収録するもの**（P-GL-04——正典で用語として定義または固有名称として確立した語に限る。いずれかを満たす）：

1. 見出し・太字・「〜とは」で名付けられている語（例：響界、拾得鍛錬、月中継点、名の残る部位）
2. 複数の正典節から名指しで参照されている語（例：二度棄ての淀、招待状、没腐遺留物）
3. 実装・素材・配信で名指しが要る語（字幕名・SE 名・構造物名・モブ名・装備名・章名——読み仮名は配信素材の源泉、P-GL-08）

**収録しないもの**：

- 修辞上の一度きりの言い回し・汎用語（「届く」「捨てる」等の素の動詞——ただし正典で文法化・動詞試験化された五動詞「待つ／届ける／合わせる／名を与える／聞かせる」は収録。なお五動詞の一員は正典内で「名を与える」（門名・結末名系）と「名づける」（カリキュラム列挙系）の2形で併存する衝突＝44-U4-Q3）
- 正典に正本節を持たない語（P-GL-03——正本のない語は収録しない。棚卸しで検出した正典不在語は本文に載せず §8 要承認へ：44-U2-Q8・44-U3-Q4 参照）
- 個別 ID の全列挙（G-GL-05——N-XXX・`understory.*` 音名・lang キー等は採番規則の正本を指す索引に留める）
- 廃止済みの旧機構・旧称で正典上の存在がないもの（例：ベッド儀式＝ADR-0005 で廃止確定——現行系統に存在しないため収録せず、検出記録のみ §8 に残す）

## 7. 登録運用

> 本節は用語集を静的リストでなく運用可能な台帳にする手順（G-GL-12）。「新語の登録」「改名・廃止」「衝突検出」の3系統と、定期的な語彙衛生を規定する。運用の型は docs/42 §3（監視運用——§3.0「誰が・どこへ」の固定＋観測契機＝§3.1/§3.3）に倣う。

### 7.1 運用原則

- **命名の権威は正典側**（G-GL-02）：用語集は登録・索引化の器であり、名を決める場所ではない。改名・統一・英語名の新規付与は全て要承認。
- **1概念1エントリ**（P-GL-01）：新語は必ず主語で登録し、別表記は異表記欄へ束ねる。別行の増殖を禁止。
- **正本ポインタ必須**（P-GL-03）：正本節（`docs/NN §x.y`）のない語は登録しない——登録できない命名は「未命名の穴」として §8 の要承認へ。
- **日本語が原語**（G-GL-03）：英語名は正典既存分のみ収録。未定は「未命名」とし、執筆時に新造しない。

### 7.2 新語の登録手順（Issue 手渡し→用語集登録→正本節指定）

新語の流入経路は2系統：

**経路①：Issue 手渡し行の受入**（先例＝docs/40 §9「Issue #9」行——垂直スライス・スライス外台帳・完成品質・検証3層・good enough・量産可否・月中継点）。以後の設計書は手渡し一覧に「Issue #9／用語集」宛の行を持つ前提とし、完了時に当該書を走査して機械検出する（docs/42 §3.2 P1 と同型の手順）。

**経路②：正典内での新規命名の取込**。設計書が新語を名付けたとき（見出し・太字・「〜とは」形・命名表の行追加）、当該書の手渡し一覧または本書 §8 への起票をもって登録対象とする。命名権威別の登録経路（§7.6 分界表）——字幕名・SE 名は docs/19 §3・§3.6 の台帳経由（「新規」印運用——63-U3-Q2）、N-系 ID は docs/38 系の採番表、記録イベント名は docs/41 §3.2-2、F 系・T 系は docs/36 §0（命名規則）が正本（旧ID→正番号の対応は §5）。

**登録手順（エントリ化）**：

| 手順 | 操作 |
|---|---|
| G1 | 正本節の存在を確認（`docs/NN §x.y` の形で指せるか）。なければ登録せず §8 へ「未命名の穴」として起票 |
| G2 | 層帰属を判定——世界観語（§1）・システム語（§2）・工程語（§3）・識別子（§4）のいずれか1層。跨層の概念（響界＝世界観名だが機構の正本が §2 系）は主語を意味層に置き、正本節は機構面の権威節を指す（44-U2-Q10/Q11 の分界に従う） |
| G3 | 必須欄を記入——用語・読み（非自明のみ・G-GL-09）・英語名/識別子・定義の正本・状態（§0.3 の4値）・異表記・備考 |
| G4 | 五十音索引（§6）への登録——主語・異表記・別称の誘導行を併記 |
| G5 | 衝突の有無を機械チェック——同名異物（§1〜§4 横断 grep）・既収録語との表記ゆれを確認し、検出があれば §7.4 の流れへ |

### 7.3 改名・廃止の手順（要承認必須）

正典確定済みの名・ID・キーの**改名・統一・廃止は全て要承認**（G-GL-02）——用語集側・執筆側が独断で行わない。

| 手順 | 操作 |
|---|---|
| R1 | 改名・廃止候補を `44-U{n}-Q{m}` として §8 に起票（推奨案＋書き戻し先＋統合元を必須とする——docs/43 §9・docs/16 §7 の書式に準拠） |
| R2 | ユーザー承認後、主エントリの用語欄を新名へ更新し、旧称は異表記欄へ「旧称」（再使用の可能性が残る場合）または「廃止」（確定廃止の場合）として移す——消さない（P-GL-07・TBX の deprecated 格付け） |
| R3 | 正典側の表記揃正は用語集の編集範囲外——各正典書への書き戻しは当該書の要承認経路（`NN-U{n}-Q{m}` または Issue コメント）で提案する。先例：音域→響界（34/05「未決事項〔open_questions〕」節の承認記録経由で改名確定——定義の正本は 34/05 §3.2）・殻の集塊→棄材のゴーレム（34 README「旧称」注記で記録のみ）・バンドル→届け物袋（N-DEV-201 置換確定） |

### 7.4 衝突検出時の流れ

衝突とは以下の**3類型**（docs/61 §4 H-06）：

1. **一概念複数名**——表記ゆれ（月の中継点⇄月中継点＝44-U1-Q1・二度棄ての淀⇄淀み＝44-U4-Q8）・略称（月の林⇄満ちなかった月の林＝44-U4-Q1・常夜の林＝44-U4-Q1）・旧称（殻の集塊）・動詞形ゆれ（名を与える⇄名づける——44-U4-Q3）・二名併記（没腐した林の獣⇄待ちぼうけの獣——44-U4-Q5）・**章名系の系統的別称**（docs/19 が全6章を正典名と別称で並記——01＝月齢の環礁・02＝届かない港・03＝開かれない広場・04＝選べない坑道・05＝歌姫の汀・終＝座の階層、docs/55＝「月の森（待ちぼうけの章）」「待ちぼうけの翁」——44-U4-Q1・44-U4-Q7）。承認済みで束ね確定の先例＝没腐の根⇄月光の根（16-U2-Q14——teach 一覧側の二名を「没腐の根」へ一本化）
2. **同名異物**——前任の露営（01・終章の2箇所——44-U4-Q6）・月見翁⇄拾い人の翁（44-U4-Q7）・欠片（結末の欠片／月の欠片／幻想文字のかけら——44-U4-Q9）・拾い人（役割名／村名／村の長——44-U4-Q10）・L3（検証層・構造物——44-U3-Q2）・段（4〜5系統——44-U3-Q1）・座（終章環礁名「原案の座」⇄設置座の汎用語「欠片の座」「走り書きの座」——44-U4-Q4）
3. **正典間の定義ずれ**——同一語が別の意味・値で使われる

> **「正典が参照するのに名のない概念」は衝突ではなく H-09「未命名・未定義の穴」の領域**（docs/61 §4 H-09）——docs/61 棚卸し語で正典に正本がないもの（同士討ち・葬送・熱リハ等＝リポジトリ内では docs/61 のみに出現）。これらは C1〜C3 の衝突経路（主語採用・束ね）には乗せず、**§7.2-G1 の「未命名の穴」として §8 の要承認へ起票する**（§0.2・§7.2-G1 どおり——命名の権威は正典側のため、用語集が名を補うことはしない）。

**検出→起票→編集の流れ**：

| 手順 | 操作 |
|---|---|
