## 着手前の熟考（AGENTS.md フィロソフィーどおり）

### なぜこのIssueをやらないといけないのか
- docs/40 §4.9/§9 で確定した構成どおり、**垂直スライス本体着工の前提は本 Issue の先行ゲート5点**（次元生成・転移骨格・個別化アイテム・転移持ち込み・異物の可視性モデル——40-Q8 承認済み）。ここが潰れないとスライスは動けない
- 正典が積み上げた実装前提はすでに大きい：構造生成4型（docs/16）・個別層/共有層モデル（ADR-0004・docs/32 §6）・音のサーバー権威発火±100ms（docs/19）・Patchouli/自前書物器・幻想文字フォント（docs/18/20）・環礁本体の生成方式（正典未決）。実現性の見通しを誤ると、設計の巻き戻しコストが最大になる層——先行研究でも「基盤の欠落」は失敗の典型
- Issue #13 の完了条件は「検証結果を Issue コメントまたは ADR に記録」。Phase 0 では実装コードを作らないため、本フェーズでの成果は**検証計画・実現性評価書**（NeoForge 1.21.1 の API 実在性と先行実装の調査ベース評価＋Phase 1 で作る PoC の仕様・合格ライン・設計代替）として正典化する——実機検証そのものは Phase 1 許可待ち

### このIssueはゲームにどんな面白さを与えるか
- 「捨てた物が届く国」「あなたが捨てたものが見える世界」「自分を棄てる転移」——本作の主題装置（P-VS-02）はすべてこの Issue の技術前提に依存する。個別層が実現できなければ「世界があなたを覚えている」という本作の心臓が成立しない
- 二層演出（現実側から見える国）と異物の「発見した人にしか見えない」性質は、プレイヤーの「俺だけが気づいた」体験＝配信の発見映えの中核
- 環礁本体の生成方式（ワールド固定＝40-Q24 承認済み）は、見晴らしの岬からの環礁群一望・月中継点の方位基盤・場所系列の脚本化という、本作の空間ドラマの物理的前提
