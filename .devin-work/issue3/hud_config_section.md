## 5. HUD・フィードバック・環境内 UI

> 本節の範囲：プレイ中の画面に現れる HUD 層・環境内の表示器・通知の実仕様。書物器（§3）・演出画面（§4）を除く全表示をここに集約する。
> 大原則：**環境が一次・UI は二次**。本節の全表示は「環境一次導線が先に成立している」ことを前提とする二次層であり、UI だけで成立する導線・情報は置かない（G-UI-04/05）。新規 HUD・専用導線記号（HUD 矢印・クエストマーカー・光の筋）は禁止（48/04 §4.3）。
> 表中のチャネル記号は docs/45/04 §3.1 の C1〜C8（光／造形／色彩／動き／位置／聴覚／字幕／装置）。C3・C6・C8 は単独算入不可（色彩は常に補強、聴覚は C7 とのペア、装置は一次環境の補助に限定）。
> 時間値は「確定値」のみを記し、正典に確定値があるものは引用で示す（38/03 §4.3 が演出時間の権威）。本節で新たに確定する UI 時間値（通知保持等）は「**確定（本書新設）**」と明記——実装微調整は Issue #15/#34 側の許容範囲。

### 5.1 没腐コンパス

**仕様注記**
- **適用範囲**：自分の捨て場の物・個別化アイテム（あなたが捨てたもの）・怖い物（呪い付き・隔離区画系の由来物）・死亡遺留物・届きもの・共同ゴミ箱の「誰かの捨てた物」・ゴミ箱の所有者表示（「◯◯のゴミ箱」——由来札の同型変種）。
- **認識の瞬間の保護**：「あれ、これ俺が捨てたやつ…」（17 §3 のクリップ瞬間）は由来札が担う——自分の物への表示形は §7 18-U4-Q4 で語彙を確定する（「あんたの物」案＝第二人称の語り口で主題と一致）。
- **他者の物**：他人の捨て場・漂着物には持ち主名が出る（マルチ視点差分＝「推しには何が見えたか」の配信要件、17 §5）。
- **招待状「あんた宛だ」の所有者限定表示**：招待状は消失しない固定所持品（投棄・破棄されない）。他人が先に開けても中身は所有者にのみ「あんた宛だ」とだけ出る——由来札と同じ個別層の所有者限定を書物 UI 表示にも適用する唯一の書物器例外（docs/32 §3.3・棚卸し B-3/B-9）。
- **環境文字上限の例外**：由来札「◯◯の物」・字幕表示名は環境内表示文字の上限規則の例外対象——環境文字（漂着物の書き入れ等）に課される文字数上限はこれらの表示チャネルに適用しない（26 §3.4・45/03 U3-Q2）。

### 5.6 字幕表示名

バニラ字幕システムへの独自 SE 表示名の登録規則（XAG 106・G-UI-15）。命名規則は「〈主体〉：〈動作〉」二項型＋方向語許容・内容言明禁止（U4-#3 承認済み）。

| 名称 | 実装形 | 起動条件 | 構成要素 | 入力操作 | 表示内容 | 状態遷移・閉じ方 | 多重化（必須チャネル適合） | 共有/個別層 | a11y・コンフィグ | 根拠（出典節） |
|---|---|---|---|---|---|---|---|---|---|---|
| 字幕表示名 | バニラ字幕システム（言語ファイル `subtitles.*` キー登録） | 独自 SE の発音時（表示対象はコンフィグ粒度に従う） | 右下字幕領域に「〈主体〉：〈動作〉」の 1 行。方向語は括弧でなく直付（「遠くで」「足下で」「頭上で」） | なし | 音の聞こえ方の名（音源の正体でなく、聞こえる音の種類）。内容のネタバレ・正体言明は禁止 | SE 終了と同時に消える（バニラ字幕の表示時間に準拠） | 聴覚 C6 のペア（C6 は C7 とのペアでのみ算入） | 個別層（字幕は個人のクライアント表示。環境共有情報は別に環境が担う） | §6.1 #1（粒度：意味を持つ SE 限定/全 SE/OFF）・#2（サイズ・表示時間） | Issue #31 U4-#3・45/04 §5.2 H-4・48/04 §4.2 |

**登録規則**
- **二項型**：「〈主体〉：〈動作〉」——例：「鐘：鳴る」「郵便船：軋む」「紙：擦れる」「拍子：鳴り続ける」「打鍵：遠くで響く」「ゴミ箱：鳴る」「小さな鐘：微かに鳴る」「人形：踊る」「頁：めくれる」「淀み：響く」。
- **方向語**：「遠くで」「足下で」「後ろで」「頭上で」を許容。距離の精密化はしない（方角はバニラ字幕の矢印に任せ、語彙は曖昧のまま）。
- **禁則**：音の正体・内容の言明をしない（「打鍵」の正体は最深部で環境が明かす——F-U4-R11）。主体名は「聞こえる音の種類」に限る。
- **無音の扱い**：第5章の無音区間では字幕も出さない——「音がないこと」自体が演出（45/04 §5.2）。
- **登録対象の基準**：導線上意味を持つ SE（遠い汽笛・打鍵音・紙擦れ・拍子・鐘・没腐の歪み音・異物の気配音・頁をめくる音・ゴミ箱の投入音等）＝45/04 §5.2 の列挙を既定対象。全登録 SE の語彙表は Issue #4（音）との共同管理とする。

### 6.3 配信対応

- **専用画面は作らない**（U4-11 承認・G-UI-19）——演出抑制・強度調整は全て §6.1 のコンフィグで対応。
- **視認強度（30 秒基準）**：最重要・主要の情報は視聴者が配信解像度の画面から読める強度とする（45/04 X-4・17 §3）。具体的な下限——字幕名・由来札・照準表示はバニラ字幕準拠サイズを下限に拡大段階を持つ（#2）、拍子印・頁形通知は画面下端〜右下の認識域で 1 回の視線移動内に収める大きさ。迷子・詰まりは配信の事故になるため、多重化（§6.2 表）はそのまま配信品質の担保になる。
- **短縮の境界**：#7 の短縮は**暗転の長さを削る程度**に限定し、幕間の「間」に置く情報の多重化・三重信号は削らない。
- **綴じ画面＝配信の山場**：結末綴じ画面（§4.1）は三択の視認性とかすれた項の存在（§5.5）が「コメントが沸く形」の要件——視聴者が「三つ目がある」と画面だけで読める強度が必須。マルチ視点差分（由来札・頁所持者のみの項）は同席者が別視点を観に行く理由として機能（17 §5）。
- **配信者向け提供素材**：シェーダー推奨設定・導入手順は docs/17 §7・46 D-7 の成果物側（Issue #8 手渡し）——本書は UI 側の視認要件のみを担う。

### 6.4 シェーダー共存の UI 要件

- **描画非依存の成立**：本書の UI 要素（HUD 層・ツールチップ・字幕・Screen・Toast/Title）は全てバニラの GUI/字幕パイプライン上にあり、シェーダーの色彩・ポストプロセス処理に乗らない——**UI レイヤはシェーダー ON/OFF で変わらないこと**が合格条件（G-UI-11・45/04 C-5）。
- **環境側演出の代替**：幕の暗転・朧な光・彩度勾配・霧滞留といった環境側演出はシェーダーで外見が変わり得るため、必須チャネルは C1 光（明度）・C2 形（輪郭）・C4 動き・C5 位置で構成し、バイオーム着色・粒子色・空の色は補強に留める（C-5）。シェーダー OFF 時の一次代替は 45/02 各章表の OFF 時併記どおり（灯台残火型＝霧が濃くなる側の光源とのペア）。
- **対象シェーダーの確定**：docs/20 §8 の残件「主要対応シェーダーの決定」は本書の確定対象——推奨3系統（Complementary Shaders - Reimagined・BSL Shaders・Sildur's Vibrant Shaders＋Iris/Oculus 実行環境——占有率の高い代表系統をカバー）を §7 18-U4-Q14 として登録。
- **検証項目（Issue #34/#6 への手渡し）**：確定した対象シェーダー×（異物演出・次元空・ボス演出・UI）の表示確認に加え、本書の各表示（字幕名・由来札・拍子印・かすれた項・没腐コンパスの指し）が OFF で一次チャネルとして機能することをプレイテスト検証項目に登録（20 §4・U2-K）。「色を取り戻す」完了表示の配色シミュレーション（protan/deutan/tritan）は環境側と併せて検証（U4-#7）。

### 6.5 祭囃子没腐姿の造形メモ（docs/16 §5.3.4・16-U3-Q1 への注記）

> 正典の三段構成（16-U3-Q1 承認）は以下の通り：(a) 下半身＝指揮台機構への接合（装束に糸巻きと拍子歯車が食い込む）(b) 両腕＝操り糸状機構に接続・鈴と扇を持つ腕のみが拍子を刻む (c) 頭部・上半身＝人の姿を保つ。デザイン側の造形詳細（衣装・表情・部位の見え方）は Issue #3 領域と正典指定されているため、本書はその概略メモを置き、docs/16 §5.3.4（16-U3-Q1）への注記とする。モデル実装側の手渡しは Issue #15（ボス/モブ数値・全表）または新 Issue 起票へ——Issue #2（構造物・ダンジョン）は完了済みのため受け皿にしない。

- **全体の読み取り設計**：遠望では劇場の暗がりに隠れ「機構だけが動いて見える」（34/03 §3#7——人形の列だけが遠目に踊る）。客席に着いた時に初めて**人の顔が見える**＝悲劇の開示（「演目そのものが彼女だった」と分かる瞬間）。
- **衣装**：祭りの囃子装束——褪せた祭り色（03 章パレット：褪せた祭り色・提灯の残光）。審美の「継がれた」面を担う：装束は**直され続けた祭り装束**（継ぎ・折れ目・重ね仕立ての痕——機構に食い込まれた裾の裂けは「巻き込まれた」でなく「長い時間そこにいた」形）。
- **下半身（接合部）**：指揮台の祭具時計台への接合——糸巻きと拍子歯車が装束に食い込む。布と機構の境目は「埋まった」のでなく「絡まった」形（継ぎ目の審美——欠けた接合）。
- **両腕（機構接続）**：操り糸状の機構に繋がれ、鈴と扇を持つ腕のみが拍子を刻む——**拍子の刻みは機構由来であり、彼女自身の手は止まっている**（刻ませられている、が読める形）。腕の動きは機構のリズム（キューと同期＝彼女はキューの一部として読める）。
- **頭部・上半身（人の姿）**：表情＝**待ちの静けさ**——涙や苦しみの顔でなく「祭りが来るのを待ち続けた者」の目。髪飾り＝祭りの簪（彼女が祭りの演者であった名残）。顔は舞台面の照度内にあり、見得視認（人形側）の妨害にならない配置（指揮台は舞台中央奥）。
- **復帰演出（撃破後）**：機構が一拍ずつ緩む逆巻き→糸が緩み装束が下ろされる→彼女が舞台中央に降りる＝**劇場で初めて舞台中央に立つ者**→結末選択へ（16 §5.3.4）。救出後の指揮台は空の祭具として殻に残る。
- **キューとの整合**：画面内拍子 UI（§5.2）は二次補助——一次合図は人形の構え＋提灯・幕の動きであり、祭囃子の腕の刻みはその環境合図の一部（彼女の動きが拍子を読ませる——彼女の姿自体が「読み合いの器」）。
