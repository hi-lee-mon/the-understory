# 設計書 05：本格ゲーム制作に必要なドキュメント体系

「企業がゲームを作るクオリティ」を実現するための成果物体系を定義する。一般的なゲーム開発標準（Pre-production → Production → Alpha → Beta → Launch → Live ops）に基づき、MOD開発向けに調整した。

## 1. ドキュメント体系（本プロジェクトの設計図一式）

### A. 概念・方向性（実施済み/一部）
- [x] `00_development_plan.md` 開発計画・フェーズ・工程
- [x] `01_research_game_fun.md` 面白さの心理学・設計原則
- [x] `02_research_mod_landscape.md` 成功MOD分析・市場・技術選定
- [x] `03_concept_directions.md` 方向性案（A〜D）
- [x] `04_direction_decision.md` 最終決定（案E採用）

### B. プリプロダクション（今後作成する中核）
- `10_game_design_document.md` (**GDD**) — ゲーム全体の設計書。以下を含む：
  - ゲーム概要・ハイコンセプト・対象プレイヤー
  - コアゲームプレイとメカニクス（コアループ、進行、経済）
  - ストーリー・フレーミング・キャラクター
  - レベル/エリアと進行
  - インターフェース
  - AI（モブ・ボス行動原則）
  - アート方向性・音楽方向性
  - 開発計画・優先度
- `11_world_bible.md` — 世界設定書。歴史・法則・勢力・用語集・タイムライン
- `12_story_outline.md` — 全章の詳細プロット・キャラシート・ロア
- `13_progression_map.md` — 進行表・難度曲線・ゲート・プレイ時間見積
- `14_items_crafting.md` — アイテム/ブロック/レシピ全表（素材・用途・入手・強化）
- `15_mobs_bosses.md` — モブ・ボス仕様（行動パターン・フェーズ・報酬・演出）
- `16_structures_dungeons.md` — 構造物・ダンジョン設計
- `17_streaming_design.md` — 配信映え要件（章構造、クリップ瞬間、マスコット、マルチ役割、イベント向け設定）
- `18_ui_ux.md` — 進捗表示・図鑑・導線・チュートリアル設計
- `19_audio_direction.md` — 楽曲・環境音・SEの方向性（「不気味さと哀愁」等）
- `20_art_direction.md` — 色彩・光・形状言語・バイオーム別パレット

### C. 技術設計
- `30_adr/` — ADR（ローダー選定、次元生成方式、セーブ/同期、マルチ対応、パフォーマンス方針）
- `31_technical_design.md` — 技術構成（パッケージ構成、データ駆動範囲、ワールド生成方式）

### D. 制作・運用
- `40_vertical_slice_plan.md` — 第1章の完成品質目標と検収基準
- `41_playtest_plan.md` — プレイテスト計画（観察項目・難度検証・配信モード）
- `42_risk_register.md` — リスク台帳（技術・スコープ・IP・工数）
- `43_release_plan.md` — 配布・ローカライズ・トレーラー・配信者向け素材
- `44_glossary.md` — 用語集（日英対応含む）

### E. ナラティブ素材（詳細化）
- `50_opening_storyboard.md` — 導入～第1章冒頭のビートごとの演出・ストーリーボード（テキスト絵コンテ）
- `51_chapter_boards/` — 各章のストーリーボード
- `52_lore_fragments.md` — 世界に散りばめるロア断片（アイテム説明・書物・環境物語）

## 2. 各ドキュメントの共通フォーマット
- 冒頭に「目的」「適用範囲」「関係者」「ステータス（draft/review/accepted）」を記載
- レビューは複数視点（ゲームデザイン/物語/配信/技術/制作現実性）で実施
- 変更はADRまたは変更履歴で追跡

## 3. 制作フロー（本プロジェクトへの適用）

| フェーズ | 成果物 | 終了条件 |
|---|---|---|
| **プリプロダクション**（現在） | 上記B+Cの全套 | レビューaccepted、垂直スライス仕様が凍結 |
| **プロダクション** | 第1章実装（垂直スライス）→全章 | 実装レビューaccepted、プレイテスト合格 |
| **アルファ/ベータ** | バランス・バグ修正 | 指標達成（難度・安定性） |
| **ローンチ** | 配布・広報 | 公開 |
| **ライブ** | 追加章・イベント・修正 | — |
