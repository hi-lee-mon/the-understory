# 62. アクセシビリティ・コンフィグ設計 調査基準（Issue #34 → docs/63_accessibility_config.md）

> 本書は docs/63（アクセシビリティ方針＋コンフィグ仕様）を作るための**共通基準**——先行調査・絶対制約（G-AC）・設計原則（P-AC）・棚卸し必須項目（H）・組版テンプレを集約する。執筆・レビュー・検証の全エージェントは本書を物差しとする。

## 0. 目的と完了条件との対応

- **Issue #34 の完了条件**：アクセシビリティ方針ドキュメント＋MODコンフィグファイルの項目一覧（サーバー/クライアント別）
- **本書の役割**：「どこまでを設計で担保し、どこからを設定に開くか」の境界を先に固定し、コンフィグ項目の正本表を一本化する
- **位置づけ**：コンフィグ項目の正本は **docs/18 §6.1（項目・既定値・範囲・影響先）と 45/04 §6（変更可能にすべき一覧の権威）**。docs/63 はその**仕様化**——型・スコープ（CLIENT/COMMON/SERVER）・同期・ファイル名・キー名・UI 置き場・運用を確定させる書であり、項目の新規発明はしない（追加は要承認）

## 1. 先行調査

### 1.1 アクセシビリティの外部規格

**XAG（Xbox Accessibility Guidelines）**——本作が既に採用している基準（docs/39 §2・45/04 の根拠）：

- **XAG 103**（複数感覚による情報伝達）：ゲームプレイ・物語の理解に必須の情報が色彩のみで表される場合、**形・パターン・アイコン・テキストのいずれか一つ以上の追加指標が必須**。音声の必須情報も同様に別感覚系が必要——45/04 規則 C-1・H-1 と一致（正典化済み）
- **XAG 104**（字幕・キャプション）：字幕テキストは**最小既定サイズの 200% まで拡大可能**であること・1行 40 字以内・同時表示は 2 行まで（例外 3）・sans-serif 書体の選択肢・**背景色と不透明度をプレイヤーが設定可能**であること
- **XAG 106**（独自音響への字幕表示名）：独自 SE には字幕表示名を持たせる——docs/19 §3.6 の字幕名台帳（約 80 名・二項型）が正典として着地済み

**WCAG 2.3.1（発作閾値）**：いかなる 1 秒間にも 3 回を超える閃光を含まない（一般閃光閾値・赤色閃光閾値）。1997年の放送事故（約700名被害・約500名発作）に端を発する国際基準。警告表示は児童が読み飛ばすため有効でなく、**設計側で閾値内に収める**ことが必須。45/04 規則 C-6「明滅は注意喚起の一拍限定・連続閃光除去」と整合——本作の点滅抑制モードはこの閾値の設計側担保として位置づける。

**プレイヤー特性の基礎統計（設計の前提観測）**：男性の約8%・女性の約0.5%に色覚特性（protan/deutan が大半・tritan は稀）——配色シミュレーション検証は protan/deutan/tritan の3型で実施する正典（45/04 §7-#7 承認済み）と一致。

### 1.2 バニラのアクセシビリティ設定（マイクラ本体）

MC 本体の Accessibility Settings（Java 版・公式一覧）——**バニラが担う項目を MOD 側で二重実装しない**ための境界表：

| バニラ側の項目 | 内容 | MOD 側の扱い |
|---|---|---|
| ナレーター | メニュー・チャットの音声読み上げ | 対象外（ゲーム内書物は対象外のため別経路＝読み上げの間・文字サイズで担保） |
| 字幕（Closed Captions） | 字幕の表示 ON/OFF | バニラ字幕パイプラインに乗る——MOD 側は**字幕名の登録と粒度の切替**のみ（項目#1） |
| テキスト背景・不透明度 | 字幕・チャットの背景色 | **バニラに委譲**（XAG 104 の背景設定は本体機能で充足）——独自項目は設けない |
| チャット文字サイズ・行間 | チャット文字の可読性 | 字幕・由来札等の MOD 表示は独自サイズ段階（項目#2） |
| 稲妻フラッシュ非表示／Darkness Pulsing | 閃光・暗闇脈動の低減 | バニラ項目。MOD 側の点滅抑制（項目#3）は MOD 独自演出が対象 |
| **通知時間（Notification Time）** | Toast 通知の表示時間（倍率） | **バニラに委譲**——拾得・進行通知の保持時間はバニラ通知時間に従属する設計（18-U3-Q3 承認どおり通知は着弾時1回） |
| オートジャンプ・キー割当・操作系 | 操作の代替 | 名付け・書き込み等の文字入力代替は MOD 独自領域（§4 の設計項目） |

※近年のスナップショット（26.x）では `subtitle_duration`・`hide_own/hide_ambient_gameplay_subtitles` 等の字幕細目項目が追加されており、バニラ側も字幕粒度の方向へ拡張中——MOD 側の項目#1（表示名の粒度）はバニラの機能拡張と競合しない「**登録対象の範囲**」として設計する（発火しない SE は出さない＝発火側制御）。

### 1.3 NeoForge 1.21.1 のコンフィグ作法

**型（ModConfigSpec の3型——ネットワーク同期が型で決まる）**：

| 型 | 読込位置 | 同期 | 用途（本作への写像） |
|---|---|---|---|
| `CLIENT` | 物理クライアントの `config/` のみ | 同期なし | **表示・演出系**（字幕粒度・文字サイズ・点滅抑制・コントラスト・聴覚補助・由来表示・没腐度表示・テキスト速度）——自分の画面にだけ効く項目 |
| `COMMON` | 両側の `config/`（同期なし） | 同期なし | 本設計では基本使わない（同期しない COMMON は片側ずれの温床） |
| `SERVER` | 両側 `config/`＋ワールド別 `serverconfig/` で上書き可 | **サーバー→クライアントへ同期** | **ワールド側の機構値**（読み合い支援のテレグラフ延長・難度係数・没腐度上昇率・迷子迷子補助の閾値）——全員に同じ世界を約束する項目。ワールド単位の上書き可（ワールドごとの難度運営に適合） |

- **キー規則**：`ModConfigSpec.Builder#push` でセクション分割・snake_case キー。ファイル名は登録時に任意指定可——`understory-client.toml`・`understory-server.toml` の2系統を推奨（COMMON を持たない設計）
- **設定画面**：NeoForge 1.21 には標準のコンフィグ GUI がない。modpack 慣行は「.toml を編集」だが、**a11y 項目はゲーム内で変えられないと救済として機能しない**——CLIENT 項目のみ独自 Screen（バニラオプション画面ではなく MOD 独自の設定画面・書物器スキン族）を設ける設計を推奨。SERVER 項目は .toml のみ（管理側の値）
- **変更の即時反映**：CLIENT 値は描画・UI 側で即時読替え可。SERVER 値は同期に従う

### 1.4 正典の現在地（前提観測）

- **コンフィグ一覧の権威**：45/04 §6 の 10 項目表＋docs/18 §6.1（全項目に既定値・範囲・影響先が確定済み——**項目の新設・削除は正典変更＝要承認**）
- **未着地の数値**：#5 読み合い支援の拡大係数・迷子最終段の発火時間閾値（45/04 §7-#5 → Issue #34/#15 へ一本化の確定着地先）・ダッキング量/復帰窓（57-U4-Q7 係留——PoC 実測後に提案する運用）
- **確定済みの関連値**：配信モード短縮係数 0.6（57-U2-Q10 承認）・字幕名台帳＝docs/19 §3.6 が正本・読み上げの間＝docs/18 §2.6（T_base=1.2s・τ=0.12s/字・T_max=10s・頁めくり 0.30/0.18s）・対象シェーダー 3 系統（18-U4-Q14）

| G-AC-10 | **正典の変更はしない**：本書の執筆で発覚した正典の矛盾・未定義は本文で改変せず §5 の要承認に集約する |

## 3. 設計原則（P-AC-01〜8）

1. **三層構造**：設計担保層（既定で成立・45/04 の規則）→コンフィグ層（強度を変えられる・本書 §2）→検証層（docs/40 §5.2.3 監査・Issue #6 観測項目）——層の混同をしない
2. **サーバー/クライアントは「誰の世界を変えるか」で切る**：自分の画面だけ＝CLIENT・全員の世界＝SERVER・プレイヤー個別の補助（応答窓等）＝CLIENT 項目だが機構側への接続を明記
3. **キー名は lang キーと同系**：`understory.<section>.<name>` の snake_case で翻訳キーと一致させる（日本語説明文は設定画面の表示文字列として別定義）
4. **ファイルは2系統**：`understory-client.toml`（表示・演出・補助）＋`understory-server.toml`（世界機構値）——COMMON は置かない（§1.3）
5. **係数は式でなく倍率**：読み合い支援・テキスト速度等は正典の式・値を変えず倍率で乗る（18 §6.1 #10 の「τ の倍率差として実装し式そのものは変えない」と同型）
6. **a11y 項目はゲーム内で変えられる**：CLIENT 項目は独自設定画面（.toml 編集不要）を必須とし、modpack/運営向けの SERVER 項目のみ .toml に留める
7. **検証項目は登録する**：色覚シミュレーション3型・シェーダーOFF・抑制モード完走——設計の「効いているか」の確認は Issue #6・docs/40 の検証系へ手渡す項目として明記
8. **迷子補助は保険**：一次導線の失敗を設定で埋める設計にしない（45/04 B-3）——迷子補助の感度変更は「最終段までの時間」を動かす範囲に限定
