# ADR-0005: 次元入口の「捨てる」一本化（ベッド儀式の廃止）

- Status: Accepted
- Date: 2026-09-25
- Deciders: 65banseki + Devin
- Related: docs/11 §4（次元への入り方）、docs/23 §5.0（招待状ゲート）、docs/24 §9.5（整合監査）、ADR-0001（方向決定——入口部分を本ADRが更新）、ADR-0003（捨てられたもの機構）

## Context

従来は入口を3系統としていた：異物（発見型）、ベッド儀式（枕元に供えて眠る）、ゴミ箱（クラフト装置）。

ユーザーレビューで「ベッドで向こう側へ行くのは違和感。ゴミ箱や棄てられた世界との関連性が弱く、世界観が壊れている」と指摘された。検討の結果、「眠る」という動作は本作の文法（捨てる・流れ着く・届く）に含まれず、世界観の一貫性を損なうと判断した。

## Decision

- **ベッド儀式を削除**。入口は「捨てる」文法に一本化し、2系統とする：
  1. **異物（発見型）**——「世界に捨てられた地形」（制作過程で没になった地形の残滓が現実に流れ着いたもの）として再解釈し、テーマと統一
  2. **ゴミ箱（定常往復路）**——初回転移はガラクタを捨て続けると国から**返礼として届く「デカいゴミ箱」のレシピ＋案内人の手紙**（「あんたが入れる箱の作り方」）を経由。レシピ解放がシステム解除でなく物語イベントになる
- ベッド儀式が担っていた儀式性は「**自分でデカいゴミ箱に入る**」が代替する（より主題的に強い：自分を捨てる＝自ら届ける）。

## Alternatives Considered

- **ベッド儀式の温存**：却下。「眠る」は捨てる文法に含まれず、棄てられた世界への架け橋として機能しない。ユーザーの世界観指摘と整合しない
- **異物の削除**：却下。発見型の一期一会入口は残す価値がある。「世界に捨てられた地形」への再解釈で文法と統一できた
- **図鑑によるレシピ解放**（従来案）：却下。システム解放に留まり物語性がない。返礼レシピ＝招待状にすることで「誰かが返事をくれた」という体験になる

## Consequences

- 全入口が「捨てる／流れ着く」に統一され、世界観の一貫性が向上
- 初回転移が「招待状」になることで、序盤の物語体験（誰かがいる・届いていた）が強化される
- ベッド儀式の「手元に残るもの」限定荷物ルールは廃止。持ち込みルールはデカいゴミ箱（全持ち込み可）に一本化
