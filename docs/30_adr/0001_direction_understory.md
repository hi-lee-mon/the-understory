# ADR-0001: 方向性「The Understory（棄てられたものの国）」の採用

- Status: Accepted
- Date: 2025-XX（ユーザー承認済み）
- Deciders: 65banseki + Devin
- Related: docs/03_concept_directions.md, docs/04_direction_decision.md, docs/11_world_bible.md

## Context
「第2の黄昏の森」を目指す大型次元MODの世界観を決める必要があった。初回4案（物語国・遊園地・夢境・時間都市）を提示したが、ユーザーの求める「まだ世界にない」独自性と配信映えを再検証するため、anomaly/バグホラーMODの潮流（The Man From The Fog 約2200万DL、The Broken Script等）と各案の既存MOD占有率を再調査した。

## Decision
案E「棄てられたものの国」を採用（公式タイトル：The Understory）。
- 「選ばれなかったもの・消されたもの・読まれなかった物語」が実在する次元
- 各章＝一つの棄てられた物語。結末を書き換える/見届ける/拾うのマルチエンド
- 入口：異物チャンク（バグ入口案の実装化）＋ベッド儀式（ユーザー案の実装化）
- オーバーワールド↔国の双方向往来（ユーザー提案を採用）
- 同行マスコット「ノミ」、拠点「拾い人の村」、クラフト「拾得鍛錬」

## Alternatives Considered
- 案A「忘れられた物語の国」：当初推奨だったが案Eの上位互換的要素となりEに統合
- 案C「夢境」：先行MOD（Good Night's Sleep等）で構造が占有済み
- 案D「時間都市」：先行MOD（ChronoDawn等）で占有済み＋実装最高難度
- 案B「真夜中の遊園地」：世界観の深みがEより弱い

## Consequences
- anomaly系バイラル言語とストーリー重厚さの両立が可能になる
- 双方向往来は黄昏の森の一方通行を超える差別化だが、両世界の状態同期・持ち込みルールの設計複雑度が上がる（13/14でルール化済み）
- 落慮王の「都市伝説的没案」はMH2G裏世界的な「知ってるものが実在する」感を狙える
- 章＝エピソード構造は配信設計（17）の基盤
