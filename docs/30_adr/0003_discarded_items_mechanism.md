# ADR-0003: 「あなたが捨てたもの」機構 — クラフト可能な「ゴミ箱」を主機構とする

- Status: Accepted
- Date: 2026-09-25
- Deciders: 65banseki + Devin
- Related: docs/11_world_bible.md §4入口C、docs/09 §6、Issue #18・#32

## Context
本作の署名メカニクス「あなたが捨てたものが国にいる」の実装方式が2系統に分裂していた（レビューB1、Issue #18）：
- 明示供え型（ベッド儀式で宣言）：実装容易だが「自分で用意した物」は驚きが弱い
- 暗黙検出型（ドロップ/未使用を自動記憶）：驚きは最大だが誤検出・他MOD互換・実装負荷の問題が大きい

## Decision
**クラフト可能な「ゴミ箱」を主機構とする**（ユーザー提案2026-09-25）。ゴミ箱に入れた物は消えず国に届く。棄てる行為そのものが国への回線となる。「自分を棄てる」で転移手段にもなりうる。

加えて「捨てる文法」（何を/どこで/誰を/再帰で捨てるかでイベントが変わる）を設計対象とする（詳細は Issue #32）。

## Alternatives Considered
- **A: 明示供え型のみ**：驚きが弱く、「供えた物」は自己演出化する
- **B: 暗黙検出型のみ**：誤検出・ストレージ系MODとの相性・マルチで全員のドロップを区別する負荷により不採用
- **C: ハイブリッド（供え＋範囲限定トラッキング）**：ゴミ箱方式に含めて再編（場所限定ドロップ検出は「どこで捨てるか」文法の一種として扱う）

## Consequences
- 良い面：棄てる行為とテーマが物理的に一致。クラフト可能＝ユーザーの「クラフトの楽しさ」方針に合致。マルチで所有者紐付けにより個別化が自然。QoLゴミ箱として実用的でありつつ物語装置でもある
- 悪い面/制約：ゴミ箱のレシピ・転移・返礼経路の仕様が必要（Issue #32）。QoL消去目的の使用とテーマ演出のバランスを設計で詰める。ゴミ箱を国に届く物の唯一の正式経路とするか、他経路と併存させるかは仕様詳細で決める
- 実装上の前提：アイテム投入の検出は「ゴミ箱への投入」のみに限定され、全量トラッキングは不要
