# ADR-0004: ストーリー状態モデル — 物語/村はワールド共有、個人差分はプレイヤー個別（ハイブリッド）

- Status: Accepted
- Date: 2026-09-25
- Deciders: 65banseki + Devin
- Related: docs/12_story_outline.md、docs/17 §5、Issue #19、ADR-0003

## Context
結末選択・没腐の浄化・拾い人の村の発展・「誰の物語か」を、ワールド共有状態とプレイヤー個別状態のどちらで持つか未決だった（レビューB2、Issue #19）。マルチプレイ・セーブ設計・全章仕様の前提条件。

## Decision
**ハイブリッド**：
- **共有層（ワールド）**：章の結末・没腐の浄化・拾い人の村の発展・「書き換えた/見届けた」の記録。マルチで1つの歴史を刻む＝群像劇の蓄積（docs/08の視聴者設計と整合）。結末の選択者は「◯◯が綴じた」として記録・表示する
- **個別層（プレイヤー）**：「あなたが捨てたもの」の表示（ゴミ箱の所有者紐付け＝ADR-0003と連動）、拾得図鑑の個人収集、個人の初回リアクション演出。共有世界の中で「私にだけ見える物」だけを個別化し実装負荷を限定

## Alternatives Considered
- **A: 全てワールド共有**：「誰の結末か」問題が残り、「あなたが捨てたもの」の個別化ができない
- **B: 全てプレイヤー個別**：全員が別世界を見る設計は群像劇・共有村・協力構造と衝突し、表示分岐の実装も重い

## Consequences
- 良い面：共有世界で群像劇が成立しつつ、個人の「捨てたもの」体験が保たれる。セーブ設計は共有層=ワールドデータ、個別層=プレイヤーデータで分離でき単純
- 悪い面/制約：結末の決裁ルール（先着か多数決か）・「誰が綴じたか」の表示範囲・後発加入者の追いつき方は未決の細目として Issue #16（システム仕様）で詰める
