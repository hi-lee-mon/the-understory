# ADR-0006: 次元生成方式 — 国＝1つのカスタムディメンション＋ワールド固定レイアウト（環礁＝骨格コード＋肌ノイズ、異物＝3区分ハイブリッド）

- Status: Proposed
- Date: 2026-10-25
- Deciders: 65banseki + Devin
- Related: ADR-0002（技術基盤・データ駆動ワールドジェン方針）、ADR-0004（共有/個別層モデル——上位決定）、ADR-0005（入口「捨てる」一本化——異物の定義）、ADR-0007（セーブ・状態同期——個別層生成の永続化側）、ADR-0008（マルチプレイ——可視性モデル・配信）、ADR-0009（パフォーマンス方針——暫定閾値・フォールバック構造）、docs/40 §4.2/§4.8/§4.9、docs/57 §2（H-01/02/07/08/11/14）・§4（H-06/12/15）・§8、docs/16 §2.4/§3.1/§3.2/§3.5/§3.7/§6.4、docs/32 §2.2/§4.1-4.3、docs/11 §4、docs/13 §2

## Context

「国」の次元地形をどう生成するかは、Phase 0 後半まで正典未決のまま残っていた最大の方式選択だった。docs/40 §4.2 は「国＝1つのカスタムディメンション（環礁間の海・淀み空間を含む次元地形、環礁間接続＝浜→林の徒歩接続）」を確定しつつ、環礁本体の生成方式自体は「正典未決——複数案の比較検証」として Issue #13 へ手渡していた（docs/40 §9）。docs/16 §2.4 の確定4型（①固定テンプレ②jigsaw モジュラー③地形依存埋没④手組み領域）は構造物の生成方式の語彙であり、環礁本体は同 §2.4 語彙規約③により一覧表の独立行に立たない別層——つまり地形側の方式は語彙の外にあり、別途の決定記録が必要だった。

方式選定を縛る要件は3点あった。(a) 場所系列はクリティカルパスとして脚本化され（docs/34 各章 §3）、序破急の時間配分（48/03 §4.2）・月中継点の方位基盤（45/01 §3.3）・見晴らしの岬からの環礁群一望（docs/16 §3.2 詳細カード⑤・§3.8）がすべて固定地理を前提にする——プロシージャルな島配置では脚本どおりの劇を上演できない。(b) 異物チャンクは**現実側（オーバーワールド）に生成される別層**（docs/16 §3.1 一覧表「現実側」・§3.7-7「現実側の残滓」・docs/32 §4.2「現実側の異物」——国次元の環礁生成とは独立の生成系、57-H-02 依存・前提）であり、「ワールドあたり数箇所＋全プレイヤーに1つはスポーン圏内に生成保証＋棄てが極まった場所に追加生成」の3区分要件（docs/32 §4.1・J5 承認）を持つ——これは worldgen の時間軸（ワールド生成時・共有）と個別層モデル（発見者のみ視認——ADR-0004）の両方に跨る。(c) ADR-0002 のデータ駆動ワールドジェン方針（構造物・バイオーム・肌＝JSON、章量産＝データ追加）と脚本地理の完全固定を両立させる実現形が必要だった。

Issue #13 の要承認一括承認（2026-10-03・28件全件推奨案どおり採用）で方式が確定した。本 ADR はその承認済み決定を「なぜそう決めたか」の記録として束ねる。

## Decision

**国の次元生成は「1つのカスタムディメンション上のワールド固定レイアウト」とする。**骨格（場所の並び・距離・見通し）はコードがチャンク座標から決定論的に固定し、地形の肌のみシード依存ノイズとする——黄昏の森型「構造はアンカー配置、地表はノイズ」。本 ADR はこの次元生成決定に連なる**2系統の生成方式**を束ねる：**国次元側＝環礁本体の生成（案C ハイブリッド）**と、**現実側（オーバーワールド）＝異物チャンクの生成（案C ハイブリッド3区分）**——両者は別次元・別層の生成系であり（57-H-02 依存・前提「環礁本体（国側）の生成方式とは別層（異物は現実側）」・docs/16 §3.1/§3.7-7・docs/32 §4.2）、異物は国のカスタムディメンション内には生成しない。

1. **国＝1つのカスタムディメンション**（docs/40 §4.2 確定）。環礁群とそれを隔てる海・淀み空間を含む単一の次元地形とし、環礁間接続＝浜→林の土手・橋めいた流れ（徒歩で辿り着ける）を次元地形の一部として生成する。領域別の場所系列はアンカー固定（漂着浜＝埋没型環礁全体を1構造群、月の林＝CP6＋寄り道3、村＝浜の奥の拠点区画、月下の小島＝沖ゾーン限定の探索型配置、自分の捨て場＝個別層の動的生成、未訪問環礁＝遠望表現のみ）。

2. **環礁アンカー・場所系列の配置＝ワールド固定**（40-Q24 承認・2026-10-03——docs/40 §4.2・docs/16 §2.4）。主線骨格（場所の並び・距離・見通し）は固定レイアウトで生成し、地形の肌のみシード依存ノイズとする。**「ワールド固定が立った」とは**：複数シードで環礁アンカー・場所系列のレイアウト（座標・距離・見通し）が一致し、場所間距離が正典目安内（01＝場所間 30〜60B・総歩距 150〜250m——docs/13 §2・16-U2-Q04）に収まること。

3. **環礁本体の生成方式＝案C ハイブリッド（骨格コード＋肌ノイズ——TF 型）**（57-U1-Q1 承認・2026-10-03）。環礁アンカー配置関数（チャンク座標→アンカー座標の決定論写像）で場所系列の骨格をワールド固定し、島体骨格（島の輪郭・海溝・見通し軸）はコード/座標依存レイヤーで生成し、肌（地表の質感・小起伏・堆積模様）は noise_settings の surface_rule/noise で生成する。場所系列アンカーは同じ関数が返す固定座標＝構造物生成（H-11 系）の着点。**「案C が立った」とは**：骨格（アンカー・島体輪郭）がシード非依存で一致しつつ肌がシードごとに変わり、同一シードで同一地形が再現されること。不成立時は案A（ノイズ・バイオーム主導）へ縮退（Consequences）。

4. **異物チャンクの生成トリガ＝案C ハイブリッド3区分**（57-U1-Q2 承認・2026-10-03——docs/32 §4.1・docs/16 §3.7）。**異物チャンクは現実側（オーバーワールド）に生成する別層であり、国次元の環礁生成とは独立の生成系である**（57-H-02 依存・前提「環礁本体（国側）の生成方式とは別層（異物は現実側）」・docs/16 §3.1 一覧表「現実側（スポーン圏内1箇所保証＋棄てが極まった場所）」・§3.7-7「現実側の残滓」・docs/32 §4.2「現実側の異物」）。①worldgen 共有希少配置（現実側ワールド生成時の希少配置——「世界に捨てられた地形」として複数箇所）＋②個別層のスポーン圏内1箇所保証（プレイヤーごとの発見保証を個別層で担保）＋③棄てが極まった場所への追加生成（後者2つはトリガ式コード生成＝ゴミ箱投棄量・場所の追跡→閾値到達で生成）。可視性モデル（H-06——ADR-0008 所掌）が「発見者のみ視認」以外に決定した場合は案A（全共有＋初接触消滅）へ退避する。

5. **構造物との接続＝docs/16 §2.4 の4型語彙**（docs/49 §2.3 準拠）。環礁本体は一覧表の独立行に立たない別層（語彙規約③）であり、構造物には4型（①固定テンプレ②jigsaw モジュラー③地形依存埋没④手組み領域——複合は「＋」併記、可変部のみモジュラー化のハイブリッドを標準形）を明記する。**異物チャンク＝③地形依存埋没＋①固定テンプレ（欠損部品＝異質パーツプール）＋個別層生成**（docs/16 §3.7-9）。埋立て地＝③地形依存埋没＋①固定テンプレ（docs/16 §6.4.1）、L3 ごみ処理場＝④手組み領域（worldgen 対象外——docs/16 §6.4.2）。連動構造＝灯台−座礁船は**単一アンカーからの連動生成**（57-U1-Q3 承認・16-U2-Q09——灯台アンカー起点に座礁船をオフセット・方向付き生成し、「灯台から座礁船が見える構図」を構造側で保証。環礁アンカー機構と同系の技術経路）。

6. **データ駆動方針との関係**（ADR-0002）：骨格＝決定論関数（コード）・構造物・バイオーム・肌＝JSON と分割し、「章を足す＝アンカー座標＋構造定義を足す」で量産性を維持する。

## Alternatives Considered

- **案A：ノイズ・バイオーム主導**（docs/57 §2 H-07）：density function 群＋カスタム BiomeSource（MultiNoise または決定論配置）で環礁別バイオームを固定座標に配置する宣言型。データ駆動で章量産が容易だが（ADR-0002 方針と一致）、「この座標にこの環礁」の完全固定には別途決定論 BiomeSource が要り、density function で島の輪郭・距離・見通しの脚本一致を保証するのは困難（記述限界が高い）。→ **主案としては不採用**。ただし案C 不成立時の縮退経路（density function 近似＋アンカー固定構造物の増量）として保持（57-U1-Q1）。
- **案B：構造物主導（環礁全体＝地形を含むを巨大構造物/自前 Feature として設置）**（docs/57 §2 H-07）：環礁全体（地形を含む）を巨大構造物/自前 Feature としてアンカー座標に設置する方式。完全な脚本一致は得られるが、地形が「構造物」化して自然な起伏・鉱石・堆積深度・ノイズ肌が出にくい。テンプレの大きさ上限（nbt/構造サイズ）と生成コスト、修正は構造テンプレ再編集で試行コスト大。「シード依存の肌」を出すには別レイヤのノイズ造形が要となり結局ハイブリッド化する。→ **却下**（地形品質・保守性で不利）。
- **プロシージャル島配置**（40-Q24 の対極）：場所系列をノイズ配置に委ねる方式。場所系列の脚本化・序破急の時間配分・月中継点の方位基盤・見晴らしの岬からの環礁群一望がすべて固定地理を前提とするため、脚本どおりの劇を上演できない。→ **却下**（docs/40 §4.2 の確定理由どおり）。
- **異物・案A：全共有配置**（docs/57 §2 H-02）：全て worldgen（structure_set spread salt 固定等）でワールド生成時に配置し、個別化は視認側に全委譲。生成は決定的・単純だが、「全プレイヤーに1つは必ず近場」の保証が worldgen 時間軸と食い違い（join ごとの既存チャンクへの後付けが必要になり得る）、個別層生成の正典（発見者のみ視認・実体は個別）とも不整合——同一地点に複数者が「自分の異物」を持つ設計が困難。→ **主案としては不採用**。ただし可視性モデルが「発見者のみ視認」以外に決まった場合の退避先（全共有＋初接触消滅）として保持（57-U1-Q2・条件付き項＝Consequences）。
- **異物・案B：全個別動的生成**（docs/57 §2 H-02）：join/探索時にプレイヤー毎の圏内・棄て場所へコード生成。個別層正典と完全整合し位置は柔軟だが、「ワールドあたり数箇所」の自然発生——共有の希少地形として「世界が捨てた地形」の物語層——を個別層だけで見せる設計に弱い。→ **却下**（物語層の担保が弱い）。

## Consequences

**良い面**：

- 脚本地理（場所の並び・距離・見通し・月中継点の方位・岬からの遠望構図）をコードで保証しつつ、地形は自然なノイズ肌——40-Q24 の要件形に最も忠実（TF 型の直写）。
- 「構造はアンカー配置、地表はノイズ」の実装先例（黄昏の森）が 1.21.1 NeoForge に実在し参照可能（docs/56 §1.1-1.2・docs/21 §2）。
- 「章を足す＝アンカー座標を足す」でデータ駆動の量産性を維持（骨格＝コード/関数、構造物・バイオーム・肌＝JSON——ADR-0002 方針と整合）。
- 異物の3区分が、共有の希少地形としての物語層（世界自体が捨てた地形が現実に点在——docs/11 §4）と個別層の発見保証（見つける行為自体が報酬の発見型入口——docs/16 §3.7）を分離して担保できる。

**悪い面**：

- 自前ジェネレータ層・配置レイヤー（noise ジェネレータへの座標依存レイヤー注入）は未確認箇所であり、性能も未知数（57-H-07 実現性評価＝中）。
- 既存チャンクへの後付け生成（②個別層の圏内保証・③棄て極まり追加）はバニラ非対応の on-demand 設置で、安定経路が未確認（57-H-02 実現性評価＝中）。
- 異物の生成形は可視性モデル（H-06——ADR-0008 所掌の案選択）に連動するため、生成側と可視性側の同時設計が必須（57-U1-Q2 の条件連鎖）。

**今後の制約**：

- **縮退経路**：案C 不成立（性能・実装複雑性）→案A（density function 近似＋アンカー固定構造物の増量）を設計代替として保持（57-H-07・42 §2.1 R-03——閾値超過は 57 側で事前生成限定・環礁規模縮小等を判定し Issue #13 コメント/ADR＋docs/40 §4.8・T-1/T-6 へ書き戻す）。異物側は可視性モデルが「発見者のみ視認」以外に決定した場合に案A（全共有＋初接触消滅）へ退避（57-U1-Q2）。
- **条件付き発動項（57-U2-Q11）**：H-06 で案C（初接触消滅）または生成側案A退避を採用した場合のみ、16-U1-Q14「使用後も残存・再入可能」→「初接触で消滅」の正典改訂が発動する（H-02 合格ライン・H-12 T-U2-04d は「個別層前提」の条件付き基準へ切替＋「消え方が曖昧の演出形」の仕様確定を併せて行う）。書き戻し先4箇所（docs/16 §3.7・docs/32 §4.1・docs/11 §4・docs/00 §3.1①）は**一括反映のみ許可**（部分反映＝42 R-17 発火）。案A/B（発見者のみ視認）採用時は発動しない——確定扱いしない（G-ADR-06）。
- **Phase 1 スパイクへの合格条件**：H-01（統合サーバーで次元が登録され生成エラーゼロ・「カスタム次元1バイオーム」成立・dimension_type 環境フィールド確認——先行ゲート）・H-02（複数シードでスポーン圏内1箇所の生成保証・棄て閾値トリガの発火・型バリエーションプール・埋没感——可視性モデルと一体の先行ゲート）・H-07（複数シードでレイアウト一致＋肌のみ変動＋同一シード同一地形＋浜→林の徒歩接続＋見晴らしの岬からの遠望構図——S1 並行）・H-08（暫定閾値の実測着地）・H-11（jigsaw の意図どおりの組み上がり＋増築経路）・H-14（単一アンカーから2構造の連動生成＋灯室→檣の line-of-sight 担保）。
- **暫定値（着地先明記）**：環礁生成の暫定閾値＝ms/chunk p95 ≤ 50ms・生成中 MSPT ≤ 50ms（20 TPS 維持）・初回転移時生成 burst 合計 ≤ 10 秒（57-U1-Q4——**仮置き値**。実測で docs/40 §4.8・§5.2.2 T-1/T-6・40-Q7⑧ へ着地。着地規則＝41-U4-Q3：実測が暫定値を満たせば暫定値を確定値として記録、値の変更はユーザー承認）。「棄てが極まった場所」の検出閾値・圏内距離の実装値＝暫定（H-02 で試行し docs/32 §4.1・docs/40 §5.2.1 E-9・Issue #13 へ着地）。L3 近接範囲の絶対値＝暫定（57-U2-Q8——判定方式＝投入口核の近接認定は確定済み、絶対値は Phase 1 スパイク2案プロト→計測→Issue #15 へ着地）。異物経由の持ち込み減損率＝暫定（57-U2-Q2——内訳＝装備欄・バインド呪い装備・既登録拾得物は必ず届く、不安定対象＝消費・素材系の非装備持ち物、届かない品は現実側異物内に由来保持で残置・再訪で回収可。減損率の絶対値は PoC 計測後 Issue #15 へ着地）。
- **個別層生成の永続化前提**：異物（発見者判定）・自分の区画（集約漂着統計からの決定論的生成——57-U2-Q6：同じ統計なら同じ区画、再生成・ログ照合可能）・自分の捨て場（②jigsaw 増築＋没腐度歪み processor）は、発見者集合・統計・所有者紐付けの保存を前提とし、永続化構造は ADR-0007（セーブ・状態同期）に接続する。個別層の縮退経路（表示のみ個別化・実体共有）は ADR-0007 所掌——データ分離自体が不能なら ADR-0004 再設計＝正典改訂の要承認へエスカレートする（57 §4 H-15・42 R-05）。
- **可視性モデルと配信の分掌**：「発見者のみ視認」の実現経路（パケット偽装/エンティティ化/初接触消滅——Phase 1 スパイク T-U2-03a〜c で確定）と個別層の見え方差分・同期は ADR-0008（マルチプレイ）に接続する。本 ADR は生成側（どう・どこに・いつ作るか）のみを決める。
- **上位決定との整合（G-ADR-03）**：ADR-0004 の個別層2系統（アイテム/表示＝実体共有・表示のみ個別化／生成物＝個別層生成）に従う。環境一次導線（定点・勾配・ランドマーク）は共有層で全員同一の見え方（45/04 M-1）——異物は発見者のみに視認する個別層の入口として共有導線規則の例外（見つけられない他プレイヤーはゴミ箱経路で同一の国へ到達する）。
- **生成戦略**：スライス区画（浜区画〔村を含む〕＋月の林環礁＋月下の小島）＋遠望シルエット群はワールド作成時または初回転移時に生成し、場所系列内の遅延生成は小規模構造物に限定（docs/40 §4.8——プレイ中の tick スパイクを防ぐ。測定系は ADR-0009 の T-1/T-6 と一体）。
- **所掌外の注記**：灼熱の埋立て地（③地形依存埋没＋①固定テンプレ——docs/16 §6.4.1）と L3 ごみ処理場（④手組み領域＝worldgen 対象外、プレイヤーが現地に組む構造——docs/16 §6.4.2）は本 ADR の次元生成方式の直接所掌外だが、同じ4型語彙の枠内で接続する。構造物のサイズ・jigsaw depth 等の実数値は Issue #15（数値全表）の責務。
