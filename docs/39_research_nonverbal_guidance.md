# 39_調査基準：非言語の導線・環境ストーリーテリング（Issue #31）

> **目的**：Issue #31「非言語の導線・環境ストーリーテリング」の制作・レビュー・改訂に使う**共通の物差し**。先行研究の方法論・正典からの制約・成果物の組版テンプレ・レビュー基準・棚卸し項目をここに集約する。制作エージェントとレビューエージェントは全員この物差しで判定する。
> **前提**：ユーザー指針「文字ベースになりすぎるのも避けたい。マイクラは全年齢で、中学生以上が楽しめるように。エルデンリングの篝火の光のようにUI/UXへの配慮がある」。層構造＝表層（読まなくても遊べる）/深読み層（読む人ほど重厚）、目的は「平易」でなく「楽しい」（docs/09 §6・docs/26 §1）。

## 2. 先行研究：非言語でプレイヤーを導く方法

### 2.1 光による指し示し——Elden Ring「祝福の導き」

- **仕組み**：各「祝福」（休憩点）から金色の淡い光の帯が、次に向かうべき大まかな方角へ流れる。地図断片を拾うと同じ筋がマップ上にも描かれる。
- **設計上の効き方**：視界端のかすかな光は**主張しすぎない**——プレイヤーは気づいた時だけ従う。指し先は正確な目的地でなく「方向の示唆」であり、到達までの自由度を残す。
- **学術的裏付け**：オープンワールドの光誘導を比較した研究（Elden Ring vs Witcher 3）では、両作の光の使い方に共通項がほぼなく、**「その世界に合った正しい一つの方法は存在しない」**と結論づけられた。重要なのは特定の技法ではなく、世界観と一体となった一貫性。
- **本作への示唆**：「没腐の歪みが濃い方角へ向かう朧な光」（docs/09 §6）はこの系譜。光は**意図の密度を方向で示す装置**として規格化できる。

### 2.2 地形が導く——Zelda: Breath of the Wild「引力・三角・見せ方」

任天堂のCEDEC講演と分析研究で形式化された3技法：

1. **引力（Gravity）**：移動は「下る方が速く楽」。重要地点を**窪地・谷に置き**、プレイヤーが自然に降りてたどり着く地形を作る。目立つ塔（ランドマーク）で「あそこへ行きたい」を起こさせ、降りた先で別の目標が見えるよう**遮蔽と開示を繰り返す**。
2. **三角のルール**：地形の主要な形を三角形に揃える。「上るか・回るか」の二者択一を常に提示し、どちらを選んでも裏側に発見が待つ。**視線の遮蔽物を目的物の直前に置く**ことで「隠して→見せる」の気持ちよさを量産した。
3. **見える化の否定**：タワーは「登ると全部見える」案を**却下**——透けすぎた導線は探索の喜びを殺す。チラ見せ（一部だけ見せる）で自発的な接近を誘う。

- **本作への示唆**：環礁（島）構造は BotW の「目標を掲げ→地形で誘導」と相性が良い。各環礁は「章の中心」を遠望できる一点を序盤に用意し、以降は遮蔽と勾配で誘導する。

### 2.3 暗黙の道しるべ——Half-Life 2（Valve）の技術集

Valveの定番技法（「鳥はただの鳥ではない」）：

- **動きで目を引く**：プレイヤーが近づくと鳥の群れが注目対象の方へ飛び立つ。突然の動きは視線を強く引き、飛行方向が「あそこを見ろ」になる。
- **補給物を道標にする**：弾薬箱に黄色い印→プレイヤーが自発的に箱を追う。先を示す補給は「パンくず導線」として機能し、**拾うと消えるため自然に一方向**を示す。
- **対比で語る**：暗い通路の果ての光源・静寂の先の物音——人は差分へ視線を向ける。光の果て・音の果てを「調べたい場所」にする。
- **本作への示唆**：Minecraft の語彙に翻訳できる——拾得物の微かな色・音（拾うと消える＝一方向）、歪みの濃度勾配（差分）、漂着物の流れ着く方向。

### 2.4 常に見える目標——Journey の山

- **仕組み**：ゲーム開始直後から、地平線の遠くに光を放つ山が常に見える。**「あそこへ行く」が説明なしに共有**される。
- **対比の色規則**：砂のベージュ世界に対し、相互作用可能な布生物は赤、案内の光は白〜黄。**「触れられるものは色が違う」**一貫則で操作語彙を非言語化。
- **本作への示唆**：各環礁には「章の中心」（待ち続けた者の場所）を遠望できる大ランドマークを置き、世界の共通光源としての役割を与える。ボス・結末の「向かうべき一点」は原則として視界内に存在させる。

### 2.5 風と他者——Ghost of Tsushima / マルチの暗示

- **風の案内**：風そのものが方向を指す（葉・草・煙の流れ）。UIなしに常時利用可能なソフトな導線——**環境の一部が案内役**になる。
- **目を凝らす行動**：A Short Hike と Elden Ring の観察では、プレイヤーは「地形の手がかり・巨大なランドマーク・活動の密度」で自然に認知地図を作る。**暗黙の道しるべは地形・ランドマーク・活動配置の三位一体**で成立する（Implicit Wayshowing 研究）。
- **本作への示唆**：ノミ（常時同行・語り装置）の「あっち、なんか淀んでるよ」+「淀みの指し示し」はこの系譜。環境が発する方向情報（漂着物の流れ・霧の淀み・音のする方）を一次、ノミの語りは二次の補助とする。

### 2.6 環境が語る——環境ストーリーテリングの技法（Matthias Worch / GDC）

Worch「What Happened Here」（GDC）の定義：**「環境の属性を配置し、意味ある全体として解釈できるように演出することで物語を進める」**。

- **因果の連鎖を見せる**：「誰かが書いた→誰かが応えた」等、痕跡を因果順に読ませる配置（L4Dの壁文字応酬）。
- **解釈はプレイヤーに開く**：BioShockの石膏ヴィネットの例——作者の意図と違う読みも正当。**正解を断定しない配置**が没入を生む。
- **残滓の匂い**：拾得物は「その物がどう愛され/捨てられたか」の一齣を配置だけで語る（本作のフレーバーテキスト＝docs/26 §3.2 の非言語版）。
- **密度勾配**：痕跡は「待っていた場所」へ向かうほど濃くなる（docs/26 §6 の配置規範と一致）。

### 2.7 多重化と配慮——アクセシビリティ研究（XAG 103/106 等）

- **重要情報は複数感覚で**：Xbox Accessibility Guidelines XAG 103——発砲音・ダメージ・相互作用物は**視覚と聴覚の両方で**伝える。一方だけに依存すると、色覚特性や難聴、あるいは「うるさい部屋でプレイ」だけの状況でも情報が届かない。
- **色のみに頼らない**：色覚特性は色の明度・色相の識別に影響する。**色＋形＋音＋位置の少なくとも2系統**で重要情報を運ぶ（色だけでの差別化は非推奨）。
- **画面読み上げ・音の視覚化**：XAG 106——視覚情報は音声でも表現可能に。Minecraft には既に字幕（サウンドの字幕）機構があり、本作の独自SEは字幕に表示される名前を持つ設計が可能。
- **本作への示唆**：「多重化規則」を導線文法の第一級ルールにする——クリティカルな導線（次に行く方向・危険・結末可能地点）は**常に≥2チャネル**（例：光＋音、色＋形）で送る。

### 2.8 Minecraft バニラの語彙（本作が使える非言語の道具）

バニラ資産での実現方法（実装はPhase 1以降、設計の語彙として定義）：

| 媒体 | バニラの器 | 本作での役割例 |
|---|---|---|
| 光 | 光源ブロック（ランタン・グロウ地衣・シュルームライト・海のランタン）・天空光・バイオーム霧・光源の減衰勾配 | 方向の示唆・重要度の濃淡・危険の霞 |
| 色彩 | ブロックパレット・草/葉/水のバイオーム着色・粒子色・空の色（次元エフェクト） | 環礁の主題色・没腐の色褪せ・拾得物の朱 |
| 音 | 音符ブロック・環境音・モブ音・風/水/火の環境SE・字幕システム | 接近度・存在の気配・「あっちの音」 |
| 造形 | 構造物・地形・ブロック配置・残骸・損傷表現（崩れた・錆びた・苔むした） | 「ここで何かがあった」の物語 |
| 粒子 | パーティクル（ポータル・魂炎・桜・水の泡・煙） | 拾える物の気配・没腐の滲み・転移の前兆 |
| 動き | 落下砂・ピストン・水流・レール・風に揺れる物（提灯・旗） | 目を引く差分・「生きている」感 |
| 文字以外の記号 | 看板（絵・模様）・地図・バナー・構造物の形そのもの | 道標・警告・領域の区切り |
| ランドマーク | 高い構造物・独特な地形・発光物・特異な巨木 | 遠望可能な目標・認知地図の起点 |
| 案内装置 | 羅針盤（縁の羅針盤）・地図・ノミの語り | 二次導線（環境が一次） |

## 3. 正典制約 G1〜G16（違反＝blocker）

| # | 制約 | 出典 |
|---|---|---|
| G1 | **層構造**：表層＝読まなくても遊べる／深読み層＝読むほど重厚。「平易さのために深さを削らない」。目的は「楽しい」 | docs/09 §6 |
| G2 | **環境が先、文字が後**：進行必須情報は文字に置かない。環境が「何かがあった」を先に示し、文字は「何だったか」を確かめる層 | docs/26 §1・§7 |
| G3 | **UIはスキン的変更のみ・操作体系を変えない**：導線は世界・演出側で作り、本編UI構造・操作はマイクラ規範を尊重 | docs/09 §6 |
| G4 | **第2〜4章は順不同**：非言語導線はどの順で攻略しても成立し、他章の攻略前提を置かない | docs/13 §1 |
| G5 | **審美は「かすれた・欠けた・継がれた」**：基調＝灰青・月白・墨・古金。アクセント＝拾得の朱・灯りの琥珀。章ごとのサブパレット | docs/20 §1・§2・§5 |
| G6 | **シェーダー/影MOD共存**：Iris＋主要シェーダーと崩れない設計。光・色演出はシェーダーON/OFF両対応 | docs/20 §4 |
| G7 | **救うと色が戻る**：章を救うとその土地が少し色を取り戻す——進行の可視化として既に採用済み | docs/20 §1 |
| G8 | **没腐コンパス＝歪みの方向を示す案内**（ノミ連動）。導線装置はこれと縁の羅針盤が既存 | docs/20 §6・docs/14 |
| G9 | **縁の羅針盤＝現実側で縁の地・異物を指す**。入手＝序盤・最初の縁の地探索時。港風セットで没腐遺留物も指す | docs/14 §3・docs/32 §4 |
| G10 | **異物＝世界に捨てられた地形**（片道・発見型入口）。周囲は没腐が濃い。「無謀な近道」として機能 | docs/32 §4・ADR-0005 |
| G11 | **ボスは読み合い可能**：全攻撃に分かりやすい予備動作＝フェアな難しさ（死に学習）。フェーズ制で演出変化 | docs/15 |
| G12 | **撃破＝理解と救済**：ボスは「待ち続けた者の没腐した姿」。撃破は殺害でなく静まり・解放であること | docs/12・docs/34 |
| G13 | **ノミ＝常時同行の演出NPC・語り装置**（敵ではない・HPなし・戦闘不参加）。導線の語りは二次補助 | docs/15・docs/25 |
| G14 | **演出は配信映えを意識**：章＝エピソード・切り抜き瞬間・予告頁・幕間（暗転）の語彙を使う | docs/09・docs/17 |
| G15 | **用語は正典どおり**：拾い人/ノミ/拾得物/没腐/落慮王/縁の地/淀み/漂着浜/読む者/原案の座 等を誤用しない | docs/11 他 |
| G16 | **正典の変更は直接書き換えず「要ユーザー承認」**：新規ランドマーク・新ブロック・世界法則の追加などは要承認として一覧化 | AGENTS.md |

## 4. 設計原則 P-01〜P-12（調査から蒸留した物差し）

| # | 原則 | 内容 | 根拠 |
|---|---|---|---|
| P-01 | **導線は世界と一体で** | 正しい一技法はなく、世界観と一体の手法のみが効く。全導線は「棄てられたものの国」の審美内で設計 | §2.1 |
| P-02 | **ランドマーク常見性** | 各環礁に「章の中心」の大ランドマークを遠望可能に。目標を失わせない | §2.4・§2.5 |
| P-03 | **遮蔽と開示** | 直前まで隠して見せる気持ちよさ。チラ見せ＞全見せ | §2.2 |
| P-04 | **勾配で語る** | 彩度・光量・痕跡密度・音の大きさを「中心へ向かうほど強く」。勾配自体が方向になる | §2.2・§2.3・§2.6 |
| P-05 | **一方向のパンくず** | 拾う・消える・進んだ先だけに残る手がかりで、戻りを誤導しない一方向導線 | §2.3 |
| P-06 | **差分が目を引く** | 動き・光・音の「変化」は視線を奪う。変化の向きを目的方向に揃える | §2.3 |
| P-07 | **重要情報は≥2チャネル** | クリティカル情報は視覚＋聴覚、色＋形等の多重化で送る。単一感覚依存を禁止 | §2.7 |
| P-08 | **環境が先、文字が後** | 「何かがあった」を配置が先に示す。文字は確かめる層 | §2.6・G2 |
| P-09 | **解釈を開く** | 環境配置は正解を断定しない。読み取りの余地を残す（考察の余白） | §2.6 |
| P-10 | **迷子を防ぐ二重構造** | 一次＝環境（地形・光・痕跡）が導く／二次＝装置（羅針盤・ノミ）が確認する。装置は環境を補うだけ | §2.5 |
| P-11 | **配信で読める導線** | 視聴者が画面から「あっち怪しい」と言える強度に。見落としにくいが押し付けない | §2.5・G14 |
| P-12 | **全年齢の前提行動** | 「説明を読まず、世界を見て動く」を想定。次に何をすればいいかを世界が答える | §2.2・§2.7 |

## 5. 成果物の組版テンプレ（docs/45_nonverbal_guidance/ 4本）

成果物は `docs/45_nonverbal_guidance/` に4ファイル＋README索引。各ファイルの必須節：

### U1：01_system_grammar.md（導線の体系文法）
1. **目的と位置づけ**（層構造での役割・docs/26 との境界）
2. **媒体×役割マトリクス**：行＝媒体（光・色彩・音・造形・粒子・動き・記号・ランドマーク・装置）、列＝役割（方向指し・重要度・危険度・接近度・物語の痕跡・相互作用可能の標識・領域の区切り）。各セルに「使えるバニラの器」と「強度ルール」
3. **強度・距離・優先度の規則**：導線の強さの段階（気配→示唆→明示）、複数導線が競合したときの優先順位
4. **併用規則**：多重化の組み合わせ表（必須ペア／相性の良い組／避ける組）
5. **禁止・非推奨事項**：押し付けすぎ・色のみ依存・文字依存の禁止等
6. **未決・要承認**

### U2：02_guidance_applications.md（場面別適用）
1. **目的と適用範囲**
2. **漂着浜（序章）の導線**：着地点から村・第1章への誘導全工程
3. **各環礁の導線構造**：遠望点→遮蔽→中心への勾配。順不同2〜4章での共通パターン
4. **環礁内の局面**：探索中・迷子時・ボス接近・結末地点・章クリア後の変化（色の回帰）
5. **現実側の導線**：縁の地の発見・異物の視認・ゴミ箱への気づき・往復の往来
6. **村と拠点**：拾い人の村の視認性・帰還地点としての目立たせ方
7. **ボス戦・結末・幕間**：予備動作（見得）の可読性・フェーズ転換・結末地点の示し方
8. **補助環礁**：任意攻略島の見つけ方（本線より弱い気配レベル）
9. **未決・要承認**

### U3：03_environmental_storytelling.md（環境が語る層）
1. **目的と位置づけ**（docs/26 語りベクターとの棲み分け：環境が先・文字が後）
2. **環境の語彙表**：配置パターン（残骸・打痕・書きかけ・整頓/散乱・向き・反復・欠如・保存）が語る意味の辞書
3. **章別適用**：各環礁で「ここで何があったか」を環境だけで示す配置設計（docs/34 章プロットの環境ビートを言語化）
4. **伏線の非言語手がかり**：docs/36 の伏線のうち環境に置くものの配分原則
5. **解釈の開き方**：断定しない配置・複数の読みを許す形
6. **未決・要承認**

### U4：04_affordance_accessibility.md（全年齢・多重化・配慮）
1. **目的と適用範囲**
2. **全年齢アフォーダンス**：「次に何をすればいいか」を説明なしに答える仕組み（行動の見える化・行き先の見える化・目的の見える化）
3. **多重化規則**：重要度ごとの必須チャネル表（最重要＝3系統、主要＝2系統、補助＝1系統可）
4. **色覚・視認性配慮**：色に頼らない標識・形と位置での代替・コントラスト規則
5. **聴覚配慮**：音だけに依存しない設計・字幕・視覚的代替
6. **配慮のコンフィグ化**：Issue #34 への手渡し項目（変更可能にすべき設定の一覧）
7. **未決・要承認**

## 6. レビュー基準（3段分類）

| severity | 定義 | 例 |
|---|---|---|
| **blocker** | 正典制約 G1〜G16 と直接矛盾、または完了条件を満たさない | UI操作体系の変更提案・進行必須情報を文字に置く設計・正典用語の誤用 |
| **major** | 設計原則 P の違反・ユニット間の矛盾・棚卸し項目の未回収・必須節の欠落 | 順不同で破綻する導線・クリティカル情報の単一チャネル化・章間でルールが齟齬 |
| **minor** | 表記揺れ・参照ずれ・説明不足・改善余地 | 用語の揺れ・例の不足・節番号のずれ |

- 「指摘0件で受理」は正当な結果。無理に指摘を作らせない。
- 正典（13/20/50 等）を書き換える提案は「要ユーザー承認」として集約し、本文で直接改変しない。
