# 13_進行表・難度設計（v0.1）

## 1. 進行の全体像（黄昏の森型ゲート＋双方向往来＋半自由な順序）

- **骨格**：各章のボス撃破＋結末選択で次環礁が解放される（メトロイドヴァニア型ゲート）。
- **順序の自由度（Issue #24）**：序→第1章→終章は固定だが、**第2〜4章は同時解放・任意の順で攻略可能**（切なさ/滑稽/恐怖の感情マップはどの順でも隣接章で対比が効く構造）。全部済むと第5章が開く
- **補助環礁・小島**：本線環礁の間に任意攻略の小環礁を散らす（「愛で壊れた」「恐れられた」「笑える没案」等の棄てられた理由の多様化を担う・docs/12 §2.1）。寄り道報酬＝希な拾得物・隠しロア・村の住民候補
- **往来自由**：現実↔国は**異物/ゴミ箱（ADR-0003）でいつでも行き来可能**（ユーザー案採用。ベッド儀式は削除済み）。国での進行は現実の装備・素材に依存し、現実の探索が国の導線（縁の地）にもなる。ゴミ箱経路は**「自分を棄てる」で自分の捨て場へ落ち、捨て場のゴミ箱から現実へ帰還**する往復路（`docs/23_discard_grammar.md` §4-5）。
- **迷子防止**：自由化の前提として光・色彩の非言語導線で誘導（Issue #31）
- **拾い人の村**：章を救うごとに住人・施設が増え、クラフト・情報・イベントが解放される中間地点。

## 2. プレイ時間・難度の想定（配信単位）

| 区画 | 想定時間 | 難度意図 | 配信目安 |
|---|---|---|---|
| 序＋第1章 | 1〜2時間 | 世界の法則・戦闘基礎の体験学習（低床） | 配信1回＝第1章クリア |
| 第2〜3章 | 各2〜3時間 | 章ギミック（水辺/リズム）で学習カーブ | 1章＝1〜2回 |
| 第4〜5章 | 各3〜4時間 | 複合ギミック、装備差が効く帯域 | 攻略配信の見せ場 |
| 終章 | 3〜4時間 | 全要素統合＋物語クライマックス | 感動の最終回 |
| 計 | 約15〜25時間＋図鑑/再戦 | シリーズ5〜8回に分割可能 | シリーズ物として成立 |

## 3. 難度カーブ（フロー維持）

- **「一段強化すれば届く」帯域**を各章に置く。ボスは「今の拾得装備では辛い→素材集め→丁度良い」。
- **死に学習**：ボス攻撃は予備動作が読める設計。死んでも「次こうしよう」が見えるフェアさ。
- **失敗の可視性**：没腐の歪み・ボスのフェーズ変化は視覚で分かる（理不尽な即死なし）。
- **段差**：章間に「拾い人の村で装備を整える」自然な間を作る。

## 4. ゲート方式

- **地理ゲート**：環礁は空中/海上に浮かび、序・1章・5章・終章はクリアで「橋/流れ」が繋がる。2〜4章は同時に開放され順不同
- **意味ゲート**：章の主題（月・手紙・祭り・坑道・歌）が先の章で少しずつ混ざり、終章で収束。
- **現実側ゲート**：現実での「縁の地」発見・拾得素材の保有が国側の進行条件になる場面も作る（行き来の意味づけ）。

## 5. エンドコンテンツ

- **拾得図鑑コンプ**、**結末分岐の周回**（書き換える/見届けるの両ルート）、**ボス再戦（ハード）**、**拾い人の村の完全発展**。
