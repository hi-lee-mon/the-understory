# 13_進行表・難度設計（v0.1）

## 1. 進行の全体像（黄昏の森型ゲート＋双方向往来＋半自由な順序）

- **骨格**：各章のボス撃破＋結末選択で次環礁が解放される（メトロイドヴァニア型ゲート）。
- **順序の自由度（Issue #24）**：序→第1章→終章は固定だが、**第2〜4章は同時解放・任意の順で攻略可能**（切なさ/滑稽/恐怖の感情マップはどの順でも隣接章で対比が効く構造）。全部済むと第5章が開く
- **補助環礁・小島**：本線環礁の間に任意攻略の小環礁を散らす（「愛で壊れた」「恐れられた」「笑える没案」等の棄てられた理由の多様化を担う・docs/12 §2.1）。寄り道報酬＝希な拾得物・隠しロア・村の住民候補。**数・密度は確定済み**（U4-8 承認：補助環礁 **3〜5 島**・素材系拾得物 20〜35個/章・寄り道欠片は**章の寄り道区画に1個**（各章欠片4個のうち寄り道側1個——34/README 規則2・N-ECO-608 が権威。16-U1-Q15 承認・Issue #2）——詳細は docs/38 04 §4.1 の章配置表）。**環境語彙の割当原則も確定**（U3-Q5 承認：一島につき語彙パターン一種を主軸＋補助一種まで——恐れられた＝残骸主軸+欠如／笑える＝書きかけ主軸+整頓のズレ／愛で壊れた＝保存主軸+不在。詳細は docs/45 03 §3.8）
- **往来自由**：現実↔国は**異物/ゴミ箱（ADR-0003）でいつでも行き来可能**（ユーザー案採用。ベッド儀式は削除済み）。国での進行は現実の装備・素材に依存し、現実の探索が国の導線（縁の地）にもなる。ゴミ箱経路は**「自分を棄てる」で自分の捨て場へ落ち、捨て場のゴミ箱から現実へ帰還**する往復路（`docs/23_discard_grammar.md` §4-5）。
- **迷子防止**：自由化の前提として光・色彩の非言語導線で誘導（Issue #31 で文法確定——**docs/45_nonverbal_guidance/** 参照）。**確定済みの運用規則**：
  - 明示導線（強度「明示」の信号）は**同一視界内に同時1系統まで**（U1-Q6 承認）。
  - 迷子判定の定量閾値＝**「一次導線の勾配圏外で90秒滞留」または「未消化の淀み地点が残る状態での同一地点周回」**を基準値とする（U1-Q6・U2-A・U4-#5 一括承認——実装時に微調整可）。
  - 迷子時リカバリの順序＝**環境再提示→装置（没腐コンパス）→最小語り（ノミ）→最終段の明示増強**（言語的救済は最後の手段。最終段＝長時間停滞時にノミ示唆の段階的強化＋コンパスの指しを一時的に明示寄りへ。常時明示はしない——U4-#5 承認）
- **拾い人の村**：章を救うごとに住人・施設が増え、クラフト・情報・イベントが解放される中間地点。
- **垂直スライス（Issue #5・docs/40）**：スライス範囲＝**序章全8場所＋第1章＋村**（40-Q1/Q3 承認・2026-10-03——序章は章でなく導入区画：ボス・結末・欠片・予告頁なし）。村のスライス初期構成＝中核棟全棟＋発展区画は月見翁の農園1件のみ＋村報第1号（翁救出号）。完了条件＝「遊ばせて感動する」品質の定量ライン（40-Q7——検証は Issue #6 へ）。Issue #13 先行ゲート＝次元生成・転移骨格・個別化アイテム・転移持ち込み・異物の可視性モデルの5点（40-Q8 承認）

## 2. プレイ時間・難度の想定（配信単位）

| 区画 | 想定時間 | 難度意図 | 配信目安 |
|---|---|---|---|
| 序＋第1章 | 1〜2時間 | 世界の法則・戦闘基礎の体験学習（低床） | 配信1回＝第1章クリア |
| 第2〜3章 | 各2〜3時間 | 章ギミック（水辺/リズム）で学習カーブ | 1章＝1〜2回 |
| 第4〜5章 | 各3〜4時間 | 複合ギミック、装備差が効く帯域 | 攻略配信の見せ場 |
| 終章 | 3〜4時間 | 全要素統合＋物語クライマックス | 感動の最終回 |
| 計 | 約15〜25時間＋図鑑/再戦 | シリーズ5〜8回に分割可能 | シリーズ物として成立 |

- **序破急配分目安（U3-N4 承認・Issue #28）**：章内の 序：破：急 の時間比率目安は `docs/48_fusion_elements/03` §4.2 の章別割当表を正とする（序＝環礁到着〜深部手前・破＝探索と断片収穫・急＝アリーナ戦）。ボス戦の内部配分は docs/38 03 §4 が権威。
- **距離目安（16-U2-Q04 承認・Issue #2）**：01章＝場所間 30〜60B・総歩距 150〜250m／02章＝主軸 250〜400m。順不同章のため両章とも他章攻略前提を置かない（G4）。地形数値との整合は Issue #15 へ

## 3. 難度カーブ（フロー維持）

- **「一段強化すれば届く」帯域**を各章に置く。ボスは「今の拾得装備では辛い→素材集め→丁度良い」。**章×帯域の対応表は確定済み**（U4-13 承認・docs/38 04 §0：通常モブの HP 帯・一撃実効帯を新設。推奨装備帯は T1〜T4 の正典値を維持）
- **終章の反転（U4-13 承認・明文化）**：通常モブ帯域は終章で **18〜30 HP／一撃 2〜4 HP に意図的に緩和**する——終章の緊張は戦闘でなく主題が担う（「抵抗要素は最小限・強くはない」に従う。難度勾配はボス帯域・装備帯で担保）
- **死に学習**：ボス攻撃は予備動作が読める設計。死んでも「次こうしよう」が見えるフェアさ。
- **失敗の可視性**：没腐の歪み・ボスのフェーズ変化は視覚で分かる（理不尽な即死なし）。
- **段差**：章間に「拾い人の村で装備を整える」自然な間を作る。**段差＝章間の幕間（U3-N4 承認・Issue #28）**：村での間は演劇構造の「幕間」としても機能する（`docs/48_fusion_elements/03` §3.2 の幕三階層——章クリアの幕切れと次章の開幕の間）。

## 4. ゲート方式

- **地理ゲート**：環礁は空中/海上に浮かび、序・1章・5章・終章はクリアで「橋/流れ」が繋がる。2〜4章は同時に開放され順不同
- **意味ゲート**：章の主題（月・手紙・祭り・坑道・歌）が先の章で少しずつ混ざり、終章で収束。
- **現実側ゲート**：現実での「縁の地」発見・拾得素材の保有が国側の進行条件になる場面も作る（行き来の意味づけ）。

## 5. エンドコンテンツ

- **拾得図鑑コンプ**、**結末分岐の周回**（書き換える/見届けるの両ルート）、**ボス再戦（ハード）**——**再戦の報酬は記録系のみ**で確定（B10 承認：拾得図鑑の再戦頁・称号・ハード限定演出差分のみ。結末の欠片・新規素材の追加なし＝1周回で揃う原則 C2。docs/38 03 §4.4）、**拾い人の村の完全発展**。
