# 村ボード——拾い人の村（章外拠点）

> **物差し**：本書は docs/65 §5 のテンプレートに従う演出ボード（時系列の確定面）。書式正本は docs/50、断片の実文正本は docs/52 §9、配置正本は docs/16 §3.4〜3.5・§4.1.4、スライス範囲正本は docs/40 §2.2〜2.3・§2.5・§2.9、誘導正本は docs/45/02 §5〜§6・§8、人物正本は docs/25 §4〜5、楽曲・SE の ID 正本は docs/19 §3・§6.2。正典値は引用のみ・改変しない（G-CB-11）。
>
> **範囲メモ**：村は章ではなく拠点——**大幕・開幕演出は張らない**（到達の一拍の扱いは 51-U3-Q4）。村内では迷子誘導を置かない（45/02 §6.2）。スライスの発展区画は**農園1件のみ**＋村報第1号（翁救出号・40-Q3 承認）。読む者（灯台守）はスライス外——返信は救出前の気配応答のみ（TX-VIL-LET06）。名付けの台は器として配置のみ（命名変換は後章解禁——40 §2.5）。OP/現実側の配置設計は書かない（G-CB-17）。
>
> **語彙前提**：画面欄は docs/45/03 §2.1 のパターン語彙（V1〜V8）と§3 章別の指示詞で記す。村は生活の場のため「整然（V4）」が基調——住人のいる棟は「使われている形」、未稼働の棟は「しまわれた形（V7の弱い形）」で区別する。層表示は 共有層／個別層（G-CB-16・38/04 N-ECO-801）。

## 0. 序列の目的

1. **「帰る場所」の獲得**——浜で流れ着いた者が、灯りのある村に迎えられる。村到達は40 §1.1 ビート24「村に着く」とビート25「拾得図鑑の実体を受け取る」の演出面（M-V-1／M-V-2）。
2. **「記録は序章から走っていた」の実体化**——拾い人の手記・拾得図鑑は「記録先行・器は後到着」の二段設計（18 §3.1〜3.2・40 §2.9）。村到達で器が渡り、序章からの頁が既に綴じられていることを初見で示す。
3. **集う場所の初見**——住人がいる・灯りがある・「捨てられた者が拾った村」（25 §4・TX-VIL-SER01 確定文）を、説明ではなく往来と灯りで見せる。
4. **仕組みの提示**——共同ゴミ箱（帰れない状態を作らない保険・38/02 §3.6・32 §2.2）・掲示板と村報・聞き役の場・名付けの台（器のみ）・共同鍛錬場——各機能を「見つける」順で固定する。加えて**浜の内側の自分の捨て場**（投入者ごと生成の個別区画・16 §3.5——村の構造物ではない）を、村の灯りと導線が指す役割として定める。
5. **救出後の成長実演**——翁が村に来て農園が増え、灯りが増え、村報第1号が発行される（B-G-05・34/01 §7）。「あんたが連れてきた人が増えるたび、灯りがひとつ増える」の可視化が本作の中核実演である。

> **感情曲線**：ほっとする（浜の奥の灯り）→ 迎えられる（挨拶・手記の手渡し）→ 読み応え（図鑑・手記・村報）→ 居場所（自分の捨て場・名付けの台の気配）→ 育つ（救出後の差分）。

## 6. 救出後の差分

> 村の「救出後」は章の転相ではなく**成長**——救出が村の形になる実演（B-G-05・40 §2.7）。

| 層 | 救出前 | 救出後（01＝翁） |
|---|---|---|
| 色（見えるもの） | 発展区画は空き地・灯りは救出数分 | 農園が増築（jigsaw）・灯り+1基・掲示板に第1号の貼り紙・畑に実系の苗 |
| 音 | 環境床＋住人の気配のみ（テーマなし） | MU-TH-VIL 解禁・間欠再生（朝夕・住人イベントなし時は鳴らない）＋村報発行音 |
| 気配 | 読む者不在（投函は気配応答のみ） | 翁の物語反応行。住人便は発火判定機構のみ残置——配達コンテンツは後章依存のためスライス内では発火しない（40-Q16・TX-VIL-LET03 の実配達なし） |

- **「もうすぐですよ」の転位**——01で宙に浮いていた口癖が、実のなる畑で初めて真になる（34/01 §7.2）。本作の中核的な感情の支払い。
- **灯り増加の恒常規則**——救出1件ごとに灯り1基。以後の章でも同規則で増える（45/02 §6.1）。
- **村報の継続**——第1号以降、発行契機①②③（U2-N5）で動的採番。最終号・臨時号（名付け号外・結末確定号外・共同箱着弾号外）はスライス外の管轄（TX-VIL-NP03）。
- **没腐度回復**——村滞在で個人没腐度 −1/10分・最大−3（38/04 N-ECO-206）。画面には出さないが「村にいると淀みが薄れる」体感の一部。
- **村は安全地帯**——敵対モブ0（38/04 N-ECO-101）。試練・戦闘の発火点は村内に置かない。

## 運用メモ

- ビートは「初到達の推奨順」——以後は自由巡回。各棟の初見は別時刻でも成立。
- 村は章でないため BD 採番は `BD-VL-###`（区画略号＝VL）。断片は TX-ID 参照のみ・実文は 52 §9 を正本として再掲しない（G-CB-10）。
- 「名を付ける」の照準表示は器の役割表示——入力は「開ける」に写像され、命名変換は後章解禁（40 §2.5）。ボード上で動詞の齟齬が出たら 51-U3-Q4 と併せて起票。
- 村内では迷子誘導を置かない（45/02 §6.2）。村への導線は浜の灯りが担う（45/02 §6.1）。
- 本書で扱わない：発展区画の農園以外（手紙屋・祭り場・名人の居場所・原案の座区画＝救出連動・Phase 3 以降）、読む者実体、村報最終号・臨時号、結末別の村（34/06 §7.2 は参照のみ）。
