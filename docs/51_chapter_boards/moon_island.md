# 月下の小島ボード——01属補助環礁

> **物差し**：本書は docs/65 §5 のテンプレートに従う演出ボード（時系列の確定面）。書式正本は docs/50、断片の実文正本は docs/52 §3、配置正本は docs/16 §3.8・§4.1.4、誘導正本は docs/45/02 §8・45/03 §3.8、収容物構成は 38/04 N-ECO-608、SE の ID 正本は docs/19 §3・§6.5。正典値は引用のみ・改変しない（G-CB-11）。
>
> **範囲メモ**：月下の小島は 01 章所属の補助環礁（唯一のスライス内補助環礁・16 §3.8）。**ランドマークを置かない**——「水平線上の小さな色の変化」＋漂着物の特徴的集積で示唆する気配級（45/02 §8）。**没腐コンパス・縁の羅針盤の指し先に含めない**（U2-J 承認・45/02 §8）。結末の欠片は**0**（16 §3.8・52 §3.6）。小試練は「没腐濃度の高い」一区画の小遭遇（ボスではない——16 §4.1.1・40 §2.6）。語彙は一島一主軸＋補助一種までの原則（45/03 §3.8）——本島の割当は 51-U3-Q8 で確定する。
>
> **語彙前提**：画面欄は docs/45/03 §2.1 のパターン語彙（V1〜V8）で記す。島の語り「摘まれなかった実が土に還り、種は眠る」（TX-01-F10）に合わせ、**主軸＝V8（保存）＋補助＝V7（欠如）**——摘まれるのを待って残されたものが、小さく保存されて眠る島。

## 0. 序列の目的

1. **「もう一つ島がある」の発見**——沖の水平線上に小さな色の変化。装置は指さず、視線と漂着物だけで「あそこに何かある」を成立させる（N14・45/02 §8）。
2. **届かなかったものの溜まり**——N-ECO-608 の構成（書物・落書き・素材・宝物級・隠しロア・宝箱）を「流れ着いて、摘まれなかった」語りで束ねる（TX-01-F10 が島の題文）。
3. **月が近い気配**——「沖に出ると、月が近くなる気がした」（TX-01-GRF06）を落書きでなく空で体感化させる——環礁全てで同じ月が共有される演出（G-CB-07）。
4. **振り返る遠景**——小島から01環礁・浜・村の灯りを見返す絵と、まだ名を言わない他環礁の気配（51-U3-Q9）。
5. **小さな試練の味**——没腐濃度の高い区画での小遭遇（安全地帯の村と外の世界の境を思い出させる）。

> **感情曲線**：気配（水平線の色）→ 近づく（渡航）→ 静かな上陸 → ほのかな不吉（試練区画）→ 拾う歓び（レコード・結晶）→ 遠望の澄み（月と村）。

## 6. 救出後の差分

> 小島の「救出後」は島自体が変わるのではなく、**見えるものが変わる**——遠望と空の差分。

| 層 | 救出前 | 01救出後 |
|---|---|---|
| 色（見えるもの） | 止まった月・村の灯りは初期数 | 結末A：満ちて動き始めた月が小島から近く見える／結末B：新月を受け入れた月（月は欠けたまま／新月へ——月の欠片は星めいた光に散る・34/01 §6.3）——どちらでも「種は眠る」の語りが読み替わる。村の灯りは+1基（遠望に反映） |
| 音 | 薄い床＋淀みの定位音 | 月齢転相が戻る結末Aでは `world.moon.phase` が再び鳴る（戦闘キュー色なし・19 §4.2 救出後変化と同型）。結末Bでは発火しない——新月を受け入れ月は動かず、月齢転相が起きないため（34/01 §6.3） |
| 気配 | 「あそこに何かある」だけ | 行ってきた島として残る——水平線上の色が「行ける場所」に読み替わる |

- **装置非干渉の継続**——救出後も指し先に加えない（U2-J）。コンパス系の挙動は救出前後で変わらない。
- **ノミの語り**——小島専用の語り行は正典にないため新設しない（既存の拾い物反応・由来の嗅ぎ分けの反復のみ）。

## 運用メモ

- ビートは発見〜遠望の推奨順。小島は寄り道扱い——01 本体の攻略と独立して成立（行かなくても進行可）。
- BD 採番は `BD-IS-###`（区画略号＝IS）。断片は TX-ID 参照のみ・実文は 52 §3 を正本として再掲しない（G-CB-10）。
- **結末の欠片は0**——欠片の気配・代替物も置かない（16 §3.8 収容物項）。
- **迷子誘導・装置指し先の対象外**（U2-J）——ビート内に「導く」演出を入れない。行き忘れは許容される設計。
- 月の共有（G-CB-07）——小島からの月は01と同じ月。遠望・渡航中の空で共有を見せる。
- 本書で扱わない：他の補助環礁（スライス外）、二度棄ての気配（翁の小屋裏の物置＝01本体側の寄り道構造・01_moon_forest.md 側の担い）。
