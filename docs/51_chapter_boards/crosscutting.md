## 0. ボード共通規格

### 0.1 書式（docs/50 を正本として継承）

- **ビート表**：列＝`BD-ID｜ビート名｜場所｜画面（開示順・V/C語彙）｜音（SE正典名）｜プレイヤーの行動｜狙う感情｜配信での見せ場｜器・通知型｜参照ID`（docs/65 §5 の型・docs/50 継承）。
- **運用メモの継承**：各ビートに「狙う感情」と「配信での見せ場」を必ず添える。実装に入る前に「ここで視聴者が何を感じるか」をレビュー観点に入れる（docs/50 運用メモ）。
- **画面欄の開示順**：「最初に見えるもの→歩くと見えるもの→見上げると見えるもの」（34/00 §2.2 の型）。絵コンテとして誰が見ても演出意図が分かる粒度に落とす（H-01）。
- **確認観点**（各ビートの自己点検）：①プレイヤーの身体を止めないか ②新しい操作を求めていないか ③読まなくても通れるか ④スキップできるか ⑤字幕があるか。

### 0.2 ID 採番（docs/65 §5 規則——二系統の併存）

ボード系の ID は二系統ある。混同しない：

- **BD-ID（ボード内ビートの自身 ID）**：形＝`BD-{区画略号}-{連番3桁}`。区画略号＝`00`（序章）・`01`（第1章）・`VL`（村）・`IS`（小島）・`X`（横断）。連番はボード内で時系列順に連続させる。結末差分のように同一発火点の分岐は `BD-01-051a`/`b` の接尾字で扱う（01_moon_forest.md の先例）。
- **B-ID（棚卸し要素台帳の参照 ID）**：形＝`B-{区画略号}-{連番}`——extract ユニット（docs/65 §4）の要素台帳の採番で、ボードは参照ID欄・節見出しで**引用のみ**行い、ボード側から新規採番・改番しない（使用例：`B-01-06`・`B-VL-10`・`B-IS-01`・`B-00-07`・`B-G-05`）。
- **`B-X-` 系＝横断要素**（要素台帳の B-X 番号が正本）。**本書の型定義節は `B-STD-` 系を使う**：拾得最小構造＝**B-STD-01**（§0.3）・予告頁交付＝**B-STD-02**（§1）・マッチカット＝**B-STD-03**（§2）・遠望＝**B-STD-04**（§4）・迷子救済＝**B-STD-05**（§5）。通知系列（§3）は系列の「型」であり単一の B-STD 番号を持たない——構成要素が台帳の個別番号を持つ（拍子印＝B-X-04・「新頁あり」気配群＝B-X-13・照準時動詞「名を付ける」＝B-X-05 の対象動詞 等）。
- **ID は確定後に改番しない**——参照元（断片・SE・通知型の対応表）が全て ID 経由のため、改番は要承認案件（51-U4 へ持ち込む）。
- 横断系列（本書 §1・§2・§4・§5 の型そのもの）をボード上の一点として引用する場合は `B-STD-0x` は型の台帳側内部採番——ボードの参照ID欄は「crosscutting §n」の節参照で記してよい（B-STD-ID は型定義の索引用。参照ID欄に節参照と併記してもよいが必須ではない）。

### 0.3 ビート粒度

- **1ビート＝1枚の絵コンテ**（docs/50 運用メモ）＝「画面が一つ変わる」単位。1ビートに複数の画面転換を重ねない——重ねたい時はビートを分ける。
- 拾得の最小構造は全行共通（**拾得標識＝拾得の朱の一点差し**——朱は拾得標識一本に専用予約された色・45/01 §4.4/45/02 §4.3-N1/N2）。断片行は拾得 Toast＋字幕「拾得物：届く」が付く型を崩さない（B-STD-01）。
- 環境が先・文字が後（G-CB-05）：文字媒体は全て環境が先に語ったことの確認として置く。ビート表では「環境のビート→確認のビート」の順で隣接させる。

### 0.5 参照記法

1. **断片実文は TX-ID 参照のみ**（G-CB-10）——実文の正本は docs/52（粗い文字品質は docs/26 §6）。ボードに実文を書かない。
2. **環境語彙の二系統の区別**：画面の内容語彙は `V1〜V8`（45/03 §2.1 基本パターン）と `C1〜C5`（45/03 §2.2 複合技法——C1因果の連鎖/C2密度勾配/C3差分/C4一方向の積層/C5後付け正体）。多重化・信号の記述で使う `C1〜C8`（45/04 §3.1 八チャネル——C1光/C2造形/C3色彩/C4動き/C5位置/C6聴覚/C7字幕/C8装置）は別系統。同字面のため、多重化文脈では **`45/04-Cn`** と出典接頭を付す（例：幕開けの三重信号＝45/04-C1光〔点灯〕＋C4動き〔復帰〕＋C6聴覚・C7字幕のペア——C3色彩は補強として重ねるのみ・単独算入不可）。
3. **層の表記**（G-CB-16・docs/32 §6・ADR-0004）：演出・通知の各行に共有層/個別層を明記。由来札・没腐コンパス・異物視認＝個別層、村報・「◯◯が綴じた結末」・幕・空の月＝共有層。
4. **数値は権威への引用のみ**（G-CB-01/22）——ボードに新しい数値を書かない。未規定の演出値は §6 の要承認へ。

## 2. 世界転調マッチカット仕様（B-STD-03——docs/09 §2 映画行の着地・本書が初出定義）

> 手渡し元：48/01 §7-#7⑥（「最終結末〜エピローグ遷移の未設計部分」「転移・転調・結末のマッチカット仕様」）。現在の参照点＝docs/50 Beat 2（蓋が閉まる→暗転→世界が壊れる）。

### 2.1 定義——画面を切らないマッチカット

本作はプレイヤーの身体を止めない・画面を切らない（P-CB-03・G-CB-03）。映画のマッチカット（カットを跨ぐ形・音・動きの一致）をここでは**「世界の変形」として定義する**：**絵の中に「重なる一点」を固定し、その一点の周りの全要素を入れ替える**。プレイヤーが見ている一点が切れないため、世界が入れ替わっても「同じものが別の意味になった」と読める（45/03-C3 差分の転調版——同じ形・同じ位置・違う意味）。**全マッチカット中もプレイヤーの操作権は保持される**（移動・照準・回避の入力は生きる——演出は世界側で完結し、操作待ち・視聴固定のビートにはしない）。

**構成三要素**（全マッチカットはこの三点で定義する）：

1. **重なる一点（絵の連続性）**：切替の前後で、画面のほぼ同位置に同じ形・同じ向きの対象を**1点だけ**置く。2点以上にすると引き継ぎが崩れるため一点に限定。
2. **音の反転**：切替の拍に音が一度「裏返る」か「最小に絞られる」——転移＝逆再生の裏面、転調＝章固有の一音だけが残るツナギ、結末＝全音が落ちて環境音が復帰する。
3. **間（ま）**：切替の一拍に情報を置かない（45/04 §4.3 規則 C-6——暗転・転換の間に情報を挟まない）。間の長さは権威値に従属する。

### 2.3 運用規則（各章ボードの義務）

- 転移・転調・結末の発火ビートでは**「重なる一点」を画面欄に明記する**（何が画面に残り続けるか——上表の一点名または章固有の一点）。
- **月は転調マッチカットの最大の重なる一点**（G-CB-07）：全環礁の空に同じ位置で見えるため、環礁を跨ぐ演出・遠望では必ず月を固定点として使える。月中継点（45/02 §7.3——02防波堤・03到着遠見・04採石場段丘・05登塔の窓に各一拍）はこの原理の常時版。
- **小幕転移（ゴミ箱の往復）の型**：往路も復路も「箱の口」一点を軸に `break`（裏返る）→`land`（反対側の世界音へ着地）で成立させる。帰還側の SE 細目は 51-U1-Q1（51-U4-Q2 で連動記録）の承認に従属——型自体は本節で確定。
- **章別残響は差し替え表から選ぶのみ**：ボードに章別残響を書くときは §2.2-α の当該章行をそのまま引用し、正典にない SE を章の幕開けに割り当てない（G-CB-12）。
- **型から外れる演出は要承認**：マッチカットを使わない転換（単なるフェード・無断のカット）は本作の作法に反するため、ボードに書く場合は §6 へ起票する。
- **配信モード差分**（G-CB-24）：演出抑制時は暗転長のみ短縮（18 §6.1 #7——係数0.6程度）。**重なる一点・音の反転・三重信号は削らない**。シェーダー OFF では月・箱の口は実体オブジェクトとして残り、暗転は天空光非依存（45/02 §7.2）のためマッチカット自体は全環境で成立する。

### 3.3 優先度・キューの規格（18 §2.5.2 引用）

- 優先度：**幕＞綴じ画面＞Title＞Toast＞HUD小通知**。演出中の一過性通知（Toast/Actionbar）はキューイングして演出後に出す。字幕はキュー対象外・発生と同時表示。
- **同型集約**：連続拾得は「○○×3」等に集約し Toast の連打を防ぐ（18 §2.5.2-2・§5.8）。
- **持続型気配は時間で消えない**（蓋の動き・光・図鑑表紙の気配）——通知（Toast）は消えても世界側の気配が残る二重構造が本作の型。

### 3.4 配信モード差分（G-CB-24）

- 演出抑制時：通知を1拍に限定（18 §6.1 #3）・暗転短縮（#7）・読み上げ速度カードのみ配布（43-U3-Q4）。**系列・多重化・字幕は削らない**——配信モードで崩れるのは「長さ」だけで「形」ではない。

## 4. 遠望・共有の空の規格（B-STD-04——環礁群の遠望系列・月下の小島からの視線・月の共有の絵）

### 4.1 遠望の型（P-CB-10「遠望は装置」——見せて絞る）

- **共通骨格＝遠望→遮蔽→勾配**（45/02 §3.1・45/04 B-2 を引用）：①遠望点＝章の中心がランドマークとして視認できる最初の開示（向かうべき一点は原則視界内に存在）②遮蔽＝中間地形で中心を隠し各区画で再開示（「登ると全部見える」はしない）③勾配＝中心へ近づくほど光量・彩度・痕跡密度・一次チャネルの音明瞭度が増す。
- **月＝全環礁の空に共有される唯一のランドマーク**（G-CB-07・docs/11）——ボードの遠望欄はこの前提で書く。月は共有層であり、結末差分は空に残る（§2 MC-3 と連動）。
- **ボス戦中の月齢転相も共有の空**（38/03 §4.4 の45秒周期転相・正典の共有前提）——01 ボス戦中の月の転相は浜・村・月下の小島・他環礁からも視認される（マルチ時・遠望含む）。章固有演出ではないため各ボードは「共有の空として見える」前提でのみ記し、発火点・位置の章内仕様は 01_moon_forest.md §1.8 側に任せる。
- **遠望は「見える」のでなく「読める」粒度**で設計する：色の変化・灯りの点・かすれの斑・島影。彩度・霧・粒子はシェーダー依存のため、OFF 時は造形差分（島影・漂着物集積・灯りの点・地形の開口部）が一次を担う（G-CB-06）。

### 4.3 規格（遠望ビートの書き方）

- 遠望対象は必ずスケールのある造形（塔・灯台・舞台・段丘・座の窪み）。**相互視認＝存在の提示のみ**——方向強制ではなく、順不同の自由と整合させる（45/02 §3.2）。
- **小島の視線規格**：ランドマークを持たない・装置の指し先に含めない（没腐コンパス・縁の羅針盤の対象外——U2-J 承認）・「水平線上の小さな色の変化」＋漂着物集積で読ませ、接近で気配→示唆に昇格（45/02 §8 強度規格）。
- **補助環礁の語彙**：一島につき主軸一種＋補助一種まで（45/03 §3.8——小さな島で三種以上混ぜると読みが散る）。
- **環礁語彙の引用**：各場所の語彙構成は 45/03 §3.1〜§3.7 の**場所別行**を引用のみとする（例＝序・見晴らしの岬＝V5向き＋遠望、01・手紙の径口＝V6反復、01・果樹園＝V4整頓＋V7欠如＋C3差分＋V6反復——環礁単位の要約行は正典に存在しないため、章全体の集約語彙をボード側で合成しない）——ボード側で新規語彙を作らない（G-CB-21）。
- **配信モード差分**（G-CB-24）：遠望は環境のまま差分なし——読み合いの素材は削れない。
