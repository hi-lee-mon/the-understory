## 2. 制作プロセス

1. **棚卸し**（docs/65 §4 H-01〜12）：割り当て領域の正典・準拠点を全件回収し、演出時間・断片・場所・UI・音・見せ場の権威を確定させる。
2. **ボード執筆**：正本 docs/50 のビート形式で時系列の演出を固定。正典値は引用のみ（§4 の規則）。
3. **自己点検**：各ビートを5観点で確認（身体を止めないか／新規操作なしか／読まなくても通れるか／スキップできるか／字幕があるか）。
4. **レビュー反復**：レビュアーの指摘ゼロまで改訂（台帳の全件収録・網羅性・数値権威の引用を重点）。
5. **横断監査**：ユニット間の矛盾（同一正典の異なる読み・章間接続の齟齬）を潰す。
6. **要承認の集約**：未決事項は `51-U{n}-Q{m}` で本 README §6 に集約し、ユーザー一括承認を待つ（承認後に各書き戻し先へ反映）。

## 3. 横断確定規則（監査で確定した全ボード共通のルール——crosscutting.md §0 の要約）

- **書式**：1ビート＝1枚の絵コンテ。列＝BD-ID｜ビート名｜場所｜画面（開示順）｜音（SE正典名）｜プレイヤーの行動｜狙う感情｜配信での見せ場｜器・通知型｜参照ID。
- **BD-ID**：`BD-{区画略号}-{連番3桁}`（00/01/VL/IS/X）。確定後に改番しない。
- **正典値は引用のみ・再定義禁止**（G-CB-01/10/12/22）：数値・ID・名称・確定文・SE名・TX-ID は権威ドキュメントを指す。変更が必要なら要承認へ。
- **画面欄は環境語彙で書く**（45/03 §3 の V1〜V8/C1〜C5・多重化は 45/04-C1〜C8——同字面の C 系は出典接頭で区別。新規語彙禁止 G-CB-21）。
- **環境が先・文字が後**（G-CB-05）：文字媒体は環境が先に語ったことの確認。一次チャネルはシェーダー OFF で成立（G-CB-06）。
- **月は共有の空**（G-CB-07）：全環礁で同じ月——結末差分・マッチカット・遠望の固定点として使う。
- **ノミは全ビート常時同行**（G-CB-08）。**順不同耐性**（G-CB-09）：02〜04 のボードは他章の知識を前提にしない。
- **層区分の明記**（G-CB-16）：共有層（幕・村報・空の月・「◯◯が綴じた結末」）／個別層（由来札・没腐コンパス・異物視認・自分の箱）。
- **マルチ**：全員に同一演出・個別層は各自状態（G-CB-18）。結末確定は先着・不可逆（読み合い猶予はコンフィグ）。
- **配信モード差分**（G-CB-24）：各ボード末尾に差分表を持つ。短縮は暗転長のみ（0.6程度）——多重化は削らない。
- **マッチカットの型**（crosscutting §2）：転移・転調・結末の切替は「重なる一点＋音の反転＋間」で定義。型から外れる転換は要承認。**幕開けの残響は章別差し替え**（crosscutting §2.2-α——`event.bell.sweep`/`event.rescue.return`/`event.mechanism.release`/`event.light.fold` は特定章専用で他章へ転用しない。01＝`world.moon.phase` の文脈変化＋環境床フェードイン＋定位音の文脈復帰・19 §4.2）。
- **通知の系列**（crosscutting §3）：幕切れ→綴じ→着弾→由来判明は1表の系列として固定。優先度 幕＞綴じ＞Title＞Toast＞HUD小通知・字幕はキュー対象外。幕開けの章別残響は §2.2-α の差し替え表に従属。
- **迷子救済の型**（crosscutting §5）：90秒滞留/同一地点周回で発火→環境再提示→装置→最小語り→明示増強の4段。強制誘導なし・個別層。

## 4. 範囲の整理

- **スライス範囲**（docs/40）：序章全8場所＋第1章＋村＋月下の小島＋OP往復＋クリア後一周。
- **スライス外**：02〜05章・終章の各ボードは Phase 3 に回す（docs/40 §9「Issue #11」行——本 Issue では型のみ収録、G-CB-20「存在のみ」）。
- **本ボード群がカバーするもの**：各場所の絵コンテ・断片/SE/通知の発火点・迷子救済系列・救出後差分・配信見せ場。
- **本ボード群がカバーしないもの**：実装（Phase 1 以降）・断片の実文（docs/52 側）・構造物の生成方式（docs/16 側）・数値（docs/38 側）——全て権威へ参照。
