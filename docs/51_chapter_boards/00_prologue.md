# 51. 章ボード（演出設計書）——序章「漂着浜」

> 本書は docs/65 §5 の型に従う序章の演出設計書。仕様の説明ではなく、プレイヤーの画面・耳・手に起きることを時系列で固定する。正典値は全て引用のみ（G-CB-01）。断片実文は TX-ID 参照とし再掲しない（G-CB-10）。区画略号は `00`、BD-ID＝`BD-00-{連番3桁}`（crosscutting §0.2 規格どおり）。
> 対象：docs/50 Beat 1〜5 の拡張＋ docs/34/00 §3 場所系列 #1〜#8・寄り道・小遭遇（N-BOS-00）・収束系列。OP側（現実側）は環境語彙の適用記録のみで配置は設計しない（G-CB-17）。
> 共通前提：**シェーダー OFF＝素のバニラ表現で一次が成立**（G-CB-06——拾得の朱は光源ブロック・光彩、月は共有の空、かすれはブロックパレット差で担保）。**欠けた月は全環礁共有の空**として扱い章固有の月演出は置かない（G-CB-07）。**ノミは座り岩の出会い以降・全行程で常時同行**（G-CB-08）。断片は「どの順で拾っても成立」する順不同設計のため、ビート順は推奨導線であり強制ではない（G-CB-09）。配信モード差分＝暗転長を削る程度に限定・情報の多重化は削らない（G-CB-24・45/04 §6 #7・docs/17 §8 U4-11）。

## 0. 序列の目的

docs/50「序章が伝える3つのこと」の拡張として、本序列が担う目的を固定する：

1. **「これは普通のマイクラではない」を30秒で伝える**——転移（BD-00-001）から着弾初景（BD-00-002）までの一連で、操作はバニラのまま世界の規則だけが違うことを体で示す（45/02 §3.3 大幕＝環礁到着の遠望開示を序章では「箱から出る→欠けた月」に写像）。
2. **「何かがおかしい」をプレイヤー自身の発見にする**——説明しない。情報ギャップ3段（a「ここはどこだ」→b「この物は俺の物だ」→c「先に誰かいた」）を、浜→丘→磯の順で環境が開く（34/00 §1 好奇心の設計・45/03 §3.1）。
3. **最初の「切り抜き瞬間」を作る**——「自分がゴミ箱に入る」（BD-00-001）→「あれ、これ俺が捨てたやつ…」（BD-00-005）の2点を山場とする（docs/17 §3）。
4. **感情曲線＝不気味さ→好奇心の転調点としての安堵**——浜の不気味さ（遠雷・かすれた朝靄）の中で、座り岩の小さな光＝ノミが最初の安堵を差す（34/00 §1・20 §5 序章パレット：灰青・月白・かすれた朝靄・遠雷）。
5. **拾い人の叙任**——プレイヤーを「捨てる側」から「拾い人」へ転換する儀式として、拾得（BD-00-004）・拾い直し（BD-00-009）・捨て場の定着の学習（BD-00-014）を履かせる（34/00 §1 物語機能）。
6. **到着時の約束の履行**——docs/24 §7 の4約束を初訪で全て発火させる：①「これは普通のマイクラではない」（異物の存在——BD-00-001/02 の転移演出とかすれた浜）②「あなたが捨てたものは、ここにある」（世界の法則——BD-00-005 の共同堆積の自画像）③「物語は、終わらせられる」（没腐を解ける＝救える——BD-00-009 の小遭遇＝没腐を解く最小体験）④「小さな相棒がいる」（ノミ——一人でない——BD-00-003）。

## 6. 救出後の差分

**序章に救出対象の淀みはない**（B-G-07・19 §4.1——救出対象なし＝床不変）。`ambient.wave_raspy.bed` は初訪から以後の再訪まで同一の床として鳴り続け、彩度・動き・音の回帰三重信号（45/04 A-4）は発火しない。

差分として成立するのは以下の2系統のみ：

1. **窪地消化の差分（BD-00-009 の残存状態・34/00 §6 確定値）**——小選択①「終わらせるか残すか」の結果が世界に残る：
   - 終わらせた場合：`event.silt.crack` 発火→窪地の淀み語彙が後退（滞留の解消・色の沈みが一部薄まる——ブロックパレット差で担保）→由来物が露出し拾い直しで由来判明→没腐コンパスの指し先が消える→図鑑に綴じ済みの頁。
   - 残した場合：窪地は歪んだまま残存・物は再訪で蠢き続ける→コンパスは指し続ける→図鑑に「未完の頁」が残る→ノミが窪地の方向へ振り返る仕草。再訪時にいつでも終わらせられる（再び `world.presence.stir` → `event.silt.crack` の同型系列）。
2. **遠望の更新（45/02 §3.4——章クリア後の色の回帰の読み）**——01章クリア以後に再訪した場合、見晴らしの岬から満ちなかった月の林の**彩度が戻った（かすれが取れた）遠望**として見える（遠望の差分表示。正典＝「救った島は彩度が戻り、残る島はかすれたまま」——初訪時はかすれたまま＝BD-00-012 の構図を維持）。
