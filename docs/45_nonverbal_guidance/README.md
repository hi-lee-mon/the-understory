## 権威と重複の解消（横断監査の記録）

- **媒体の文法・強度・禁止事項の権威は U1**（§2〜§5）。U2は場面への割当のみ、U3は「語る内容」のみ、U4は「届き方の合格線」のみを担う。
- **落書きの管轄**：置く場所・密度・時系列の決定権は **U3**（前任落書き行・勾配A）。U1は「存在が案内として機能するか」の読み取り基準のみ。実文規範は docs/26。
- **迷子リカバリの順序は全書で統一**：環境再提示→装置（没腐コンパス）→最小語り（ノミ）→各書の最終段（U1 §3.5＝安全側の常時明示／U2 §4.2＝環境ループ＋§6.2 の常設安全網／U4 B-3→#5＝コンパス明示強化）——言語的救済は装置より後段という全書共通の規則。定量閾値は U1-Q6 で一本化（90秒＋未消化淀み地点の仮案）。
- **多重化の算入規則**：色彩・聴覚・装置は単独不算入（U4 §3.1）。U1 §4.2 の必須ペア表は算入可能系統で記述、補助は括弧内に併記。
- **U4 の C1〜C8 は独自採番**（U1 の9媒体とは1:1非対応——対応表は U4 付記）。
