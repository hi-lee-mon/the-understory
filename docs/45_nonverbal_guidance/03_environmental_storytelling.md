# U3：環境が語る層 —— 環境ストーリーテリングの語彙と章別適用

> **対象**：Issue #31「非言語の導線・環境ストーリーテリング」ユニット U3。物差し＝`docs/39_research_nonverbal_guidance.md`。本書は章プロット（docs/34）に**配置済み**の環境要素を語彙として言語化し、新規配置はすべて §6 の要承認に集約する。

### 1.1 本書が定めるもの

環境ストーリーテリング＝**「環境の属性を配置し、意味ある全体として解釈できるように演出することで物語を進める」**（Matthias Worch「What Happened Here」——docs/39 §2.6）。本書はそのために (a) 配置パターンの辞書（§2）、(b) 章別の環境ビート言語化（§3）、(c) 伏線の環境配分原則（§4）、(d) 解釈を開く作法（§5）を定める。

本作との特異な適合：**棄てられたものの国は、全てが「残された痕跡」の世界**である（docs/24 §1.2——Carson/Jenkins 系譜）。物が漂着し・堆積し・そこに「捨てられた経緯」が残っている、という世界の法則そのものが環境ストーリーテリングの形式を取る。**この国では環境が第一の語り手**であり、「世界は語らない。残っているものが語る」（docs/24 §1.3）を環境側で実行するのが本書の役割。**導線は世界と一体**（P-01）の究極形——痕跡そのものが導線であり物語であり、UI 的な案内を増やさないで済ませる器である。

### 1.2 docs/26 との棲み分け（環境が先・文字が後 —— N13/G2/P-08）

| | 環境（本書） | 文字（docs/26 管轄） |
|---|---|---|
| 語るもの | 「何かがあった」「誰かがいた」「ここは特別」——気配と**事実の光景**のみ | 「何だったか」を確かめる・深める・泣く |
| 上限 | 真相の言明・真相用語の名指し（「原案」「没腐」「落慮王」）・動機の説明をしない（三層モデルの表層規範——docs/36 §4） | 「全体像を説明する文書」を置かない（答えを持つ者を置かない） |
| 順序 | **先**——問いと物的証拠を置く | **後**——読む人が答えを確かめる層 |
| 進行必須情報 | 環境が担う（文字に置かない——G2） | 担わない |

- **二段構えの運用例**：隠し工房の名札付き完成品の棚は、環境が「彼は作れていた」を光景として示す（表層の事実）。それが「公の仕事としては一度も作れなかった」者の私室だったことは日誌が後で教える（docs/34/04 §4）。**環境が置くのは答えでなく問いと物証**——「作れた」「なのに作らなかったことになっている」の落差が文字への導線になる（P-08）。
- **落書き・看板・碑文の境界**：環境文字は docs/26 §3.4 のベクター（場の記憶）に属するが、**置く場所・密度・時系列は本書が管轄**する（N14——濃度勾配A・最深部隔離・後書き訂正の配置先）。実文の規範（「その場所での彼の状態」のみ書く——U1-新4 承認）は docs/26 側。
- **U1/U2 との境界**：U1 は「光・色彩・音……が何を指せるか」の媒体文法、U2 は「遠望→遮蔽→勾配」でプレイヤーをどこへ導くかの工程、**U3 はその各段で環境がどんな出来事を語るか**。U2 の骨格の各節に語りの内容を填める関係にある。
- **OP 側（現実）の管轄範囲**：docs/50 の導線工程（異物の視界端→返礼の気づき→転移→漂着——シーケンスと演出の工程）は U2 が担い、**本書は到着側（浜以降）の環境配置のみを管轄**する。OP 側の光景にも本書の語彙は適用できるが（§3.1 注記）、その適用結果は docs/50 への書き戻し対象とする（docs/39 §7 N18——U3-Q9 参照）。

### 1.3 層構造上の保証

- 環境だけで「救う」体験が完結する：読まないプレイヤーは「何かがあった場所を救った」体験を、読むプレイヤーは「何を救ったか知る」体験を得る（docs/24 §8・docs/26 §7）。
- **順不同耐性**：配置は到達順を制御できないため、全ての環境伏線は「どの順で見ても成立する光景」で設計する（Carson/Jenkins——提示順序はプレイヤー依存・docs/24 §1.2、G4、docs/33 §6）。
- **全年齢の前提行動**（P-12）：説明を読まず世界を見て動く層が主対象——環境の語りは「見る→近づく→気づく」の身体動作で読める形に置く。
- **配信で読める語り**（P-11・G14）：環境の「あっ」は配信者本人の発見として切り抜かれる（狼の巡回を見て「え、待って」が立つ等——docs/17 §3・docs/34/01 §10）。環境ビートは「自分で気づいた瞬間が画面で読める」形で置き、各章に配信映えする環境発見を1点以上据える（ミッドポイント物証が兼ねる）。

## 2. 環境の語彙表（配置パターン辞書 —— N12）

> 環境が「ここで何があったか」を語るための基本語彙。各パターンは単体では**気配**、§2.2 の複合技法で**因果の連鎖**を語る。バニラの器は docs/39 §2.8 の媒体表に準拠（実装は Phase 1 以降、ここでは語彙として定義）。
> 全パターン共通の審美：**「かすれた・欠けた・継がれた」**（G5・docs/20 §1）。痕跡は綺麗な遺跡でなく、色が薄れ形が欠けたまま残る。
> 「語る意味」列は表層で読めること。表層の上限（**語ってはいけないこと**＝真相の言明・動機の説明）は全パターン共通のため列を持たず、§2.3 の表層規範に統一する（docs/36 §4）。

### 2.3 層対応（各パターンが表層で何を運ぶか）

- **全パターンは表層で読める形に置く**——「何かがあった」「誰かがいた」「ここは特別」「何かが続いていた」「何かが足りなかった」の事実の光景（docs/36 §4 表層規範）。「語る意味」列は全て表層の読みであり、真相（なぜ／誰が／正体）は環境に置かない（§5）。
- **経年表現は 2 層のみ**——「物語が止まった時点の層」（埃・風化・かすれ）と「その後に誰かが通った層」（前任の落書き・踏み固めた径・持ち去られた跡）。3 層目を混ぜるとタイムライン一貫性が壊れる（docs/36 §4 §3.6）。
- **体系ノイズの置き方**——ガラクタ集約漂着（種類×量の景観）は語彙として運用するが、個々の物に意味を持たせない「無の海」として置く（docs/36 §4 §3.6 五種定義・docs/38 04 N-ECO-704）。全てに意味を求める姿勢をほぐし、個別記憶対象（F-U4-P01）の特別さを際立たせる。

## 3. 章別適用（各環礁で「ここで何があったか」を環境だけで示す —— N12）

> 各章は「環境が先に語る一文」を持つ——文字を一切読まなくても場所系列を通るだけでその一文が光景から立つことが本章配置の合格条件（docs/33 §5「クエストは空間に宿る」）。骨格は全章共通の **遠望（P-02/P-03）→遮蔽→密度勾配（P-04）→中心→結末の色の回帰（G7/N5）** で、章ごとの事情に翻訳する。
> ビート表の列：場所／語彙（§2.1-2.2 の ID）／環境だけで語る内容／バニラの器／根拠（章プロット節）。

### 3.8 補助環礁（3〜5島）—— 主軸一種＋補助一種までの原則

補助環礁は「没になった世界案の断片」（docs/13 §1）。**一島につき語彙パターン一種を主軸**に据え、**補助は一種まで**——小さな島で三種以上のパターンを混ぜると読みが散る。推奨割当：「恐れられた」島＝隔離の残骸を主軸＋欠如（V1+V7）、「笑える」島＝書きかけの滑稽を主軸＋整頓のズレ（V3+V4）、「愛で壊れた」島＝保存の極致を主軸＋不在（V8+V7）。個別島の確定割当は補助環礁プロットの作業時に決める（§6-Q5）。

## 4. 伏線の非言語手がかりの配分（docs/36 との接続 —— N13）

### 4.1 配分原則

docs/24 §6 の**3ベクター分散**（同一真実を環境の痕跡・書物・住人の口漏らしに分散——単独では示唆、揃うと確信）のうち、**環境ベクターが担うのは「気配と物証」の先端**である：

1. **環境は示唆を置く、書物は確信を置く**——同じ伏線でも環境側は「光景として読める形」までに留め、言明は書物・語りが担う（P-08・G2）。
2. **フェアプレイ**——回収される真実は必ず先に環境に断片として提示する（docs/24 §6）。環境の断片は「読みが二つある」双方向設計を徹底し、唯一の正しい読みに依存する配置を置かない（docs/36 §4 双方向断片原則）。
3. **回収場所は原案の座**——環境に撒いた問いの着地は終章に集約する（埋めてすぐ回収しない＝距離と反復、docs/24 §6）。

### 4.2 環境に置く伏線の選別基準

環境ベクターへ割り当てるのは以下の条件を全て満たす断片：

| 基準 | 内容 | 反例（環境に置かない） |
|---|---|---|
| 光景として読める | 配置自体が「何かがあった」を立てる（説明不要） | 動機・正体の説明が要る断片 →書物層へ |
| 順不同耐性 | どの順で見ても成立（他章知識不要・プレイ順非依存） | 時系列が前提の断片 →docs/36 §4 検証表へ照合 |
| 表層規範内 | 真相用語の名指し・動機の説明を含まない | 「原案」「落慮王」の語が要る断片 →最深部書物へ |
| 再読性4要件 | ①表層の読みは誤りでなく不十分 ②真相を知っても光景が破綻しない ③再読で別の読みが勝つ ④感情の温度が変わる（docs/36 §4 §3.5 の環境版適用） | 真相を知ると配置が嘘になる断片 →置かない |
| 発火形態 | 発見／2ルート／記号読解／遭遇／探索報酬／規則体感／収束のどれかで機能 | —— |

## 5. 解釈の開き方（断定しない配置・複数の読み —— P-09）

### 5.1 断定しない：環境は「結果」を置くが「理由」を言わない

「明答しない」の環境版＝**「答えを持つ者を置かない」（docs/36 §4）を配置で実行する**。環境は事件の結果（残骸・打痕・止まった作業）を置くが、その理由・動機・正体を環境が代弁しない。

| 作法 | 内容 | 良い例（正典） |
|---|---|---|
| 結果だけを置く | 「祭りは中止されたのか？」と感じる光景は置くが、「祭囃子が延期した」は光景が言わない | 03 の延期重ね貼り——「延期」という語は文書が持つが、「誰が」は楽屋の痕跡との照合でしか読めない |
| 表層の見え方と実体を分ける | 「恨み」のような感情の名付けは表層の見え方としてのみ許し、実体（渇望）は示唆に留める | 04 の「恨み」注記——「表層の見え方のみ、実体は渇望」（docs/34/04 P2 注記）を全章の運用規範として一般化する |
| 書き手の存在を透かす | 環境に置く全ての痕跡は「誰かが・何かのために・置いた」三点が透ける配置にする | 残火を絶やさなかった灯台守／名札を付け続けた鍛冶師——人物はいなくても手付きが残る |
| 複数の読みを許す組み合わせ | 物証は単独で断定形にならない組み合わせで置く | 「封を切られていない手紙」（04）——02攻略済みなら「読む者に届くはずの文」、未攻略なら「まだ誰も読んでいない気配」。どちらも正しい |

**検査基準**：配置だけを見たプレイヤーの発話が**疑問形**（「なぜここだけ…？」「誰がこれを…？」）なら成功。**断定形が出る配置**（「これはあの人が恨んでいた跡だ」）は表層規範違反——理由の説明が環境に混入している。

### 5.2 複数の読みを許す形

- **双方向断片原則**——攻略順で読みが変わってもどちらも正しい設計（04 の封を切られていない手紙型）。順不同区間の全環境伏線に適用（docs/36 §4）。
- **再読性4要件の環境版**（docs/36 §4 §3.5 の適用）：
  1. 表層の読みは誤りでなく**不十分**（「祭りが中止になった」は誤りでなく不十分——延期だったと知っても初見の読みは成立）
  2. 真相を知っても**光景が破綻しない**（延期の重ね貼りは「中止」の読みでも「延期を貼り直し続けた」の読みでも同じ光景）
  3. 再読で**別の読みが勝つ**（空の椅子が「誰かの席」→「あんたの席」／磯の残骸が「誰かの捨て場」→「座へ流れた彼の家」）
  4. **感情の温度が変わる**（灯台の残火：温かい→やりきれない／保存の極まった収集庫：几帳面→愛ゆえの監禁にも読める）
- **環境版の再読作法**：後付け正体（C5——ずっと見えていたものが違うものだった）／モチーフの韻（反復者の系譜——初見は「またこの型か」、再読は「全部同じ渇望の形だった」）／欠如の意味反転（空の役の連鎖）／保存の意味反転（整頓＝監禁の予行）。
- **検査**：§4.3 配分表の全行が「再読の味」を持つこと（台帳の同名列と照合）。環境断片を実作する際の検査項目として Issue #10/実装フェーズへ引き渡す。

### 5.3 ノイズの環境版（本物を埋もれさせる側）

- 5種ノイズ（docs/36 §4 §3.6）のうち環境が担うのは**実用ノイズ**（前任の道標・警告・実用書き置き——00 の落書き5箇所は全てこの系統＝F-U4-G01 と兼業、docs/38 04 N-ECO-704）、**生活ノイズ**（品書き・名札・配達票——章の質感）、**体系ノイズ**（ガラクタ集約漂着＝無の海）、**個別化ノイズ**（自分・他者の捨て物のフレーバー）。
- **誤答ノイズは落書きに限定**——環境配置そのものを「間違った答え」にしない（偽の答えの捏造禁止——docs/36 §4 §3.6 禁止項）。光景が嘘をつくと世界の実在感が壊れる。**配分数値（正典確定・U4-Q2 承認）**：**各章の前任落書きのうち1〜2箇所を彼の間違った仮説として運用する**（docs/26 §3.4・docs/38 04 N-ECO-703——02〜05 の配分は各章プロット §8 に確定済み）。誤答は「書き手が間違えた」形のみ許容——正しい読みを偽装して覆す配置は置かない。
- **タイムライン一貫性**——経年表現は 2 層のみ（停止時点の層＋前任の通過層——§2.3）。埃の深さ・風化度・筆致の乱れが矛盾するとノイズが「置き物」に見える。

### 5.4 「何かがあった」までの線引き

| 環境が語ってよい（表層） | 環境が語らない（深読み層・考察班層へ委譲） |
|---|---|
| 「誰かがいた」「何かがあった」「ここは特別」「続いていた」「足りなかった」 | なぜ／誰が（正体）／真相用語（原案・没腐・落慮王）／動機 |
| 出来事の輪郭（届いた／届かなかった／作っていた／撞いていた） | 出来事の意味（選ばれなかった／世界の没案） |
| 関係の気配（残火を守っていた者・待っていた者） | 関係の内容（読む者の正体・王の名） |

判定規準：配置だけを見た読み手が**「ここで何があったか」を一文で語れる**が、**「なぜ」を語るには文字が要る**——これが環境層の合格線（docs/36 §4 §3.1 三層運用基準に整合）。最深部の環境断片（原案素材・幻想文字・書庫の頁群）だけがこの線を越えて「示唆」まで届く（最深部隔離＝到達難度自体がメタ信号——docs/36 §4 §3.4）。

**20%ルールの環境側運用**（U3-E/30-A 承認の3層適用）：環境配置は主に**気づき層**の供給源（差分・対比で「意味がある」と気づかせる——規範値20%は気づき〜傾向層で測る）。**特定層**（正体の正確な特定）は最深部断片＋文字の組み合わせに委ね、環境だけで正体が透ける配置は漏洩として扱う。
