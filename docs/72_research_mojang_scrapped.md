# 72_調査：Mojang 却下・没案機能（Issue #35）

> Issue #35 の成果物。Minecraft 本家および派生作で「要望されたが採用されなかった／発表後に没になった」機能・mob・次元を調査し、The Understory に取り込めるネタの候補と採否判定を出す。
> 権利判定は §2 の枠組みに従う。本書は**判定材料**であり、採用候補の実取り込みは §6 要承認のユーザー決裁後に別工程で行う。
> 調査実施：2026-11-15。出典は §8 に集約。

## 0. 位置づけ

- 「棄てられたものの国」＝没になったものが集まる世界、という本作の主題に対し、**Mojang の没案は一次資料そのもの**である（Issue #35 完走条件：一覧＋却下理由＋採否判定＋テーマ親和性の評価）。
- docs/42 R-24（課題行「Mojang 没案との距離」）の解消条件②＝本書の着地。R-29（類似・誹謗指摘）の説明材料にもなる（docs/43 §10——公開アルファ掲載前の整備を推奨されていた）。
- 42-U3-Q5（承認済み）：没案由来要素の採用検討は本調査の先行実施が前提。**本書着地まで没案要素の採用は一時凍結**の扱いだったため、本書で凍結を解く判定材料を揃える。

## 1. 結論サマリ

| 判定 | 件数 | 代表 |
|---|---|---|
| **採用候補（テーマ親和性 高）** | 6系統 | mob 投票落選 mob／Minecraft Earth 終了 mob／Sky Dimension／ホタル／ルビー／没構造（赤木の森・キノコ村等） |
| **機能モチーフとして採用候補（中）** | 4系統 | 引きずり込み系（Barnacle 的）・小さな物持ち/かくれんぼ系（Tuff/Rascal 的）・場を教える系（Glare 的）・没構造モチーフ |
| **ロア・語り材料（中）** | 2系統 | 投票制度の廃止自体・各種「没の理由」（色覚・有毒・現代的すぎる） |
| **不採用** | — | 銃・リアル敵対動物・クリーピーパスタ・名称/デザインそのままの複製・公式関係を匂わせる表現・マネタイズ系 |

**核心的な発見**：Mojang は落選案を「Ideas Library（案の書庫）」に保管し、適すれば後日復活させる（沼地リニューアル＝Wild Update、Copper Golem＝The Copper Age の実例）。つまり「没案」はMojang 側でも「消えたもの」ではなく**「選ばれずに流れ着いたままのもの」**——本作の主題と構造が一致する。採用する場合は「公式復活による将来の偶然一致」を織り込み済みの設計にする（§2-L5）。

## 2. 権利判定の枠組み（L1〜L5）

| 区分 | 内容 | 扱い |
|---|---|---|
| **L1 アイデア・機構** | 「深海で引きずり込む」「物を持つ小さな像」「かくれんぼで報酬」等の**機能概念** | 著作権の対象外（アイデア・表現の二分論）。**参照自由**——ただし表現は独自化が条件 |
| **L2 名称・造形デザイン** | Moobloom・Iceologer・Wildfire 等の**固有名と公開済みの姿** | Mojang の創作物（表現）。**そのまま複製は禁止**——名は独自名、造形はモチーフを残して再デザイン。「没案由来」は内部台帳のみで管理しゲーム内表記には使わない（§6-Q2） |
| **L3 アセット・コード・テクスチャ** | ruby.png 等の残留テクスチャ・公式画像・実装コード | **一切持ち込まない**。リソースパックへの混入も禁止 |
| **L4 商標・ブランド** | 「Minecraft」名・ロゴ・公式関係を匂わせる表記 | Minecraft Usage Guidelines / EULA の範囲で運用。MOD 配布は許容されるが、公式・準公式を装う表現は不可（docs/43 §3.7・docs/32 §9 収録条件と整合） |
| **L5 復活リスク** | 落選案は Ideas Library 保管＝将来公式実装されうる（Copper Golem 実例） | 採用要素は**名称・造形・機能の独自化を必須**にして、公式復活時に「本家が戻ってきた物語」として衝突しない形にする。判定材料として各案の復活暦を §3 に記録する |

**却下理由の分類**（台帳の「没経緯」列）：`投票落選`／`発表後カット`／`設計判断却下`（ブランド・ゲーム性の規範）／`技術理由`／`置き換え`（別要素が役割を継いだ）／`サービス終了`／`言及のみ消滅`。

## 4. 採用可否の判定原則

1. **採用できるのは「アイデアと来歴」まで**——名称・造形・画面・アセットは全て独自化（L2/L3）。
2. **「没の理由」を来歴として使う**——色覚のために場を譲った（ルビー）・有毒だから食べさせられなかった（ホタル）・似すぎ（赤木の森）・現代的すぎる（鉱員帽）。「なぜ捨てられたか」をそのまま物語の因縁にできるのは本作ならではの強み。
3. **復活リスクは除去できない**（L5）——Copper Golem の実例どおり公式復活がありうる。独自化を徹底すれば復活時は「本家が迎えに来た物語」として矛盾しない。**復活済みの案（Copper Golem・沼地・バンドル・考古学・firefly bush）は実機能としては採らない**（語り材料のみ）。
4. **先行占有の注意**——Sky Dimension は Aether が事実上占有（docs/21 と突合要）。没案であっても MOD 界隈に先行者がいるかは採用時に再チェックする。
5. **却下の法的区分**——今回の調査範囲に「訴訟・権利上の理由で切られた」事例は確認できなかった（没理由は全て設計判断・技術・投票・置換・サービス終了）。権利側の壁は「没理由」ではなく「表現の複製」（L2/L3）にある。
