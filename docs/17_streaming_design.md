# 17_配信設計（YouTuber/VTuber向け v0.2）

> v0.2：docs/08（配信者・視聴者の深い調査）の結果を反映。**視聴者を「観客」ではなく「同席者」として設計する**方針を明確化。
>
> **v0.3 追補（17-U4-Q1 承認・2026-11-03）**：確定方針の詳細仕様は **`docs/70_streaming_detail/`**（クリップ瞬間台帳 clip_moments・イベント/期間限定 events・観客参加/同席感 audience・README 索引）へ分冊。本書は方針の正本として据置き。

## 1. 設計目標
「プレイして面白い」に加えて**「観て面白い」「シリーズ化できる」「切り抜ける」**。配信を**設計対象の第一級の要件**とする。

さらに視聴者側の3要件（`08` §2）：
- **マルチ視点**：同じ場所が各プレイヤーで違う内容に見える（「あなたが捨てたもの」の個別化）
- **考察班**：「答えがある謎」を置いて視聴者が推理できる（幻想文字解読・断片ロア）
- **同席感**：結末・名付け・予告を視聴者が議論・予想できる

## 2. シリーズ化できる構造

- **章＝配信回**：各環礁＝1章＝「今日は◯◯編」と宣言できる明確な区切り。シリーズタイトルに章名が使える。
- **区切りの演出**：章開始（環礁に着く）と結末（書き換え/見届ける）が配信の自然な始まりと締め。
- **次回予告（`09`）**：章クリア時にノミが「予告頁」を綴じ、次章の断片を垣間見せる＝**配信の締めに「次回は◯◯だ」と宣言できる機構**。視聴者の「次回も観る」動機と考察材料。
- **全章で5〜8回シリーズ**＋番外（図鑑・再戦・村発展）を想定。

## 3. 「切り抜ける」瞬間の設置

> **44-U3-Q5 承認済み（2026-10-15・Issue #9 一括承認）**：案A——設計概念＝「切り抜き」・検証項目名＝「クリップ瞬間」（docs/40 §5.2.4 S-1）・口語＝「見せ場」の棲み分けを明文化

各章に**「配信を知らない人にも30秒で状況が分かる」劇的瞬間**を必ず1つ以上：
- 入口の「異物」に触れて世界が壊れる
- ゴミ箱を開けたら中に返礼のレシピと手紙（「あんたが入れる箱の作り方」）→自分でデカいゴミ箱に入って転移
- ボスのフェーズ変化・形態変化（「見得」的な劇的ポーズ＋幕の暗転）
- 結末選択で「土地が色を取り戻す」瞬間
- **「あれ、これ俺が捨てたやつ…」とプレイヤーが気づく瞬間**（個別化メカニクスは配信者本人の反応を直接産む）
- **「自分の捨て場を見つける」瞬間**——国に実在する自分だけの捨て物の山との対面（`docs/23` §4。マルチでは他人の捨て場を覗く視点差分も生まれる）
- **「ゴミ箱を開けたら返事が届いている」瞬間**——QoLのゴミ箱がいつしかポストになる転換（`docs/23` §7）
- **「自分がゴミ箱に入る」瞬間**——蓋が閉じて開くと空。転移手段を身体で見せる切り抜き
- **「仲間をクレーンで掴んでマグマに落とす」儀式**——ごみ処理場で他人を「捨てる」大掛かりな仕掛け。落とされた側だけが特別エリア（灼熱の埋立て地）へ届く＝視点差のあるマルチ名場面（`docs/23` §8.5）
- ノミの機微（プレイヤーが愛着を見せたときの反応）

## 4. マスコット・愛着設計

- **ノミ**：名付け・簡易反応・会話の種・プレイヤー行動への機微。配信者が「相棒」として扱える存在。
- 配信者がノミと掛け合い・いじり・愛でるための**反応パターン**を豊富に（配信で語りかけられる設計）。

## 5. マルチプレイ（役割分担＋マルチ視点）

- 探索班・素材班・戦闘班に自然に分かれる設計（縁の地探索／拾得／ボス）。
- 「みんなでゴミ箱に入る順番を決める」「結末選択を多数決」のような**共有される決断**の瞬間を作る。
- **マルチ視点**：「あなたが捨てたもの」はプレイヤー毎に内容が違う→同じ場所で各配信者が別の反応・別の内容を見せる＝**視聴者が別視点を観に行く理由**（`08` §2-1）。「推しには何が見えたか」を各視点で追う文化に適合。
- 拾い人の村は共有拠点として発展（誰が救ったかを記録しても面白い＝群像劇の蓄積）。

## 6. 観客・イベント参加性（同席感）

- **「あなたが捨てたもの」**：プレイヤーの捨てた物が世界に出る演出は「自分の行為が物語になる」話題性。
- **考察班**：幻想文字を解読可能な暗号にし、「拾い人とは」「落慮王とは」「異物の正体」は明答を出さず断片を集めると分かる構造に（`08` §2-3）。**ARG接点規則（U4-9 承認・Issue #28）**：現実側（宣伝サイト等）に出すのはガラのみ・本物の刻印は国の最深配置のみ——ヒントまでで答えは置かない（docs/48/04 §6）。
- **議論できる結末**：結末選択は視聴者が「書き換える派？見届ける派？」と議論できる二択のまま（コメント参加）。
- イベント向けに**期間限定の「没の素材」「異物」**を入れられるよう設計。**収録規格は確定（17-U2-Q1〜Q5 承認・2026-11-03）**：期間限定要素は**段F追加単位として別出荷**（本体常設同梱はしない——撤去は公開停止で実施・判定経路は G-5/G-7 に従属・復刻は「もう一度棄てられたものが戻る」語彙でそのまま再録可）。収録基準＝語彙整合・伏線系統非混入・由来語義保全・核心除外・撤去可能・性能内の R1〜R6（正本 docs/70 events.md §2.2・名付け・拾得図鑑は通常対象）。コラボ要素は**「相手世界の没品」形**でのみ収録（由来札＝非プレイヤー由来）。常設共有鯖は持たず、期間中テーマ鯖に群像劇蓄積の見せ場を集約する。
- **観客参加機構は新設しない**（17-U3-Q1 承認）——既存機構（ノミ＝助言の聞き役・誤配便・共同ゴミ箱・村宛イベント・クレーン儀式）で観客参加を成立させる。非プレイヤー視聴者の物の届け＝期間限定イベントの運用枠（docs/70 events.md §3.3・17-U3-Q5 承認）。
- **運営は視聴者の考察の正誤に言及しない**（沈黙ポリシー——17-U3-Q4 承認・docs/43 §6）。
- **サーバー/イベント運用を前提**（`08` §1-2）：複数人進行・共有村・観戦/俯瞰視点を設計範囲に（期間限定テーマ鯖の実績形式に対応）。**配信者到達の主経路は確定（Issue #22 D-7 承認）**：配信者への到達は**サーバーイベント運用が主経路**（期間限定テーマ鯖・共同進行の場で自然発生するクリップ）——個別提供素材は副経路（docs/46 §5.4・Issue #8 の運用設計へ）。
