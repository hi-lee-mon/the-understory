## 1. この機構が運ぶ体験目標

**「捨てることは、失うことではなく、世界の裏へ届けること」**。

- プレイヤーは Minecraft で最も日常的な操作（要らない物を捨てる）を通して、**自分の行為が静かに物語になっていく**ことを体験する。
- 提供する感情：自分の捨てた物との**再会の驚き**（「あれ、これ俺が捨てたやつ…」）、**届ける/届く充足**（配達・返信の喜び）、そして推理主軸の燃料（**「この物は誰のか、なぜここに届いたか」を辿る**）。
- ユーザー方針との整合：感動は狙い撃ちしない。本機構は**推理・伏線・実験の構造**を供給し、感情は結果として生まれる（`docs/12` §2.1）。

## 2. 基本モデル：ゴミ箱＝「持ち運べる縁の地」

世界観内の理屈づけ：**棄てられたものが集まる場所では世界の境界が薄くなる**（縁の地の法則）。ゴミ箱は「棄てるための場所」を道具に閉じ込めたもの＝**ポータブルな薄い境界**。

- 投入した物は現実から消えるが、消滅ではなく**国への転移**である。
- これにより3入口の棲み分けが完結する：
  - **異物（入口A）**：自然発生した薄い境界。一期一会、発見できないと行けない
  - **ベッド儀式（入口B）**：夢を通じた一期の転移。持ち込みは「手元に残るもの」に限定される儀式的経路
  - **ゴミ箱（入口C）**：人が作る常設の薄い境界。**実用的な往復路**——クラフトで得られ、荷物を持って行き来できる定常手段
- **追跡の2層モデル**（ADR-0003 の「投入のみ検出」を具体化）：

| 層 | 対象 | 国での現れ方 |
|---|---|---|
| **個別記憶** | 名付き品・記入済み本・エンチャント品・拾得物・梱包物・ゴミ箱・「自分」 | **その物として**届く（アイテム実体/NBTを保持、由来＝捨てた人を記録） |
| **集約漂着** | 上記以外のガラクタ全般 | 個別には追跡せず、種類×量の統計として記録。捨て場や漂着浜に**景観として堆積**する（個別実体を持たないため負荷を抑える） |

**QoLとの整合（設計の核心）**：消去目的で使われても破綻しないどころか、ガラクタを捨てるほど国の捨て場が育つ＝**便利な消去が署名機構の燃料になる**。プレイヤーはいつか国で「自分のゴミ山」と対面する。便利さとテーマを分離しない（§10）。

## 3. 「捨てる文法」の格体系

動詞「捨てる」は格（何を/どこで/誰を/どう/いくつ）の組合せで意味が変わる。以下が文法の統語表である。

### 3.1 何を捨てるか（対象格）

| 投入物 | 文法上の扱い | 国での結果 |
|---|---|---|
| **ガラクタ**（無名の通常品） | 集約漂着 | 捨て場/漂着浜に景観として堆積。量と種類で景観が変化 |
| **由来のある物**（名札で名付けた品・記入済みの本・エンチャント品・誰かが作った品） | 個別記憶 | その物として届き、**章アフィニティ**で配達先が変わる（§6）。「誰かの宝物」として再配置される |
| **拾得物・国の物** | **「還す」** | 国に戻る。由来の分かる物は本来の持ち主/場所へ届く可能性（`docs/14`「返す・譲る・残す」と接続） |
| **手紙**（記入済み本・署名つき書物） | 個別記憶＋通信 | 「読む者」に届き、**返信イベント**の起点になる（§7） |
| **梱包物**（バンドル・シュルカー等に詰めた荷物） | 個別記憶＋届け物 | 向こうで「届け物」として扱われる（住人への贈り物経路。§5.4） |
| **ゴミ箱** | 再帰（§4） | **あなたの捨て場**として国に定着する |
| **自分** | 転移（§5） | 自分が国へ落ちる |
| **名を付けられた生き物** | 拡張案（§12 D5） | 「物語を持つ者」として国に届き、村の住人候補になる |
| **名前のない生き物・他プレイヤー** | 文法外 | 投入できない（者は自分で入る以外棄てられない。名付け＝物語化の資格） |

### 3.2 どこで捨てるか（場所格）

| 場所 | 効果 |
|---|---|
| **通常場所** | 標準の届き方（自分の捨て場へ。未生成なら漂着浜の共同堆積へ） |
| **縁の地** | 「太い回線」——ガラクタの保存度が上がり、章アフィニティの配達精度が上がる。縁の地に置いたゴミ箱は国側の捨て場を大きくする「本陣の捨て口」になる |
| **異物の近辺** | 異物が棄て物に反応し吸い込む演出。投入記録が異物の活動に響く（世界観：異物は棄て物が堆積した場所に生まれる——隠し導線とロアを兼ねる） |
| **拾い人の村・共同ゴミ箱** | 共同の捨て場（村の一角）へ届き、住人の反応が最も起きやすい |
| **国の中** | **二度棄て**：さらに奥へ流れ着く。村の捨て場（誰かが拾うかもしれない物置）へ。極端な二度棄ては「原案の座」＝落慮王の収集へ届く（終盤ロア接続）。ペナルティではなく「より深く流れ着く」演出 |

### 3.3 どう捨てるか（様態格）

| 捨て方 | 効果 |
|---|---|
| そのまま入れる | 標準 |
| **名付けて入れる** | ガラクタが「名前のある物」に昇格し個別記憶へ。**名付け＝責任をもって手放す行為**。第4章「名を与える」結末と響き合う |
| **梱包して入れる** | 「届け物」として届く。開封者を住人に指定でき、配達・贈り物の動詞を担う（`docs/14`「届ける」と接続） |
| **まとめて入れる** | 「一括の届け物」演出。住人が「山が届いたぞ」と反応する |

### 3.4 いくつ捨てるか（量格）

- 単品＝標準。まとめ捨て＝届け物演出。
- **常習的な大量投棄＝捨て場が育つ**。ゲートやペナルティは設けない。QoL層への報酬は「自分のゴミ山が国で景観として育つ」こと自体。

## 4. 再帰：ゴミ箱をゴミ箱に入れる（本機構の核心設計）

プレイヤーが必ず試す再帰を、禁止でなく**仕組みの中心**に据える：

1. **ゴミ箱を捨てると、それは国で「あなたの捨て場」として定着する**
   - 捨て場＝国に実在する、あなたの捨て物が集まる場所（個人の漂着地）。捨てたゴミ箱そのものが捨て場の中心に置かれている。
   - まだゴミ箱を捨てていないプレイヤーの捨て物は**漂着浜の共同堆積**に流れ着く（「あんたの物、全部あっちに流れてるよ」とノミ/住人が教える＝捨て場を持つ動機づけ）。
   - **「あなたが捨てたものがここにいる」を物理的な場所として体現する**——署名機構の最も強い実装形。
2. **捨て場のゴミ箱は帰還口になる**
   - 国で自分の捨て場のゴミ箱に入ると、**現実の対応するゴミ箱へ帰還**できる（往復路の完成）。
   - 自分の捨て場を持たない者も、拾い人の村の**共同ゴミ箱**（「誰かの捨てたゴミ箱」が必ず村にある）から帰還できる＝帰れない状態を作らない。
3. **二度目以降のゴミ箱投棄**：捨て場の増築（景観グレードアップ）として扱う。
4. **二度棄てられたゴミ箱**（国でさらに捨てる）：捨て場ごと「より深く」流れ、**原案の座へ届く特別品**となる（落慮王の収集物としてロア接続）。

## 5. 「誰を捨てるか」——自分を棄てる転移仕様

- **方法**：自分のゴミ箱（所有者＝自分）に入る（蓋が閉まる→国で打ち上げられる演出。外から見ると蓋が閉じ、開くと空になっている）。
- **落ちる場所**：自分の捨て場。未生成なら漂着浜に流れ着く。**他人のゴミ箱から入ると他人の捨て場に落ちる**（面白い事故・マルチの笑い所）。
- **荷物**：**持ち込み可**（実用往復路としての差別化。ベッド儀式の「手元に残るもの」限定と対になる）。
- **待遇**：転移は「自分も棄てられるものだから国へ行ける」という理屈。国側では住人がプレイヤーを「棄ててきた側の人間」として労う/訝しむリアクションの余地（語りベクター #29 へ連携）。
- **片道/往復**：行き＝自分のゴミ箱→自分の捨て場（片道）。帰り＝捨て場のゴミ箱→元のゴミ箱（往復の完成）。帰還口のフォールバック（現実側のゴミ箱消失時等）は Issue #16 に手渡し（原則：**帰れない状態は作らない**）。
- **死亡との区別**：転移＝自発的・喪失なし。死亡＝法則⑤の「忘れられる」（没腐への喪失、回収可能）。国でのリスポーン地点は「自分の捨て場（あれば）or 漂着浜」を推奨案として Issue #16 へ。

### 5.4 梱包物・配達の接続（「届ける」動詞）

- 梱包して捨てた物は向こうで**開封者指定の届け物**になる。住人への贈り物・配達クエスト（`docs/14` の届ける/配達の楽しさ）の物理的経路。
- 「宛先の分からない届け物」は村の共同捨て場に届き、住人が「誰宛だろうね」と話題にする（ロアイベント）。

## 6. 届き先：章アフィニティ表（docs/12 §3 の確定版）

由来のある物はその種類で届く環礁が変わる——**捨てた物が「その物の物語」に合う場所へ流れ着く**という世界の法則：

| 捨てた物の種類 | 届き先 |
|---|---|
| 月・夜・植物・種・農具系 | 第1章「満ちなかった月の林」 |
| 本・紙・手紙・記録・地図・名札 | 第2章「読まれなかった港」 |
| 装飾・遊び・食べ物・祭り的な物 | 第3章「踊らなかった広場」 |
| 武器・防具・道具・鉱石・呪い付き・怖い物 | 第4章「選ばれなかった坑道」 |
| 楽器・音・鐘・レコード系 | 第5章「歌えなかった塔」 |
| 没素材・ゴミ箱・不可分類・特大の物 | 漂着浜 / 原案の座（二度棄て・特大は座） |
| 上記以外のガラクタ | 自分の捨て場（未生成なら漂着浜の共同堆積） |

- 届き先での現れ方：**「誰かの宝物」として章内に配置**される（住人が拾う・風景になる・個別層で「◯◯が捨てたもの」と由来が見える）。
- **推理・伏線への供給**：「なぜこの物がここにあるか」を捨てた人・捨てた場所・由来から辿れる構造。マルチでは他人の捨て物を拾って本人に届ける遊びも生まれる（Issue #30 の推理構造と接続）。

## 7. 返礼経路：ゴミ箱＝ポスト（双方向）

ゴミ箱は片方向の捨て口でなく**双方向の投函口**になる：

- **届きもの**：自分のゴミ箱を開くと中に届き物がある。蓋の微かな動き・光で気づかせる（非言語導線、`09` §6）。
- 届きものの種類：
  1. **返信手紙**：記入済み本・署名つき書物を捨てると、向こうの「読む者」が応答を返す。**読まれなかった手紙の国（第2章）で、あなたの手紙は読まれる**——本機構の感動装置の中心でありつつ、手紙の内容は推理・ロアの素材として機能させる（感動は狙い撃ちしない方針と整合）。
  2. **住人便**：救った住人・村の住人が時折、拾得物・手紙・小さな実用品（記念品級）を届ける。救った住人が多いほど届く（関係性の報酬・変動要素として不定期に）。
  3. **誤配**：稀に「別の誰か宛の物」が届く漂流便（拾得物・ロア）。「自分宛でない物が届く」違和感＝考察材料とマルチでの話題。
  4. **共同箱への届きもの**：拾い人の村宛の届きものは共同ゴミ箱に集まり、誰が受け取るかのやりとり自体がマルチイベントになる。
- **頻度設計**：返礼は物語・関係性の報酬を中心とし、実用報酬ループにしない（護石式マラソン禁止の方針と整合。実用品は記念品級まで）。捨てた物への応答（手紙系・由来物）＋村の発展度＋変動要素で発生。

## 8. ゴミ箱自体の仕様（ティア構造）

拾得鍛錬の思想「捨てられた素材で作る」をゴミ箱自体にも適用：

| ティア | 名称（案） | できること | レシピ思想 |
|---|---|---|---|
| **T1** | 粗末なゴミ箱 | 物を捨てられる（国に届く）。自分は入れない・届きものは受け取れない | 序盤の廃材系素材（詳細レシピは Issue #15） |
| **T2** | しっかりしたゴミ箱 | **自分を棄てられる**（転移可能）。**届きものを受け取れる**（ポスト機能）。個別記憶の上限UP | 強化材＋没素材の組込み。「国に近い箱」になるほど届きが良くなる理屈づけ |
| **T3** | 名づけられたゴミ箱 | 捨て場が「あなたの場所」として定着度UP（景観が育つ・住人が覚える・章アフィニティの配達精度が上がる）。拡張案：名付け生物の転移に対応 | 没素材の強化＋名札の組込み（名付け＝物語化の一貫性） |

- **表示**：ワールド内で「◯◯のゴミ箱」と所有者が見える（ADR-0004 個別層）。
- **容量**：投入は即転送なので容量問題は表面化しない。個別記憶のみティアごとに上限を設ける（超過分は古い物から「流れ」が弱まる＝個別性が失われ集約漂着に変わる、等の graceful な縮退）。
- **破壊**：ゴミ箱を壊すと中身は全てその場で国へ転送される（壊した瞬間に中身が「国に落ちる」演出）。

## 9. マルチプレイ仕様（ADR-0004 との整合）

- **帰属の原則**：ゴミ箱は**設置者（所有者）**に紐付く。捨てた物は**投入した人**に紐付く（「あなたが捨てたもの」は捨てた人の個別記憶）。
- **捨て場**：投入者ごとに生成。他人のゴミ箱に入れた物は、入れた人の捨て場へ届く（箱は回線、荷物は送り主のもの）。
- **共同ゴミ箱**：村の共同箱は全員の捨て物が「共同の捨て場」（村の一角）に集まる。各人の由来は保持される。
- **他人の捨て場**：見学可。拾えるのは無主の漂着物のみ。**他人の捨て場の物は「◯◯の捨て物」として由来が残り**、拾うと「届ける/返す」行為が発生する（宝物ルール `docs/14` と整合：取れるが、取るとその物の物語が変わる）。他人のゴミ箱への帰還は不可——帰還は自分の捨て場 or 共同箱のみ。
- **他プレイヤーを棄てることはできない**（押し込み不可。者は自分で入る以外棄てられない）＝グリーフィング防止を明確化。

## 10. QoL運用との整合（消去目的使用を燃料にする設計）

- 消去目的で使うプレイヤーにとっても機能は正しい（入れた物は現実から消える）。**消え方の演出**（国へ落ちる音・微かな残響）で「消滅でなく移動」の感触だけを残す。
- ガラクタは集約漂着のみ（個別実体を持たないため表現・負荷とも軽い）。
- 捨て場の景観は種類×量で段階変化し、上限を超えると「生い茂る/整頓される」等の収束演出にする（無限に表示し続けない）。
- **「捨てた物があとで意味を持つ」構造**：QoL利用が後の自分に効いてくる（返ってくるのは罰ではなく物語）。図鑑の「あなたが捨てたもの」節（§11）が記録を保証するため、プレイヤーが忘れていても世界が覚えている。

## 11. イベント体系一覧（投入→現実応答→国着弾→後続）

| イベント | 現実側応答 | 国側の結果 |
|---|---|---|
| 常時投入 | 投入音・蓋の動き・かすれた残響（「届いた」感触の非言語フィードバック） | 対象格に応じた着弾 |
| 由来物の投入 | 同上 | 章アフィニティ配達・「誰かの宝物」として再配置・住人反応 |
| 手紙の投入 | 同上 | 「読む者」へ届き返信イベント起点 |
| 拾得物の投入（還す） | 同上 | 由来の場所/持ち主へ戻る。還した記録が残る |
| 自分を棄てる | 箱に沈む→転移演出 | 捨て場/漂着浜に打ち上げられる |
| ゴミ箱の投棄 | 同上 | 捨て場の生成/増築（初回はノミが「あんたの箱、届いたよ」と案内） |
| 二度棄て | 同上 | より深く流れる。極端な二度棄ては原案の座へ |
| 梱包物の投入 | 同上 | 届け物として開封者へ配達される |
| 累積 | — | 捨て場の景観変化・図鑑「あなたが捨てたもの」節の記録・住人の記憶セリフ（「あんたが捨てたあれ…」） |
| 住人の反応 | — | ガラクタ山→「物持ちだねぇ」/宝物→「こんな物まで…」/怖い物→「こ、これは…」/大きな物→「デカいのが届いたぞ」 |

**配信・切り抜き瞬間（`docs/17` §3 へ追加候補）**：「自分の捨て場を見つける」「他人の捨て場を覗く」「ゴミ箱を開けたら返事が届いている」「自分がゴミ箱に入る」「他人の箱から他人の捨て場に落ちる」「自分のゴミ山と対面する」。

## 12. 要ユーザー承認の決定点（推奨案つき）

| # | 決定点 | 推奨案 |
|---|---|---|
| D1 | 個別記憶の対象範囲 | 名付き・記入済み・エンチャ品・拾得物・梱包物・ゴミ箱・自分。ガラクタは集約漂着のみ |
| D2 | 自分を棄てる際の荷物 | **全持ち込み可**（実用往復路の差別化。喪失リスクは死亡/没腐側に残す） |
| D3 | 帰還口 | 自分の捨て場のゴミ箱＋村の共同箱の2系統（帰れない状態を作らない） |
| D4 | 他人の捨て場からの拾得 | 可能だが由来が残り「届ける/返す」行為が発生（宝物ルール準拠） |
| D5 | 名付け生物の転移（名札を付けた生き物→村の住人候補） | 採用するが**T3/拡張案**として Phase 1 検証対象に |
| D6 | 縁の地での「素手投棄」（ゴミ箱なしで物を捨てて届かせる） | **不採用**——ゴミ箱一本化で文法を明瞭に。縁の地は「太い回線」としてのみ扱う（投入検出をゴミ箱に限定した ADR-0003 の意図とも整合） |
| D7 | 返礼の実用報酬度 | 物語・関係性中心（実用品は記念品級まで。護石式禁止と整合） |
| D8 | 共同の捨て場の扱い | 共同箱は村設置型・共同の捨て場は村の一角として全員に開く |

## 13. 先行占有の確認（`docs/07` 運用ルール：各層で前例を洗う）

- QoLゴミ箱・捨て物回収の先行（Trashventory、Wandering Collector 等）は**ユーティリティのみ**で物語機構としては未占有（`docs/21` §3 確定済み）。
- 「届けた物への返信」系：手紙/郵便系MODはあるが「**捨てた物への返事がゴミ箱に届く**」機構は未占有。
- 「自分が入って転移するゴミ箱」：バニラの転移装置（エンダーチェスト類似含む）とは別物で先行なし。
- 本機構の未占有性は単一要素でなく、**「投入の文法 × 個別記憶 × 捨て場の実在 × 双方向の返礼」**の複合で担保される。
