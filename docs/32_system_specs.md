## 1. 持ち帰り/持ち帰れない物の境目ルール

### 1.1 基本原則（世界観と整合する文法）

**「拾い直された物だけが外に出られる」**。国のものは国のもの——だがプレイヤーが「拾う」という行為で新しい持ち主になると、その物は「棄てられた物」でなくなり、現実へ持ち帰れる。境目はアイテムの種類ではなく**「拾い直したかどうか」**で引く（法則④の実装形）。

### 1.2 持ち帰り可否の分類

| 区分 | 例 | 可否 | 理由 |
|---|---|---|---|
| **拾得物**（由来が確定し拾い直した物） | 没の素材・拾得装備・ロア断片・結末の欠片 | **可** | 拾い直し＝新しい持ち主がついた |
| **拾得の携行品に収めた物** | 未登録・未加工の収め物（生の没素材・未鑑定の拾得物・装飾品） | **器の容量分のみ可** | 携行品（`docs/14`）が「外へ出す資格」の器。**容量が効く対象は「未登録・未加工の収め物」に限る**——一度鑑定・登録（拾い直し完了）した拾得物は通常持ち物として自由に持ち出せる（案A：2026-09-27 承認——U1 #15。器は「未加工品の関税」の役割に確定）。**例外項（U1 #5 承認）**：名の残る部位（N-ITEM-027・名付き由来の部位）の持ち出しは**拾い直し完了（使用済み）になった物に限る**——04 §5 の領域外流出禁止と整合 |
| **汎用建材・大量資源** | 国の土・石・普通のブロック | **不可**（携行品にも入らない） | 国の風景を削り取る行為を防ぐ＋現実の経済バランスを守る |
| **生き物・住人** | 縁の民・住人・名付けた生物 | **不可**（出られない） | 「住人を連れ出す」は誘拐になる。名付け生物の転移は `docs/23` §8 準拠（同行のみ・連れ出し不可） |
| **没腐に汚染された物** | 没腐ブロック・呪いの残骸 | **不可**（浄化すれば可） | 没腐は世界の病。外に出せば広がる（理由を世界観に落とす） |

### 1.3 逆方向（現実→国）の持ち込み

- **持ち込み可**（`docs/23` §5.1）：装備・道具・食料・ゴミ箱資材などは自由に持ち込める。往復路の実用性のため制限しない
- 例外：二度棄て用のゴミ箱、梱包用の器は持ち込み可だが「入れると届く」ので実質「持ち込み＝捨てる準備」

### 1.4 設計意図

- 「これは持ち帰れるか？」の判断自体がゲームになる（拾い直す＝価値の再評価）
- 携行品の容量制限が「何を持ち帰るか」の選択を生む＝拾う行為の重みづけ
- 汎用資源の禁止で「国を削って現実を潤す」破壊的プレイを防ぐ（テーマ上も「捨てられたものを削る」のは本末転倒）

## 2. 死亡・没腐の喪失/回復ルール

### 2.1 死亡時（法則⑤「忘れられる」の実装）

| 項目 | 仕様 |
|---|---|
| 失われる物 | **携行中の未登録拾得物の一部**（拾得図鑑に未登録の分の25%、小数切捨・最大8個）＋携行品の中身 |
| 失われ方 | 死亡地点に「**没腐した遺留物**」として残る——その場所が小さく歪む演出 |
| 回収 | **可能**。死亡地点に戻れば遺留物を拾い直せる（取りに戻る＝死に学習の動機） |
| 既登録の拾得物 | **失われない**（図鑑に記録された物は「もうあなたの物」）。緊張感は「まだ記録されていない物」に集中させる |
| 装備・通常持ち物 | 失われない（クラフト品はあなたの物。失うのは「拾ったばかりの物」だけ） |

**設計意図**：死が「全ロスト」だと本作の「捨てる/拾う」主題と衝突し、怖さだけが残る。「忘れられる」＝一部が没腐に呑まれてその場に残る設計で、死を「恐怖」でなく「取り返しに行く物語」に変える。

### 2.2 リスポーン地点（優先順位）

1. **自分の捨て場**（生成済みならそこから再開——「あなたの場所に戻る」）
2. **漂着浜の共同堆積**（捨て場未生成の場合）
3. **拾い人の村**（村が成立していれば村のベッド的拠点——発展度で変わる）

**原則：帰れない状態を作らない**（`docs/23` §5.1 の宿題）。捨て場のゴミ箱が現実側で破壊・消失していても、村の共同ゴミ箱から必ず現実へ帰還できる。

### 2.3 没腐の定量化（個人単位の歪み度）

- **個人没腐度**：プレイヤーが持つ隠しカウンター（上限10）。死亡 +1、国への長期放置（現実側で一定時間国にいない）で逓増——**放置ティックは初回7日・次5日・以後3日毎に +1**（放置由来の増加は合計 +4 までで頭打ち——U4-3 承認・定数確定）
- **効果**：没腐度が高いほど国の敵が強化・拾得物の没腐リスク増。**閾値を超えると自分の捨て場が歪み始める**（自分の物が壊れていく演出——放置の対価を個人に見せる）。**閾値定数（U4-3 承認・確定）**：≥5 で警戒（中立モブが距離を取る・敵の微強化＋拾得物没腐リスク増）・**≥8 で敵対化**（環礁住人の敵対化条件と同値——docs/38 04 §2.4）
- **回復**：章の救出 −3・結末の記録（綴じ）−2・村への貢献 −1・**拾い人の村に滞在すると −1/10分（1滞在最大−3）**（村＝安息の地として機能）。**章クリア時は効果量をまとめて −5 として一括適用**——章クリア後の村滞在の清涼感を強調（U4-3 承認）
- **上限**：10（即死・理不尽を作らない範囲——死に学習のフェアさ優先・`docs/13` §3）

## 3. 招待状ゲートの厳密仕様（`docs/23` §5.0 の確定版）

### 3.1 発火条件（確定案——推奨 (a)＋フォールバック (b)）

| 条件 | 内容 |
|---|---|
| **主条件 (a)** | **初めて「由来のある物」を捨てた直後**——名付き品・記入済み本・条件付き拾得物等、世界が「意味のある物」として識別できるものを捨てると発火 |
| **フォールバック (b)** | (a) に該当せず累積投入が閾値（**64個＝1スタック分**）を超えた場合、次回開封時に発火。「捨て続ければ必ず届く」で取り零しを防ぐ |
| **発火演出** | ゴミ箱を開くと中に返礼がある（ポップ音＋ゴミ箱内に光るレシピカード）——「向こうから届いた」を体験させる |

**設計意図**：(a) を主にしたのは「意味のある物を捨てる→意味のある返事が来る」が文法上最も美しいため。偶然起きたように見えるのが重要（システムイベントに見えないこと）。

### 3.2 異物経由で先行訪問した場合の分岐

| 状況 | 対応 |
|---|---|
| 異物を見つけて先に国へ来た | 招待状は**届かない**（既に来た者として扱う）。代わりに漂着浜でノミが直接渡す——「もう来てたか。ならこれが要るだろ」と現地でデカいゴミ箱のレシピを渡す |
| 招待状入手後に異物を見つけた | 異物は「別の捨てられた地形」として機能（入れば国だが招待状の返礼ルートとは別物） |

### 3.3 マルチでの招待状

- **所有者の箱に届く**（自分のゴミ箱を捨てた者にだけ返礼が届く）。招待状は **1人1通**（個別層＝プレイヤーデータ）
- 他人が先に開けても中身は所有者にのみ見える（「あんた宛だ」とだけ出る）
- 後発加入者は先住者の招待状を横から「拾って読める」ようにしてもよい（配信の話題）

## 4. 異物チャンクの生成・導線仕様

### 4.1 生成ルール

| 項目 | 仕様 |
|---|---|
| 定義 | 「世界に捨てられた地形」——棄てが極まった場所に生まれる没になった地形の残滓（ADR-0005） |
| 発生頻度 | **ワールドあたり数箇所**（希少）。全プレイヤーに1つは必ず近場（スポーンから一定距離圏内）に生成される保証 |
| 生成場所 | 世界生成時にランダム配置＋**「棄てが極まった場所」に追加生成**される設計（長時間プレイで増える＝世界が捨てていく） |
| 大きさ | 数チャンク規模の異質地形（周囲と明確に異なる見た目——夜更け・色抜け・歪んだ構造） |

### 4.2 導線（発見の助け）

- **縁の羅針盤**（`docs/14`）：縁の地・異物を指すコンパス。捨て物を多く捨てるほど反応しやすくなる（棄てが極まる方角を指す世界観）。**入手時期＝序盤——現実側で最初の縁の地探索時に入手**（定常往復路の開通より前——U2 #15 承認）。**港風セット装備時は指し先に死亡時の没腐遺留物を追加**（U2 #7 承認——羅針盤連携の拡張）。**複数対象の指し分け（U1-Q4 承認・Issue #31）**：バニラのコンパス互換アイテムで針が最寄りの対象を指し、対象種別（縁の地・異物・港風セット時の没腐遺留物）は**「針の色＋針の形」または「音色＋字幕名」の複合**で識別する（単一チャネルの判別にしない・新規UI画面は作らない）
- **縁の地の発見導線（U2-B・U4-#4 承認・Issue #31）**：①縁の地（捨て場・廃村・棄てが極まった場所）は**スポーンから一定圏内に生成保証**（異物の圏内1箇所保証と同型）＋②視認は**造形一次**——「残っている構造物」（捨て物の集まり・枯れた形の遺構）で周囲と区別し、彩度低下「色が抜ける区画」は二次補助＋③縁の羅針盤は二次装置（入手前は視覚的手がかりのみで成立）。異物との差別化＝規模と没腐濃度（異物＝数チャンクの異質地形・危険、縁の地＝小規模・安全・素材あり）
- **異物の視認度基準（U1-Q5 承認・Issue #31）**：視認強度は「**気配〜示唆**」段階に固定し、ランドマーク級の明示にしない——遠望で「あるはずのないもの」が視界の端に映る程度＋近接時の軽いノイズ・かすれた昔の音（地形の異質性＝造形が一次、ノイズ・画面歪みは二次）。発見保証はスポーン圏内1箇所＋縁の羅針盤で担保（§4.1・上記）。発見型入口は押し付けない（片道の性質上、見つける行為自体が報酬）
- **見つけた時**：中に入ると国へ転移（**片道・持ち込み不安定**——装備の一部が届かない等の緊張感）。ゴミ箱経路との対比（制御可能な往復 vs 発見型の片道）
- **発見の意味**：異物経由で来ても捨て場は未生成。帰りは村の共同ゴミ箱or漂着浜を探す——「異物で来た者は捨て場を持たない」ことでゴミ箱の意義を逆に際立たせる

### 4.3 没腐との関係

異物の周囲は没腐が濃い（世界が捨てた地形は最も歪んでいる）。攻略報酬は高いが危険も大きい——**発見型入口は「無謀な近道」として機能**。

## 5. 灼熱の埋立て地からの帰還（`docs/23` §8.4 の宿題）

- **処理場で落とされた側**：灼熱の埋立て地に落ちる。死ではなく「処理された物として届いた」扱い
- **帰還口**：埋立て地内の「**処理口**」（焼却炉の逆流口）から現実へ戻れる——ただし**焦げ跡をつけて帰る**演出（無傷で帰れない軽いペナルティ。死ではなく「処理品としての記録」が残る）
- **ゴミ箱経由との違い**：処理場→埋立て地は「他人に捨てられた」特殊ルート。帰還は埋立て地→現実（直接）だが、往復には使えない（片道の処理路）

## 6. マルチプレイ細目（ADR-0004 の宿題の確定）

| 項目 | 確定案 |
|---|---|
| **結末の決裁** | **先着**（最初に「綴じる」動作をした者の結末が記録される）。ただし他者は「その結末を見届けた/書き換えようとした」として並記可能——相談を促す演出。**「殴る＝書き換える」ではない**——王への攻撃は結末の確定でなく戦闘開始のみで、結末を確定するのは綴じ動作の先着のみ（K7 承認）。戦闘転換点（椅子に坐る／頁を拾い切る）は**個人単位の戦闘離脱**——その者の戦闘のみ止まり綴じ画面へ移行できる。**頁全収集による勝利は世界の状態**で全員の戦闘を終わらせる（K3/K7 承認）。**綴じ画面の開閉・頁の帰還**：綴じ画面は閉じて再開可能・かすれた「拾う」項は**選択不可**（頁所持が選択の前提）・本文と選択は頁の所持者のみ解放・**手放された・所持者のいなくなった頁は座の境の元の場所に還る**（永久封印を防ぐ——K3 承認） |
| **ノミの同行・帰属** | **一人一ノミとして全章・戦闘中を含め常時同行**する演出NPC（HPなし・戦闘不参加）。各プレイヤーに自分のノミが随伴し、**名付け帰属は名を付けた本人のノミ**（K16 承認——第5章聞き手規則の前提。docs/15 §5・docs/25 §1 併記） |
| **宝箱・モブドロップ** | **個別層で全員分**——宝箱構成は開ける者ごとに独立抽選、モブドロップは参加者全員に別層で付与（欠片等の世界一意品を除く——U4-9 承認・「欠片以外全員分」の明文化。docs/38 04 §4.3） |
| **「誰が綴じたか」の表示** | 共有層で全員に表示（「◯◯が綴じた結末」）。個人の図鑑にも「私が関わった」記録が残る |
| **後発加入者の追いつき** | 済んだ章の断片は「**◯◯の手記の写し**」書物アイテムとして拾える（U2-N4 承認・Issue #28——先に進んだ者の手記の複写頁・表題に「◯◯の手記より」の由来付き・初見の場所での発見演出は再生しない。読み物として追体験）。未攻略章は共同で攻略可能 |
| **村の発展** | 共有。誰かが救った住人は全員の村に現れる |
| **「あなたが捨てたもの」** | 個別層（所有者紐付け・ADR-0003）。他人の捨て物は見えるが「◯◯の物」として表示。**表示粒度（U4-#9 承認・Issue #31）**：由来表示はホバー/接近時を既定とし常時表示はコンフィグ（Issue #34 へ）。かすれた項（頁の所持者のみ読める項）は**全員に存在のみ常時表示**（隠さない）だが本文は所持者のみ（K3 承認どおり） |
| **環境手がかりの共有（U2-G 承認・Issue #31）** | 環境一次導線（定点・勾配・ランドマーク）は**共有層**で全員に同じ見え方を保証し、個別層の差分は表示のみ——迷った者は「先に進んだ者が物理的に導く」構造を基本とする（他者の拾得済み定点は残り続け、進捗差で導線が消えないよう設計。詳細は docs/45 02 §4.2・04 M-1） |

## 9. 外部連携・流通要件（Issue #22 D-1・D-4 承認）

- **JEI/EMI 連携（D-1・要件化）**：通常レシピは JSON で JEI/EMI に自動表示、独自機構（拾得鍛錬台・ゴミ箱経路等）は JEI カテゴリの実装対象、意図的に隠すレシピ（招待状・没の由来品等）は表示制御の設計論点として管理（Issue #8 側の実装検討へ引き継ぎ——docs/14 §5 併記）
