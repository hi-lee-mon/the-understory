## 1. 持ち帰り/持ち帰れない物の境目ルール

### 1.1 基本原則（世界観と整合する文法）

**「拾い直された物だけが外に出られる」**。国のものは国のもの——だがプレイヤーが「拾う」という行為で新しい持ち主になると、その物は「棄てられた物」でなくなり、現実へ持ち帰れる。境目はアイテムの種類ではなく**「拾い直したかどうか」**で引く（法則④の実装形）。

### 1.2 持ち帰り可否の分類

| 区分 | 例 | 可否 | 理由 |
|---|---|---|---|
| **拾得物**（由来が確定し拾い直した物） | 没の素材・拾得装備・ロア断片・結末の欠片 | **可** | 拾い直し＝新しい持ち主がついた |
| **拾得の携行品に収めた物** | 未加工の没素材・装飾品 | **器の容量分のみ可** | 携行品（`docs/14`）が「外へ出す資格」の器。容量がゲーム上の制限になる |
| **汎用建材・大量資源** | 国の土・石・普通のブロック | **不可**（携行品にも入らない） | 国の風景を削り取る行為を防ぐ＋現実の経済バランスを守る |
| **生き物・住人** | 縁の民・住人・名付けた生物 | **不可**（出られない） | 「住人を連れ出す」は誘拐になる。名付け生物の転移は `docs/23` §8 準拠（同行のみ・連れ出し不可） |
| **没腐に汚染された物** | 没腐ブロック・呪いの残骸 | **不可**（浄化すれば可） | 没腐は世界の病。外に出せば広がる（理由を世界観に落とす） |

### 1.3 逆方向（現実→国）の持ち込み

- **持ち込み可**（`docs/23` §5.1）：装備・道具・食料・ゴミ箱資材などは自由に持ち込める。往復路の実用性のため制限しない
- 例外：二度棄て用のゴミ箱、梱包用の器は持ち込み可だが「入れると届く」ので実質「持ち込み＝捨てる準備」

### 1.4 設計意図

- 「これは持ち帰れるか？」の判断自体がゲームになる（拾い直す＝価値の再評価）
- 携行品の容量制限が「何を持ち帰るか」の選択を生む＝拾う行為の重みづけ
- 汎用資源の禁止で「国を削って現実を潤す」破壊的プレイを防ぐ（テーマ上も「捨てられたものを削る」のは本末転倒）

## 2. 死亡・没腐の喪失/回復ルール

### 2.1 死亡時（法則⑤「忘れられる」の実装）

| 項目 | 仕様 |
|---|---|
| 失われる物 | **携行中の未登録拾得物の一部**（拾得図鑑に未登録の分の25%、小数切捨・最大8個）＋携行品の中身 |
| 失われ方 | 死亡地点に「**没腐した遺留物**」として残る——その場所が小さく歪む演出 |
| 回収 | **可能**。死亡地点に戻れば遺留物を拾い直せる（取りに戻る＝死に学習の動機） |
| 既登録の拾得物 | **失われない**（図鑑に記録された物は「もうあなたの物」）。緊張感は「まだ記録されていない物」に集中させる |
| 装備・通常持ち物 | 失われない（クラフト品はあなたの物。失うのは「拾ったばかりの物」だけ） |

**設計意図**：死が「全ロスト」だと本作の「捨てる/拾う」主題と衝突し、怖さだけが残る。「忘れられる」＝一部が没腐に呑まれてその場に残る設計で、死を「恐怖」でなく「取り返しに行く物語」に変える。

### 2.2 リスポーン地点（優先順位）

1. **自分の捨て場**（生成済みならそこから再開——「あなたの場所に戻る」）
2. **漂着浜の共同堆積**（捨て場未生成の場合）
3. **拾い人の村**（村が成立していれば村のベッド的拠点——発展度で変わる）

**原則：帰れない状態を作らない**（`docs/23` §5.1 の宿題）。捨て場のゴミ箱が現実側で破壊・消失していても、村の共同ゴミ箱から必ず現実へ帰還できる。

### 2.3 没腐の定量化（個人単位の歪み度）

- **個人没腐度**：プレイヤーが持つ隠しカウンター。死亡 +1、国への長期放置（現実側で一定時間国にいない）で逓増
- **効果**：没腐度が高いほど国の敵が強化・拾得物の没腐リスク増。**閾値を超えると自分の捨て場が歪み始める**（自分の物が壊れていく演出——放置の対価を個人に見せる）
- **回復**：章の救出・結末の記録・村への貢献で減少。**拾い人の村に滞在すると徐々に回復**（村＝安息の地として機能）
- **上限**：即死・理不尽を作らない範囲で設計（死に学習のフェアさ優先・`docs/13` §3）

## 3. 招待状ゲートの厳密仕様（`docs/23` §5.0 の確定版）

### 3.1 発火条件（確定案——推奨 (a)＋フォールバック (b)）

| 条件 | 内容 |
|---|---|
| **主条件 (a)** | **初めて「由来のある物」を捨てた直後**——名付き品・記入済み本・条件付き拾得物等、世界が「意味のある物」として識別できるものを捨てると発火 |
| **フォールバック (b)** | (a) に該当せず累積投入が閾値（**64個＝1スタック分**）を超えた場合、次回開封時に発火。「捨て続ければ必ず届く」で取り零しを防ぐ |
| **発火演出** | ゴミ箱を開くと中に返礼がある（ポップ音＋ゴミ箱内に光るレシピカード）——「向こうから届いた」を体験させる |

**設計意図**：(a) を主にしたのは「意味のある物を捨てる→意味のある返事が来る」が文法上最も美しいため。偶然起きたように見えるのが重要（システムイベントに見えないこと）。

### 3.2 異物経由で先行訪問した場合の分岐

| 状況 | 対応 |
|---|---|
| 異物を見つけて先に国へ来た | 招待状は**届かない**（既に来た者として扱う）。代わりに漂着浜でノミが直接渡す——「もう来てたか。ならこれが要るだろ」と現地でデカいゴミ箱のレシピを渡す |
| 招待状入手後に異物を見つけた | 異物は「別の捨てられた地形」として機能（入れば国だが招待状の返礼ルートとは別物） |

### 3.3 マルチでの招待状

- **所有者の箱に届く**（自分のゴミ箱を捨てた者にだけ返礼が届く）。招待状は **1人1通**（個別層＝プレイヤーデータ）
- 他人が先に開けても中身は所有者にのみ見える（「あんた宛だ」とだけ出る）
- 後発加入者は先住者の招待状を横から「拾って読める」ようにしてもよい（配信の話題）

## 4. 異物チャンクの生成・導線仕様

### 4.1 生成ルール

| 項目 | 仕様 |
|---|---|
| 定義 | 「世界に捨てられた地形」——棄てが極まった場所に生まれる没になった地形の残滓（ADR-0005） |
| 発生頻度 | **ワールドあたり数箇所**（希少）。全プレイヤーに1つは必ず近場（スポーンから一定距離圏内）に生成される保証 |
| 生成場所 | 世界生成時にランダム配置＋**「棄てが極まった場所」に追加生成**される設計（長時間プレイで増える＝世界が捨てていく） |
| 大きさ | 数チャンク規模の異質地形（周囲と明確に異なる見た目——夜更け・色抜け・歪んだ構造） |

### 4.2 導線（発見の助け）

- **縁の羅針盤**（`docs/14`）：縁の地・異物を指すコンパス。捨て物を多く捨てるほど反応しやすくなる（棄てが極まる方角を指す世界観）
- **見つけた時**：中に入ると国へ転移（**片道・持ち込み不安定**——装備の一部が届かない等の緊張感）。ゴミ箱経路との対比（制御可能な往復 vs 発見型の片道）
- **発見の意味**：異物経由で来ても捨て場は未生成。帰りは村の共同ゴミ箱or漂着浜を探す——「異物で来た者は捨て場を持たない」ことでゴミ箱の意義を逆に際立たせる

### 4.3 没腐との関係

異物の周囲は没腐が濃い（世界が捨てた地形は最も歪んでいる）。攻略報酬は高いが危険も大きい——**発見型入口は「無謀な近道」として機能**。

## 5. 灼熱の埋立て地からの帰還（`docs/23` §8.4 の宿題）

- **処理場で落とされた側**：灼熱の埋立て地に落ちる。死ではなく「処理された物として届いた」扱い
- **帰還口**：埋立て地内の「**処理口**」（焼却炉の逆流口）から現実へ戻れる——ただし**焦げ跡をつけて帰る**演出（無傷で帰れない軽いペナルティ。死ではなく「処理品としての記録」が残る）
- **ゴミ箱経由との違い**：処理場→埋立て地は「他人に捨てられた」特殊ルート。帰還は埋立て地→現実（直接）だが、往復には使えない（片道の処理路）

## 6. マルチプレイ細目（ADR-0004 の宿題の確定）

| 項目 | 確定案 |
|---|---|
| **結末の決裁** | **先着**（最初に「綴じる」動作をした者の結末が記録される）。ただし他者は「その結末を見届けた/書き換えようとした」として並記可能——相談を促す演出 |
| **「誰が綴じたか」の表示** | 共有層で全員に表示（「◯◯が綴じた結末」）。個人の図鑑にも「私が関わった」記録が残る |
| **後発加入者の追いつき** | 済んだ章の断片は「誰かが綴じた記録」として拾える（読み物として追体験）。未攻略章は共同で攻略可能 |
| **村の発展** | 共有。誰かが救った住人は全員の村に現れる |
| **「あなたが捨てたもの」** | 個別層（所有者紐付け・ADR-0003）。他人の捨て物は見えるが「◯◯の物」として表示 |

## 7. 章進行との接続（この仕様が効く場面）

- **持ち帰り境目** → 各章の拾得物設計・携行品の入手タイミング（第1章で器を得る等）
