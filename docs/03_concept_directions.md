# 設計書 03：世界観・ストーリー・アイテムの方向性案

「第2の黄昏の森」＝**一貫した世界観を持つ新次元＋進行＋ボス＋物語**。以下4案はいずれも調査の設計原則（docs/01）を満たすよう作られた候補。ユーザーに方向を選んでもらい、採用案を次フェーズで詳細設計する。

## 評価基準

1. **独自性** — 既存MODと差別化できるか
2. **ストーリー深度** — 重厚な物語を載せられるか
3. **アクション適性** — ボス・戦闘が映えるか
4. **クラフト適性** — 世界観とクラフトが有機的に結びつくか
5. **配信映え** — 切り抜き・章構造・マスコット・マルチ適性
6. **実装リスク** — MCの技術的実現性

---

## 案A：忘れられた物語の国 — *The Unwritten*（推奨案）

### コンセプト
「書かれなかった結末」「失われた物語」が流れ着く次元。世界中の**未完成の物語**が実在の土地として漂着している国。プレイヤーは「語り部」として各物語に介入し、失われた結末を書き換える。

### 導入（ポータル儀式）
- 地上で見つかる**「空白の本」**。夜に焚き火を囲み、本に「自分の名前」を記して火にくべる → 灰が星屑となって舞い上がり、**「語り部の招き」**と共に次元へ落ちる。
- 儀式的・物語的で配信映え。「名前を書く」はVTuber本人が物語に入る演出。

### 世界構造（章立て）
各バイオーム＝**一つの「未完の物語」**。物語の舞台がそのまま土地・モブ・ボスになる。

- **第1章「赤ずきんの森（狼が月を食べた話）」**: 常夜の森。赤いずきんの村跡。ボスは「月を喰らった狼」——月の欠片を集めて夜を制する戦い。
- **第2章「海の泡の城（人魚が帰れなかった海）」**: 沈んだ真珠の城。酸素と光を管理しながら潜る水中城。
- **第3章「灰被りの舞踏会（踊り続ける姫の話）」**: 時が止まったガラスの宮殿。音楽と拍子が仕掛けになるリズムボス。
- **第4章「巨人の豆の国（空に棄てられた庭）」**: 天に伸びる枯れた豆の木。浮遊する庭の遺跡と墜落の恐怖。
- **終章「最初の物語」**: すべての物語が書かれる前の「白紙」の世界。黒幕＝「物語を書き損じた最初の語り部」。

### ストーリー骨子（重厚）
- 世界のルール：**「物語は結末を得られなければ、その舞台と登場人物はこの次元に囚われ、歪んで魔物化する」**。
- プレイヤーは各章で「結末の欠片」を集め、その物語に**結末を書き込む**ことでエリアを解放・浄化する。
- 黒幕「最初の語り部」は、自分の物語（＝世界を失った物語）の結末を諦め、すべての物語を未完に止めようとしている。
- テーマ：**「終わらない物語より、終わらせる勇気」**。配信者が「この物語の結末を書く」のは本人——伏線をそのまま配信の章タイトルに使える。

### 同行NPC（マスコット）
- **「頁の妖精 / ページウィスプ」**: 燃え残った本の頁が蝶になった精霊。プレイヤーに随行し、収集した「結末の欠片」を本に綴じてくれる。プレイヤーが名付け・会話（簡易反応）できる。
- 各章に「囚われた登場人物」（赤ずきんの老婆、人魚姫、灰被りの召使い等）がいて、救出で拠点に移住→拠点が「救った物語のキャラたちの村」として発展していく（関係性・拠点成長の供給）。

### アイテム／クラフト方向性
- **「結末の欠片」**: 各章の探索・ボスで得る。集めて本に綴じるとエリア浄化＋固有報酬。
- **「語り部の筆記具」**: クラフトの主軸。「言葉」を素材として鍛える（「勇気の言葉」「哀しみの言葉」等→装備やギミックのエンチャント）。
- **物語由来の固有道具**: 例「狼の月齢の爪」（夜に強い武器）、「人魚の泡沫」（水中呼吸＋泡の盾）、「ガラスの踵」（踏み外しで地形破壊する踏み技）、「豆の木の杖」（伸縮足場・鉤）。
- **拠点クラフト**: 「書見台」で収集物語を読み返し、新しい「言葉」を抽出して装備に織り込む。

### 配信映えポイント
- 「今日は人魚編！」と章宣言しやすい完全な章構造。
- 各章の美術が全く違う（森/海/宮殿/空）→毎配信でサムネが変わる。
- 「物語の結末を自分で書く」は配信の物語と重なる（自分＝語り部）。
- 頁の妖精への名付け・会話が定番ネタ化する余地。

### リスク
- 「物語を書き換える」システムのゲーム実装に抽象度がある（実質は「欠片集め＋浄化イベント」で十分実装可能に設計）。
- テキスト/ロア量が大きい → 英日ローカライズ工数。

## 案B：真夜中の遊園地 — *The Midnight Carnival*

### コンセプト
100年間、一度も開園したことがないのに**夜ごと灯りが点る遊園地次元**。歓声と音楽は流れているが客はいない。プレイヤーは迷い込んだ「最初の客」として、園の仕掛けと「園長」の秘密を解く。

### 導入
- 森で見つかる**古びた入場チケット**。深夜0時に空を見上げてチケットを掲げると、観覧車の光が夜空に回転し、それに手が届くようになる→掴まって次元へ。

### 世界構造（アトラクション＝ダンジョン）
- **「メリーゴーラウンドの夢魔」**: 永遠に回り続ける木馬の円盤、ボスは回転を操る「回転木馬の王」。
- **「鏡の館」**: 自分の姿が敵になる鏡像ボス。
- **「絶叫の果て（コースター）」**: 落下と加速を使う移動ボス戦。
- **「お化け屋敷」**: 恐怖ギミックと灯り管理。
- **終章「園長室の観覧車の頂上」**: 全園を見渡す場所で黒幕と対峙。

### ストーリー骨子
- 園は「子供たちの『楽しかった』という記憶だけを集めて作られた」世界。客がいないのに動いているのは、記憶が客の代わりをしているから。
- 園長は「楽しさを永遠に保存するために時間を止めた」元持ち主。プレイヤーは各アトラクションの記憶を解放していく。
- テーマ：**「保存された楽しさは、本物の楽しさではない」**。

### 同行NPC
- **「ピエロの案内人」**: 道化姿の案内人。怖いはずなのに憎めない言動のマスコット。配信での掛け合い・いじられ役に最適。

### アイテム／クラフト
- **「アトラクションの鍵」**: 各アトラクション攻略で入手、次アトラクション解放。
- **「記憶のキャンディ」**「綿菓子の雲」等の食料系クラフト（バフ食）。
- 乗り物系ギミック：コースターを実際に組んで走れる（Create風の「動く楽しさ」）。

### 配信映え
- 最も「映える」色彩と造形（ネオン、回転灯、夜の遊園地）。サムネが強い。
- 「怖いのに楽しい」の温度感がVTuberの反応を引きやすい。
- アトラクション単位で配信回が区切れる。

### リスク
- 「遊園地」は建築・ギミック密度が高く、制作コストが最も重い。
- ホラー寄りの演出はバランス調整が必要。

## 案C：夢境 — *The Oneiric Veil*（夢と悪夢の二層世界）

### コンセプト
ベッドで眠ることで入る**夢の次元**。同じ場所が「美しい夢」と「悪夢」の二層を持ち、眠り直すたびに切り替わる。プレイヤーは「明晰夢（ルシッドドリーム）」を習得していく存在として、夢の中の「眠れない者たち」の物語を追う。

### 導入
- 「明晰夢の枕」をクラフト（特殊素材）して眠ると夢境へ。起きると持ち帰れるもの/持ち帰れないものがある（持ち帰り＝夢の「記憶」資源）。

### 世界構造（二層制）
- 同一エリアが「夢層（甘美・安全・資源）」と「悪夢層（歪み・敵・深層ロア）」を持ち、**意識レベル**で切替。
- 「深く眠るほど真実に近づく」——層を深めるほど物語が怖く・深くなる構造。

### ストーリー骨子
- 夢境は「眠り続けた人々の夢が蓄積した世界」。かつて「夢見王」が夢を統べていたが、王が悪夢に呑まれて以来、夢は秩序を失った。
- プレイヤーは各層で「眠れない者」（悪夢に囚われた登場人物）を目覚めさせ、夢見王の物語を解く。
- テーマ：**「眠ることは、逃げることか、向き合うことか」**。

### アイテム／クラフト
- **「明晰夢ゲージ」**: 夢内の行動リソース。現実で集めた素材を夢の中で「想起クラフト」する。
- **「悪夢の素材」**: 悪夢層でのみ取れる希少素材→最強装備の素。
- 夢特有の道具：「現実を疑う鐘」（悪夢層で真実を暴く）、「夢の縫い針」（層の継ぎ目を縫ってワープ）。

### 配信映え
- 「寝る→起きたら別世界」の反復がリズムを生む。
- 夢/悪夢の劇的な見た目差（美しい→不気味）が切り抜き向き。

### リスク
- 二層世界のワールド生成が最も技術的に重い。
- 「持ち帰れるもの/持ち帰れないもの」ルールは説明コストが高い。

## 案D：時喰いの都 — *Chronovore*（止まった時の中の王国）

### コンセプト
**「時間」そのものを喰らう怪物**に呑まれた王国。都のあちこちで時間が止まり・巻き戻り・加速している。プレイヤーは「時の欠片」を操り、止まった王国の「最後の一日」の真相を追う。

### 世界構造
- 都の各区画で**時間の法則が違う**（静止区画、ループ区画、加速区画、逆行区画）。
- パズルと戦闘に時間操作を組み込む（静止中の敵の攻撃軌道を読む等）。

### ストーリー骨子
- 王国は「永遠の今日」を願った王のせいで時喰いに呑まれた。王は「大切な一日」を永遠に繰り返そうとした。
- テーマ：**「永遠は救いではない」**。

### リスク
- 時間操作の実装は**最高難度**（敵AI・世界状態・物理の同期）。技術検証が必須。野心最大だが実現リスクも最大。

## 推奨

**案A「忘れられた物語の国」**を第一候補に推す：

- 「物語」は黄昏の森の「storybook感」を最も自然に継承しつつ、TFが持たない「明示的な物語構造・キャラ・結末」を差分として打ち出せる。
- 章＝物語＝配信回という構造が、ターゲットのシリーズ配信に直結。
- 「物語を書き換える」はシステム上は「欠片収集＋浄化イベント」に分解可能で、実装リスクを制御できる。
- クラフトの主軸（言葉を鍛える・結末を綴じる）が世界観と一体化し、「クラフトもちろんあり」の要件を満たす。

**次ステップ**：ユーザーにA〜D（または合成）を選んでもらい、採用案の詳細設計書（世界設定書・章別仕様・ボス仕様・アイテム/クラフト表・進行表・技術検証計画）を作成する。
