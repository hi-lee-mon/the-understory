# 06_Phase 0 レビュー報告：調査の十分性と方向性の再検証

> 依頼：「調査が本当に足りているか」「方向性として面白く作れているか」を深い思考で再検証。
> 対象：docs/01（面白さ調査）、02（MOD市場）、03（方向性4案）、04（再調査と決定）、ADR-0001/0002、および展開済み設計書（10〜20, 50）。
> 判定基準：blocker（先に閉じるべき前提）/ major（重要な穴・緊張）/ minor（改善余地）。

---

## 0. 結論（先に）

**方向性（案E＝The Understory）は強く、採用を支持する。** ただし、その強さの根拠は当初の調査資料には書かれていない事実にある——「没コンテンツを実現する」テーゼは市場で既に証明済み（Deeper and Darker 約8760万DL）であり、本作の真の武器は「あなたが捨てたものがここにいる」という署名メカニクスである。

**調査は「方向を選ぶ」には足りたが、「採用案を検証する」には不十分だった。** 04の再調査は案C・案Dの先行占有だけを確認し、採用した案E自身の先行占有チェックを行っていない（結果、部分的な先行者が存在した）。また差別化の柱である感情設計・流通経路・署名演出の技術前提の3領域が未調査。

**設計の骨格は正しいが、2つの決定フォークが未解決のまま章仕様が深化している。** この2点は章詳細設計より先に閉じるべき前提である。

---

## 1. 調査の十分性レビュー（01/02/04への指摘）

### 1-1. 妥当だった部分（評価）

- **01の設計原則12箇条**（SDT/Flow/Bartle/Juice/変動報酬/未完コレクション/低床高天井/失敗可視性/創発/クリップ性/章構造/マスコット）は方向性の品質評価軸として機能しており、以降の全設計書がこの軸で自己審査できる構造は正しい。
- **02のTF分解**（世界のアイデンティティ・儀式・ボスゲート・手作り構造物・新動詞報酬・環境物語）は正確で、「弱みを差分にする」戦略構図は妥当。
- **技術選定**（NeoForge / MC 1.21.1 / Java 21）は妥当。Iris・SodiumはNeoForge 1.21.1を公式サポート済みであり、ADR-0002のシェーダー共存前提は実際に成立する（確認済み）。
- **04のanomaly系バイラル分析**（Man From The Fog 約2200万DL、From The Fog、The Broken Script）は正しい潮流の捕捉。

### 1-2. 見つかった穴（major）

#### M1. 案Eの先行占有チェックが未実施だった
04はC（夢）とD（時間）の先行MODを調べて却下したが、**採用したE自身には同じ検査をしていない**。実際には：

| 先行例 | 内容 | 意味 |
|---|---|---|
| **Deeper and Darker**（約8760万DL） | Mojangが没にした「Warden次元」構想をOtherside次元として実現 | 「没コンテンツを実現する」テーゼの**市場検証済み**＝Eの正当性を強める証拠 |
| **Rediscovered** | 没コンテンツの実装MOD。**Skylands次元**（没になった空次元案）＋Far Lands＋豚の社会 | 「捨てられたものの次元」に**部分的に先行占有** |
| **Lost Chapters** | Moobloom等の落選モブを実装 | 没モブ復刻の先行例（04の「未作」主張の修正が必要） |
| **Aether: Lost Content** | Aetherの没コンテンツを復刻するアドオン | 同コンセプトの存在 |

**影響**：Eの採用自体は覆らない（むしろD&Dが市場証拠を与える）が、ドキュメントの「物語駆動の次元MODは未占有」という主張は**「物語＋没コンテンツ＋双方向往来の複合が未占有」**に修正すべき。個々の要素には先行者がいる。（→ Issue #20）

#### M2. 現代の次元MOD先例層が調査にない
02は2011〜2019年のレジェンド級（TF/Create/Alex's Mobs/Botania/Aether）＋Cataclysmを分析したが、本作の直接的な先輩にあたる世代が抜けている：

- **The Betweenlands** — 「雰囲気＋物語重視の次元MOD」として本作に最も近い先行。1.12.2→1.21の移植に多年を要しており、**次元MODの真のコストは設計ではなく保守である**という教訓の供給源。
- **Alex's Caves**（約3000万DL、1.20.1） — オーバーワールドに高テーマ性のゾーンを注入する建築先例。「異物チャンク」「縁の地」はまさにこの型で、生成方式・パフォーマンス・他MODとの共存の実践例になる。
- **Stellarity / The Bumblezone / BetterEnd・Nether / Undergarden / End Remastered系** — 1.19〜1.21世代の次元系コンテンツ。「1.21.xで新次元の大型新作が少ない」は半分正しいが、空席は「誰も挑戦していない」ではなく**「維持困難」という意味でもある**。その事実はスコープ設計に効く。（→ Issue #20）

#### M5. 感情設計・選択設計の調査がない
本作の差別化は「面白さ」ではなく**「哀愁・愛着・選択の重さ」**だが、01の枠組み（SDT/Flow/Bartle）は動機理論であり、感情を設計する方法論を持たない。ベンチマーク（Omori / UNDERTALE / MOTHER系の「可愛い×不気味×哀愁」ブレンド、選択に重さを与える機構、同行キャラへの愛着形成）の調査が必要。（→ Issue #21）

#### M6. 流通・エコシステムの調査がない
「配信者に届くか」は本作の成否の分岐点だが未調査：
- **JEI/EMI連携**：拾得鍛錬がクラフト主体である以上、レシピがJEIに表示されないMODは実質的に遊べない。設計要件として必須。
- **Patchouli**：ゲーム内書物MODの標準であり、「書物・頁・綴じ目」のデザイン言語と完全に一致。図鑑・ロア・ガイドの実装器。
- **modpack経路**：MODプレイの大半はパック経由。収録されるには config 整備・性能予算・依存ポリシーが条件になる。
- **配信者の実経路**：02が挙げた実績（ぶいきゃす等）は「MOD入りカスタムサーバー/イベント」であり、単体MOD遊びではない。届け方の設計が異なる。（→ Issue #22）

#### M7. anomaly系のメカニクス抽出が浅い
MFTF/Broken Scriptがバイラルした機構は「**自分の世界に不穏なものが存在し続ける**」＋予測不能性＋ARG的外部化（解読するコミュニティ）である。現設計は異物を「一度きりの扉」としてしか使っていない。縁の地・幻想文字（解読可能な暗号にすればARGレイヤーになる）など、移植可能な資産が残っている。（→ Issue #22・#17 に反映候補）

#### M8. 署名演出の技術前提が未検証のまま
以下は設計の中核だが実現性が脚注すらない（詳細は Issue #25）：per-player異物可視性・個別化アイテム・「色を取り戻す」バイオーム再色付け・「世界が壊れる」ポストFX×Iris共存・ベッド転移の持ち込みルール・和文カスタムフォントの製作量・GeckoLib基盤。

### 1-3. その他（minor）

- **m4.** 調査数値（DL数等）に出典・時点がなく再検証できない。今後の調査書は出典を添える。
- **m6.** 設計原則12箇条はすべて「最大化すべき正の規準」であり、原則同士が衝突したとき（著者の物語 vs 自律性、Juice vs シェーダー互換）に仲裁できない。**優先順位/アンチゴールの明記**を推奨。

## 2. 方向性の検証（面白く作れているか）

### 2-1. 強い点（採用を支持する理由）

1. **テーマの統一性が稀有**：「棄てられる」一語が、世界観（棄てられたものの国）・メカニクス（拾得=拾う・鑑る・鍛える）・感情（没への共感）・配信フック（異物発見・没モブ話題）の4層を同時に説明する。
2. **署名メカニクスの潜在力**：「あなたが捨てたものがここにいる」は、プレイヤー個別の行為が物語になる**手続き的パーソナル物語**。実現できれば本作の最大武器。
3. **双方向往来**：TFの一方通行に対する構造的差分で、「現実で捨てたものが届く」という往復は世界観を日常まで侵食させる。
4. **市場検証済みフックの複合**：anomaly（MFTF級のバイラル）×没コンテンツ郷愁（D&D級の実績）×「削除要素」動画ジャンルの定番性。
5. **黒幕の設計**：「最初に棄てられたもの＝世界の原案」は実在するMojang没案（旧Sky Dimension構想）と響き合い、「知ってるものが実在する」感を生む（ただしRediscoveredのSkylandsと差別化要——「原案=設計文書の人格化」を推す）。
6. **Copper Golemの一件**：2025年に落選モブのCopper Golemが正式採用された。「捨てられても拾われることがある」は本作テーマの現実的裏付けとして広報・ロアに使える。

### 2-2. 脆弱点

#### blocker

- **B1. 「あなたが捨てたもの」機構が未定義のまま**：「ベッド儀式で供える」（明示・実装容易）と「捨てた物が勝手に出現する」（暗黙・感動最大だがトラッキングは困難でマルチで破綻）の2機構が混在している。本作の感情の山を支える機構であり、章詳細仕様より先に決定が必要。（→ Issue #18）
- **B2. ストーリー状態モデル未決**：結末・没腐・村発展を「ワールド共有」で持つか「プレイヤー個別」で持つか。共有ワールドでの「誰の結末か」はマルチの根本問題で、ADR（セーブ/同期）・マルチ設計・全章仕様をブロックしている。（→ Issue #19）

#### major

- **M3. 感情レンジの単調さ**：全5章が「待つ/届かない/中止/選ばれない/歌えない」＝哀愁一辺倒。入口がanomaly的な恐怖を約束する一方、中身に恐怖章がない。配信の反応レンジと物語の起伏の両方を削る。「愛されて壊れたもの」「恐れられて捨てられたもの」等、棄てられた理由のバリエーションで感情を拡張すべき。（→ Issue #23）
- **M4. テーマと報酬ループの矛盾**：「大切にする」がテーマなのに、拾得鍛錬は「全部拾って最強装備」が最適解＝プレイヤーは国を掠奪する。「拾う」に鑑定層（本来の姿が見える/見極める楽しさ）や「取らない」選択の価値を設計したい。（→ Issue #24）
- **M9. 自律性・探索密度の薄さ**：線形の環礁列のみで、TF型ゲートの背後にあるオープン探索層がない。任意の小島・隠し環礁・章の順序自由度・環礁内の密度設計が必要。（→ Issue #24）

#### minor

- **m1.** 結末の二択（書き換える/見届ける）を5回繰り返すと形式化する。第4章の「名を与える」のような選択肢の型自体の多様化を。
- **m3.** 低スキル配信者への難度救済（アシスト/設定）がない。Cataclysm級の難度は視聴者層の一部を締め出す。
- **m5.** ベッド儀式=自由な転移手段は「ボス戦からの無料脱出ハッチ」になりうる。ルール化が必要。
- **m7.** 「異物は発見者にしか見えない」演出は技術困難。「全員に見えるが初接触で消滅する」にすれば「一期一会」を物理的に成立させられる（要検討、Issue #18/#25と連動）。

## 3. 総合判定

| 問い | 判定 |
|---|---|
| 調査は足りていたか | **方向選択には十分、採用案の検証には不足**（Eの先行占有・現代先例・感情設計・流通・技術前提が抜けている） |
| 方向性は面白いか | **面白い。5案中最強で、採用は正当** |
| 設計はこのまま進めていいか | **B1/B2の決定フォークを閉じてから** 章詳細仕様に進むべき |

**推奨アクション**：Issue #18・#19（決定フォーク）→ #20〜#22（追加調査）→ #23〜#24（設計修正）→ #25（技術検証拡張）の順。これらが閉じるまで Issue #14（各章詳細プロット）以降の深化は保留が安全。
