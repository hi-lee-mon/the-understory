## 権威と重複の解消（横断監査の記録）

- **予告頁の綴じ先＝拾得図鑑に統一**（ノミの綴じ役——docs/36 F-NOMI-05・34/06 §7.3）。拾い人の手記側には再読用の索引のみが残り、「綴じ」の主語は全書で図鑑に固定。
- **Patchouli 採用時の器割当は 02 §4.4 表を正とする**：拾得図鑑＝Patchouli Book、拾い人の手記＝自前書物器（形式別ファクシミリの表現幅のため Patchouli 標準頁は割り当てない）。D-2 本文との差異は U2-N6 に記録し承認時に揃える。
- **幕の分類は U3 の三階層を権威**：戦闘内幕間＝中幕の幕間（正典語「幕間」）／章の幕切れ＝大幕・幕切れ／終章特殊幕＝大幕の例外型／小幕転移＝小幕——対応表を U1 §3.1・U3 §3.2 の双方に記載。「幕開け」（U1＝幕切れ後の初景）と「開幕」（U3＝章到着の幕）は別の幕瞬間。
- **章の色は docs/20 §5 のパレット行を引用**——パレット外の一時色・予約色（朱・琥珀）の装飾名使用は禁止。
- **エンドロールの器分類は全書統一**——「書物UI言語で装丁された独自演出画面」（頁送り＝表示切替・閉じる＝既存UI閉操作）。
- **規則IDはユニット接頭辞で一意**：U1-R-*（エンドロール）・U2-R-*/U2-B-*（書物UI共通規格・読み返し規則）——docs/45/04 の B-*/M-*/C-* 系と衝突しない。Y-*/I-*/PC-* は U1 内部採番。
- **要承認IDの運用**：本群の未決項目は U2-N*（02）・U3-N*（03）・U4-<数字>（04）・U1 #<数字>（01）で採番し、過去Issueの承認済みID（Issue #30 の U1-新*/U2-Q*/U3-A*/U4-Q*/30-*・Issue #31 の U1-Q*/U3-Q*/U4-#*）と衝突しない。本文中の過去承認引用は「Issue #30 U4-Q1」「Issue #31 U1-Q10」のように出典接頭辞を付ける。
- **マッチカット風の世界転調**（docs/09 §2 映画行）は本Issueでは未定義のまま扱わず、Issue #11（章ボード素材割）へ手渡し。
