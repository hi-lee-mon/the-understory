# 02_語り形式・鑑賞層の実現仕様（U2）

> **対象**：Issue #28（異ジャンル融合要素の詳細化）ユニット U2——章別語り形式（6形式）と鑑賞層（読む／観る／聞く）の実現仕様。準拠：docs/47（本 Issue の物差し・P-01〜P-08・G1〜G18）、docs/09、docs/12、docs/26、docs/36、docs/34 各章プロット、docs/45_nonverbal_guidance、docs/46、docs/32、docs/14、docs/23、docs/28、docs/38/03、docs/30_adr。
>
> **本書の守備範囲**：(a) 6つの語り形式を「どう読ませるか」まで掘った実現仕様（断片の形式・UI表示・演出・配分量）。(b) 鑑賞層の器——拾い人の手記（読む物語）・拾得図鑑（集める図鑑）・形式の視覚差（P-04）の設計。(c) 読み返し規則。**踏み込まないもの**：幻想文字の文字体系・暗号鍵の配置（U4 管轄——境界のみ §3.7 に記録）、演出UIの可/不可の法典と形式別「皮の変わり方」見本（U4 管轄——本書は内容側の差を渡す）、見得・幕・序破急（U3）、予告頁の内容構成・挿絵規格・実装方式（U1——本書は手記側の索引記録のみ。綴じ先＝拾得図鑑）、書物UI本体の器（頁めくり挙動・フォント描画・表示時間の実装＝Issue #3/#18）、断片の実文（Issue #10）・個数の最終値（Issue #15）、環境語彙の置き方（docs/45/03）。
>
> **前提方針**：「世界は語らない。残っているものが語る」（docs/24 §1.3）。語り形式は「残っているものの声の形」であり、鑑賞層は拾った声を**ゲーム内で**再び読める器である——Destiny グリモア（物語をゲーム外サイトに置いた）の失敗を繰り返さない（docs/47 §2.7）。「感動は狙い撃ちしない」（docs/12 §2.1）——読み物の主軸は推理と伏線である。

## 1. 目的と位置づけ

### 1.1 目的

docs/09 §2 で確定した「章ごとに異なる語り形式」は、現状「形式の名前と声色」（docs/26 §3.1・§4.2）までしか定義されていない。本書はこれを**プレイヤーが手に取り・読み・集め・読み返せる仕様**へ翻訳する：

1. **形式を「読み合いの対象」にする**（P-02 形式美＝読み合い）：絵本の頁・書簡の宛名・戯曲のト書き・日誌の日付・詩の行の断ち・設計書の「案：」見出しは、それぞれ**読者を違う位置に立たせる構造**を持つ。形式が違えば「誰が・誰に向けて・どう書いたか」の読み方自体が変わる——これを断片の実体・UI・音の設計に落とす。
2. **鑑賞層をコアループの「鑑賞」工程に接続する**（docs/09 §3）：探索→対峙→**鑑賞（読み・観・聞き、ノミが綴じる）**→鍛錬→結末。鑑賞工程の器を「拾い人の手記」と「拾得図鑑」の二器に分けて定義する。
3. **「集める＝読める」を構造にする**（P-05）：拾った断片が読めるものを増やし、まだ拾っていない断片が「欠け」として見える設計——Tunic の説明書（頁を集めると読めるものが増える）と同一の型を本作の器に翻訳する（docs/47 §2.7）。

### 1.2 層構造上の位置

- 本書が扱う全ての文字媒体は**深読み層**である（docs/26 §1）。進行必須情報を文字に置かない（G2・docs/45/01 K-1）——断片は「確かめる・深める・泣く」層の物であり、拾わなくても全章クリア可能（docs/24 §8・docs/26 §7）。
- 文字は「読む導線」を担わない（docs/45/01 §4.3「文字媒体×導線」禁止組）——断片の配置と拾得標識は導線側（docs/45/02）が担い、本書は拾った後の「読み・観る・聞く」側を担う。
- 断片アイテムは拾得物でもあるため拾得トークン統一仕様（発光＋微粒子/動き/音の2チャネル必須・音色全章統一——Issue #31 U1-Q3 承認・docs/45/01 §2.3・docs/14 §3）に従う。「読める物を兼ねる拾得物」への琥珀例外は 02 の着地静止手紙型の限定場面に留め、断片一般には拡大しない（docs/45/01 §4.4・docs/20 §2——アクセント予約色の希釈防止）。

- **終章＝文体は設計書一本、構造は全形式の収束**：docs/34 README が終章を「—（全形式の収束）」と表記するのは構造面（全章の形式の断片が座に集まる——06 §8 の断片群に各章形式の由来物が混じる）を指し、文体面では全断片が設計書語に統一される（docs/12 §2.1・docs/34/06 §8）。両表記は矛盾しない——文体の層と収束の層が別である。
- **設計書先行露出列（勾配B）**：設計書形式は終章の専有ではなく、**形式外の異質文体**として序章〜第5章に先行配置される（docs/36 §3.3 勾配B・F-U4-R05・§3.7）。各章の語り形式に混ざる「読み慣れない書式」として機能する例外断片であり、§3.7 で扱う。
- **幻想文字は語り形式に数えない**：幻想文字は環境文字系統（落書き・碑文）の別系統かつ最深部の解読班投入物であって（docs/36 §3.4・G14）、章の語り形式ではない。読み方・鍵・配置は U4 の管轄——本書では境界としてのみ扱う（§3.7）。

## 3. 形式別の実現仕様

各形式について「**断片の形式**（どんなアイテム/書物として出るか）・**UI表示**（書物UIでの見せ方）・**演出**（読む際の音・間）・**配分量**」の四点を定義する。全形式に共通の規格を §3.0 に集約する。

### 3.0 共通規格（全形式に効く規則）

| # | 規則 | 内容 | 根拠 |
|---|---|---|---|
| U2-R-1 | **断片は「誰かが・何かのために・書いた」もの** | 全断片は書き手の三点が透ける形（docs/26 §2・docs/36 §3.7 書き手の存在証明）。無署名の説明文は置かない | docs/26 §2・§4.1 |
| U2-R-2 | **断片は単体で読め・揃うと一点に収束** | 拾い順の順不同耐性（Carson/Jenkins——提示順序はプレイヤー依存）。G4 順不同章では他章知識を前提にしない | docs/26 §3.1・docs/34/01 §8 |
| U2-R-3 | **読まなくても進行できる** | 必須情報を文字に置かない。断片は「確かめる・深める・泣く」層 | docs/26 §1/§7・docs/24 §8・G2 |
| U2-R-4 | **拾うとノミが記す** | 断片を拾得するたびノミが綴じ役として記す動作を行い、口上（「覚えておくよ」系）が綴じと共に挟まる。読了の一拍＝ノミの反応 | docs/26 §3.5-3・docs/50 Beat 4・docs/34/00 §2 |
| U2-R-5 | **読み上げの間** | テキスト表示の最低表示時間・頁めくり速度の数値は Issue #3/#18 の確定値を引用する（本書では実数値を持たない——Issue #31 U4-#10 承認の委譲）。綴じ画面は「閉じて再開可能」が最低保証 | docs/26 §8・docs/34/06 §6.1 K3 |
| U2-R-6 | **朗読に耐える分量** | 1篇は短い頁区切り・配信者が読み上げられ・視聴者が画面で読み切れる分量。章あたりの総量は §2 マトリクスの各章確定値 | docs/26 §6・§8・docs/17 §3 |
| U2-R-7 | **字幕の命名** | 読み物の音（頁をめくる・封を破る・紙擦れ等）はバニラ字幕の表示名を持ち、「〈主体〉：〈動作〉」二項型で命名——例「紙：擦れる」「封：切れる」「頁：めくれる」。内容の言明はしない。無音区間では字幕も出さない | docs/45/04 §5.2 規則H-4・Issue #34 手渡し |

| U2-R-10 | **強度の上限** | 断片・読み物の存在提示は「気配〜示唆」段階まで——明示は進行必須の安全情報と物語上の確定点に限定 | docs/45/01 §3.1 |

### 3.1 絵本（第1章「満ちなかった月の林」）

| 項目 | 仕様 |
|---|---|
| **断片の形式** | **「絵本の頁」アイテム**——冊子から散逸した頁として漂着・配置される拾得書物（頁1〜5＋白紙の最終頁＝頁7＋隠された最終頁の草稿群）。頁は章内に散り、拾うたび拾い人の手記（§4.2）の第1章節に「抜けた絵本の頁が戻る」形で綴じ込まれる。本体は「欠けた一冊」——頁が揃うほど絵本が形を取り戻す（P-05）。 |
| **UI表示** | 書物UIを**見開き絵本の比率**で使う——頁あたり文量少・余白多・挿絵が頁面の大きな比率を占める（docs/47 §2.2「書物UI＋挿絵アイテムの組み合わせ」）。挿絵は独自挿絵頁（頁面を絵が占める装丁差——スキン範囲の法典化は U4 へ手渡し）。**頁4（乱れる頁）は挿絵自体がかすれ・崩れる**（docs/26 §3.1「途中で絵が乱れる」——形式の破綻が視覚で先に伝わる）。**白紙の最終頁（頁7）は文字の読めない真っ白な頁**として開く——「存在は見せる・内容は読めない」の文法を断片レベルで先に教える（終章綴じ画面の「かすれた第三項」と同型、K3——§3.6 参照）。結末綴じ後はこの白紙の頁に選んだ結末が綴じ込まれ、初めて「読める頁」になる（01 §8 #7「結末選択の紙」——選んだ結末が頁として残る）。 |
| **演出（音・間）** | 読む間の音＝**子守歌的BGMのかけら**（docs/09 §5「絵本の子守歌」——楽曲の形式変化は章×形式でパラメータ化・Issue #4/#26 へ記録済み）＋優しい紙擦れ（字幕名「紙：擦れる」）。草稿群を読む時は BGM がほとんど退き、頁をめくる音だけが残る（翁が書けなかった結末の静けさ）。白紙の頁を開く時は**無音**——「何も書かれていない」ことが演出になる。 |
| **配分量** | 書物系6〜7点（絵本頁1〜5・白紙頁7・草稿群・最古/最新の手紙・読みかけの暦・立て札群）＋環境断片約10点（01 §8 確定値）。最古の手紙／最新の手紙・読みかけの暦・翁の立て札は**絵本形式ではない副断片**として併置（「同じ文を書き続けた者」の物証——絵本の童話調と対になる実務文字、01 §8 #8-10）。 |
| **どう読ませるか** | 絵本の読者は「読み聞かせを受ける子」の位置に立つ——大きな文・素朴な語り・余白に身を委ねる読み方。だからこそ頁4で絵が乱れ、頁5で「用意されていた結末」が下書きのまま見つかると、読み聞かせの安心感が「この物語は終わっていない」という発見に反転する。**拾うこと＝頁を戻すこと**なので、プレイヤーは絵本を「読む」のではなく「綴じ直す」側に立つ——結末綴じ（白紙の頁に結末を書き込む）の予行が形式そのものに内蔵されている（§3.6 の設計書が読者を選定者に立たせるのと対になる、「読者を綴じ手に立たせる」形式）。 |

### 3.2 書簡（第2章「読まれなかった港」）

| 項目 | 仕様 |
|---|---|
| **断片の形式** | **「手紙」アイテム**——封・便箋・宛名のある個物。かすれた宛名の打ち上げ手紙（防波堤）・航海日誌の断片（波止場）・配達記録票・分類票（集配所）・住民の手紙（港町）・灯台守の日誌断片（灯台・守の家）——全て書簡体の変種（02 §8 A表9篇）。滞留便の束は「届かなかった」が固まって見える形。**拾得物系統との一致**：「読まれなかった手紙」は拾得物でもあり、読み手が読んだ時点で「届いた手紙」へ変換される（docs/14 §2 語義承認済み——「宛て先でなくとも読み手に届いた＝読まれた」）。ボス戦開示の「差出人のない手紙」×1は貨物室が P3 幕転換で初めて開く断片で、探索拾得と分離集計する（02 §8 B表）。 |
| **UI表示** | **便箋書式**——頁頭に宛名欄（宛先／差出人／日付）を構造的に置く書式。「宛名欄が埋まっているが、宛先はもういない」が書式だけで読める。記録票系は罫線の多い帳票体裁（生活ノイズ・docs/36 §3.6）。**差出人のない手紙は宛名欄が空白のままの特別頁**——形式の「欠け」が断片の主題（生涯で一度だけ書いた手紙）と一致する（02 §8 B）。封のある手紙は開くと封を切る演出（封蝉・封の差分はテクスチャ）。 |
| **演出（音・間）** | 封を切る音（字幕名「封：切れる」）＋**書簡の朗読BGM**（docs/09 §5）。読了時：読み終えた時点で「届いた手紙」へ変換され、ノミが記す動作と反応の口上が挟まる（実文は Issue #10）——**「読む」動作が「届ける」の完了と同じ動詞になる**形式と機構の一致（本章の核心演出。ボス戦最終局面「甲板を渡り灯台守に彼自身の手紙を届ける」（02 §10-5）と同じ動詞の反復）。救出後にゴミ箱から届く返信も同じ書簡形式——「あんた宛て」の手紙が初めて形式の中に入る（docs/26 §3.6・§9-8「あんたに向くのはノミと返信だけ」）。 |
| **配分量** | 探索書物約9篇＋ボス戦開示1篇＋落書き十数箇所（02 §8 確定値）。誤答配分：落書きのうち1〜2箇所は前任の間違った仮説（「この港は最初から届かない場所だった」等）、後書き訂正＝集配所の戻り郵便区画（Issue #30 U4-Q2 承認済み・docs/26 §3.4）。 |
| **どう読ませるか** | 書簡の読者は「宛先でないのに読んでしまう第三者」の位置に立つ——宛名・敬語・差出人の形式美が「これはあんた宛ではない」と常に告げる。だからこそ**誰にも届かなかった手紙を読む行為自体が、その手紙を初めて「届かせる」**（docs/14 §2 の語義拡張と一致）。読者は受取人の代行者に立たされ、「読む＝届ける」の形式体験がボス戦の「届ける」へそのまま伸びる。環境側の戻り郵便記号（折れ目・「戻」朱印・結び直し紐——docs/45/02 規則B-2）は読まないプレイヤーにも「一度運ばれて戻った物」を伝え、書簡断片はその「なぜ」を確かめる層として機能する（G2 二段構え）。 |

### 3.3 戯曲（第3章「踊らなかった広場」）

| 項目 | 仕様 |
|---|---|
| **断片の形式** | **「台本・書類」アイテム**——『祭りの筋書き・第一幕』『第二幕・みんなの輪』『第三幕・千秋楽の段取り』『人形の造り方メモ』『楽屋日誌』『開幕の挨拶』草稿群『招待状の束』『祭り企画書』（「没」印）の計8篇（03 §8 確定値）。 |
| **UI表示** | **台本書式**——冒頭に登場人物欄、ト書きは括弧書き・墨字より薄い色（演じ手に向けられた補助行として視覚的に一段下げる）、台詞は役割名＋文。**『開幕の挨拶』草稿群は「同じ冒頭を書き直した頁の束」として束ねて綴じる**——何百通もの書き直しが「反復の形」として頁の束で見える（翁の手紙と同型の反復モチーフ、F-U4-R03）。『招待状の束』は一斉配布の印刷めいた体裁・宛名は「みんなへ」のみ——**案内人の招待状（個人宛て・手書き・口癖が微かに滲む）との質の対照**が形式差として読める（Issue #30 U2-Q6 承認済み・45/03 §8）。『祭り企画書』は設計書文体の片鱗（「案：」見出し・「没」の印）——形式外断片として §3.7 で管理する折れ点候補（F-U4-R05）。 |
| **演出（音・間）** | 読む間の音＝**演目の囃子・遠い拍子**（docs/09 §5）——「拍子だけが鳴る広場」で台本を読むと、環境の拍子が台本の「合図」に重なる（環境が先・文字が後の実演：拍子は既に鳴っている、台本はその正体を確かめる）。**『第二幕・みんなの輪』は「観客が合図に応える」演目構造を先読みさせる**——ボス戦の応答キュー（キュー間隔3.0秒・応答窓±0.40秒、docs/38/03 §4.3）の物語的予行。ただし進行必須情報は置かない（U2-R-3）：読まなくても人形の構え・客席を指す誘導で同じ合図が成立する（docs/45/02 §7.1・03 §5——二重化の確保）。『第三幕』は終わり方まで書かれている——「終われなかったのは構成でなく運用」と読むだけで分かる構造断片。 |
| **配分量** | 戯曲書物8篇＋環境文字（延期のお知らせ重ね貼り・屋台品書き・座席名札「みんな」）＋落書き十数箇所（03 §8）。誤答配分：落書きのうち1〜2箇所が「祭りは中止された」型の読み違え（実際は延期の連続——Issue #30 U4-Q2 承認済み）。 |
| **どう読ませるか** | 戯曲の読者は**「上演されなかった演目の演出家」**の位置に立つ——ト書きと台詞から、あったはずの上演を頭の中で組み立てる読み方。台本は「演じ手に向けて書かれた形式」なので、読むこと自体が「この劇を頭の中で初めて上演する」行為になる——そして第3章のボス戦ではプレイヤーが実際に「観客になる」（03 §5 twist）。**読者が観客になる形式**——読んだ者は「合図に応える客席の役」が何かを先に知っている。 |
| **「延期」と「中止」の言い分け** | 世界内文書は「延期」で統一、ボス名は正典どおり「中止の人形劇」——意図的な齟齬は承認済み（03 未決事項）。台本群は「延期」側の文書として扱う。 |

### 3.4 日誌（第4章「選ばれなかった坑道」）

|---|---|
| **断片の形式** | **「作業日誌」アイテム**——日付付きの記録帳の断片6篇（各1〜3頁・分量規範の上限側、04 §8）。公の面は「作れない者」の筆致、隠し工房の名付け記録だけが「作れた者」の筆跡——二層構造は承認済み執筆運用（04 §11 P4・Issue #10 への前提通知済み）。併置断片：発注書1枚（形式外断片・「没」印——§3.7）・幻想文字1箇所（根幹坑道・原案素材近くの壁——U4 管轄の境界のみ）・漂着した他者の捨て物1つ（宛名の残る呪いの刃＋未開封の巻き紙——04 §8）。 |

| **演出（音・間）** | 読む間の音＝**遠い打鍵音**（環境音——到着時から鳴り続けている虚空を打つ音、F-U4-R11）＋坑道の労働歌的な低い楽句（docs/09 §5）。**日誌の「今日も掘った」という文字を読んでいる間も、読み手の耳には実際に打鍵音が鳴っている**——音が先に語り、文字が後から確かめる二段構えの模範的同期（G2）。最深部では日誌の筆致が走り書きに崩れ、打鍵音の正体が読みと環境の双方で開く（読んだ者は文字で、読まない者は最深部の光景で——04 §5）。炉心手前の確定落書き「おれは帰れなかった。でも、物は届いていた」（04 §8——前任の旅路の折れ点）。 |

### 3.5 詩（第5章「歌えなかった塔」）

| 項目 | 仕様 |
|---|---|
| **断片の形式** | **「詩の断片」アイテム**——「目覚めの歌」の連①〜⑤（余白の庭①／鐘撞きの径②③／楽堂④／塔内⑤）＋公演プログラム（末尾の献辞は宛先不明の「座」宛——初見は謎の献辞、回収時は原案の座への二重の意味）＋歌姫の草稿（同じ歌の冒頭を何百通も書き直した跡）＋鐘楼刻印（幻想文字「この音は座へ届く」——U4 管轄、解読文内容は確定済み）。書物系計8点（05 §8 確定値）。 |
| **UI表示** | **詩書式**——行の断ち・反復・余白。頁あたり行数を極端に少なく（余白が「欠け」の体現、docs/47 §2.2）。**連を追うほど手記の頁が連として揃い、歌の全体像が形になる**（P-05——集める＝歌が綴じられる）。プログラムは楽譜・曲目の帳票体裁（献辞の設計書文体の片鱗は §3.7 の折れ点候補、F-U4-R05）。草稿群は『開幕の挨拶』と同型の「書き直しの束」。刻印は環境文字系統（幻想文字——本書では境界のみ）。 |
| **演出（音・間）** | **無音を演出に使う**：本章は「聞き手のいない音は実在しない」環礁ローカル法則（05 §3.3・Issue #30 U1-新7 承認）のため、断片を読んでいる間も世界の無音を維持する——**読む音は読み手の中でだけ鳴る**。響界内では歌のかけらが微かに聞こえ、救出後の読み返しでは歌姫のアリアが重なる（docs/09 §5「歌姫のアリア」——同じ頁が「無音で読む詩」と「声で聴く歌」の二つの読みを持つ＝再読性4要件の④「感情の温度が変わる」の構造的実現、docs/36 §3.5）。字幕規則：無音区間では字幕も出さない（45/04 §5.2——「音がないこと」自体が演出）。鐘楼刻印の読みは解読班層（最深部・P-07「暗号は贈り物」）。 |
| **配分量** | 詩断片①〜⑤＋公演プログラム＋歌姫の草稿＋鐘楼刻印＝書物系8点＋落書き12〜15箇所（困惑→気づき→悔いの軌跡・結論は書かない。誤答1〜2箇所＝「呪いで音を奪われた」型、後書き訂正＝鐘撞きの径——05 §8・Issue #30 U4-Q2 承認済み）。 |
| **どう読ませるか** | 詩の読者は**「歌を字で聴く者」**の位置に立つ——行の断ちと反復が「声に出されるはずだった形」を残す。音のない世界で歌を読む＝聞くべきものがなかった世界で、読者自身が最初の聞き手になる（聞き手規則の物語的着地——「音は聞き手がいなければ実在しない」に対し、**詩は読み手がいれば実在する**）。連を揃えると「国を呼び覚ます」呼び声の歌が立ち、その歌が原案の一部だったと刻印・献辞で分かる構造。 |

### 3.6 設計書（終章「原案の座」）

| 項目 | 仕様 |
|---|---|
| **断片の形式** | **「設計書断片」アイテム**——没企画書・設計図・仕様書の断片。書物系9〜10点：総設計／空と月／案内人／来訪者／環礁／改訂履歴／頁目録の欠落／王／選ばれた世界の没案＋条件付き3点（座に流れ着いた返信＝あんた宛の没配便・王宛の届かなかった手紙・歌姫の頁に加わった声、06 §8 #1-23 表）。 |
| **UI表示** | **設計書書式**——箇条書き・項番号・仕様書語・「案：」見出し・「没」の印（取り消し線または朱の没印）。声色＝「世界そのものの没案としての冷たさと畏怖」（docs/26 §4.2）。**余白に書き込まれた問い（王筆——手書き三系統の一つ、docs/26 §3.4）**——仕様書の均質な字面に、判で押したような「問い」だけが別の手で反復して滲む（反復者の系譜の着地、F-U4-R03）。 |

| **配分量** | 書物系9〜10点＋環境断片約10点（06 §8 確定値——集積の間の票付き棚に結末の欠片全20個が並ぶ回収演出を含む、06 §8 #23・§6.1(d) 承認済み）。 |
| **どう読ませるか** | 設計書の読者は**「選定者の席に座らされる者」**——「案：」「没」の形式は読者を物語の登場人物でなく企画の審査者に置く。落慮王の二連の問い（「選ばれなかったものに、価値はなかったのか」）が読んだ後の綴じ画面に直結するのは、この形式が既に読者を「選ぶ側」に立たせているからである（docs/34/06 §5-6）。**全形式の収束**：座の断片には各章形式の由来物が混じる（「届かなかった手紙」「歌姫の頁」等——構造面の収束、§2 補助線）が、それらは全て設計書語の項として記録されている——「全ての物語がここでは『案』になっている」ことが形式差として読める。 |
| **「拾う」の形式条件** | 綴じ画面の第三項「拾う」は頁（前任の白紙の頁）の所持が選択前提——**読めるのは頁所持者のみ、存在のみ全員常時表示**（K3）。形式レベルの意味：「拾う」は設計書の中に**本文を持たない白紙の項**として現れる——白紙の頁は「書かれなかったものを書き込める器」であり、第1章の白紙の最終頁（頁7）と同じ形式の語彙が終章で最大の選択肢になる（§3.1 と同型の「存在の可視・内容の不可視」）。 |

### 3.7 形式外断片——設計書先行露出列（勾配B）と序章漂着文書

| # | 断片 | 配置（章・場所） | 形式外としての読み | 勾配B の位置 | 根拠 |
|---|---|---|---|---|---|
| 1 | 設計書めいた頁 | 00・見晴らしの岬の足下（最も取りにくい場所） | 箇条書き・「案：」の見出しを持つ頁——まだ意味は分からない、変わった書式としてのみ記憶される | 文体のみの初露 | 00 §8 #6・F-U4-R05 |

| 5 | 書庫の全断片 | 06・原案の座 | 文体の由来が確定——全断片が「世界の設計書」の断片だった（発見） | 全開 | 06 §8・docs/36 §3.3 |

**順序非依存の保証**：03 の企画書と 04 の発注書は互いに不要で独立可読——**先に遭遇した方が折れ点**（初の直接証拠）となり、「没」の印の意味はどちらが先でも「選ばれなかった」として読める（docs/36 §3.3 勾配B・F-U4-R05・§7 横断レビュー反映13——G4 順不同の絶対条件に整合）。

**序章漂着文書6篇の形式標本としての扱い**：各篇は対応する章形式の**欠けた標本**（月の写し絵＝絵本の気配／宛名のない手紙＝書簡／祭り半券・台片断片＝戯曲／作業日誌＝日誌／歌詞の一節＝詩／設計書めいた頁＝設計書）。捨て主の分からない世界側の漂着文書であり、章アフィニティ配達の対象外（00 §8）。拾い人の手記では序章節に「形式の分からない断片」として綴じられ、対応章の頁が揃った時に「あの断片はこの形式だった」と再読で分かる構造（再読性要件③——再読で別の読みが勝つ、docs/36 §3.5）。

**幻想文字との境界**：幻想文字・異物の文字化けは語り形式に含めず、落書き・碑文系統の別系統（U4 管轄——文字体系・鍵・配置規則）。希少性配分（01・02・03には置かない／00・04・05・06のみ）と内容方針（「没になった世界設計の断片」に統一・動機・正体を言明しない）は確定済み（docs/36 §3.4・docs/26 §3.4 Issue #30 U4-Q1/Issue #31 U3-Q2）。

## 4. 鑑賞層の仕組み

「読む・観る・聞く」の鑑賞工程（docs/09 §3 コアループ第3工程）を支える器を設計する。器は二つ——**拾い人の手記**（読む物語の器・頁単位）と**拾得図鑑**（集める図鑑の器・項単位）。この二分は docs/26 §2 のベクター棲み分け（書物＝物語の断片／図鑑＝プレイヤーの足跡）を器に投影したものである。

### 4.1 三層の視覚差（P-04——読む／観る／聞くを別層として設計）

| 層 | 担うもの | 形式差の出し方 | 器・管轄 |
|---|---|---|---|
| **読む層** | 断片の本文——文体・構造・書き手の声 | 形式別の声色規範（docs/26 §4.2 確定表：絵本＝素朴で歪みが滲む／書簡＝宛名・敬語・届かない想い／戯曲＝賑やかな台詞と空虚／日誌＝実務的で乱れる／詩＝行の断ち・反復／設計書＝箇条書き・仕様書語）。本文の実文は Issue #10、文体規範は docs/26 §4 の正典 | 書物UIの頁面（本文領域） |
| **観る層** | 装丁・挿絵・頁面の見た目——形式が「見て分かる」差 | 絵本＝挿絵主体の見開き・大きな文・余白（途中で絵が乱れる）／書簡＝便箋・宛名欄・封蝋／戯曲＝人物欄・ト書きの薄字・段取り帳票／日誌＝日付欄・筆致の乱れ勾配／詩＝行の断ち・極端な余白／設計書＝項番号・「案：」見出し・「没」印。器は全て書物UIの頁面装丁（スキン的変更の範囲——G3）で、**どこまで皮が変わるかの法典と見本は U4 管轄**。本書は「何の要素が形式ごとに変わるか」の内容側のみを渡す | 書物UIの装丁・挿絵頁（Issue #3 器 × U4 法典） |
| **聞く層** | 読む際の音・読み上げの間——形式が「聴いて分かる」差 | 形式別の読み音（docs/09 §5 確定：絵本の子守歌／書簡の朗読BGM／演目の囃子／坑道の労働歌／歌姫のアリア／設計書＝静けさと紙音[本書 §3.6 の設計案]）＋頁めくり・封を切る等のSE（字幕名＝「〈主体〉：〈動作〉」二項型、H-4）＋無音区間の扱い（05章は世界の無音を維持——字幕も出さない）。読み上げの間の数値は Issue #3/#18 確定値を引用（U2-R-5） | 音響・字幕システム（Issue #34 へ手渡し項あり） |

**原則**：同じ哀愁でも「手紙で読む悲しみ」と「劇で観る悲しみ」は別物（docs/09 §2）——三層それぞれに形式差を持たせることで、形式の違いが本文を読まなくても「頁面の形・読む音」で体に入る（P-04）。**観る層と聞く層は読む層の代理ではない**——形式の差は三層で独立に設計し、読まないプレイヤーにも「この章の断片は見た目が違う」まで届くようにする（層構造の補強・G8）。

### 4.2 拾い人の手記（読む物語の器）——**新設・要承認 U2-N1**

**定義**：拾った語り断片をノミが綴じ込んでいく、**頁単位で増える一冊の書物**。読み返しの主器であり、「あんたが読んできた物語」そのものが形になる。

## 5. 読み返し規則

拾った断片が「どこで・どう読み返せるか」の規則表。目的は**読み損ねと喪失の不安を構造で潰す**こと——深読み層の報酬は「また読める」ことが前提になる。

| # | 規則 | 内容 | 根拠 |
|---|---|---|---|
| **U2-B-1** | **断片アイテムは所持中いつでも再読可** | 手紙・頁・日誌・台本・詩の断片・設計書断片は全て書物の器のアイテム——インベントリ内で開いて読める（バニラ書物の性質） | P-03・docs/26 §8 |
| **U2-B-2** | **手記に綴じられた断片は不滅** | ノミが記した断片は拾い人の手記に写しが綴じ込まれ、物理アイテムを失っても手記から読み返せる。**既登録（図鑑・手記に記録された物）は死亡で失われない**——未登録拾得物のみ25%ロスト（最大8個・没腐遺留物として回収可） | docs/32 §2.1・本書 §4.2 |
| **U2-B-3** | **未収集は「欠頁」として存在のみ見せる** | 手記の章節で綴じ目の空きが「まだ頁がある」を語る（枚数のみ可視・内容も場所も示さない）。収集を強制しないが、欠けが次の探索の気配になる | §4.2・P-05・G8（§7 U2-N2） |
| **U2-B-4** | **未読の表示** | 新綴じ頁は頁端の折れ目/綴じ糸の色で未読を示す。読むと消える。手記の表紙・装丁に「新頁あり」の気配 | §4.2（§7 U2-N2） |
| **U2-B-5** | **招待状は消失しない固定所持品** | いつでも再読可能——終章の書庫で「案内人の項」の筆致と見比べる推理の物的担保 | docs/26 §3.6（Issue #30 U1-新3・Issue #30 U2-Q5 承認済み） |
| **U2-B-6** | **綴じ画面は閉じて再開可能** | 読み損ね・即断を構造的に防ぐ最低保証。第三項「拾う」は頁未所持だとかすれて読めない・選択不可——頁所持が選択前提。存在のみ全員常時表示 | docs/34/06 §6.1 K3（五重保証 a-e） |
| **U2-B-7** | **結末の欠片は宝箱に入れない** | 集積の間の票付き棚に並ぶ回収演出——棚が「集めた証」の場所（欠片数だけ綴じ画面の器＝見開きが形になる） | docs/34/06 §6.1(d)・§8 #23・README 規則2 |

## 付記：境界の自己照合

- **進行必須情報を文字に置いていない**——全断片は「確かめる・深める・泣く」層（U2-R-3）。『第二幕・みんなの輪』の応答構造のような先読み断片も、表層の非言語誘導（人形が客席を指す・拍子）と常に二重化（docs/45/02 §7.1）。
- **形式は6形式＋形式外断片＋「続く形式」の三段構造**——設計書先行露出列（勾配B）と序章漂着文書（形式標本）は例外として §3.7 で管理、村報・返信は「終わらなかった形式」から「続いていく形式」への着地としてエピローグに位置づけ。
- **ユニット境界**：幻想文字＝U4（§3.7 で境界のみ記録）／装丁の法典と皮の変わり方見本＝U4（§4.1 の内容側のみ提供）／見得・幕・序破急＝U3（幕間数値は引用のみ）／予告頁の内容＝U1（綴じ先の帰着のみ §4.2 に記録）／書物UIの器・読み上げの間の実数値＝Issue #3/#18／実文＝Issue #10／個数最終値＝Issue #15。
- **感動は狙い撃ちしない**：各形式の「どう読ませるか」は推理（なぜこの形式で書かれたか・誰が書いたか）と人物の魅力（書き手が透ける構造）を主軸に設計——感情の起伏は形式差の結果として出る（docs/12 §2.1 方針）。
- **正典用語**：拾い人／ノミ／拾得物／拾得図鑑／結末の欠片／結末綴じ画面／没腐／淀み／読む者／原案の座／落慮王／前任の拾い人（先達）／案内人筆・先達筆・王筆／村報／響界——正典どおりに使用。「拾い人の手記」は U2-N1 で正典化を求める新規用語。
