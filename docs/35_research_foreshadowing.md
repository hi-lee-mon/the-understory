# 35. 伏線・転調設計の調査と基準（Issue #30 調査フェーズ成果物）

> Issue #30「横断的な伏線・転調・衝撃展開の設計」のための先行調査。ミステリ作家の技法・脚本理論・論文・成功ゲームの分析から、本作が従うべき伏線設計の基準を定義する。`docs/33`（物語構造の調査）の姉妹篇——本書は「撒く・回収・驚かせる」の工学に特化する。

## 1. ミステリのフェアプレイ原則（探偵小説の契約）

古典推理の鉄則：**「読者は騙されることに同意している——ただし欺瞞は読者の目の前で行われた場合に限る」**（Knoxの十戒・Van Dineの二十則の系譜）。

- **全ての手がかりは見せる**——読者を出し抜くのは情報の隠匿ではなく**ミスディレクション**（注意の向け方）による
- 「ミステリは一冊の本に二つの物語が同居している」——表の物語（読者が追う事件）と裏の物語（真相）。伏線は両者を繋ぐ橋
- 実務作法（日本のミステリ執筆論）：**真相を先に決め、そこから逆算して手がかりを配置する**。書く順序と読ませる順序は逆
- ノイズ管理：手がかりは本物の手がかりと紛れ込ませる「意味のある無関係な情報」の中に埋める
- **暗黙のルールを破らない**：世界が提示した規則の内部で真相が成立していること

→ 本作への適用：**全ての重大な真実（落慮王・ノミ・前任・「あんたも捨てる側」）は、終章以前にプレイヤーが自力で到達可能な断片として全編に配置済みでなければならない**。終章は「答え合わせ」であり「新情報の開示」でない。

## 2. 伏線の三部構成：Setup / Misdirection / Payoff

伏線は「撒き（setup）」と「回収（payoff）」だけでは成立しない。間に**ミスディレクション**が要る——プレイヤーに「分かったつもり」の中間解釈を与え、真の解釈を隠す。

- 例：ノミの「来たか。待っていた」は表層では「案内人として待っていた」に読める（ミスディレクション）——真実は「原案が、読んでくれる者を待っていた」
- **全ての撒きには副次的な物語上の役目を持たせる**：ヒントのためだけに存在する断片は「これは伏線だ」と透ける。序章の残骸は「前任の痕跡」であると同時に「捨て場という概念の教材」でなければならない

→ 本作への適用：各伏線は「表層での素直な読み（誤読を含む正しい解釈）」と「真相側の読み」の2層を仕様として持つ。

## 3. Sanderson の約束・進行・回収（Promise / Progress / Payoff）

- **約束**：物語冒頭で読者に「何が待っているか」の期待を作る（トーン・謎・感動の種類）。伏線の撒きは約束の立案
- **進行**：中間で「答えに近づいている感」を定期的に与える（濃度勾配）
- **回収**：約束を果たす。果たせない約束は読者の信頼を壊す
- **「Lost 効果」の警告**：謎を引き延ばしすぎると、どんな真相も期待に届かなくなる。**第1章から引っ張る秘密は、第7章あたりで問いを立て始めるもの**——長距離伏線は「その時点で初めて問いが立つ」種類に限る
- 振り返って見える伏線：大きな仕掛けは「読者が終盤に問いを立てた後、振り返ると最初に種があった」と分かる形が最も強い

→ 本作への適用：伏線を**距離で分類**する——
- **短距離**：章内で撒き・同章で回収（章の推理の満足感）
- **中距離**：1〜2章を跨ぐ（例：予告頁→次章の気配、王宛の手紙→終章の届きもの棚）
- **長距離**：全編を貫く（ノミの正体・前任・「あんたも捨てる側」）——これらは**終章で初めて「本当の問い」が立つ**種類にし、途中では断片が「ある」だけに留める

## 4. ねじれ（転調）の品質テスト

優れたツイストを検証する5問（スリラー分析の実務基準）：
1. **稼いだか**：微妙で発見可能な手がかりで稼がれているか、作者が不公平に情報を隠したか
2. **再読で太るか**：真相を知った状態で読み返すと物語が豊かになるか、矛盾・綻びだらけに崩れるか
3. **意外だが必然か**：その瞬間は驚き、後から見ると「こうなるしかなかった」か（主題と噛み合うか）
4. **再解釈するか**：それまでの全てを情緒的に再文脈化するか、「引っかかった！」だけで終わらないか
5. **20%ルール**：読者の約5人に1人がツイストを事前に当てられる程度が適正（全員が当てられる＝浅い、誰も当てられない＝隠匿）

→ 本作への適用：**中盤転調（「あんたも捨てる側だ」）と終章転調（落慮王の正体・ノミの正体）**は全てこの5問をパスする必要がある。特に「ノミの正体」は本作の核なので20%ルールの検証対象。

## 5. 環境的伏線（ゲーム固有の技法）

学術論文（Environmental Foreshadowing）とレベルデザイン実務から：

- **ビフォー・アフター技法**：安定した以前の状態と、それを壊した出来事を空間に配置し、プレイヤーが遷移を再構成する（「中断された食事」の部屋）
- **状態の層化**：全ての物は状態（無傷・使用済み・破損・修復・朽ち）を持ち、状態が時間経過を符号化する
- **タイムライン一貫性**：全ての小道具が同じ「どのくらい前か」に従う——埃の深さ・植物の成長・腐敗度が一致しないと空間が「本物でない」と密かに宣告する
- **モチーフの植え付け**：繰り返し現れる視覚モチーフが無意識に先の展開を準備する
- 悪い空間は「何も言わない」のでなく「混乱したことを言う」——中途半端な配置は不整合として読まれる

→ 本作への適用：各章の場所系列は「ビフォー（物語がまだ機能していた姿）／アフター（没腐の停滞）」の対で設計され、断片の「古さ」は全編で一貫したタイムライン（世界が捨てられてからの経過）を持つ。

## 6. Outer Wilds 型：知識による進行

- **知識そのものが進行**：唯一持ち越せるのは記憶。本作の「拾い人の図鑑・読んだ断片」がこれに相当
- **コンパクトで濃密**：広さより深さ。断片は互いを指し（蜘蛛の巣状）、「キュリオシティ」（最大の謎への答えが在る場所）へ収束する
- **紙プロトタイプで物語構造を検証**：場所カードと断片カードで、プレイヤーが手がかりを繋げて意味を再構成できるかを物理的にテストした——**伏線台帳は「実際に辿れるか」の検証対象**
- 好奇心の設計：「行け」と言わない。断片が次の謎の場所を示唆し、プレイヤーが自分で繋ぐ

→ 本作への適用：伏線台帳は「断片Aを読んだ者が断片Bの場所・意味を推測できるか」の**連結グラフ**として検証する。孤立した（どこからも辿れない）断片は欠陥。

## 7. 本作固有の制約：順不同耐性と明答しない構造

- **順不同耐性**（第2〜4章）：伏線の解釈が他章の攻略順に依存しない。中距離伏線は「どの順で拾っても成立する断片」に分割する
- **明答しない構造**（docs/08 §2-3）：表層で答えを言わない。答えは断片の集積から自分で組み立てる——「言われないと分からない」は失敗だが「頑張っても分からない」も失敗。適正は**20%ルール**
- **考察班供給**：考察班が楽しめるのは「確証はないが整合する推測が組める」密度。幻想文字（解読可能暗号）は最深部の投入物
- **再読性**：2周目・他人の配信で「あ、これ伏線だった」と分かるためには、**断片が初見で無害に読める**ことが必須（読み返して初めて意味が変わる文＝二度美味しい設計）

## 8. 伏線台帳のスキーマ（Issue #30 の成果物形式）

全伏線を以下の行形式で台帳化する（`docs/36` に集約）：

| 列 | 内容 |
|---|---|
| ID | 伏線識別子（例：F-WORLD-01） |
| 伏線 | 何を示唆するか（真相側の読み） |
| 表層の読み | 初見でどう解釈されるか（ミスディレクション先） |
| 撒き | 章・場所・語りベクター（書物/落書き/環境/語り/音） |
| 濃度勾配 | 中間でどう強化されるか（進行の断片列） |
| 回収 | 章・形態（対峙/発見/選択/仕掛け） |
| 距離 | 短距離/中距離/長距離 |
| 明答度 | 表層で答えが言われるか（すべきでない） |
| 順不同耐性 | 第2〜4章のどの順でも成立するか |
| 再読の味 | 知った後で読み返すと何が変わるか |
| 状態 | 設置済み（docs/34 にある）／要追記（正典または章へ追記が必要） |

**転調点一覧**：| 転調点 | 位置 | 表層の理解→真実 | 事前布石 | 後の再解釈 | 5問テスト結果 |

## 9. 検証基準（レビューアが判定する物差し）

1. **網羅性**：docs/34 各章 §9・docs/24 §4 真実表・docs/28 にある全ての「撒き」が台帳にあり、各行に回収先がある（または「回収しない」が明示的な意図として記されている）
2. **逆方向の網羅性**：終章で回収される全ての断片・開示が、どこかに種を持つ（突然の新情報がない）
3. **順不同耐性**：第2〜4章由来の伏線は、どの攻略順でも破綻しない
4. **距離分類の健全性**：長距離伏線は「終盤で初めて問いが立つ」種類か（Lost 効果の検査）
5. **明答度**：表層に答えが直接書かれていないか（層構造・「必読情報は文字に置かない」）
6. **20%ルール**：核心の謎（ノミ・王・前任）について、注意深いプレイヤーが終章前に自力で推測可能か
7. **副次的役目**：各断片が伏線以外の物語機能を持つか（透けない伏線）
8. **タイムライン一貫性**：断片の「古さ」・状態の層化が世界の経過時間と一致するか
9. **転調の5問**：各大転調が意外だが必然・再解釈を生むか
10. **語りベクター整合**：各断片の担い手が docs/26 の媒体配分と矛盾しないか
