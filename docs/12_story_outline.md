# 12_ストーリー詳細（v0.1）—「The Understory（棄てられたものの国）」

> `11_world_bible.md` の設定を、章単位のプロット・キャラ・結末分岐に落とした詳細版。各章＝一つの「棄てられた物語」。**「現実（オーバーワールド）↔ 国」の行き来構造**を採用（ユーザー提案・採用候補）。

## 0. 新たな構造：双方向の往来

黄昏の森が「行ったら終わり」の一方通行だったのに対し、本作は**現実と国の行き来**を柱にする：

- **現実での行為が国に届く**：捨てた・使わなかった物、やらなかったことは、国では「棄てられたもの」として実在する（アイテム・住人・風景に）。
- **国での行為が現実に返る**：国で救った物語・拾った「拾得物」は現実に持ち帰れる。国の変化が現実側の「異物」にも反映される。
- **「縁（ふち）の地」**：現実の中の「棄てられたものが集まる場所」（捨て場・廃村・忘れられた構造物）が、国への薄い境界・隠し導線になる。現実での探索そのものが冒険になる。
- 意味的効果：**「自分が捨てたものがあちらにいる」**が成立し、プレイヤーの行為が物語と直結する（「この手紙、私が読まなかった…」という種類の驚き）。

## 1. 大枠のプロット

- **導入**：プレイヤーは「拾い人」として国に落ちる。ノミに出会い、「ここは捨てられたものの国」と知る。
- **各章**：環礁（棄てられた物語）を探索→その物語が「なぜ未完か」「本当は何だったか」を追う→「没腐」した核（ボス）と対峙→**結末を書き換えるか見届けるかを選ぶ**→環礁が変化、救った者が拾い人の村へ。
- **中盤の転調**：国は「捨てる側」の行為で歪みが増すことが判明。プレイヤーが捨ててきたものが、歪みを助長している。
- **終章**：「最初に棄てられたもの＝世界の原案（落慮王）」と対峙。彼の「選ばれなかった世界」を見せられ、**国を書き換えるか・見届けるか・第三の答え**を選ぶ。

## 2. 章別詳細（案）

> 各章は**異なる語り形式**で語られる（`09` §2 参照）。物語の断片は「読む・観る・聞く」鑑賞として拾う。

### 序「漂着浜」
- 打ち上げられた無数の物が積もる浜。空に欠けた月。
- ノミとの出会い。「あんたが捨てた物も、ここにある」と世界の法則が体験で分かる。
- 拾い人の村の「場所」だけを示唆。

### 第1章「満ちなかった月の林」
- **語り形式**：**絵本/御伽噺**。ページを繍うように物語が読み進められる。
- **棄てられたもの**：「満月にしか実らない作物」の没案。月が欠けたまま止まった常夜の林。
- **物語**：林の主・**月見翁**は「満月の夜に実を摘む」物語だった。だが月は欠けたまま動かず、翁は待ち続けて「没腐」に呑まれた。
- **歪み**：林全体が「待ち続ける」時間に閉じ込められている。獣は「満ちない月」に飢えて荒れる。
- **ボス「月欠狼」**：月の欠片を背負った巨狼。月齢ギミックの戦闘（月が満ち欠けする間に弱点が変わる）。
- **結末選択**：**月を満ちさせる**（翁の物語に結末を）／**新月を受け入れる**（満月を諦め、別の実りを祝う）。
- **救出**：月見翁 → 村の農園担当に。

### 第2章「読まれなかった港」
- **語り形式**：**書簡体**。拾った手紙そのものが物語を語る（読む行為＝エピソード）。
- **棄てられたもの**：届かなかった手紙・読まれなかった航海日誌の港。
- **物語**：港の**灯台守**は「必ず届く」手紙を守り続けた。だが誰も読まず、彼は手紙の山に呑まれて没腐した。
- **歪み**：読まれなかった言葉が霧になって港を閉ざす。「届かない」が具現化したボス。
- **ボス「未読の座礁船」**：手紙の山を引きずる座礁船の化け物。「届くはずだったもの」の重みが攻撃になる。
- **結末選択**：**手紙を読み・届ける**（言葉に結末を）／**海に還す**（届かない想いを水に流す）。
- **救出**：灯台守 → 村の「手紙屋/情報屋」に（ロア・隠し要素の案内役）。

### 第3章「踊らなかった広場」
- **語り形式**：**戯曲/演目**。祭りは上演されなかった劇として扱われ、役割と幕で語られる。
- **棄てられたもの**：中止になった「祭り」の広場。飾られたまま止まった屋台と提灯。
- **物語**：広場の**祭囃子**は「みんなが踊る日」を指揮するはずだった。祭りが中止になり、彼女は踊る相手を待ち続けて没腐した。
- **歪み**：止まった祭りが「終わらない前夜」に閉じ込められる。拍子だけが鳴り続ける。
- **ボス「中止の人形劇」**：人形の列が踊る劇場の化け物。リズム・拍子で攻略（音ゲー的読み合い）。
- **結末選択**：**祭りを開く**（みんなを呼んで初めての祭り）／**静かに畳む**（祭りを終わらせてあげる）。
- **救出**：祭囃子 → 村に「祭り場」ができ、時折イベントが起きる（配信のイベントネタ）。

### 第4章「選ばれなかった坑道」
- **語り形式**：**日誌/記録**。鍛冶師の作業日誌を辿る形で物語が進む。
- **棄てられたもの**：没になった鉱石・道具・輝かなかった鉱脈の坑道。
- **物語**：坑道の**鍛冶師**は「世界一の道具を作る」はずだった。だが彼の素材は全て「没」になり、彼は何も作れないまま没腐した。
- **歪み**：使われなかった道具・素材が恨みを持って蠢く。「選ばれなかった道具たち」の反乱。
- **ボス「棄材のゴーレム」**：没素材でできた巨大ゴーレム。部位の「没素材」が落ち、それを拾って使う戦闘（拾ったもので戦う＝本作の核心）。
- **結末選択**：**鉱脈を目覚めさせる**（没素材に意味を与える）／**名を与える**（選ばれなかった道具に名前を与えてあげる）。
- **救出**：鍛冶師 → 村の「拾得鍛錬」の名人（クラフト強化の中心NPC）。

### 第5章「歌えなかった塔」
- **語り形式**：**詩/歌詞**。聞かれなかった歌の歌詞が断片となり、音を取り戻すほど物語が聞こえる。
- **棄てられたもの**：没になった音楽・鳴らなかった鐘の塔。
- **物語**：塔の**歌姫**は「鐘を鳴らして国を呼び覚ます」物語だった。だが鐘は鳴らず、彼女は無音の中で没腐した。
- **歪み**：無音の塔。音の欠落が空間を歪める。「聞かれなかった歌」の悲しみ。
- **ボス「無音の歌姫」**：音のない領域で戦うボス。「音を取り戻す」ギミック（鐘・楽器で反撃）。
- **結末選択**：**歌わせる**（彼女の歌を聞かせてあげる）／**新しい歌を与える**（拾い人が一緒に歌う）。
- **救出**：歌姫 → 村に「歌と鐘」が戻る（村が音楽で彩られる）。

### 終章「原案の座」
- **語り形式**：**設計書/原案**。世界の没企画書そのものが物語として読める（メタ層）。
- **棄てられたもの**：世界の「最初の没案」。全ての棄て物の王。
- **物語**：**落慮王**は「世界はこうあるべきだった」という原案の人格化。選ばれなかった世界の在り方を、彼はこの国で証明しようとした。
- **対峙**：彼は「選ばれなかった世界の美しさ」をプレイヤーに示す。ここで全ての救った物語が集結。
- **ボス「落慮王」**：多段戦。全章の要素（月・手紙・祭り・道具・歌）を統合したギミック。
- **結末の選択（マルチエンド）**：
  - **書き換える**：国を「選ばれた世界」に変えようとする → だが「選ぶ」ことは「また何かを捨てる」こと。
  - **見届ける**：棄てられたものたちの物語を、結末まで一緒にいる。
  - **第三の答え**：「拾う」——選ぶのではなく、棄てられたものをこれからも拾い続ける選択（本作らしい終わり）。

## 3. サブプロット（現実↔国の因果）

- **「あなたが捨てたもの」**：プレイヤーが序盤に捨てた/使わなかった物が、各章に「誰かの宝物」として出てくる演出（没腐の正体にプレイヤーの無意識の「棄てる」が絡む）。
- **「縁の地の住人」**：現実の廃村・捨て場にいる者たちは、国と現実を行き来できる「縁の民」という設定にできる（導線＆ロアの両立）。
