## 1. 概要と役割

没腐の境界は、全ての環礁の縁を包む**没腐の濃い帯**である。壁ではない——越えられる。ただし越えたことは刻まれる。黄昏の森型の進行ロックを置かない本作（G4 順不同）において、**「世界の端」を閉じることなく機能させる内側の進行制御**が本帯の役目である。

役割は三つ：

1. **縁の可視化**——環礁の物語領域の終わりを、説明せず空間で伝える（P-NR-01 到着側の絵）。
2. **喪失体験の刻印**——「越える」は自発的な一回の行為であり、世界はそれを記録し、没腐度に一段の烙印を与える。
3. **帰還の保証**——帯はいかなる物もプレイヤーも留めない。帯の内側にも外側にも「帰れない状態」は存在しない（`docs/23` §5.1・`docs/32` §2.2 の原則）。

設計の骨格は「**帯の流れは常に内側へ**」の一句に集約される。帯の濃層も、外側の海も、落とした物も、泳いだプレイヤーも、すべて緩やかに環礁の内側へ還す。越えることはできるが、**世界の縁は何も奪わず、流れだけが還してくる**。刻まれるのは物ではなく、越えたという事実だけである。

## 3. 空間・構造（区画割り・導線）

### 3.1 三層モデル

境界は線ではなく**帯**であり（P-NR-04）、プレイヤーの位置は常に次の三区のいずれかにある。

| 区 | 定義 | 読み |
|---|---|---|
| **内側** | 帯の内面より環礁側——物語のある地 | 通常のプレイ空間。全ての構造物・導線・案内がここに属する |
| **帯内**（仮称） | 内面と外面の間に挟まれた没腐の濃層 | 「越え」の途中であり、**入って引き返せる**緩衝域。ここにいるだけでは刻まれない |
| **外側**（外海——仮称） | 帯の外面より外——世界の外縁 | 行き先のない海。環礁は水平線の影として見えるが、外海は環礁間を運ばない |

帯は環礁を**縁で包む**。したがって「帯に近づく」には案内も門も要らない——環礁の縁へ向かえば、どの方角でも帯に出る。帯の構造表現（内面の見え方・濃層の質感・外面の膜）は `docs/16` §2.7 側の領域として手渡す。

### 3.2 導線の規則

- 帯への進入は自由・無記録。帯内では「渡る」か「引き返す」かの二択のみが意味を持つ。
- 帯は全ての環礁の縁を包むため、**空間上は環礁間の移動経路が必ず帯の体積・外海を通過する**（外海は帯の外側の面として環礁を取り囲む海である）。ただし位置状態の判定と烙印の対象は「越え」の行為に限定され、次の正規通路は免除される（§4.1・67-U3-Q13）：
  - **環礁間の橋・流れ**：正典どおりの章進行導線。帯を空間的に貫くが、経路上の移動は `IN` 扱いとし烙印・記録の対象外とする。通路は「帯を越えずに抜ける道」——越えるのは歩いた者だけである。
  - **転移系**（ゴミ箱往復・招待状・座行き・処理口等）：空間を経由しない直接転移。そもそも位置状態の判定対象外。
  - **クレーン・処理口系**：埋立て地への直接到達であり外海を経由しない（G-NR-03 の片道確定値どおり）。
- 外海自体はプレイヤーの移動手段としてどこにも接続しない——泳ぎ・ボートで外海を渡って別の環礁へ辿り着く経路は成立しない（67-U3-Q1）。他環礁は相互視認（`docs/45/02` §3.2）の延長で水平線上に見えるのみ。
- **空と月は外海からも共有のまま**（`docs/11` §5 準拠）。外海は「世界の外」ではなく「世界の縁」——月は変わらずそこにあるが、地の物語は終わっている。この非対称が外海の主要な見え方である。

### 3.3 帯内の物理感

- 帯内の濃層は**淀んだ媒質**として扱う：移動は重く（減速）、視界は短縮され、環礁側の環境音が遠くなる。内面から見える向こう側は読めない層である。
- **帯内には内側へ向かう緩い流れが常時働く**。入力をやめたプレイヤーは流れに乗って環礁側へ還る。抗して滞在はできるが、それは「抗っている」状態として体に感じる（強度配分は 67-U3-Q5）。
- 帯内は滞在しても没腐度は増えない——**刻むのは越えの一回だけ**。
- 帯内・外海には敵性個体を出現させない（67-U3-Q6）。帯の怖さは戦闘ではなく「刻まれること」と「空っぽさ」が担う。

## 4. システム仕様（判定・発火・状態遷移）

### 4.1 位置状態

各プレイヤーに対し、環礁ごとの位置状態を持つ：`IN`（内側）／`BELT`（帯内）／`OUT`（外側）。判定はプレイヤー実体の位置のみに依る（移動手段・速度・乗物の有無は問わない）。

**正規通路の免除**（67-U3-Q13）：正典到達経路——環礁間を結ぶ橋・流れの経路体積（仮称「**正規通路**」）上にいるプレイヤーは位置状態判定を停止し、通路への進入直前の状態を維持する（実質 `IN` 扱い）。転移系は空間を経由しないためそもそも判定対象外。通路体積の範囲・帯との接続部の定義は生成側へ手渡す（Issue #13・`docs/16` §2.7）。

### 4.2 状態遷移

| 遷移 | 名 | 発火するもの |
|---|---|---|
| `IN → BELT` | 入り | 帯内演出の開始（§5.2）。記録なし |
| `BELT → IN` | 引き返し | 帯内演出の解除。記録なし・無料 |
| `BELT → OUT` | **越え** | 烙印イベント（§4.3）＋越え記録（§4.4）＋演出系列（§5.3） |
| `OUT → BELT` | 戻り（前段） | 帯内演出の再開。新たな越えではない・無刻み |
| `OUT → BELT → IN` | **戻り** | 帰還演出（§5.4）。烙印と記録は残り、没腐度は通常の回復系で癒える |
| 正規通路上の移動 | —— | 判定停止・`IN` 扱い（§4.1）。烙印・記録なし——章進行のたびに刻まれることはない |
| 正規通路 → 外海（落下・離脱） | 到達 | 位置状態 `OUT`。**烙印は `BELT→OUT` の外面越えに限定されるため発火しない**（§4.3・§4.5-3・67-U3-Q13）。帰還は外海の流れに任せる |

**通常移動では `OUT` から `IN` へ直接遷移する経路は存在しない**——帯は体積を持ち、帰還は必ず帯内を経由する。なお死亡・リスポーンは本遷移系をまたぐ別機構として扱い本表の対象外である（リスポーン順位は `docs/32` §2.2 どおり——外海で死んだ場合も捨て場→村→浜の順で環礁内側へ戻る）。

### 4.3 烙印イベント（越えの刻み）

`BELT → OUT` 成立の瞬間に発火する。烙印は「一度の喪失体験」として、既存の没腐度体系の**一段**に収める（P-NR-05・G-NR-06——`docs/38/04` §2 の体系内イベントとして追加）：

- **没腐度加算**：`+BELT_BRAND_DELTA`（推奨 +1——死亡 +1 と同幅で「一回の喪失」の重さ。67-U3-Q3。新規 N-ECO-2xx 行として Issue #15 へ手渡し）。
- **状態変数**：烙印の追跡には二つの個別層変数を持つ——`BRANDED`（越え烙印の有無フラグ）と `BRAND_MARK`（烙印直後の没腐度値）。`BELT→OUT` 成立時に `BRANDED` が未セットなら、加算して `BRANDED` をセット・`BRAND_MARK` に加算後の没腐度値を記録する。
- **重複規則**：`BRANDED` セット中は、再び越えても加算しない・`BRAND_MARK` も更新しない。**烙印は一度だけ効く**——二度目の越えは「刻み直し」でなく「確かめ」。
- **解除条件**：没腐度が `BRAND_MARK` を下回った時点で `BRANDED` を解除する（烙印分が癒えた＝いずれかの回復イベント受領で没腐度が下がり MARK を割った瞬間）。解除後の越えは再び +1 を得る。没腐度は共通カウンタで烙印分と他由来分は区別不能なため、「MARK 未満への低下」を癒えの判定とする型に留める（値・優先順位は Issue #15）。
- 上限 10 の規則（N-ECO-212）をそのまま適用——烙印で 10 に達しても段階は深腐に留まり、記録のみが積まれる。
- **連続発火の抑制**：重複規則により没腐度は連続越えで積まれないが、越えごとの共有層イベント（§5.3-2）は短いクールダウンを持つ（変数として Issue #15 へ——短時間の往復で発火点が連打されないようにする）。
- 外側・帯内での死亡は既存規則どおり処理する（死亡 +1 は別イベントとして独立加算、リスポーン順位は `docs/32` §2.2 どおり）。**境界は致死性を足さない**。

### 4.4 越え記録（刻まれる・恒久面）

- **初回越え**：「世界の外縁を見た」記録を個別層に残す（`TX-X-REC` 系・発火点のみ定義、本文は `docs/52` へ。67-U3-Q8）。
- **累計**：越え回数を個別層で内部カウント（段階名・数字は UI に出さない——記録層の話）。
- **可視の痕**：`BRANDED` セット中（烙印未回収の間）、プレイヤーに薄い淀みの気配が付く（マルチで「あいつ越えたな」が読める可視性。67-U3-Q4）。`BRANDED` 解除とともに痕も消える。

### 4.5 フェア性（意図しない越えの保護）

「帰れない状態を作らない」に加え、帯の規則として以下を固定する：

1. **外面の抵抗**：外面に近づくほど内向きの流れが強まる。外面を通過するには**持続的な外方向の移動**が要る——走って勢いで抜ける・ノックバックで飛ばされる・縁から落下する等の瞬間移動では外面を貫通しない（流れが外面手前で内側へ押し戻す）。事実上「わざと出ようとしないと出られない」——これが烙印の発火条件と一致し、**烙印は `BELT→OUT` の外面越えのみに限定される**（67-U3-Q2）。
2. **気配の前兆**：内側での接近（気配）→帯内進入（淀んだ視界・移動の重さ）→外面の直前（最も強い内戻しの流れ）の三段で、越えの前に必ず世界が「ここが端」を教える。文字は使わない。
3. **落下の安全**：環礁の縁・高所から落下したプレイヤーは**帯の濃層に捕まる**（落下ダメージは濃層が吸収——淀んだ受け止め）。外面は瞬間移動を通さないため、環礁側からの落下が外海へ達することはない（§4.5-1 と一貫）。外海の面への着水が起きるのは**正規通路から外れて落ちた場合のみ**——外海は沈まない水面を持ち、着水で落下ダメージを無効化・溺死ルートは置かない。この到達は位置状態 `OUT` だが越え由来でないため烙印は発火しない（67-U3-Q10・Q13）。
4. **帰還保証**：帯内・外海の流れは常に内側へ。ボート破壊・泳ぎ疲れ・放置のいずれでも流れが帯へ運ぶ。ログアウト位置が帯内/外側でも、再ログイン後は同じ流れが働く。
5. **物の帰還**：帯内・外海へ落とした物（アイテムエンティティ）は内向きの流れに乗って帯の内縁へ集まる。**消えず、二度棄てにもならない**——世界の縁は物を取らない（67-U3-Q7）。投棄による廃棄は正典の経路（ゴミ箱・二度棄ての文法）に限定される。
6. **回復の余地**：烙印は体系内一段であり、全ての既存回復系で癒える。不可逆な罰はない（G-NR-06）。

### 4.6 没腐度連動

- 越え烙印は N-ECO-2xx の新イベント行として増減表に置く（型のみ定義——値は Issue #15）。
- 烙印で段階境界を跨ぐことがある（澄明 2→淀み 3、淀み 4→歪み 5 等）。歪み 5 以上では既存の `ambient.molder.bed` 連動がそのまま効き、帯内演出と個人層演出が重なる。
- **帯の見え方の段階変化**：没腐度段階で帯の読みが変わる演出を置く（澄明＝淀みが最も異質に見える／深腐＝淀みが「馴染んで」見える——世界の縁が怖くなくなる、それ自体が怖さになる）。判定・加算は段階に依らず不変（67-U3-Q12）。
- 帯内での迷子扱い：帯内で滞留しても、迷子規則の回帰先は「内側」。環境再提示＝内向きの流れの強化。装置段の没腐コンパスは正典指標どおり動き続けるのみ（帯内専用の指し先規則は新設しない——67-U3-Q9）。

## 5. 演出（到着・帰還・刻みの絵）

### 5.1 接近（内側）

環礁の縁に近づくと気配が始まる——`world.silt.hollow` の薄い層（正典の淀み定位 SE を境界接近の気配へ発火文脈拡張して流用——拡張の確定は `docs/19` 側・§10）、世界の色がさらに薄くなる、視界の先に「向こうが読めない層」が見える。初回の接近にも文字は出さない。環境が教える。

### 5.2 帯内へ入る（IN → BELT）

- 足を取られる重さ、短くなる視界、遠くなる環礁の環境音。帯内レイヤーとして `ambient.molder.bed` 相当の淀んだ音床が重なる（個人層の没腐度連動 SE を帯内地域レイヤーへ発火文脈拡張して流用——拡張の確定は `docs/19` 側・§10。帯内専用の環境音床を新設する場合は 67-U3-Q11 案B）。
- 内向きの流れが緩やかに働く——静止すると環礁へ向かって流される。
- 帯内で外へ向かい続けると流れが強まる（示唆）——世界が「越えようとしている」を認める。
- ノミは帯内では原則語らない（同伴の沈黙自体が「ここが端」の告知）。任意で初回越え時のみ一句の気配語りを置ける発火点を `TX-X-NOMI` として予約する（本文は `docs/52`、採用は最小限）。

### 5.3 越えの瞬間（BELT → OUT）——刻みの絵

外面の膜を抜ける一拍に、以下を列で重ねる：

1. 膜を抜ける抵抗の一拍（移動が一瞬だけ極端に重い）。
2. 通過点で `event.silt.crack` を発火——**`docs/19` §3.2 で層＝共有登録済み（SE-YOD-02）の共有 SE として、発火点はサーバー権威で共有層へ配信され近傍の他者にも同時に聞こえる**。帯が割れて閉じる気配——「誰かが越えた」が分かる。
3. 本人のみ：視界が一瞬完全に薄くなる → 没腐度段階表示の更新（既存 UI 規格どおり段階名のみ）→ 烙印の可視痕の付与。
4. **世界の気配が切れる**：帯を抜けた側では環礁の環境音が終わる。残るのは外海の静けさと、共有の月。最も大きい音は「世界の音がなくなった」こと。
5. 専用 SE は新設せず、上記の既存構成で成立させる（67-U3-Q11）。

### 5.4 帰還（OUT → BELT → IN）

- 外海では流れが内側へ運ぶ——帰還に迷子は起きない（帰る方向だけがある海）。
- 帯内を抜けて内側に戻ると、環礁の環境音が薄く戻る——「還ってきた」の体感は音の帰還で作る。
- 可視痕は `BRANDED` が解除されるまで残る。

### 5.5 外海での滞在

- 外海は静かで、月があり、水平線に他環礁の影がある。拾えない残滓の流れが稀に遠くを通り過ぎる（「捨てられた物が行く海」の気配——視覚のみ・拾得不可）。
- どれだけ外へ向かっても行き先はない（67-U3-Q1）。流れが静かに帯へ戻す。

## 7. 生成方式

- **帯**：各環礁の縁を包む生成層として地形生成に伴う。帯の厚さ・内面/外面の位置・流れの強度は変数として Issue #15 へ、帯域そのものの生成は Issue #13（構造・生成側）へ手渡す。
- **外海**：環礁の外側に「行き先のない海」として生成される。沈まない水面を持ち、環礁間を運ばない。到達不能性の担保（他環礁へ泳ぎ渡れないことの実現方式）は生成側の決定として Issue #13 へ（67-U3-Q1）。
- **正規通路**：環礁間の橋・流れが帯の体積・外海上を通過する経路体積の定義は生成側へ（Issue #13・`docs/16` §2.7——67-U3-Q13）。通路が帯を貫く見え方（「端の内側を通る」視覚差分）は `docs/16` §2.7 の構造表現側に委ねる。
- **視覚残滓**：帯内に散る拾得不可の残滓（淀みに絡まった欠け/かすれの造形）の分布パラメータは Issue #13/#15。
- 帯域構造の表現（濃層の質感・膜・外面の見え方）は `docs/16` §2.7 の管轄——本書の三層モデル・遷移規則を入力として渡す。

## 8. 配信の見せ場

- **帯の縁に立つ絵**：向こうが読めない濃層と、環礁側の賑わいの対比。
- **越えの瞬間の「音切れ」**：世界の環境音が切れて静けさと月だけになる一拍——配信で最も映える一拍。
- **通路が帯を抜ける一拍**：橋・流れで環礁を渡る途中に帯の膜を抜ける視覚差分——越えずに「端の内側」を通る絵。
- **外から見る自環礁**：今まで内側にいた世界を外から眺める絵。
- **烙印の痕**：同行者に「越えた」のが見える可視性——パーティ内での問いかけの起点。
- **還ってくる流れ**：何もしないと流れが内側へ運ぶ発見——「世界の縁は押し戻さない、還すだけ」の実演。
- **二度目は刻まれない**：再び越えても加算されない仕組みの発見——「一度の喪失体験」の意味がプレイ中に読める。
