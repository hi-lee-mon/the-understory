## 1. 概要と役割

本書は「灼熱の埋立て地」の**在る者たち**を設計する。領域の主役は物と人——「怖い物・消したかった物の集積」（16 §6.4.1・docs/23 §8）と、それらと共に届いた者たちである。

**体験目標**：P-NR-02（襲う怖さでなく存在の怖さ）の具体型として、ここの敵性個体はすべて「**処分の続きを演じている者たち**」とする。追いかけてくる敵は置かない。プレイヤーは山を掘り、物を拾い、人に会う——その行為の周りで、届いたものが「やっていたこと」を続けている。怖さは殺意でなく「ここにあること」自体から来る（G-NR-19：説明しないで発見させる）。

**本編「気配のみ」（16-U4-Q4/Q6 確定）との接続——次コンテンツで置くもの・置かないものの推奨**：

| 置く | 置かない |
|---|---|
| 敵性個体 3 種（燃え残り・集める者・届いた者——仮称。各少数定点） | ボス・アリーナ構造（この領域に主題はあっても「待つ者」はいない——ボス化すると棄て物の山が「敵」に読み変わり、存在の怖さが壊れる） |
| 住人候補 1 名＋空の住処の痕（複数） | 説明役 NPC・大群モブ・新規独自素材（G-NR-07：独自素材は燃えなかった煤のみ） |
| ロア物層（実漂流物＋設計ロア物の二層） | 結末依存要素（G-NR-11）・本編側への新規敵性配置（16-U4-Q4 を侵さない） |
| TX-LF-* 断片型（発火点のみ） | 断片の実文・固有名の確定値（docs/52・docs/44 側の権限） |

本編側で既に確定している「気配」——隔離区画の焼却の気配（熱・橙漏れ光・焦げた痕・欠片・呪いの刃漂着）、住人候補の場の住処の痕・灯り——は、次コンテンツ側で「**それらは全て本物だった**」として着地させる。特に灯りは、本編で「気配として置かれた灯り」が「住人候補が灯し続けている灯り」そのものとして接続する（§5.3-1）。

### 3.2 導線（出会いの系列と迷子接続）

- **住人候補への導線**：着弾点から住処の灯りが視認できる位置関係を U1 側へ要求（非言語一次導線——灯り＝住人候補が灯し続けている灯り）。灯り→窪地→住処の痕→対面の系列は §5.3。
- **迷子回帰**：正典どおり処理口が焦層の丘の高所から見える構造（煙・橙漏れ光）。没腐コンパスはこの領域を指さない（補助的領域——指し先は未攻略の主線環礁の淀みのみ）。迷子時は環境再提示（灯り・煙・橙）を一次チャネルとし `event.mayoi.guide` の発火型を踏襲——発火点のみ §4.7 に登録。
- **敵性個体の導線的位置づけ**：全個体は「場の一部」として配置し、追跡線でプレイヤーを誘導しない（§4.1）。届いた者のみ領域全域を徘徊しうるが、高所・灯りの周り・住処の近傍には出ない境界を設ける（恐怖が住人候補の場を侵さないため）。

## 4. システム仕様（判定・発火・状態遷移）

### 4.1 敵性個体の総型——「存在の怖さ」の演出型

E-401（統一規範）をこの領域向けに具体化し、以下の 3 原則を全個体の共通型とする：

1. **追跡線を持たない**：全個体が領域・縄張り・条件の内側でのみ動く。徘徊して追いかける敵は置かない——襲うのでなく「そこに居る」。
2. **動詞の反復が威嚇**：予備動作＝元の動詞の反復・加速（E-401①）。攻撃の前に「その者がずっとやっていたことが速くなる」ことで知らせる。
3. **撃破＝静まる**：撃破個体は死亡でなく残滓として静まり（E-401②）、由来を残して堆積の一部に戻る（拾い直し可能）。静まった個体は静まったまま残る（「静まった者」規格と同型——38/04 §1.4）。

各個体の数値（HP・実効・閾値・猶予・個数・ドロップ率）は**型と変数名のみ**定義し、絶対値は Issue #15 へ手渡す（G-NR-13/14/15）。帯域の位置づけ自体は正典にない新規ルールのため 67-U2-Q2 として要承認化する。

### 4.2 個体 A：燃え残り（仮称——命名は docs/44 経路②へ）

- **原型**：焼却を経たのに燃え切らなかった物の残滓。動詞＝「燻る」。
- **見た目**：堆積物と見分けのつかない休眠形（欠けた黒の内側に橙の残り火が一点——差し色の最小使用）。発見は説明でなく「丘の一部が薄く明滅している」の気づき（G-NR-19）。
- **配置**：焦層の丘・堆積区画の燻り点として地形依存生成に組み込まれる（§7）。丘ごとの燻り点数は生成パラメータ（個数変数 `LF_A_DENSITY`）。
- **状態遷移**：

| 状態 | 入る条件 | 振る舞い |
|---|---|---|
| 休眠 | 生成時 | 堆積の一部。橙の残り火が緩く明滅するのみ（気配級）。接触・採掘なしでは活性化しない |
| 再燃（予備） | 半径 `LF_A_R` 内で堆積の掘り起こし・拾得・継続滞在 `LF_A_T` 秒 | 燻りの明滅が加速——元の動詞の反復がそのまま警告。逃走余地として `LF_A_GRACE` 秒の猶予を挟む |
| 活性 | 猶予経過後も範囲内に留まる／接触 | 炭の噴き散らし・近接接触（実効は帯域変数、天井6HP/9HPの内側） |
| 静まる | 撃破 | 残滓として堆積に戻る——燃えなかった煤の塊＋低確率 `LF_A_DROP` で由来札つきの物を残す。再休眠しない（静まったまま残る） |

- **没腐度連動**：個人没腐度 ≥5（歪み帯）で再燃の加速が早い——同じ動詞の肥大（E-401③）。係数の形は 38/04 §1.3 帯に従う（型のみ・値は Issue #15）。
- **設計意図**：資源の丘の一部が「生きている」。掘る行為＝怖さの発火トリガーであり、煤を集めるほど再燃に触れる構造が「拾うことの怖さ」を生む。数で埋めず、丘ごとに点在させる。

### 4.3 個体 B：集める者（仮称——命名は docs/44 経路②へ）

- **原型**：堆積を「分ける・積む・運ぶ」し続ける没腐した拾い系の者。拾い人の歪んだ鏡像——拾うことだけが残った者。住人遷移表（E-402）を継ぐ中立準敵対個体。
- **見た目**：かすれ・欠けた人影が山の周りで仕分けの手つきを反復している（E-401④）。
- **配置**：堆積区画の山ごとに縄張りを持つ定点巡回（山＝その者の拾い場。1 山に 1 体）。
- **状態遷移**（E-402 の準拠形——閾値の値は変数として Issue #15）：

| 状態 | 入る条件 | 振る舞い |
|---|---|---|
| 中立 | 初期 | 山の周りで分け・積む仕草を反復。プレイヤーが近づくと作業の手を止めずに流し目で見る |
| 警戒 | プレイヤーがその山の物を拾う／削る／接近閾値 `LF_B_R` を超える | 手を止めて向き合う・距離を取る。警告動作＝仕分けの反復の停止（動詞の静まりが威嚇） |
| 敵対 | 警戒中にさらに拾う・攻撃する | 「掻っ攫い」——最寄りの落下実体（ドロップ品・死亡遺留物）を掴んで自分の山の頂へ運ぶ動詞の加速。間隔変数 `LF_B_SNATCH`。プレイヤー本体への接触実効は最小（帯域変数） |
| 警戒（復帰） | プレイヤーが縄張りから退去し `LF_B_COOL` 秒経過 | 警戒へ戻る（E-402 の 24B 以上離れ60秒規格に準拠——距離・時間は変数化） |
| 静まる | 撃破 | 残滓として残る——山が「開き」集められた物が露出する。拾い直し可能（「静まった者」規格と同型） |

- **特異点——「集められた物」の返し方**：掻っ攫われた物は失われず、その者の山の頂に**由来つきで置かれる**。拾い直し＝山の頂に手を伸ばす行為（それ自体が再び縄張りへの侵入＝緊張の反復）。対象は**ワールド内に存在する落下実体のみ**——プレイヤーの持ち物欄からは奪わない（理不尽防止・C4 死に学習と整合）。
- **撃破報酬**：静まると山が「開く」——集められた物＋残滓が露出して拾い直せる。
- **没腐度連動**：≥5 で警戒遷移の距離閾値が拡大・≥8 で掻っ攫い間隔が短縮（型のみ）。
- **設計意図**：「ここでは届いた物を拾うこと自体が誰かの縄張りに手を入れること」という読み。倒して消える敵でなく「山の番人」——静まった後も、その山がその者だった構造が残る。

### 4.4 個体 C：届いた者（仮称——命名は docs/44 経路②へ）

- **原型**：「◯◯に捨てられた」記録を持つ人影の残滓——誰かが人を処理した記録が歩いている存在。戦うモブでなく「在る」モブ。領域で最も薄く、最も重い気配。
- **動詞**：「近づく」——**プレイヤーの視界内では静止し、視界外でのみ位置を進める**（34/04 §2 の鉱脈機構「見ていると止まり、見ていないと動く」の**同型機構の転用**——鉱脈の「見られていないときだけ生きている」性質をそのままモブへ適用する）。
- **配置**：領域の深部・縁側に同時 `LF_C_MAX` 体まで（少数——値は Issue #15）。丘の陰・堆積の谷間に佇む。高所・灯りの周り・住処の近傍には出ない（§3.2）。
- **状態遷移**：

| 状態 | 入る条件 | 振る舞い |
|---|---|---|
| 佇立 | 出現時 | 遠くに人影として立つ（視界に入ると停止しているだけの者） |
| 接近 | 全監視プレイヤーの視界外 | 段階的に近づく——視界に入った瞬間に停止。音の気配は常時薄く伴う（視覚外接近でも「居る」ことは分かる——複合表現・G6 準拠） |
| 接触 | 至近 `LF_C_R` 内に未被視で到達 | 一度だけ触接触（実効は帯域下限側の最小値——恐怖が主題で殺意を持たせない） |
| 潜り直し | 接触後 | 最寄りの焦層へ沈み、`LF_C_RESPAWN` 後に別の位置へ再浮上——倒して消える敵でなく「巡回する気配」 |
| 静まる | 撃破 | 由来札つきの残滓を残す——**人の記録形式「◯◯に捨てられた」（捨て主＝クレーン操作者、23 §8.5）を主表示とし、処理場由来「◯◯の処理場から来た」（設置者、23 §8.4）を副層に保持する**二層表示の遺留物（E-307 の由来札機構で読める・§4.6） |

- **視界判定の範囲**：全プレイヤーの視界で判定する案を推奨（誰かが見ていれば止まる——見ている者が他者を守る構造。マルチでの「見てて！」が即興劇になる）。単一プレイヤー判定との比較は 67-U2-Q6。
- **フェア性**：接近には必ず音の気配を伴わせる（新規 SE の型のみ——§10 から docs/19 へ）。視界外でのみ動くが「気配が近い」こと自体は常時検知可能とし、理不尽な不意打ちにしない。
- **設計意図**：他人を捨てる文法の裏側の顔。「ここに届いた者」が処理の記録と共に残っている——存在の怖さの極点として、ダメージでなく目線の管理をプレイヤーに要求する。配信では視聴者にだけ動くのが見える構造になる（§8）。

### 4.5 住人候補と救出物語（F-MECH-14 明示管理）

- **人数**：救出可能な住人候補は **1 名**（固定テンプレ「住人候補の場」に在る）。領域内の複数の空の住処の痕（§3.1）が「他にも届いた者がいた/いる」を数を明かさず残す（P-NR-08）。
- **人格の型**（docs/25 §4 規格に準拠——実文・固有名は docs/52・docs/44 側）：

| 項目 | 型 |
|---|---|
| 原型 | 「燃やされて届いた者」——誰かの処理場に落とされて届いた人物。焦げ跡（処理品の記録）を消せない者 |
| 性格の軸 | 「自分は燃やされるべきものだった」という思い込みと、それでも灯りを灯し続けていることの矛盾 |
| 口調 | 静か・最小限。問いかけに先に「済まない」と言う型（実文は docs/52） |
| 秘密 | 捨てた者の名を**知っているが言わない**——名前は断片にも記録にも出さない設計（67-U2-Q7 推奨：F-MECH-14「回収しない」明示管理として「分からないまま」を世界の答えにする） |
| 好きなもの | 埋立て地で拾い集めた「まだ使える物」の棚 |
| 弱み | 「届くこと」への恐怖——処理口に近づくと怯える（帰還同行の緊張点） |
| システム接続 | 救出後＝拾い人の村に着地。役職の型＝「埋立て地の語り部／由来を識る者」（67-U2-Q4 推奨——怖い物・由来札の読解で鍛冶師の由来鑑定と棲み分け：鍛冶師は「素材」を読み、彼は「処分」を読む） |

- **救出物語の状態遷移**（発火点のみ定義——実文は docs/52）：

| 段階 | 内容 | 発火条件 |
|---|---|---|
| 1. 気配の発見 | 窪地から見える一点の灯り＋住処の痕（本編確定の気配を「本人がいた」として着地） | 着弾後・灯りの初視認 |
| 2. 対面 | 初接近で警戒——隠れる・距離を取る（住人警戒の振る舞いに準拠・敵対化しない） | 住処への接近 |
| 3. 信頼形成 | **名付け**——名札で名を与える（docs/23 §3.1・§8.2「名付け＝物語化の資格」・docs/25 §4「名を持たない住人」機構の転用）。名付けの瞬間に「個人」になる＝救出の実質的成立（67-U2-Q3 推奨） | 名札の使用 |
| 4. 同行帰還 | 処理口から共に逆流——焦げ跡は彼らには到着時から刻まれているため「帰りに刻まれる」のではなく「刻まれたまま帰る」演出差分。**本人の意思による同行であり、プレイヤーが「連れ出す」構造にはしない**（32 §1.2「生き物・住人＝連れ出し不可」との整合の確定は 67-U2-Q9——同行逆流を対象外とする解釈の承認） | 名付け後・処理口への同行 |
| 5. 村への着地 | 拾い人の村へ着地——**着地経路は逆流口の国側分岐で村の共同箱へ着弾する 67-U4-Q5 に従属**（住人は現実へ出られない正典どおり、現実を通さない分岐）。対案＝現実経由で名付け生物の住人候補化規格（23 §8/D5）に準拠する案は 32 §1.2 解釈拡張が採用された場合に限り残す。移送の実仕様（同行ルート・分岐発火）は l3_connection.md §4.4 側の処理口実構造が正本 | 帰還完了 |

- **救出前の安全性**：住人候補は中立を崩さない（敵対化しない・撃破対象にしない——「静まる」規格の対象外の住人として扱う。67-U2-Q3 に併記）。
- **マルチでの扱い**：住人救出は共有——誰かが救った住人は全員の村に現れる（N-ECO-806・docs/32 §6）。救出の成立（名付け）は先着ではなく一度きりの世界イベントとして扱い、二度目以降の到達者には「もう個人になった者」として村にいることが分かる状態を示す。
- **F-MECH-14 明示管理**：救出物語は本書で設計するが、**本編側への回収は約束しない**（G-NR-08）。加えて本領域内部でも回収しない糸を明示する：①捨てた者の名（67-U2-Q7）②他に届いた者の数（空の住処の痕は数を明かさない）③彼らの元の物語（到着前の人生は断片に出さない）。36a §7 の未回収表に「回収しない」のまま保持する台帳行として §10 へ登録。

### 4.6 「◯◯の処理場から来た」由来紐付けの配置規則（群像劇燃料）

堆積のロア物は二層で構成する：

- **(a) 実漂流物層**：実際に L3 処理場で焼却された物——設置者由来（ADR-0004 個別層の所有者紐付け）を保持したまま堆積に現れる。**堆積の一部が「最近の処理物」で継続的に更新される**——領域の堆積は時間と共に変わる、処理の届き先として生きている地形（更新の技術仕様は U1/Issue #13 側、本書は配置規則のみ）。
- **(b) 設計ロア物層**：「怖い物・消したかった物」の型に沿う固定配置物証。型を 4 分類する：
  1. **封印系**：誰かが恐れて沈めた物——04 隔離区画の呪いの刃と同系の顔（焼却でしか消せないと判断された物）。
  2. **消去系**：消したかった記録——焼け残った手紙・日誌・証票（読みかけの形）。
  3. **誤算系**：燃えるはずが燃えなかった物——燃えなかった煤の由来となった素材の親。
  4. **異物系**：処理場でなくここに落ちたはずのない物——考察班への餌（二度棄て→座の語彙には触れない——E-031 は保留領域）。
- **由来札の粒度**：(a) は実名由来「◯◯の処理場から来た」（E-002/E-307 の機構側表示として個別層表示）。(b) は物語内の設置者名——由来札の実名欄の**型のみ**を定義し、名の実文は docs/52 側（名前は「分かるが知らない誰か」として群像劇を燃料化）。
- **読解の遊び**：同じ設置者由来の物が堆積の別々の丘にばらけて眠る→同じ名を複数発見すると「その人が何度も処理した／何を燃やそうとしたか」の推測が立つ。由来表示の連鎖＝領域探索自体が群像劇の読解になる（P-NR-07——物の正体が届いた人の物語を映す）。
- **届いた者との接続**：§4.4 の残滓が由来札を持つ——**人は人の記録形式「◯◯に捨てられた」（捨て主＝クレーン操作者・23 §8.5）を主表示、処理場由来「◯◯の処理場から来た」（設置者・物と同じ規格・23 §8.4）を副層とする二層表示**とし、人と物それぞれが正典の記録形式で読める粒度を保つことで、「人もまた処理品だった」ことが説明なしに伝わる構造（23 §8.4/§8.5 の形式差＝設置者と捨て主の差を残滓側でも保持する）。

## 5. 演出（到着・帰還・刻みの絵）

### 5.1 到着（届く側の絵——P-NR-01/P-NR-06）

1. 転移 4 連：`event.transit.close`（現実側・蓋/マグマの上で閉まる一拍）→ `break`（暗転・逆再生感）→ `land`（焦層への着弾——灰の堆積に落ちる実音＋環境床の立ち上がり）→ `open`。
2. **着弾直後の絵**：堆積の窪地に伏せて着地。立ち上がると自分の輪郭が灰に残る——「処理品として届いた」ことの身体感。直後に `TX-LF-REC` の到着記録「◯◯に捨てられた」が刻まれる（機構側表示）。
3. **初景**：焦層の丘の連なり・橙の漏れ光・遠くの一点の灯り（住人候補の場——本編の「灯りの気配」と同一点）。処理口は最初は見せない（「ここが終着ではない」不安→後で高所から見える回帰点として開示）。

### 5.2 個体の演出系列

- **燃え残り**：休眠（堆積と同色・橙の残り火のみが緩く明滅）→ 掘り起こしで明滅加速（予備——光演出は輪郭への複合表現：差し色の橙が「呼吸する」ように縁に滲む）→ 噴き散らし → 静まる（橙が抜けて欠けた殻に戻る）。
- **集める者**：作業の反復（仕分けの手つき・積み上げ）が常時演出 → 警戒で手を止めて向き合う → 敵対で掻っ攫い → 静まると山が「開く」（集められた物の露出）。
- **届いた者**：遠望の人影 → 目を離した瞬間に近い → 接触 → 焦層へ沈み直す。「振り返ると近い」の反復。音の気配は常時薄く（複合表現）。
- **住人候補**：灯りの側で待つ/隠れる → 名付けで個人になる瞬間（§5.3-4）→ 処理口で怯える → 逆流で「刻まれたまま帰る」。

### 5.3 救出の演出系列

1. 灯りの気配（窪地から見える一点の灯り——非言語一次導線）。
2. 住処の痕（寝床・集めた棚——「いる」が確度を上げる段）。
3. 対面（警戒——隠れる素振り）。
4. 名付け（名札を差し出す→個人になる瞬間——拾い人の文法のクライマックス形。ノミの反応 `TX-LF-NOMI` を伴う）。
5. 同行帰還（処理口で共に逆流——「処理された者」が「帰る者」に変わる一拍。怯え→覚悟の最小演出。着地経路は 67-U4-Q5 の国側分岐に従属）。
6. 着地（村での加入——`TX-LF-NP` 村報の号外と役職）。

### 5.4 帰還・記録の刻み（本書の所掌分のみ）

焦げ跡の刻みの実構造は `l3_connection.md`（U4）の所掌。本書側が固定するのは：①到着時の「◯◯に捨てられた」記録が図鑑に残る点（`TX-LF-REC`）②救出同行時に住人候補が「刻まれたまま帰る」演出差分③帰還後の気配——焦げ跡を持つ者同士が村で顔を合わせる構造（救出済み住人候補とプレイヤー）。

## 6. 収容物・報酬

- **燃えなかった煤（N-ITEM-015——引用のみ）**：ここでしか得られない独自素材・耐熱・火系（G-NR-07）。採掘の形：堆積の掘り起こし＝燃え残りの再燃リスクと表裏（資源と恐怖の同居——「拾うことの怖さ」が収集行為そのものに入る）。
- **敵性個体の残滓**：燃え残り→煤の塊＋低確率で由来つき物／集める者→山の開放（集められた物＋残滓）／届いた者→由来札つきの遺留物（ロア物としての拾得）。確率・収量は Issue #15。
- **住人救出報酬**：拾い人の村への住人加入（着地経路は 67-U2-Q9 に従属。役職＝由来識別の機能・67-U2-Q4）＋個人没腐度 −1/件（N-ECO-205「住人救出・村施設増築・宝物返還の完了ごと」の行に乗る適用——数値は引用・帰属の確定は Issue #15 で明記）。
- **ロアの収穫**：怖い物・消したかった物の拾得——由来札つき拾得物として「誰かの怖い物」を持ち帰る行為（拾得物規格に従う・帰還時に持ち出せるものの範囲は l3_connection 側に従属）。
- **拾い直し**：死亡遺留物は正典どおり没腐遺留物として場に残る（32 §2.1・`world.remnant.warp`）＋集める者の山への「集められ」を追加ルールとして扱う（§4.3——取られた物は失われない）。

## 7. 生成方式

## 8. 配信の見せ場

G-NR-18——捨てる側と届く側の双方：

- **捨てる側**：クレーン儀式（23 §8.5・`world.crane.warn/grab`）——既存確定。
- **届く側**：落とされた者の視点——暗転→灰に伏せて着弾→見知らぬ丘→遠くの灯り。「◯◯に捨てられた」記録が残る瞬間（捨てた側が見守る中で届いた側が探索する非対称の見せ場——コメントで「あっちだよ」が起きる構図）。
- **届いた者の視界ギミック**：配信者の画面に映っていない間だけ動く——**視聴者には動くのが見えて配信者には見えない**恐怖の構造（コメントが先に気づく型）。マルチでは「見てて！」の即興劇。
- **集める者の掻っ攫い**：死んだら遺留物が「集められて」山に積まれる——「取られた！」から「取り返しに行く」緊張の即興劇。
- **名付けの救出**：埋立て地で名を与える＝配信の感動枠（名付け＝物語化の資格の実演——名を持たない者が個人になる瞬間）。
- **由来札の読解**：「◯◯の処理場から来た」物を拾って「この人何を捨ててるの…」——マルチでは実名・ソロでは設計ロア物の名が群像劇を生む。同じ名の連鎖発見で「何度も何かを燃やしている人」の輪郭が立つ。
