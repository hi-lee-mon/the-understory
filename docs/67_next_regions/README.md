## 2. 3 領域の関係図

```
現実                        国（深部・補助領域）
┌─────────────┐   処理     ┌──────────────────────────────┐
│ L3 ごみ処理場 │ ──管──→  │  没腐の喪失境界（帯）          │
│ 投入口+クレーン│  片道    │ ┌─────────────────────────┐ │
│  +マグマ槽    │         │ │   灼熱の埋立て地           │ │
│  （個数制限なし）│        │ │  逆流口（唯一の帰還口）      │ │
└──────▲──────┘         │ │  着弾域／山・丘／住処      │ │
       │                │ │  敵性個体・住人候補・煤      │ │
       │   逆流          │ └─────────────────────────┘ │
       └──口─────────── │  越えられるが刻まれる帯        │
            片道         └──────────────────────────────┘
            （焦げ跡つき）

・処理＝現実→埋立て地（クレーンで落とされる片道・死でなく転移）
・逆流＝埋立て地→現実（処理口をくぐる片道・往復不可）
・救出対象の移送＝逆流口の国側分岐（→村の共同箱）
・喪失境界は埋立て地の領域を囲う帯（帯の仕様＝U3／接続点は帯の内側——埋立て地外縁の帯配置可否は 67-U3-Q15：推奨＝帯を置かず U1 の岩壁＋橙霧を視覚境界にする）
・到達＝領域天井部の灰噴出域を抜けて着弾域へ落下（逆流口＝帰還専用。逆流口直上着弾は帰還発火への誤着弾を構造的に防ぐため分離——横断監査の決着）
・二度棄て→座の実連動＝座未実装のため語彙/記録のみ・消費先は終章実装（docs/40 §7.2・U2 §4.6-4 と同型に所掌外と明記）
```

三領域は三つの役割で一枚の機構になる：**埋立て地＝着弾する側（空間・素材・灯り）、住人＝届いた者（人格・物語・敵性）、喪失境界＝領域の縁（越境・烙印・迷子化）、接続点＝現実との管（処理・帰還・記録）**。
