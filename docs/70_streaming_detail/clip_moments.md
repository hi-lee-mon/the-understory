## §1. 判定基準（クリップ瞬間であるとは何を指すか）

### 1.1 30秒ルール（G-SD-07）

docs/17 §3 の確定文「**配信を知らない人にも30秒で状況が分かる劇的瞬間**」を、本台帳では次の2条件に分解して判定する：

- **条件A（状況の言語化）**：前提知識なしで見た視聴者が30秒以内に「いま何が起きているか」を一文で言語化できる（例：「自分がゴミ箱に入って別世界に落ちた」「ボスを倒したのに救った」）。ミュート呈示で状況が言語化できるかの検証は S-3(a)(c)（docs/41）と接続。
- **条件B（タイトルが立つ）**：その30秒に対して「切り抜きのタイトル」が自然に立つ——§4 の型（気づき系・逆転系・開示系・決断系・感覚系）のいずれかに収まる命名ができる。

### 1.2 配信者反応の要件（P-SD-03）

クリップ瞬間は**配信者本人の反応が発生する構造**を持つものに限る。「個別化メカニクスは配信者本人の反応を直接産む」（docs/17 §3 確定文）。反応の型：

| 反応の型 | 内容 | 例 |
|---|---|---|
| 気づき | 自分の行為・所有物に気づく（個別層の直接反応） | 「あれ、これ俺が捨てたやつ…」 |
| 逆転 | 想定した文法が覆る | 「倒したのに救った」「戦わないのが正解」 |
| 開示 | 画面が一転して状況が分かる | 大幕開幕・遠望・色の回帰・着地初景 |
| 決断 | 選ぶ側に重さがのしかかる | 結末綴じの二択/三択・「入る/入らない」 |
| 感覚 | 音/光/動きの転変に身体が反応する | 無音への突入・幕間の一音・月の充填 |

### 1.3 採録・除外のルール

- **採録**：§1.1 の条件A+B と §1.2 の反応の型を両方満たす瞬間。正典（docs/34 各章 §10・docs/51 見せ場欄・docs/17 §3）に実在する演出のみ。
- **除外**：長い説明・長文閲読に依存する瞬間（docs/08 §3 失敗モード「長い説明」）／演出時間規格上の「間」（幕間暗転・静まりの一拍——情報を置かない間そのものはクリップでなく、クリップの「ため」を作る部位。docs/48/03 §3.4）／シェーダー OFF で一次が崩れる瞬間（一次チャネルは OFF で成立する前提——G-CB-06）。
- **配信モード差分**（G-CB-24・57-U2-Q10）：`stream.effect_compression=shortened` 時は暗転長のみ係数0.6で短縮。**多重化・系列・字幕は削らない**ため、本台帳の全エントリは配信モードでも成立する（崩れるのは「長さ」だけで「形」ではない——crosscutting §3.4）。
- **マルチ同期**：共有層イベントの発火同期はサーバー権威±100ms（19-U1-Q3/19-U4-Q4・57-U2-Q12）——同席する複数配信者が「同じ瞬間」を同時に反応できる担保。

### 1.4 S-1 採点集合との関係

検証項目 S-1（docs/40 §5.2.4・40-Q7⑨）は「クリップ瞬間≥3個が実際に切り抜き可能な反応」を合格ラインとし、観測集合＝「S-1 列挙6件∪Issue #17 確定版7件∪34/01 §10 の9件」の3系統和集合として事前固定済み。**採点集合＝S-1 正典列挙の6瞬間**（転移の「壊れる」・「全部俺のゴミ」・翁の正体・満月窓・結末綴じ→色回帰・捨て場の自画像——docs/40 §5.2.4 引用忠実）は **41-U4-Q8 で承認済み（2026-10-04）**。本台帳は全候補を収録し、承認済み6瞬間と CM-ID の対応を §5-17-U1-Q1 の対応表として記録する。採点集合を観測和集合へ広げる変更は 41-U4-Q8 の定義どおり「40-Q7⑨ のライン実質変更＝ユーザー決裁対象」に相当するため、変更する場合のみ §5-17-U1-Q1 の変更要求として扱う。

### 1.5 エントリの書式（判定可能な6欄）

| 欄 | 内容 |
|---|---|
| CM-ID | `CM-{区画略号}-{連番2桁}`（00/01/02/03/04/05/06/VL/IS/X）。確定後に改番しない（crosscutting §0.2 準用） |
| 瞬間名 | 30秒の内訳が見える呼称（正典の呼称を優先） |
| 発生条件 | どのビート/トリガで起きるか（BD-ID・34/NN §n・N-BOS 等。スライス外は節参照＝暫定） |
| 配信者反応 | §1.2 の型＋具体的な反応内容（プレイヤーが驚く/語ること） |
| 視聴者反応 | 前提知識なしで30秒に言語化できる状況（＋考察班・コメント同期の接続） |
| 出典 | 完全修飾の正典 ID（P-SD-01）＋切り抜きタイトル例（§4 の型準拠） |

## §4. 切り抜きタイトル例・サムネポイントの型

### 4.1 切り抜きタイトルの型（命名の規格）

判定基準 §1.1 条件B の「タイトルが立つ」を、配信者が実際に付けられる5つの型で固定する。各 CM エントリのタイトル例は以下の型に収まる：

| 型 | 構造 | 適用例 |
|---|---|---|
| 気づき系 | 「あれ、これ俺が〜」「〜だと気づいた」一人称の発見 | 「あれ、これ俺が捨てたやつ…」「葉っぱ全部手紙なんだけど」 |
| 逆転系 | 「〜したのに〜」「〜が正解だった」文法の反転 | 「倒したのに救った」「戦わないのが正解だった」「ボスを倒す＝手紙を届けることだった」 |
| 開示系 | 「〜が見えた」「〜に着いた」画面の一転 | 「霧の港に灯台の残火だけが見えた」「この世界の地図が一望できた」 |
| 決断系 | 「〜派？〜派？」「〜するか〜しないか」選択の重さ | 「書き換える派？見届ける派？」「扉を開けるか開けないかで揉めた」 |
| 感覚系 | 「〜が鳴った/動いた/消えた」身体の反応 | 「一歩踏み入れたら全部の音が消えた」「無音の世界で鐘が初めて鳴った」「撃つたび月が満ちていくボス戦」 |

**命名ルール**：
- 30秒の内容がタイトルだけで想像できること（前提知識なしで読める）。
- ネタバレ境界：核心（由来物の正体・没腐・結末構造・切り抜き瞬間そのもの＝docs/43 §6.3 情報粒度表）をタイトルに書かない——「翁の心」「落慮王の正体」など核心語は避け、絵面・反応で表す（43-U3-Q6「切り抜き瞬間そのものは素材化しない」と整合——本節は**配信者が自分で付けるタイトルの型の記録**であり、公式の提供素材ではない。§5-17-U1-Q2 参照）。
- 「俺/あんた」の一人称は配信者視点のまま（個別層の反応をそのまま活かす）。
