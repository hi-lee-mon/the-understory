## 3. 横断規則（全3書共通の判定枠——引用のみ）

- **用語の棲み分け**（44-U3-Q5 承認済み）：検証項目名＝**クリップ瞬間**／設計概念＝**切り抜き**／口語＝**見せ場**。本書群はこの3語を交換不可能な語として使う。
- **30秒ルール**（docs/17 §3）：「配信を知らない人にも30秒で状況が分かる」劇的瞬間——判定可能な言語化（P-SD-02）で、前提知識なしの視聴者が30秒以内に状況を言語化でき、切り抜きタイトルが立つことを各瞬間の合否条件とする。
- **配信者反応の設計**（P-SD-03）：各クリップ瞬間は「視聴者の反応」だけでなく「プレイヤー本人が驚く／語る」構造まで言語化する——個別層演出（自分の捨てた物・自分の捨て場）は配信者本人の反応を直接産む正典の設計（docs/17 §3）。
- **層の分離**（P-SD-04）：ゲーム内機構（正典の実在仕様）と配信運用（宣伝・素材・イベント運営）を分けて記述する——配信運用の正本は docs/43・docs/46。本書群はゲーム内機構側を主担当とし、運用側は接続の形で記す。
- **採否判定構造**（P-SD-05）：観客参加・期間限定要素は全採用を前提としない——各候補に「採る/採らない」の判定を立て、採る場合の保守コストと得られる価値を並べる。採否はユーザー決裁（G-SD-05）。
- **同席者方針**（G-SD-03）：視聴者＝同席者——視聴者にだけ別の景色・情報を出す機構を創作しない。コメント参加は「プレイヤーと同じ景色への反応」の設計として扱う。
- **承認済み制約の引用のみ**（G-SD-02）：D-7 サーバーイベント主経路・U4-11 配信モード画面なし・18-U4-Q13 観戦/俯瞰不採用・U2-D/U4-#2 予告頁＝ノミ語り＋挿絵・U4-9 ARG接点素材規範（ガラ字形・ゲーム内既出刻印の引用のみ・真相言明禁止——正本 docs/48/04 §3.5）・43系運用承認群（43-U3-Q1〜Q7）——これらを覆す記述はしない。
- **保守負荷の明記**（G-SD-08）：期間限定・イベント運用の各候補には保守コスト・サーバー運用負荷を配慮として併記する（正本＝events.md §4——単独開発・docs/42 の保守リスク系に接続）。
- **暫定値の扱い**（G-SD-09）：未着地・暫定値は「暫定＋着地先」を明記する。
