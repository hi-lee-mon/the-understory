# docs/27：体験サンプル（短編小説）

> この世界でプレイヤーが辿る体験を、小説として書いたもの。
> 「面白いかどうか」の判断材料は、説明ではなく物語そのものである。
> ゲーム内テキストではなく、プレイヤー視点の体験記。

## 捨てたものの国で

チェストがいっぱいになった。

丸石、腐った肉、壊れかけの石斧、あと――攻略本でしか見たことのないレシピが、いつの間にか本に挟まっていた。「ゴミ箱」。作ってみると本当に便利で、いらないものを放り込むと、きれいに消えてくれた。

ぼくはそれから毎日、捨てた。使わなかった鉄の剣も、読みもしないのに貯まった本も、初期に作って二度と振らなかった木の槍も。

ある日、なんとなく日記の続きを書いて、それをゴミ箱に入れてみた。

翌朝、ゴミ箱の中に何かがあった。

よれよれの地図と、一枚のレシピ。「デカいゴミ箱――ゴミ箱8個」。レシピの端に、誰かの字で書き添えてあった。

**「あんたが入れる箱の作り方」**

誰かが、返事をくれていた。

ゴミ箱を八つ作って、組み立てた。人がひとり入れる大きさの、ゴミ箱。蓋を閉めると、音が遠くなった。世界が歪んで、ぼくは落ちた。

落ちた先は浜辺だった。

見覚えのある風景だった。正確には、見覚えのある**ものたち**だった。壊れかけの石斧が砂に突き立ち、読まなかった本が積み上がり、木の槍が斜めに倒れている。ぼくが捨てたものが、全部、ここにあった。捨てたつもりで、届いていた。

「来たか」

振り返ると、小さい毛皮の生き物が立っていた。尻尾の先が少しだけ欠けている。

「待っていた。ずっと待っていた」

案内人だと名乗ったその生き物は、ぼくを連れて歩き始めた。この国は、棄てられた物語が地形になっているのだという。月が満ちなかった森。読まれなかった港。踊らなかった広場。どこも、終わるはずだった何かが、終われないまま残っている。

森の奥には老人がいて、ずっと月を見上げていた。彼の手紙にはただ「もうすぐですよ」とだけ書いてあった。同じ手紙を、何百通も書いた跡が、小屋に残っていた。ぼくはその手紙の最後を、一緒に書いた。翁は月を見て、長い間止まっていた何かが、ゆっくり動き出す音がした。

「やっとだ」

翁がそう言ったとき、森に色が戻った。倒したわけじゃない。終わらせたんだ、とぼくは思った。

それからずっと奥で、壁に殴り書きの落書きを見つけた。

「おれは帰れなかった。でも、物は届いていた。この国は、おまえの捨てたものでできている。おまえが捨てたものの、行き先だ」

ぼくは、浜辺のあの山を思い出した。

一番深い場所には王がいるという。一度も存在しなかった世界の、王。ぼくたちが「捨てる」と呼んできた行為の向こう側で、棄てられなかった全部を、拾い集めてきた王。

案内人は言った。

「あんたは拾い人だ。拾うというのはな、この国ではたいへんな意味を持つ言葉だ」

帰り方は、簡単だった。浜辺の、自分の捨て場のゴミ箱に入る。蓋が閉まって、目を開けると、いつもの拠点だった。

ゴミ箱がそこにある。

もう「消すための箱」には見えなかった。

今日も何か捨てようと、ぼくは蓋を開けた。

## この短編が検証しているもの

| 体験の核 | 小説内の対応箇所 |
|---|---|
| QoLの捨てるが世界になる | 捨て物がそのまま浜辺の風景になる |
| 届けると返ってくる | 日記を捨てる→レシピと手紙が返礼として届く |
| 自分で箱に入る儀式性 | 「あんたが入れる箱の作り方」→デカいゴミ箱に自ら入る |
| 読むと刺さる層 | 「もうすぐですよ」の手紙を見届ける体験 |
| 伏線・推理の深読み | 前任の拾い人の落書き、王の正体、ノミの言葉 |
| 「拾う」の第三の意味 | 案内人の最後の言葉が物語全体の主題をひっくり返す |
| 帰還の日常化 | 現実に戻ったあとゴミ箱の見え方が変わる |

## 設計メモ（なぜこの構成か）

- **入口はベッドではなくゴミ箱**：「捨てる」以外の動作で世界に入ると世界観が壊れる。初回転移は「返礼レシピが届く→自分で箱を作る→自分で入る」の流れに一本化した。
- **返礼レシピは案内人（ノミ）が送る**：初めての接触が「招待状」になることで、レシピ開放がシステム解放ではなく物語イベントになる。
- **捨て場がそのまま最初の光景**：到着直後に「自分のゴミ山」と対面させることで、ゲームの核心（個別化）を説明不要で体験させる。
- **王の正体は最後に一句だけ**：語りすぎない。残りはプレイヤーが歩いて探す。
