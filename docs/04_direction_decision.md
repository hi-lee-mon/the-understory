# 設計書 04：方向性の最終決定（再調査の結果）

## 1. 再調査で分かったこと

### 1-1. 案C（夢次元）は既存ニッチが埋まっている
- **Good Night's Sleep**（1.6.4時代から存在する老舗）：特殊なベッドで眠ると夢/悪夢次元に行く — ユーザー案「ベッドで特定操作すると夢世界へ」とほぼ同構造。
- **Dreams N' Nightmares**、その他複数の夢次元MODが存在。
- 結論：夢次元単体では独自性が弱い。

### 1-2. 案D（時間操作の都）も部分的に占有済み
- **ChronoDawn**（2025年）：時間テーマの次元MOD（ポータル・ボス・時間アーティファクト）。
- **The Time Stop Mod / Temporal Disjunction**：時間停止・巻き戻しのツール系MODが実在し、技術的実現性は証明済み。
- 結論：時間テーマは先行者あり＋実装難度は依然最高。

### 1-3. 「異形・バグ・消されたもの」系はバイラル実績が証明済み（重要）
ユーザー提案「昔のバグが実はMOD世界の入口だった」は、現在Minecraft界隈で最も伸びている潮流と一致：

| MOD | 内容 | 規模 |
|---|---|---|
| **The Man From The Fog** | 霧の中から見つめるストーカー実体 | **約2200万DL**、2800超のmodpack採用 |
| **From The Fog** | Herobrine（都市伝説）の実体化 | **約1600万DL** |
| **The Broken Script** | ARG型ホラー。MOD内に隠しMOD、暗号化音声、現実侵食の演出 | ホラー配信で大流行、専用Wiki・ARGコミュニティあり |

- このジャンルは「**ゲームの外まで謎が侵食してくる**」メタ演出が核。配信者が「解読する」コンテンツとして爆発的に伸びた。
- **Far Lands**（旧バージョンの地形バグ）はMinecraft史上最も有名な「消されたバグ」。復元MODは存在するが、**「Far Lands的な異物を入口にした物語次元」は未作**。

### 1-4. 「没になったコンテンツ」には既存の感情投資がある
- Mojangの**モブ投票落選者**（Glare、Moobloom、Iceologer、Rascal、Tuff Golem等）、没になった仕様、削除された要素（Far Lands、旧空ディメンション案等）はコミュニティの「ロス」の対象。
- 「落選したモブたちが実はどこかの世界に生きている」という発想は、コミュニティの既存感情を直接掬える。**これは他のどの案にもない強いフック**。

## 2. 新たに見つかった第5の案：**「棄てられたものの国」**（案E）

### コンセプト
**「選ばれなかったもの、消されたもの、バグとして捨てられたものが流れ着く次元」**。
プレイ中に捨てた・使わなかった物、没になったモブ、削除された地形、旧バージョンの遺物——すべてがこの世界では実在する。

### ユーザーの2つの案を同時に取り込める
- **「昔のバグが入口」**: 現実世界に稀に出現する**「異物チャンク」**（旧世代の地形・存在しないブロック・異様な生成物）。近づくと世界が壊れ、次元へ呑まれる。anomaly系MODのバイラル要素そのもの。
- **「ベッドでの儀式」**: ベッドの傍らに「自分が捨てた物／一度も使わなかった物」を置いて眠ると、夢の中で世界が壊れてあの国へ落ちる（夢遷移＝入口＆没入的導入）。

### ストーリー骨子
- この世界は「現実に選ばれなかった一切」が集う。ここに住む者たちは「自分が没だった」と知っている。
- 各章＝**一つの「棄てられたもの」の物語**。プレイヤーはそのものの「なぜ捨てられたか」「本当は何だったか」を追い、**結末を書き換えるか、受け入れるか**を選ぶ。
- 黒幕／核心：「最初に棄てられたもの」＝世界そのものの原案（現実のゲームの没になった初期設計）。全ての棄て物の王。
- テーマ：**「選ばれなかったものにも意味がある」**（世捨て人の慰めと再生——日本の配信文化に深く刺さる感動系テーマ）。

### 構造（案Aの強みを継承）
- 章立て構造＝案Aの「物語ごとに別世界」構造を流用。各章が「捨てられた物語」になる。
- 同行NPC＝**没になったモブ風のオリジナルキャラ**（例：光る茸の精霊、投票に落ちた案内人）。名付け・愛着対象。
- アイテム＝「消された素材」「β版の鉱石」「没になった道具」などを実装。クラフトの主軸は**「捨てられた素材の再発掘」**（ガラクタを真の宝に鍛え直す）。

### 配信映え
- 「異物チャンクを見つける」導入はanomaly系バイラルと同型。
- 「あの没モブに会える」話題性。
- 「ベッドに物を置いて眠る」儀式は模倣されやすい作法。
- 章＝捨てられた物語のエピソード単位＝配信回。

### リスクと対策
- **IP配慮**: Mojangの没モブのデザイン・名称を直接流用しない。**オマージュ・オリジナル**の「選ばれなかった者たち」として設計（モチーフは共通認識できる程度に留める）。
- 「バグ」の演出はホラー寄りになりすぎないよう、入口は「不気味」、中は「哀愁＋幻想」で温度差を作る（切り抜きの落差が生まれる）。

## 3. 最終決定

| 案 | 判定 |
|---|---|
| A 物語の国 | 良いが「物語の中に入る」はやや抽象。Eに構造を継承 |
| B 遊園地 | 映えるが制作コスト最大・物語深度がやや浅い |
| C 夢次元 | **既存MODが先行**（Good Night's Sleep等） |
| D 時喰いの都 | **既存MODが先行**（ChronoDawn等）＋実装最高難度 |
| **E 棄てられたものの国** | **採用**。ユーザーの2案（バグ入口＋ベッド儀式）を統合し、バイラル実績のあるanomaly流と、コミュニティの没コンテンツへの感情を結合。独自性・物語深度・配信映えの全てで最高点 |

**決定**：**案E「棄てられたものの国」（仮称：The Unchosen Realm / 捨てられし者の国）**を採用する。
方向性としては「**anomaly的な導入（異物・バグ・夢）＋物語次元（章構造）＋クラフト（捨てられた素材の再発掘）**」の複合。

仮称候補：「棄てられた者の国」「没世界（ぼつせかい）」「Unchosen」「Discarded Realm」「落選世界」 — ネーミングは別途検討（todo.mdへ）。
