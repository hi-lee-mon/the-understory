# アイテム・拾得物全表（01_items.md 相当）—— Issue #15 担当ユニット U1

> 本節は全表ドキュメント群（38_numeric_tables/）のうち「素材・拾得物」系を担う。**全行の状態列（確定/暫定/要承認）と出典列を必須とし、ID 規則 N-ITEM-xxx に従う**（docs/37 §5）。食料の満腹度はバニラ値を参照アンカーとして括弧併記する。数値のうち正典に根拠のないものは「提案」として状態列に明記する。

## 1. 目的と読み方

- この表は「世界にある物の分類と流通の帳簿」である。**個々の品目ごとに：拾えるか／持ち帰れるか／由来を嗅ぎ分けられるか／素材になるか**を一意に決める。
- 「拾得物」とは国側で拾い直しが済み持ち主がついた物（00 §6）。「宝物」は明確な由来を持つ拾得物で、マテリアル化（素材化）の対象——**素材化すると「失われた物語」として記録され、持ち主に還せなくなるトレードオフ**（C6）。「ガラクタ」は個別記憶を持たない集約漂着物。「結末の欠片」は結末綴じの収集物（別分類）。
- 拾い直し可否・持ち帰り可否の判断軸は docs/32 §1.2 の五分類（拾得物／携行品に収めた物／汎用建材／生き物・住人／没腐汚染物）に一致させる。

### 2.4 拾得の携行品（器）系列表 —— 容量系列の根拠つき

器の容量＝**携行品に収めた物を現実へ持ち出せる個数スロット**（スタック不可・1枠1個）。**ただし容量が効く対象の範囲について正典は分裂している**：docs/32 §1.2 は二段構造（「拾得物＝由来確定・拾い直し済み」は無条件に持ち帰り可／「携行品に収めた物＝未加工の没素材・装飾品」は器の容量分のみ可）で、容量は後者にのみ効くと読める。00 §6 も「序章は器未導入、拾い直した物は素の持ち物枠で持ち帰れる」と器なしの持ち帰りを規定する。一方 docs/14 §3「拾得の携行品：拾得物を現実へ持ち帰るための器」は全拾得物に器を要する読み（B）を支持する。**本節は暫定的に A 読み＝「登録済み拾得物は通常持ち物として自由に持ち出せ、器の容量は未登録・未加工の収め物にのみ効く」で記述する**（00 §6・32 §1.2 の字面整合側）。B 採用時は序章の持ち帰りを素の持ち物枠の例外経路として明文化する必要がある（未決 #15）。死亡時は携行品の中身を全て没腐遺留物として落とす（docs/32 §2.1）ため、容量の成長はそのままリスクの成長になる。

## 3. 設計上の判断（この表固有の運用決定）

1. **「届きもの」は逆向きの流通として扱う**：拾い直し可否の列を「—（届く物）」とし、拾得物と区別。返信手紙・住人便・誤配は物語・関係性の報酬が中心で実用品は記念品級まで（23 §7 頻度設計・D7 と整合——護石式禁止の維持）。
2. **没腐汚染物は「浄化で持ち帰り可に遷移」**：043 の行で持ち帰り可否を条件付きにし、浄化機構（灯った提灯等）との接続を明記——32 §1.2 の五分類を完全に表に落とす。
3. **摘み籠の容量系列は暫定 A 読みを前提に置いた提案値**：器＝未登録・未加工の収め物の出口枠という読み（未決 #15）の下で 4→6→12→20 の系列を設計した。B 読み（全拾得物が器スロットを消費）採用時は容量の意味が「拾得物の総枠」に変わるため、系列の根拠自体を再検討する。
4. **食料の数値権威は U2（02_gear_devices.md）に集約する**（docs/37 §5.2 の責務割当——横断監査で発覚した「祭りの残り」「宵の実」の U1/U2 二重定義を解消）。本表のうち U2 と二重定義だった行（060 祭りの残り・061 宵の実）は拾得物メタ（分類・鑑定・拾い直し・持ち帰り・入手先）のみを持ち、回復量・バフ・スタック・使用回数の数値は U2 §3.7 を参照とする。U1 固有の鍛錬生成食（063/064）は引き続き本表で値を持つが、品目採択時に U2 §3.7 へ行を追加する運用とする。バニラ参照アンカー（ステーキ級 8/12.8・りんご級 4/2.4・金のニンジン級）の語彙は両表で共通運用する。旧案（祭りの残り＝再生I＋速度バフ案）は U2 側の拍子窓補助案に一本化され棄却——議事録として本項に残す。
5. **名の残る部位の領域外流出禁止との折り合い**：027 は「章内で使う＝拾い直し完了」の章内動詞に留め、持ち出し可否は「可」だが運用上は要承認級の例外として注記（04 §5 の領域外流出禁止と表の持ち帰り可否を矛盾させないため）。
6. **幻想文字は拾得物（かけら・071）と環境文字（079）に分離**：碑文・刻印は拾えない物として類型行にまとめ、「拾える幻想文字のかけら」の正典上の配置は序章・岬足下の1箇所のみに限定した。
7. **結末の欠片の効果は「垣間見せ」以上を書かない**：「結末に関わる」の具体形（結末への効果の有無）は正典上未明記（36a §7）のため、未決へ。
8. **分類列は単一値で運用**：§5.1 の分類 enum（没素材/宝物/ガラクタ/結末の欠片/その他）に従い、類型行の混在は代表値＋「（品による）」注記で処理する（§2.7 の運用規定）。
