# 20_UI・デザインシステム・アート方向（v0.1）

> ユーザー要望：影MOD対応・カスタムフォント・独自ゲーム感のデザインシステム。ここにMOD全体の「見た目・触れた感じ」の言語を定義する。

## 1. デザイン言語の統一コンセプト：**「かすれた・欠けた・継がれた」**

棄てられたものの国の審美は、バニラの「鮮やかで完全」に対して**「色が薄れ・形が欠け・それでも継がれてきたもの」**。この審美をブロック・UI・フォント・演出すべてに浸透させる。

- キーワード：**かすれ / 欠損 / 古色 / 接ぎ木 / 灯りの温かさ / 静かな不気味さ / 哀愁**
- 対になる審美：現実（鮮やか・完全）↔ 国（かすれ・欠損）→ 章を救うとその土地が**少し色を取り戻す**（進行の可視化にもなる）

## 2. デザインシステム（独自UI体系）

バニラUIの流用でなく、MOD専用のデザインシステムを構築：

| 要素 | 方針 |
|---|---|
| **カラーパレット** | 基調：灰青・月白・墨・古金。アクセント：拾得の「朱」と「灯りの琥珀」。章ごとにサブパレット |
| **形状言語** | 欠けた矩形・破れたページ・継ぎ目・不完全な円。角は「欠ける」ことを恐れない |
| **アイコン体系** | 統一した線の太さ・欠け表現の独自アイコンセット（拾得/没腐/結末/図鑑） |
| **レイアウト** | 「書物・頁・綴じ目」をモチーフにしたUI（図鑑・結末記録・村報） |
| **モーション** | 「かすれて現れる」「欠片が綴じられる」等、独自の画面遷移・エフェクト |

## 3. フォント方針

- **独自フォントを実装**：バニラフォントを使わず、世界観用の書体を設計・同梱
  - **幻想文字**：国の住人の文字・碑文・ロア書物用の架空書体（解読要素にもなる）
  - **本文フォント**：和英対応の読みやすいデザイン書体（通常UI）
  - **「かすれ文字」**：古い文書・異物の表記用の崩れた書体
- **文体は `docs/26_narrative_vectors.md` §4 の「かすれた・欠けた・継がれた」規範に従う**（見た目と言葉で同じ審美を共有）
- 技術：`font` プロバイダ（TrueType/Bitmap）＋言語切替対応。実装はADRで確定
- 注意：和文フォントはグリフ数・ライセンスに注意（自作または利用可能書体を選定）

## 4. シェーダー/影MOD対応（配信者必須要件）

配信者はほぼ全員シェーダー/影MODを使用。**公式対応を設計要件に入れる**：

- **対象**：Iris + 代表的シェーダー（Complementary, BSL, Sildur's 等）、Distant Horizons（望遠）との併用
- **設計上の配慮**：
  - 独自の空・霧・光の演出がシェーダーと共存できるよう、**レンダリングをシェーダー互換の範囲で設計**
  - 「かすれた世界」の色味はシェーダー越しでも成立するパレットに
  - 異物の演出はシェーダーON/OFF両方で崩れない検証
- **検証項目（playtestへ）**：主要シェーダー3種×（異物演出・次元空・ボス演出・UI）の表示確認

## 5. バイオーム別アート方向（章）

| 章 | パレット・質感 | 光・演出 |
|---|---|---|
| 序・漂着浜 | 灰青・月白・打ち上げた無数の物 | かすれた朝靄、遠雷 |
| 1・月の林 | 深緑を欠いた灰緑・欠けた月の光 | 月が欠けたまま止まる、蛍の残光 |
| 2・読めなかった港 | 錆・古紙・潮風の白 | 灯台の残火、潮の満ち引き |
| 3・踊らなかった広場 | 褪せた祭り色・提灯の残光 | 止まった屋台、風に揺れる飾り |
| 4・選ばれなかった坑道 | 鈍い鉱石の輝き・土と鉄 | 坑道の灯り、輝きかけて止まる鉱脈 |
| 5・歌えなかった塔 | 白亜・無音の響き・鐘の陰 | 響かない鐘、間（ま）の演出 |
| 終・原案の座 | 白紙・最初の色・世界の設計図 | 全章の回帰、物語の集約演出 |

## 6. UI画面一覧（`18`で詳細化）

- **拾得図鑑**：拾ったもの・救った物語の図鑑（綴じ目UI）
- **結末の記録**：各章の選択と世界変化の記録
- **村報（むらだより）**：拾い人の村の発展・住人・解放要素
- **没腐コンパス**：歪みの方向を示す案内（ノミと連動）
- **結末綴じ画面**：「書き換える/見届ける」選択の特別UI（ここが最大の演出面）
- **予告頁**（`09`）：章クリア時にノミが綴じる次章の断片（書物演出）
- **幕間演出**：ボスのフェーズ転換や章の結末を「幕」として演じる画面遷移
- **エンドロール/ポストクレジット**：終章後の名・残した者たちの名と一場面

## 7. 音の方向（`19`詳細、ここではUI音のみ）

- UI音も「かすれた・古い」質感（紙、木の軋み、かすれた鐘、巻き戻る音）
