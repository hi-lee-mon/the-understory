# 20_UI・デザインシステム・アート方向（v0.1）

> ユーザー要望：影MOD対応・カスタムフォント・独自ゲーム感のデザインシステム。ここにMOD全体の「見た目・触れた感じ」の言語を定義する。

## 1. デザイン言語の統一コンセプト：**「かすれた・欠けた・継がれた」**

棄てられたものの国の審美は、バニラの「鮮やかで完全」に対して**「色が薄れ・形が欠け・それでも継がれてきたもの」**。この審美をブロック・UI・フォント・演出すべてに浸透させる。

- キーワード：**かすれ / 欠損 / 古色 / 接ぎ木 / 灯りの温かさ / 静かな不気味さ / 哀愁**
- 対になる審美：現実（鮮やか・完全）↔ 国（かすれ・欠損）→ 章を救うとその土地が**少し色を取り戻す**（進行の可視化にもなる）
- **色の回帰の演出規則（U1-Q2 承認・Issue #31）**：救出時の色の回帰は「**中心から外へ滲む動的勾配**」で演出する——物語の中心（救出対象・座標点）から彩度が外縁へ滲むように戻る。彩度・かすれは二次指標であり、救出完了の一次表示は「点灯個数・動きの復帰・音の復帰」の三重信号が担う（docs/45 04 規則C-2）

## 2. デザインシステム（独自UI体系）

バニラUIの流用でなく、MOD専用のデザインシステムを構築：

| 要素 | 方針 |
|---|---|
| **カラーパレット** | 基調：灰青・月白・墨・古金。アクセント：拾得の「朱」と「灯りの琥珀」。章ごとにサブパレット。**色の予約（Issue #31 承認）**：拾える物の標識＝拾得の朱一本／「読める物」を兼ねる拾得物のみ琥珀を許す例外（docs/45 01 §4.4）。拾得トークンの統一仕様は docs/14 §3 参照 |
| **形状言語** | 欠けた矩形・破れたページ・継ぎ目・不完全な円。角は「欠ける」ことを恐れない |
| **アイコン体系** | 統一した線の太さ・欠け表現の独自アイコンセット（拾得/没腐/結末/図鑑） |
| **レイアウト** | 「書物・頁・綴じ目」をモチーフにしたUI（図鑑・結末記録・村報） |
| **モーション** | 「かすれて現れる」「欠片が綴じられる」等、独自の画面遷移・エフェクト |
| **環境トークン（Issue #31 承認）** | **打痕・摩耗表現**：ひび割れ系ブロック変種＋同一位置の摩耗/色剥落＋撞座の反復配置で「無数の打痕」「磨り減った撞木」を表現（U3-Q3）。**経年の2層ルール**：停止層＝かすれ風化変種、前任層＝その上の新しい痕跡（落書き・踏み固め・持ち去り跡）、3層目は禁止（U3-Q4） |

## 3. フォント方針

- **独自フォントを実装**：バニラフォントを使わず、世界観用の書体を設計・同梱
  - **幻想文字**：国の住人の文字・碑文・ロア書物用の架空書体（解読要素にもなる）
  - **本文フォント**：和英対応の読みやすいデザイン書体（通常UI）
  - **「かすれ文字」**：古い文書・異物の表記用の崩れた書体
- **文体は `docs/26_narrative_vectors.md` §4 の「かすれた・欠けた・継がれた」規範に従う**（見た目と言葉で同じ審美を共有）
- 技術：`font` プロバイダ（TrueType/Bitmap）＋言語切替対応。実装はADRで確定
- 注意：和文フォントはグリフ数・ライセンスに注意（自作または利用可能書体を選定）

## 4. シェーダー/影MOD対応（配信者必須要件）

配信者はほぼ全員シェーダー/影MODを使用。**公式対応を設計要件に入れる**：

- **対象**：Iris + 代表的シェーダー（Complementary, BSL, Sildur's 等）、Distant Horizons（望遠）との併用
- **設計上の配慮**：
  - 独自の空・霧・光の演出がシェーダーと共存できるよう、**レンダリングをシェーダー互換の範囲で設計**
  - 「かすれた世界」の色味はシェーダー越しでも成立するパレットに
  - 異物の演出はシェーダーON/OFF両方で崩れない検証
  - **導線演出の演出言語（U1-Q1 承認・Issue #31）**：「朧な光」＝**光源配列（点→線→面）＋天空光・霧の傾斜＋滞留粒子差の複合器**と定義。直線の光筋は明示段階の限定場面（序章必走路等）のみ許可。全導線は「シェーダーOFF＝素のバニラ表現」で成立が必須条件（彩度・色味依存の信号は明度差・形状差・配置差で担保——docs/45 01 §1.4）
- **検証項目（playtestへ）**：主要シェーダー3種×（異物演出・次元空・ボス演出・UI）の表示確認。**Issue #31 承認で追加**：本書系の導線演出（彩度勾配・朧な光のパーティクル・淀みの霧滞留・客席の照明・空の月の見え方・村の灯り・画面歪み）も同じ検証対象に含め、各演出の OFF 時一次チャネルが機能することを確認（U2-K。OFF 時の代替併記は docs/45 各章表を参照）。加えて「色を取り戻す」救出完了表示の配色シミュレーション（protan/deutan/tritan 各型）での実機確認を検証項目に登録（U4-#7）

## 5. バイオーム別アート方向（章）

| 章 | パレット・質感 | 光・演出 |
|---|---|---|
| 序・漂着浜 | 灰青・月白・打ち上げた無数の物 | かすれた朝靄、遠雷 |
| 1・月の林 | 深緑を欠いた灰緑・欠けた月の光 | 月が欠けたまま止まる、蛍の残光 |
| 2・読まれなかった港 | 錆・古紙・潮風の白 | 灯台の残火、潮の満ち引き |
| 3・踊らなかった広場 | 褪せた祭り色・提灯の残光 | 止まった屋台、風に揺れる飾り |
| 4・選ばれなかった坑道 | 鈍い鉱石の輝き・土と鉄 | 坑道の灯り、輝きかけて止まる鉱脈 |
| 5・歌えなかった塔 | 白亜・無音の響き・鐘の陰 | 響かない鐘、間（ま）の演出 |
| 終・原案の座 | 白紙・最初の色・世界の設計図 | 全章の回帰、物語の集約演出 |

**章パレットの運用規則（Issue #31 承認）**：
- **彩度勾配の2軸（U1-Q2）**：彩度↑＝物語の中心へ（パレット充填率：外縁→中間→中心の3帯・目安30%/70%/100%・実装側の仮置き目安）／かすれ↑＝淀みへ（彩度↓＋灰化＋滞留粒子）を別軸として運用。救出の完了表示は色でなく三重信号（docs/45 04 C-2）が一次を担う
- **現実側サブパレット（U2-B・U4-#4）**：縁の地の標識は**造形一次**（廃村・捨て場の遺構——捨て物の集まり・枯れた形）とし、彩度低下「色が抜ける区画」は二次補助として運用（シェーダーOFFでは造形が一次を担う——G6）
- **経年表現の2層（U3-Q4）**：章パレットの風化変種＝停止層（世界が止まった経年）、その上の新しい痕跡＝前任層（落書き・踏み固め・持ち去り跡）。3層目は置かない

## 6. UI画面一覧（`18`で詳細化）

- **拾得図鑑**：拾ったもの・救った物語の図鑑（綴じ目UI）
- **結末の記録**：各章の選択と世界変化の記録
- **村報（むらだより）**：拾い人の村の発展・住人・解放要素
- **没腐コンパス**：歪みの方向を示す案内（ノミと連動）。**指し先の対象範囲は確定（U2-J 承認・Issue #31）**：**未攻略の主線環礁の淀みのみを指し、補助環礁の気配級淀みは対象外**（「装置は寄り道を指さない」原則——G8 汎用仕様のスコープ限定）
- **結末綴じ画面**：「書き換える/見届ける」選択の特別UI（ここが最大の演出面）
- **予告頁**（`09`）：章クリア時にノミが綴じる次章の断片（書物演出）。**実装方式は確定（U4-#2 承認・Issue #31）**：**ノミ語り＋挿絵の書物演出**に決定（実シーン再生は不採用）。環境側の淀み濃度と照合できる設計は docs/45 04 §2.4・docs/17 §8 参照
- **幕間演出**：ボスのフェーズ転換や章の結末を「幕」として演じる画面遷移
- **場面別定量の権威一元化（U1-Q10 承認・Issue #31）**：各場面の演出強度の数値目安（02 霧濃度・03 拍子明瞭度等）は本書に持たず、`docs/45_nonverbal_guidance/02` §3 の場面別定量目安に集約する。幕の暗転長・「間」の長さの規格は docs/38 03 が権威
- **エンドロール/ポストクレジット**：終章後の名・残した者たちの名と一場面
