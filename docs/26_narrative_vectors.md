# 26_語りベクター体系：書物・フレーバー・セリフ・落書きの規範（v0.1 draft）

> **目的**：Issue #29 拡張スコープ第3段（本体）。docs/24 の世界観と docs/25 の人物から、**物語を運ぶ媒体（ベクター）の体系**を定義する——何を・どの器に・どのくらいの量で・どんな文体で書くかの規範。ここが崩れると、世界観の上に積む全ての言葉が崩れる。
> **適用範囲**：書物/文書、フレーバーテキスト、住人セリフ、落書き・看板・碑文、ノミの語り、ゴミ箱経路（手紙・返信・誤配）、図鑑・記録テキスト。
> **関係者**：docs/24（真実の構造）・docs/25（人物の声の源泉）/ 実作業 Issue #10（docs/52 ロア断片）・#11（docs/51 章ボード）・#30（伏線の媒体配分）・#28（語り形式の演出）・#31（非言語導線との住み分け）。
> **ステータス**：draft（要承認の決定点は §10 に集約）。

**設計層**：⑤システム詳細と⑥意味づけの接合。本規範は「深読み層」の全容器を規格化する。

## 1. 層構造の位置づけ（原則の再確認）

- **表層（必読）**：光・色彩・音・造形・配置で導く——**文字を読まなくても遊べる**（Issue #31 の領域）。
- **深読み層（本書の全容）**：文字媒体の全部。**読む人ほど重厚な体験が返る**。深さは読む人の報酬であり削らない（平易さのために深さを犠牲にしない）。
- **境界ルール**：進行に必須の情報を文字に置かない。文字は「確かめる・深める・泣く」層——環境が先に「何かがあった」を示し、文字が後から「何だったか」を確かめる（環境が先、文字が後の二段構え）。

## 2. ベクター総覧（媒体の分類と役割分担）

「世界は語らない。残っているものが語る」（docs/24 §1.3）の原則を、媒体に分解する。**全テキストは「誰かが・何かのために・書いた」三点が透ける**こと——無署名の説明文は置かない。

| ベクター | 器 | 役割（運ぶもの） | 書き手（世界内の人格） |
|---|---|---|---|
| **書物・文書** | 拾える本・紙片 | 章の物語の断片（形式は章の語りに一致：絵本/書簡/戯曲/日誌/詩/設計書） | 章の主・住人・記録係（前任の拾い人の日誌断片も含む） |
| **フレーバーテキスト** | アイテム説明文（Lore行） | その物の「残り香」——誰の・どう愛され/捨てられたかの一齣 | 物自体（語り手不在の客観視点） |
| **住人セリフ** | NPCの吹き出し/会話 | 世界への反応・噂・関係性・日常。村の「生きている」感 | 拾い人の村・各環礁の住人（docs/25 の人格） |
| **落書き・看板・碑文** | 環境の文字 | 場の記憶・警告・名残・「誰かがここにいた」痕跡 | **主に前任の拾い人**・かつての住人・異物の文字化け |
| **ノミの語り** | 同行者の台詞 | 導線の最小限・感情の鏡・予告・綴じ・拾い物への反応 | ノミ（唯一プレイヤーに随伴する語り装置） |
| **ゴミ箱経路** | 手紙・返信・誤配・記録 | **双方向**の通信——唯一プレイヤー「宛て」のベクター | プレイヤー→国 / 「読む者」(救出後の灯台守)→プレイヤー |
| **図鑑・記録** | 拾得図鑑・結末の記録・村報 | プレイヤーの歩みの蓄積（「あなたが捨てたもの」節・結末の記録） | ノミが綴じる（記録係としてのノミ） |

**役割の棲み分け（重複禁止）**：書物＝物語の断片／フレーバー＝物の匂い／セリフ＝人の日常／落書き＝場の記憶／ノミ＝導線と感情／手紙＝双方向の通信／図鑑＝プレイヤーの足跡。同じ情報を2つのベクターに完全には置かない（分散原則：伏線はベクターを跨いで配る、docs/24 §6）。

## 3. 各ベクターの仕様

### 3.1 書物・文書（章の語り形式の実体）

- **形式は章の語りに一致**（docs/09 §2）：
  - 第1章 絵本：大きな文・短い頁・余白の多い語り。「むかし、まんまるの月をまつ人がいました」的な素朴な文体＋歪み（途中で絵が乱れる）
  - 第2章 書簡：宛名・差出人の手紙そのもの。届かなかった想いの束
  - 第3章 戯曲：台本形式（登場人物・ト書き・台詞）。上演されなかった演目の台本
  - 第4章 日誌：日付付きの作業記録。**深部へ行くほど筆致が乱れる**（バイオ型の恐怖演出）
  - 第5章 詩：歌詞の断片。行の断ち・反復・韻
  - 終章 設計書：箇条書き・仕様書語・「案：」の見出し。メタの畏怖
- **分量**：1篇は頁数を絞り朗読に耐える長さ（§8）。1章あたり数篇を散りばめ、集めるとその章の物語が立体になる構成。
- **拾い順の順不同耐性**：どの順で拾っても意味が通る（Carson/Jenkins——提示順序はプレイヤー依存）。各断片は単体で読めて、揃うと大きな絵になる。

### 3.2 フレーバーテキスト（アイテム説明文）

- **役割**：その物の「残り香」。説明でなく「この物がどう愛され/捨てられたか」の一齣。
- **書き方**：1〜2行の短文。抽象的な形容でなく**具体的な物・動作・名**で語る（例：「使い古された鍬。柄に小さな名前の刻印」）。
- **名付けられた物の効果**：プレイヤーが名付けて捨てた物は、フレーバーに**その名が残る**（命名が物語を生む実証——docs/23 §3.3「名付けて入れる」と接続）。
- **由来の読み分け**：拾得物・章アフィニティ物・捨て物で文の温度を変える。

### 3.3 住人セリフ（村・環礁の人格）

- **役割**：世界への反応・噂・関係性・日常。物語の主線でなく「村が生きている」感を運ぶ。
- **規範**：
  - 一人ひとりに**口癖・関心・他者との関係**を持たせる（Stardew型の群像）
  - **選択を記憶する**：結末の選択・拾った物・名付けたことを後から引用する（docs/22「選択が記憶され続ける」）
  - 短く（1〜2文）。朗読・画面表示に耐える長さ
- **カテゴリ**：日常（挨拶・噂）／物語反応（章の結末への言及）／伏線（口を滑らせる真相の欠片）／関係（他の住人への言及で群像を織る）。

### 3.4 落書き・看板・碑文（場の記憶）

- **役割**：「誰かがここにいた」の痕跡。警告・名残・道標・愚痴。
- **主な書き手＝前任の拾い人**（docs/25 §3）：走り書きで次第に乱れていく筆致で、彼の旅路と心境を環境に刻む。「急げ」「もう分かった」「あれは罠だ」——**追う者が自分と同じ道を辿っている**ことをプレイヤーに悟らせる装置。
- **書き方の面白さ**：筆跡に人格を持たせる（誰が書いたか名は無いが分かる）／後で誰かが訂正・返事を書き込んだ落書き（時代差の対話）／間違っている落書き（考察の罠と発見）。
- **異物の文字化け**：読めない文字＝世界のバグの表現。幻想文字（解読可能暗号、docs/20・#28）に接続。

### 3.5 ノミの語り（唯一移動する語り装置）

- **役割**：導線の最小限＋感情の鏡＋予告＋綴じ＋拾い物への反応。
- **体系**：
  1. **導線**：核心を説明せず方向だけ示す（「あっち、なんか淀んでるよ」）
  2. **拾い物反応**：拾った物への一言（由来を嗅ぎ分ける特技——「これ、あんたが捨てたやつだ」）
  3. **綴じ**：図鑑に記す時の口上（「覚えておくよ」）
  4. **予告頁**：章クリア時の次章断片（声・色・一場面を語る——実シーンでなく語り）
  5. **感情の鏡**：プレイヤーの選択・拾い方への反応（選択が記憶される装置）
- **書き方**：「あんた」呼び・砕けた語尾・**核心で口を濁す**（隠している真実が滲む）。正体開示の落差のため、時折「知っているはずのないこと」を口にする（伏線）。

### 3.6 ゴミ箱経路（唯一「あなた宛て」のベクター）

- **手紙（プレイヤー→国）**：記入済み本・署名つき書物で送る。書き手はプレイヤー自身——**形式の規範は緩め**（プレイヤーの自由な言葉）。届く先は章アフィニティ（第2章の港が手紙の集積所）。
- **招待状（国→プレイヤー・初の接触）**：初の返礼として届く「デカいゴミ箱のレシピ＋案内人（ノミ）の手紙」（docs/23 §5.0）。**送り主は匿名**——ノミの正体と伏線になるため名は伏せる（「あんたが入れる箱の作り方」とだけ）。文体はノミの口癖が微かに滲む程度。
- **返信（国→プレイヤー）**：**救出後の灯台守＝「読む者」**が書く（docs/25 §2.2）。文体は実直で不器用、自分の言葉を持たない者が初めて書く言葉——「読みました。届きました」という確認の重み。**返信機能は彼の救出で解放**される構造にする（機構と物語の接続・推奨案 G5）。
- **誤配**：別の誰か宛の漂流便。短い断片小説（「自分宛でない物が届く」違和感＝話題）。
- **「◯◯に捨てられた」記録**：マルチの儀式（docs/23 §8.5）の記録文体——「処理場の落とし主」として残る。**笑いの文体**（堅い記録形式で滑稽さを書く）。
- **規範**：返信・誤配は短く（読むコストを下げ、驚きを上げる）。返信はプレイヤーの言葉を引用して応答する（「あんたが書いた『〜』を読んだ」の形）。

### 3.7 図鑑・記録（プレイヤーの足跡）

- **拾得図鑑**：拾ったもの・救った物語の記録。綴じ目UI（docs/20）。
- **「あなたが捨てたもの」節**：プレイヤーの捨て物が記録される節（docs/23）。**振り返ると自分の捨て方の癖が見える**——自画像的な面白さ。
- **結末の記録**：各章の選択と結果。短い史記調で記す（「あんたは月を満ちさせた」——ノミの綴じとして書く）。
- **村報**：村の発展・住人・解放要素。朗らかな村内新聞の文体。

## 4. 文体規範：「かすれた・欠けた・継がれた」

全テキストが従う統一の筆致（docs/20 の審美を文体に適用）：

### 4.1 基本ルール（Do / Don't）

| Do | Don't |
|---|---|
| **断定を避け、余白を残す**（「〜だったはず」「〜のつもりだった」） | 説明し切る・答えをその場で言う |
| **行為と物で語る**（「使い古した」「積み上げた」——感情語でなく状態） | 感情語の直説（「悲しかった」「怖かった」） |
| **過去・未完・書きかけ**（終わらなかった手紙、書きかけの日誌） | 完成した宣言・教訓の締め |
| **具体的な名・数・物**（「三番目の鐘」「七回目の祭り」） | 抽象的な一般論（「多くの」「いつか」） |
| **問いかけ・言い淀み**（「——届いたかな」） | プレイヤーへの直接的な教示（「あなたは〜すべきだ」） |
| **「かすれ」表現**：欠落・言い直し・滲み（かすれ文字フォントと連動） | 全てが完璧に整った文 |

### 4.2 章の語り形式別の声色

| 形式 | 声色の規範 |
|---|---|
| 絵本（1章） | 素朴・大きな文・優しい言い回し。だが頁を繍るほど歪みが滲む |
| 書簡（2章） | 宛名・敬語・届かない想い。「拝啓」「あなたへ」——読者不在の手紙 |
| 戯曲（3章） | 賑やかな台詞・ト書き・役割名。上演されなかった演目の、張り切った空虚 |
| 日誌（4章） | 実務的・日付・次第に乱れる筆致。「今日も掘った」から「掘るしかない」へ |
| 詩（5章） | 行の断ち・反復・余白。聞かれなかった歌の形 |
| 設計書（終章） | 箇条書き・仕様書語・「案：」——世界そのものの没案としての冷たさと畏怖 |

## 6. 分量・配置規範（予算）

- **書物**：章あたり数篇・1篇は短い頁で朗読に耐える分量。**拾い集めると章の物語が立体になる**数に設定（多すぎて読む負担、少なすぎて薄い——章の語りに見合う断片数を章詳細 #14 で詰める）。
- **落書き**：章あたり十数箇所。前任の拾い人の「旅路を追える」密度。
- **住人セリフ**：住人あたり日常数種＋章進行への反応＋伏線口漏らし＋他住人への言及。
- **ノミ**：状況反応を多数（拾う・捨てる・迷う・名付ける・没腐に近づく等のトリガーに応答）。
- **フレーバー**：個別記憶の対象（名付き・拾得物・由来物）に必置。ガラクタは集約漂着なのでフレーバー不要。
- **配置**：痕跡は「待っていた場所」（各章の中心）に向かうほど密度を上げる——深部ほど「何があったか」が濃くなる勾配。

## 7. 読まなくても遊べる保証（層構造の実務）

- 必須情報は文字に置かない（非言語で導く・#31）。
- 書物は**結末の理解度を変えるが、結末の有無は変えない**——読まないプレイヤーは「救った」体験を、読んだプレイヤーは「何を救ったか知る」体験を得る。
- 収集率を強制しない：拾えなくても章はクリアできる（ただし拾うほど真実が深まる）。
- **環境が先、文字が後**：風景が先に「ここで何かがあった」を伝え、書物が「何だったか」を確かめる二段構え。

## 8. 配信・マルチの考慮（面白さの伝達）

- **朗読に耐える長さ**：書物・返信は頁を短く区切り、配信者が声に出して読める・視聴者が画面で読み切れる分量に。
- **真似したくなる口癖**：ノミ・各住人に配信者が思わず真似る口癖を持たせる（「あんた」「もうすぐですよ」等——docs/17 §4）。
- **読み上げの間**：テキスト表示は「読み切れる最低表示時間」を確保（#18 UI詳細に手渡し）。
- **マルチ**：手紙を他人に読ませる遊び・誤配の「これ誰宛？」の話題・「◯◯に捨てられた」記録の笑い。セリフは複数人で読み合わせても破綻しない短文に。

## 9. 面白くする方法の定義（セリフ・テキストの作法）

面白いセリフ・テキストは以下の構造を持つ（どれか一つ以上を満たす）：

1. **二重運搬**：一文で「情報」と「人格」を両方運ぶ（「灯台の火はまだ生きてるよ。……字はもう、ほとんど読めないけどね」）。
2. **言わないことを言う**：言い淀み・省略・話しそびれ——核心を言わないことで、核心を感じさせる。
3. **口癖の意味変化**：同じ言葉が状況で違う意味になる（月見翁の「もうすぐですよ」は、序盤は微笑ましく、終盤は切ない）。
4. **温度差の笑い**：大きなことをさらっと、小さなことを深刻に言う落差。
5. **問いを投げる**：答えるのでなく問う（落慮王「選ばれなかったものに、価値はなかったのか」）。
6. **具体的で小さい**：世界の危機でなく「三番目の鐘が鳴らない」——スケールの小ささが世界の大きさを感じさせる。
7. **書き手が透ける**：無署名でも「誰が書いたか分かる」（前任の拾い人の乱れた筆致、灯台守の不器用な文）。
8. **プレイヤーに向く**：唯一「あんた/あなた」に語りかけるのはノミと返信だけ——他は「自分のため・誰か他者のために書かれた」形式にして、世界の閉じた実在感を保つ。

## 10. 要ユーザー承認の決定点（推奨案つき）

| # | 決定点 | 推奨案 |
|---|---|---|
| H1 | ベクター総覧（7媒体の役割分担） | 採用。棲み分けで重複を防ぐ |
| H2 | 文体規範「かすれた・欠けた・継がれた」の筆致ルール | 採用。説明しない・行為と物で語る・未完/書きかけ |
