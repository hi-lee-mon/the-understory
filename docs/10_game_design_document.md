# 10_ゲームデザイン書（GDD）v0.1 —「The Understory（棄てられたものの国）」

> ステータス：draft。本プロジェクトのマスター設計書。詳細は各専門ドキュメント（`11`〜`52`）を正とし、ここには全体の設計判断を集約する。

## I. ゲーム概要

| 項目 | 内容 |
|---|---|
| ジャンル | Minecraft MOD：次元冒険＋物語＋アクション＋クラフト |
| コンセプト | **「現実に選ばれなかった一切が流れ着く国」を冒険し、棄てられた者たちの物語の結末を書き換える/見届ける** |
| 対象 | YouTuber/VTuber（配信されることまで設計対象）およびその視聴者 |
| スコープ | 序＋5章＋終章の次元、同行マスコットNPC、拠点成長、章別ボス、拾得クラフト |
| 技術基盤 | NeoForge / MC 1.21.1 / Java 21（要ADR確定） |
| 目指す位置 | 「第2の黄昏の森」級の世界観＋物語＋配信性を持つ大型MOD |

### ハイコンセプト
「いつもの世界の裏側に、消されたものたちの国がある」。MH2Gの裏世界・都市伝説的な「噂の実在」感×黄昏の森的次元冒険×重い物語。入り口は**anomaly（有り得ない異物）**または**ベッド儀式**。

**再設計後の独自性（`09`）**：**「マイクラの中で演じる連続ドラマ」**。世界は「終わらなかった物語たちが演じ続ける劇場」。各章＝演目（序破急）＋次回予告＋章ごとに異なる語り形式（絵本/書簡/戯曲/日誌/詩/設計書）。異ジャンル融合により「次元MODの中身」でなく「物語の語り方」で差別化する。

## II. コアゲームプレイ

### コアループ
1. **探索**：次元内の各環礁（章）を探索、異物・住人・ロアを発見
2. **没腐との対峙**：歪んだ者/土地と戦闘・謎解きで対処（アクション）
3. **拾得**：素材・記憶・結末の欠片・**語りの断片**を拾い、拠点/現実へ持ち帰る
4. **鑑賞**：拾った断片を「読み・観・聞き」、物語の本当の姿を知る（ノミが綴じる）
5. **鍛錬**：捨てられた素材を「本来の姿」に鍛え直す（クラフト）
6. **結末**：「書き換える or 見届ける」→**幕が下りる**（世界が変化）→**予告頁**で次章へ

### プレイスタイル対応（Bartle）
- 探検家：異物・環礁・ロアの発見密度
- 達成者：章ボス・拾得図鑑・高難度再戦
- 社交家：ノミ・村住人・マルチ役割
- 殺し屋：ボスの派手撃破・タイムアタック再戦

## III. 世界・ストーリー（要約 — 詳細は`11`/`12`/`52`）

- **法則**：①棄てられたものしか存在しない ②物語が未完だと「没腐」に歪む ③結末は選択できる ④拾ったものは現実に持ち帰れる ⑤死ぬと「忘れられる」
- **大枠**：棄てられた案たちの国を、主敵「落慮王」（世界の最初の没案）が統べる。各環礁＝一つの棄てられた物語
- **テーマ**：「選ばれなかったものにも意味がある」（世捨て人の慰めと再生）

## IV. 進行構造（詳細は`13`）

| 章 | 環礁 | 棄てられたもの | ボス | 難度/ギミック |
|---|---|---|---|---|
| 序 | 漂着浜 | 到着地 | — | 世界の法則の体験学習 |
| 1 | 満ちなかった月の林 | 満月作物の没案 | 月欠狼 | 夜/月齢ギミック、低床の導入戦 |
| 2 | 読まれなかった港 | 未読の手紙・航海 | 未読の座礁船 | 光と波、水辺戦 |
| 3 | 踊らなかった広場 | 中止の祭り | 中止の人形劇 | リズム/拍子の仕掛け |
| 4 | 選ばれなかった坑道 | 没鉱石・没道具 | 棄材のゴーレム | 坑道・素材主題の戦い |
| 5 | 歌えなかった塔 | 没音楽・無音の鐘 | 無音の歌姫 | 音・間の読み合い |
| 終 | 原案の座 | 世界の原案 | 落慮王 | 全要素の統合・物語絡みの多段戦 |

**ゲート**：前章ボス撃破＋結末選択で次章解放（黄昏の森型）。章＝配信1〜2回分を想定。

## V. キャラクター（詳細は`12`）

- **ノミ**：同行マスコット。没になった案内人の精霊。名付け可能・簡易反応・結末を綴じる役＋**予告頁の語り手**。配信のいじられ・名物キャラ狙い
- **落慮王**：主敵。憎めない悲劇の王
- **村住人**：各章で救った者が「拾い人の村」に移住→拠点発展

## VI. クラフト/アイテム（詳細は`14`）

**「拾得鍛錬」**：没素材を「本来の姿」に鍛え直す系統。ガラクタ→宝の快楽がクラフトの主軸。素材→変化→成果物の系統樹を`14`で全表化。

## VII. ボス/モブ（詳細は`15`）

各章ボスは**フェーズ制・読み合い可能・固有演出**（Cataclysm基準）。章の主題（月/手紙/祭り/坑道/歌）をそのままギミックにする。

## VIII. UI/UX・デザインシステム（詳細は`18`/`20`）

- **デザインシステム**：MOD専用の独自UI/フォント/アイコン体系を設計。「かすれた世界」の言語をUIにも浸透させる
- **フォント**：独自書体（幻想文字＋和英対応）で世界観を強化
- **シェーダー/影MOD対応**：公式にシェーダー系MODとの同時利用を想定・検証（配信者の必須環境）
- **進捗表示**：「拾得図鑑」「結末の記録」「村の発展」をゲーム内UIで提供

## IX. AI（詳細は`15`）

- モブ/ボスはgoal-selector＋カスタムステート。フェーズ・読み合い・反応を重視
- ノミは同行ロジック＋状況反応（収集・警告・ロア語り）

## X. オーディオ（詳細は`19`）

- 「かすれた」「欠けた」「静かな不気味さ」と哀愁を基調。章ごとに主題を持つ楽曲。異物の演出音は「古い音」の残響

## XI. 開発・優先度

1. **P0**：次元+入口（異物/ベッド）＋ノミ＋第1章＋拾得鍛錬＋月欠狼 — 垂直スライス
2. **P1**：第2〜5章＋拾い人の村成長
3. **P2**：終章・分岐・演出強化
4. **P3**：ローカライズ・リリース・配信者素材

## XII. レビュー観点（本GDDの合格基準）

- 01の設計原則12箇条を全て満たすか
- 「黄昏の森の世界構造」＋「物語/キャラ/クラフト強化」＋**異ジャンル融合（連続ドラマ構造）**の差分が明確か
- **マイクラらしさを損なっていないか**（語りは書物・フレーバーテキスト・住人セリフなど既成ベクターで運ぶ。UI改変は見た目の小変更のみ・操作体系は変えない——`09` §6）
- **層構造で楽しいか**（表層＝文字を読まなくても直感で遊べる非言語の導線。深読み層＝日記・セリフ・書物を読む人ほど重厚な体験が返る。平易さのために深さを犠牲にしていないか——目的は「楽しい」）
- 物語に**重厚さ・驚き・章を跨ぐ伏線**があるか（横断設計はIssue #30で扱う）
- 章構造が配信シリーズとして機能するか（08の視聴者要件を満たすか）
- 技術的実現性がADRで裏付けられているか
- スコープが垂直スライス→章量産に分解可能か
