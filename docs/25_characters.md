# 25_登場人物設計（v0.1 draft）

> **目的**：Issue #29 拡張スコープ第2段。docs/24 の世界観・真実の構造から、**物語を動かす登場人物**を設計する。荒木飛呂彦「漫画術」の**身上調査書**手法を採用——外見・弱み・過去・性格・趣味・特技・尊敬する者まで記録することで、話が進んでも設定矛盾を起こさず、人物に深みとブレない声が生まれる。
> **適用範囲**：ノミ・各章の主・落慮王・村の住人・語りに登場する全人格。セリフの実文は docs/26、伏線配置は Issue #30、章演出は Issue #14。
> **関係者**：docs/24（真実の構造）が全人物の根拠。ここで定義した「弱み・秘密・関係」がセリフ・書物・環境の全ての言葉の源泉になる。
> **ステータス**：draft（要承認の決定点は §8 に集約）。

**設計層**：⑥意味づけ——人物は「この国の法則を体現する者」として設計する。全員が何かの「棄てられた側」であり、その棄てられ方が人格になる。

---

## 0. 人物設計の原則（本作固有のルール）

1. **全員「待ち続けた者」**：各章の主は共通の型（何かを待って止まった者）だが、**待つ対象が違う**（月・読者・祭り・素材・聴き手・世界）＝バリエーションの体系。
2. **弱みが魅力**（身上調査書の核心）：強い者でなく、**守りたい何か・克服できない何か**がある者だけが愛される。
3. **秘密を持つ**：全員に「初見では分からない秘密」を一つ持たせ、それが伏線になる。
4. **システムと接続する**：人物は必ず「どのアイテム・機構・場所を通じてプレイヤーと関わるか」を持つ——物語と遊びを分離しない。
5. **救出者は村で生き続ける**：各章の主は救出後、拾い人の村で役職を持ち、救った物語が日常として続く。

## 1. ノミ（案内人・同行マスコット）

| 項目 | 内容 |
|---|---|
| 役割 | 同行マスコット・拾得図鑑の綴じ役・予告頁の語り手・没腐コンパス。本作の「語りの口」であり最大の伏線 |
| 外見 | 光る頁めいた小さな精霊。欠けた一角を持つ。小さく、非力そう |
| 性格 | 世話焼き・皮肉っぽいが根は優しい・少し卑屈。面倒見がよく、拾い人を放っておけない |
| 口癖・話し方 | 「あんた」呼び。「〜だよ」「〜なんだよな」の砕けた語尾。解説しすぎず、核心で口を濁す |
| 好きなもの | 拾われた物が整理されていくこと・名付けられること（めったに言わない）・プレイヤーが無事なこと |
| 嫌いなもの・怖いもの | **「原案の座」の話題**（触れられると話を逸らす）・自分の出自 |
| 特技 | 棄てられた物の「由来」を嗅ぎ分ける（誰の・どこからの・どう捨てられたかを感じ取る） |
| 弱み | **自分が「没になった案内人」であることを認められない**。役目を続けていれば、まだ自分は必要とされていると信じている |
| 秘密 | **「世界の原案に書かれていた案内人」**——落慮王の没世界でプレイヤーを導くはずだった存在。落慮王に会えば「お前の世界は没になった」と確定するため、ずっと彼を避けている（docs/24 §4.4） |
| システム接続 | 拾得図鑑・予告頁・拾い物反応・名付け（D5 拡張案と接続：名付けると「役目でない自分」を得る）・ゴミ箱機構の案内役 |
| 関係 | プレイヤー（拾い人として導く→やがて仲間に）／落慮王（彼の世界の名残、避けている相手）／各章の主（彼らの「待ち」を少し知っている） |
| 面白さの定義 | **序盤は「頼れるが何か隠している小物」、終盤は「物語の鍵」**。反復される口癖が終章で意味を変える。配信のいじられ役であることが、正体開示の落差を最大化する |

**ノミの名付け**（重要）：プレイヤーが名付けた時、ノミは初めて「役目の名」でない自分を得る。**名付けは彼の物語の結末イベント**——以後、彼のセリフの口調・態度が微細に変わる（より個人として話す）。名付けないまま終章に行くと、落慮王が「お前はまだ名前を持っていないのか」と指摘する分岐。

## 2. 各章の主（環礁の中心人物 — 没腐した者たち）

### 2.1 月見翁（第1章「満ちなかった月の林」）

| 項目 | 内容 |
|---|---|
| 役割 | 第1章の主。「満月にしか実らない作物」の没案を守る老翁 |
| 外見 | 小柄な老人。月の欠片を象った杖・実のならない木を抱えている |
| 性格 | 穏やか・のんき・気長すぎるほど気長。一度も急いだことがない |
| 口癖・話し方 | 「もうすぐですよ」——何に対しても言う（満月・結果・再会）。温かいがどこか悲しい常套句 |
| 好きなもの | 種・発芽の瞬間・月を眺める時間 |
| 弱み | **「待つ」ことしかできなくなった**。動くこと・変えることを諦めた |
| 秘密 | 月が満ちない理由を薄々知っていた——知らないふりをして待ち続けた（知ると待つ理由を失うから） |
| システム接続 | 種・農具系の章アフィニティ（捨てた種がこの章に届く）。救出後＝村の農園担当（拾得作物の栽培） |
| 面白さの定義 | ほのぼの会話（「もうすぐですよ」の反復）→ 終わりに向けてじんわり哀しみ。絵本の語りと一致 |

### 2.2 灯台守（第2章「読まれなかった港」）

| 項目 | 内容 |
|---|---|
| 役割 | 第2章の主。「必ず届く」はずの手紙を守り続けた者 |
| 外見 | 潮風に洗われた外套。抱えきれないほどの手紙の束 |
| 性格 | 実直・責任感が強い・不器用。人の言葉を大切にするあまり自分の言葉を持たない |
| 口癖・話し方 | 「届けるのが役目です」——丁寧だが自分のことを話せない |
| 好きなもの | 手紙の重み・宛名の筆跡・「読まれた」という事実 |
| 弱み | **自分の手紙を書いたことがない**。人の言葉を守る者であり、自分は書き手でないことへの劣等感 |
| 秘密 | 彼自身も「届かなかった手紙」の書き手の一人——彼が出した一通もここに流れ着いている（それを本人は探せずにいる） |
| システム接続 | 手紙・本・記録の章アフィニティ。**救出後＝村の「手紙屋」＝ゴミ箱返信の「読む者」**（docs/23 §7 との直結——機構に顔を与える役割）。**返信機能は彼の救出で実質解放される** |
| 面白さの定義 | 切なさの頂点の章。「あなたの手紙を読む人」が具体的な顔を持つことで、QoL機構（ゴミ箱）が物語になる |

### 2.3 祭囃子（第3章「踊らなかった広場」）

| 項目 | 内容 |
|---|---|
| 役割 | 第3章の主。中止になった祭りを指揮するはずだった女 |
| 外見 | 祭りの装束のまま止まっている。鈴・扇子・提灯の飾り |
| 性格 | 明るく派手・人懐っこい。だが独りだとこっそり泣いている（ギャップ） |
| 口癖・話し方 | 「せーの、で始まるのよ」——祭りの合図口調。プレイヤーを「初めてのお客さん」と呼ぶ |
| 好きなもの | 人の声・祭りの支度・誰かの笑い声 |
| 弱み | **一人では祭りを始められない**。相手がいることでしか意味を持たない役目 |
| 秘密 | 祭りが中止になった本当の理由を知っている（人がいなくなったのではなく、開くことを諦められた） |
| システム接続 | 装飾・食べ物・祭り系の章アフィニティ。救出後＝村に祭り場・時折イベント（配信のイベントネタ）。梱包物の配達演出にも絡む |
| 面白さの定義 | 笑いの章だが、賑やかさの裏の「踊る相手がいない」喪失が透ける。配信者が「笑ってたのに泣いた」ポイント |

### 2.4 鍛冶師（第4章「選ばれなかった坑道」）

| 項目 | 内容 |
|---|---|
| 役割 | 第4章の主。「世界一の道具を作る」はずだったが素材が全て没になった者 |
| 外見 | 煤けた作業着、大きな手。見た目は恐い |
| 性格 | 無骨・口数少ない・実直。素材への愛が異常なほど深い |
| 口癖・話し方 | 「…使われねぇ道具は、ただの鉄だ」——淡々とした実務家の口調 |
| 好きなもの | 素材の音・仕上げの手触り・誰かが道具を使い込む様子 |
| 弱み | **完成品を一度も作れなかった**。何も成し遂げられなかったという重み |
| 秘密 | 没素材の一つは「落慮王の原案の素材」——彼は原案の一部に触れていた（伏線）。また、**没素材に名前を付けて可愛がっていた**（ギャップ） |
| システム接続 | 武器・道具・鉱石の章アフィニティ。救出後＝村の拾得鍛錬の名人（クラフト強化の中心NPC）。**灼熱の埋立て地（焼却物の行き先）を知っている**——処理場機構との接続点（docs/23 §8.4） |
| 面白さの定義 | 恐怖→勇気の章。恐い見た目の者が最も優しい。没腐した素材の恨みと、名付けられた愛の対比 |

### 2.5 歌姫（第5章「歌えなかった塔」）

| 項目 | 内容 |
|---|---|
| 役割 | 第5章の主。「鐘を鳴らして国を呼び覚ます」物語だった者 |
| 外見 | 白亜の装束、開かれたままの喉に鐘の影 |
| 性格 | 静か・高潔・少し世間離れ。歌うために作られた者の純粋さ |
| 口癖・話し方 | 無音の世界で言葉少な。歌詞の断片で語る（「——鳴らしたかった」） |
| 好きなもの | 音・響き・誰かのため息すら |
| 弱み | **自分の歌を聞かれたことがない**。無音では自分の声さえ届かなかった |
| 秘密 | 彼女の歌は「国を目覚めさせる」もの——鳴らせば原案の座に届く設定（終章への伏線） |
| システム接続 | 楽器・音・鐘・レコード系の章アフィニティ。救出後＝村に歌と鐘が戻る（音楽的報酬）。結末選択「一緒に歌う」は本作の音楽生成アプリ構想（Issue #26）との接続点 |
| 面白さの定義 | 畏怖・荘厳の章。無音→音が戻る瞬間の鳥肌。「聞かれること」の尊さを体現 |

### 2.6 落慮王（終章「原案の座」）

| 項目 | 内容 |
|---|---|
| 役割 | 最終ボス。「世界の最初の原案」の人格化。全ての棄て物の王 |
| 外見 | 白紙の王冠・設計図のローブ。威厳だがどこか「作りかけ」の不完全さ（線が残っている） |
| 性格 | 尊大だが子供っぽい無垢さ（一度も存在しなかった者の純粋さ）。丁寧な言葉で哀しいことを言う |
| 口癖・話し方 | 「私は選ばれなかった」——静かな断定。説教でなく、問いかける |
| 好きなもの | 集めた棄て物・原案の設計図・「拾い人」という概念 |
| 嫌いなもの・怖いもの | **「選ぶ」という行為そのもの**（選ぶ＝捨てることだから）。そしてノミ——会えば自分の世界の没が確定する |
| 弱み | **一度も存在したことがない**。臣民を一度も持たなかった王——国に集めたものは「捨てられたもの」であって「彼の民」ではない |
| 秘密 | **ノミを知っている**。彼の世界でノミが案内人だったこと、そして彼がずっとノミに会いたかったこと。終章で二人が再会する＝最大の感情点 |
| システム接続 | 終章・原案の座・「あなたが捨てたもの」の集約先（中盤の転調：プレイヤーの捨て物が彼の歪みを助長したと指摘する） |
| 面白さの定義 | 悪役でなく「終わらせられない者」。「選ばれなかったものに価値はなかったのか」という本作の主題を人格化した問い。考察・決断の緊張 |

## 3. 前任の拾い人（痕跡だけが残る人物 — 新設）

| 項目 | 内容 |
|---|---|
| 役割 | プレイヤー以前に国に落ちた「先達」。本人は登場せず、**落書き・残された装備・やり残したこと**で存在だけが残る |
| 正体 | **途中まで拾い人として旅したが、ある章で「書き換える」を選んで失敗し、没腐した**——痕跡だけが残る（推奨案。考察の最大の餌） |
| 外見 | 登場しない（痕跡のみ。没腐した個体が「あの落書きの主」と分かる設計） |
| 性格 | 痕跡から逆算：勇敢だが急ぎすぎた者。「早く終わらせたい」という焦りが彼を書き換えに向かわせた |
| 口癖・話し方 | 落書きの文体：走り書き・短い・次第に乱れていく（「急げ」「もう分かった」「あれは罠だ」） |
| 弱み | **「物語を終わらせたい」焦りが、見届けるより先に書き換えを選ばせた** |
| 秘密 | 彼の捨て場が残っている（プレイヤーが見つけられる）＝「あなたが捨てたもの」と同型の「彼が捨てたもの」 |
| システム接続 | **落書きベクターの主な書き手**・拾得装備の由来・没腐の個体差・終章で落慮王が「前にも拾い人が来た」と語る |
| 面白さの定義 | **「誰かが先にいた」の発見**は環境ストーリーテリングの最強形。彼の旅路の痕跡を追うことが考察の副軸になる。彼の失敗はプレイヤーの選択への警告 |

## 4. 拾い人の村の住人（群像）

救出者が村に役職を持って帰る構造に加え、**元から村にいる住人**を少数持つ（救出者と区別）：

| 住人（案） | 役割 | 口調・面白さ |
|---|---|---|
| **村の長「拾い人の翁」** | 最初に村を始めた者。プレイヤーを「拾い人」として認める | 老齢・穏やか。「ここは捨てられた者が拾った村だ」と切ない原点を語る |
| **雑貨屋「拾い子」** | ガラクタを集めて売る子供っぽい住人。拾得物の売買 | 元気・お喋り。「これ、あんたの世界から流れてきたやつだよ！」と由来を覚えている |
| **「読む者」**（正体は救出後の灯台守） | 村の手紙屋。ゴミ箱返信の書き手 | 救出前は正体不明（「どこかで読まれている気配」だけ残す——返信は救出で解放） |
| **名を持たない住人たち** | 名付けられると「個人」になるモブ枠（D5 接続） | 名付け前は役割のみ、名付け後に個性が発現する仕組みの実証役 |

村の機能的役割：救った物語が「ここで生き続ける」ことの見せ場。各住人は「拾い人の物語の相手」（図鑑・手紙・噂・イベントの発生源）。

## 5. 縁の民（現実側の接続）

- **「捨て場の番人」**（老婆）：現実の縁の地に住み、国と現実を行き来する者。「あんたの世界の捨て場を守ってるよ」と現実での接続を語る。
- **役割**：現実での探索導線・「縁の地」の説明・往復の安心感。数を絞る（大勢にしない——国側の住人が主役）。

## 6. 関係構造（誰がどう繋がるか）

```
プレイヤー(拾い人)
 ├─[同行・名付け]── ノミ ──[案内人と王]── 落慮王
 ├─[捨てた物]── ゴミ箱 ──[手紙]── 灯台守(読む者)
 ├─[拾得物]── 各章の主(月見翁/祭囃子/鍛冶師/歌姫) ──[救出]── 村の役職
 ├─[痕跡]── 前任の拾い人(落書き・没腐)
 └─[縁の地]── 縁の民(現実側)
```

- **機構との接続**：手紙→灯台守・道具/没素材→鍛冶師・鐘/音→歌姫・祭り/梱包→祭囃子・種→月見翁・名付け→ノミ・落書き→前任の拾い人。**全てのプレイヤーの行為が「誰かの物語」に繋がる**よう配線する。
- **伏線の配置**：ノミ↔落慮王（終章回収）・鍛冶師↔原案素材・歌姫↔国の目覚め・前任↔落書き全章。

## 7. 配置原則（物語が進むように人物・オブジェクトを置く）

1. **各章の主は「待っていた場所」にいる**：没腐した場所＝彼らの望みの中心（月見翁は月の林の中心、灯台守は灯台、祭囃子は広場の舞台、鍛冶師は坑道の最奥、歌姫は塔の頂）。**ボスアリーナ＝彼らの「待ち」の象徴**。
2. **オブジェクトが導線**：拾得物が次の人物を指す（手紙を拾えば港が気になる、鐘の欠片を拾えば塔が気になる）——拾う行為が物語の次の章を予告する。
3. **村は「救った物語の見せ場」**：救出者が役職として帰ることで、村に行くたび救った物語と再会できる。
4. **前任の拾い人の落書きは「やり残し地点」に置く**：彼が通った道のりを追う構造——同じ道を辿ることで「先達の旅」を追体験する。
5. **ノミだけが移動する**：唯一プレイヤーと共に全章を巡る語り装置。だからノミの正体が最重の伏線になる構造と整合。
