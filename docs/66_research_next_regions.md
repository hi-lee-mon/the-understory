> **目的**：Issue #37「次コンテンツ領域：灼熱の埋立て地＋没腐の喪失境界の詳細仕様」に先立つ調査基準。docs/67 は**「本編の設計済み領域を再設計する」のではなく「確定済みの分離線（16-U1-Q17・16-U4-Q4/Q6）の向こう側を詳細化する」設計書**——埋立て地の到達経路・敵性個体・構造物と、喪失境界のシステム仕様（帯域・刻まれる形・戻りルール・没腐度連動）を、実装者・物語担当・数値担当が同じ絵を見られる一次入力として作る。

## 1. 先行研究（「世界の果て」「捨てられた先」「境界を越える」の設計例）

| 先行 | 学ぶ作法 | 本設計での適用先 |
|---|---|---|
| **Dark Souls 系の辺境（墓場・灰の湖）** | 最深部は「静けさで怖がらせる」——敵の数でなく、物の集積と欠損で「ここに来てはいけない」を語る | 埋立て地の敵性個体設計（物語重視・数で埋めない）。怖さ＝物と気配に由来（16 §6.4.1-7 確定どおり） |
| **Minecraft バニラ＝ネザー/エンドの片道感** | 次元の帰還コスト（ポータル確保・座標記憶）自体が緊張を作る。「帰れないかもしれない」は最強の導線圧 | 処理口片道・焦げ跡つき帰還（32 §5 確定）の体感設計。帰還の不安を演出の燃料にする |
| **STALKER / ゾーンの境界** | 境界は「壁」でなく「帯」——侵入可能だが異常が刻まれる。可視の警告＋不可逆の痕 | 喪失境界の帯域設計（越えられる・刻まれる・戻れるが失う） |
| **Outer Wilds（種なしシードの知識ゲート）** | 到達手段は「知識」の解錠——装置でなく「やり方を知る」こと自体が鍵 | 埋立て地到達経路の設計哲学（クレーン以外の経路の有無を、知識ゲートの思想で検討） |
| **Pikmin / 集めて戻る系** | 一日の終わりに「置いていかれた者」の集積——喪失の可視化が主題 | 埋立て地の堆積表現（燃えなかった物・消したかった物の丘）の感情設計 |
| **配信実況の儀式性（docs/17 §3）** | 「捨てる」が配信の見せ場になる構造コスト＋逃走余地＋記録 | クレーン掴みの儀式演出を埋立て地側の着弾演出と対にする（捨てる側と届く側の絵を両方設計） |

## 3. 制作原則（P-NR——設計を「面白くする」作法）

| # | 原則 | 出典・根拠 |
|---|---|---|
| P-NR-01 | **届く側の絵を作る**——「捨てる側」の儀式は 23 §8.5・16 §6.4.2 で確定済み。本書系は**届いた側**（落とされた者・処理された物）の視点で埋立て地を設計し、到着→探索→帰還（焦げ跡）の体験弧を書く | 23 §8.5・32 §5 |
| P-NR-02 | **怖さは物と気配に由来**——敵性個体は「襲う怖さ」でなく「存在の怖さ」に寄せる。数で埋めず、文脈のある個体（燃えなかった者・集める者）を少数設計 | 16 §6.4.1-10・U4-10 引き継ぎ |
| P-NR-03 | **片道の不安を燃料にする**——帰還が焦げ跡つき・往復不可であることを、探索の緊張感（「何を持って帰れるか」「焦げ跡を残す覚悟」）へ転換する | 32 §5 |
| P-NR-04 | **境界は「線」でなく「帯」**——喪失境界は厚みのある領域として設計し、帯内の振る舞い（滞在・越え・引き返し）を全て規定する。越える／越えない／越えて戻るの3系統を用意 | docs/23 §10・16 §2.7 |
| P-NR-05 | **刻まれる形は体系内の一段**——烙印は没腐度体系（38/04 §2）内の意味ある一段とし、発見・読解・回復の余地を残す（不可逆の罰にしない——G-NR-06） | docs/38/04 §2 |
| P-NR-06 | **配信の見せ場を双方で作る**——捨てる側（クレーン儀式）と届く側（埋立て地着弾）の両方を絵として設計。コメントで「あっちだよ」が起きる構図（40 §5.2.4 S-3） | docs/17 §3・40 §5.2.4 |
| P-NR-07 | **設置者紐付けを保持**——「◯◯の処理場から来た」由来が分かる＝群像劇の燃料（23 §8.4）。埋立て地の堆積は由来表示の連鎖を担う | docs/23 §8.4 |
| P-NR-08 | **未回収の明示管理**——埋立て地の物語回収は意図的に残す（F-MECH-14）。設計書は「何を残すか」を明示し、全部埋めない | 16 §6.4.1-8・36a §7 |
