## 制作プロセス（Issue #14 の指示どおり）

1. `docs/33` でプロ作家・制作手法の調査を先行実施（起承転結×3幕、シーン/シークエル、「最善の悪い選択」等を基準化）。
2. 7章それぞれに対し **制作エージェント → レビューエージェント（深い思考・blocker/major/minor 分類）→ 改訂エージェント** の反復をマルチエージェントで実行（受理まで各章1〜3ラウンド）。
3. 全章受理後、**物語整合・システム整合の2系統の横断レビュー**を実施 → 指摘19件を本章群へ反映済み（各ファイル先頭の「横断レビュー反映」注記参照）。
