# 第3章「踊らなかった広場」詳細プロット

> Issue #14 章別詳細プロット。正典（docs/11・12・24・25・26・28・32）準拠。
> 語り形式：**戯曲**（台本・ト書き・役割名）／主感情：**滑稽・歓楽→不意の喪失**／ボス：**中止の人形劇**／主：**祭囃子**／救出後＝村に祭り場・時折イベント。
> 横断レビュー反映：予告頁を一般形（未攻略章の気配を動的選択・全自由章クリア後は第5章）に統一（§7）／「結末の欠片」本章配分を4個（CP3＋寄り道1）として §9 に明記。

## 0. 本章の設計キーワード：「延期」

この章の祭りは、一度も「中止」と言われたことがない。貼られ続けたのは「延期のお知らせ」——中止なら祭りは終われる。延期だから終われない。これは没腐の定義「**終わりを信じられなくなった停滞**」（docs/24 §4.3）の、本章における体現であり、プレイヤーが世界の病理を学ぶ装置でもある。世界が呼ぶボス名「中止の人形劇」と、世界内文書が決して言わない「中止」の齟齬が、この章の推理の芯になる。

もう一つの芯：祭囃子は**「踊り手のいない指揮者」**である。これは落慮王＝「臣民を一度も持たなかった王」（docs/25 §2.6）の鏡写しであり、本章は終章の主題（選ばれなかったものに価値はなかったのか）を、笑いの形で静かに予行する。

---

## 1. 章の目的

- **担う感情**：全編で唯一「笑い」を主軸に据える章（docs/12 §2.1 感情マップ）。哀愁一辺倒を崩す振れ幅担当。狙いは「笑いの後の静けさ」——プレイヤーが笑ったもの全部が、後から「誰もいなかった」を隠していたと気づかせる二重底構造。感動は狙い撃ちせず、推理と人物の魅力が結果として感情を生む配置。
- **物語機能**：
  - 没腐の仕組みを「延期」という形式で教える（第1章が「待ち続ける」を教えたのに対し、本章は「終わらせることを避け続けた」を教える）。
  - 「祭り＝みんなのための催し」という観客概念を提示し、「観客が最初からいなかった催し」を通して終章の問い（誰のための世界だったか）への布石を置く。
  - 推理の問いの三層：①祭りはなぜ開かれなかったか → ②誰が延期を貼り続けたか → ③客は、そもそも存在していたのか。
- **狙う配信反応**：笑い（変な屋台・人形のドタバタ）→ ざわつき（客席に座ると劇が始まる）→「笑ってたのに泣いた」（劇の終わりと結末）。シリーズ構造上は「面白回」として切り抜きが最も多く産まれる章。
- **システム上の役割**：救出後に村へ「祭り場」が解放され、不定期イベントの発生装置を得る（配信のイベントネタ・エンドコンテンツの燃料）。語り形式「戯曲」は本作の演劇レイヤー（幕・見得・幕間・予告頁、docs/09）が最も自然に発露する章。

## 2. 到着〜導入

- **着き方**：漂着浜／捨て場から環礁へ。第2〜4章は同時開放・順不同の地理ゲート（docs/13 §1）のため、他章の攻略は一切前提にしない。
- **遠見**：海上に浮かぶ環礁に、祭りの飾りが煌めいて見える。近づくほど、**音が先に届く**——太鼓と鉦の拍子。歌がない、掛け声もない、**拍子だけ**が律儀に鳴り続けている（正典：「拍子だけが鳴り続ける」docs/12 §2）。
- **最初に見えるもの**：祭り前夜で止まった広場。飾り門・連なる提灯・閉じた屋台・中央の舞台。時刻は「祭りの前夜」に固定されている（永遠の宵の口）。全ての飾りは完成しているが、**どれにも一度も使われた形跡がない**——かすれて色褪せているのに、使用感だけがゼロ。「準備が全部終わっているのに誰もいない」を、文字なしの風景でまず伝える（層構造の表層）。
- **ノミの反応**：到着時ははしゃぐ（祭りの賑わいへの期待）→ 誰もいないと気づいて急に口を濁す → 拍子に小さく首を傾け、何かを言いかけてやめる（**伏線**：彼女はこの拍子を「どこかで」聞いたことがある——原案の世界の名残、§9参照）。屋台へ向かうプレイヤーの捨て物の気配を嗅ぎ分けて誘導する実用役も兼ねる。
- **導入の設計意図**：表層だけで「祭りの用意は全部ある、人だけがいない」を読ませる。説明は一切しない（docs/24 §7 の約束を各章レベルで履行）。

## 4. ミッドポイント

- **位置**：楽屋裏（人形工房）＋舞台袖の鏡部屋。探索の中盤、客席に座る前の強誘導区画（読まずに進んでも章はクリアできるが、ここを通るとボス戦の意味が変わる）。
- **覆る認識**：
  - 到着時の見立て：「祭りが中止になった → 人がいなくなった」
  - 覆る真実：「**人がいなくなったのではなく、開くことを諦められた**」（docs/25 §2.3 正典）。さらに一段——**延期の貼り紙を貼り直し続けたのは祭囃子本人**。中止にすれば祭りは終わる。延期なら「まだ開ける」。彼女は祭りを終わらせないために延期し続け、踊り手がいないなら人形を作り、開幕の合図を言い切れないまま止まった。
  - もう一段（深読み層）：招待状の宛名が全て「みんなへ」——**客席のために想定された「みんな」は、一人も個として用意されていなかった**。祭りは「誰も来なかった」のではなく「来る者が最初からいなかった」（没企画ゆえに）。
- **目的の転換**（docs/33 §3 の要件）：プレイヤーの目的が「人形劇を止める／祭囃子を救う」から「**この止まった合図に、誰かが応えなければならない——応えるとはどういう行為か**」へ変わる。

## 5. ボス設計「中止の人形劇」

- **没腐した正体**：祭囃子の「待ち」が舞台機構と一体化した姿。彼女は指揮台に組み込まれ、鈴と扇で拍子を刻み続けている——拍子とは、彼女が一度も言い切れなかった合図の繰り返しである。人形たちは彼女が作った代役の踊り手であり、ボスは単体の敵でなく「**演目そのもの**」。これは「倒す敵」でなく「待ち続けた者の没腐した姿」の規範に従う（docs/33 §6）：撃破＝理解して救う＝**上演を最後まで受け止めること**。
- **見た目の滑稽さ**：人形の列は奇妙な振付で踊る——失敗する芸、絡まる糸、順番を間違えてぶつかる列、空の客席への一斉の礼。笑える造形が、そのまま喪失の装置になる（倒すほど「誰も観ていなかった」が滲む正典を機械化）。
- **幕構成（フェーズ＝幕、転換＝幕間の暗転。docs/09 の演劇レイヤーをボス戦に直接適用）**：
  - **第一幕「教習」**：小編成の人形が読みやすい拍子で踊る。人形の攻撃は全て振付であり、強攻撃は「見得」の予備動作で明確に告知される（読み合い・死に学習のフェアさ、docs/13 §3）。屋台で教えた「拍子に合わせる」がそのまま回避・応撃の入力になる。**プレイヤーの攻撃は人形を壊さない——当たった人形はそれを振付に組み込む**（殴られた人形は回転して舞に変え、外れた拍子を人形が訂正する）。進行するのは体力でなく「**上演の進行**」。
  - **第二幕「乱入」**：列が増え拍子が速くなる。プレイヤーの行動がどんどん振付に取り込まれていく違和感。幕間に、人形たちが**誰もいない客席へ向かって礼をする**——缶詰の拍手音だけが鳴る。笑いの裏の空虚が露出し始める転換点。
  - **第三幕「千秋楽」（twist）**：人形列が見得を切って動きを止める。**以後、攻撃は劇を進めない**——殴っても劇は中断して幕が巻き戻るだけ（「まだ終わらない」演出）。前に進む唯一の行為は**観客になること**：客席に座り、最後の演目を最後まで観て、終盤の合図の「間」に拍子で応える。初めて最後まで観られた劇が終わると、指揮台の彼女の手が止まる——**拍子が、止まる**。幕が下りる。
- **teach-test-twist の対応**（docs/33 §5）：teach＝屋台遊びと踊り損ねた者、test＝第一・二幕の拍子読み合い、twist＝第三幕の勝利条件の反転（戦う→観る）。
- **撃破後**：舞台は静かになる。祭囃子が指揮台から解放され、結末選択へ。
- **固有報酬（案・Issue #15 へ）**：祭り系バフ・イベント解放（正典 docs/15 §2）＋合図に応える動詞を持つ小道具（例：世の拍子に合わせて鳴る鈴——後章の音ギミックと緩やかに響き合うが依存はしない）。

## 6. 結末選択

- **「祭りを開く」**：今ここで、一度だけ祭りを開く。いる者だけで踊る夜——プレイヤーとノミ、救出済みの住人がいれば来場し、残った人形たちも加わる。飾りと提灯が、一度だけ本当に使われる。
  - 得るもの：彼女の合図に初めて「みんな」が応える。「みんなが踊る日」が、小さくても本当に来る。
  - 失うもの：「いつか」が使い切られる。永遠の前夜は終わり、祭りは「本当に終わった祭り」になる。そしてそれは、企画書が描いた「みんなが踊る日」には永遠に届かない規模で叶う——夢は叶うが、夢見た形では叶わない。
- **「静かに畳む」**：祭りを「延期」のまま終わらせてあげる。飾りを下ろし、提灯を消し、人形を仕舞い、「開かなかった」ことにして彼女を連れて帰る。
  - 得るもの：半端な祭りで夢を消費しない。彼女は「待つ」をやめて生きる側に戻る。用意された祭りは「まだこれからの祭り」として傷つかずに残る。
  - 失うもの：この広場のために作られた祭りは、永遠に一度も開かれない。全ての支度は使われないまま畳まれる。
- **「最善の悪い選択」の成立**（Coyne の危機、docs/33 §2）：開く＝夢を叶えて夢を終わらせる／畳む＝夢を保存して夢を諦めさせる。どちらも失うものが大きく、どちらにも救いがある。選択は結末の記録に残り、村の住人・ノミの後の言葉がそれを引用し続ける（docs/22：選択が記憶され続ける）。
- **正典との整合**：どちらを選んでも祭囃子は救出され村に祭り場ができる。差異は「広場の姿」と「村の祭りの意味」に残る——開いた場合、村の祭りは「あの夜の続き」として扱われ、畳んだ場合は彼女の古いプログラムが村で**初演**される（延期され続けた祭りが、場所を変えてようやく開く）。

## 7. 救出後

- **主の行き先**：祭囃子 → 拾い人の村に「祭り場」が建つ。彼女は祭りの準備を始める——今度は「みんな」がいる場所で。
- **村への変化**：時折イベントが発生（村祭り・踊りの催し——配信のイベントネタ、正典）。**初回の村祭りが小さな「みんなが踊る日」として機能**：救出した住人たちが踊るのを彼女が指揮する＝章の願いが遅れて小さく成就する。梱包物の配達・住人便にも絡む（docs/25 §2.3）。
- **広場の変化**：拍子が止む。「祭りを開く」なら後夜祭の静けさ（使われた飾り・灯りの名残）／「畳む」なら整えられた空の広場。どちらも没腐は浄化され、土地が少し色を取り戻す（世界法則）。
- **次への引き**：ノミが予告頁を綴じ、残っている章の断片を語る（順不同対応——**「未攻略の順不同章」を指す動的選択**：ノミは残り章のうち最も「淀んでいる」方角を語る＝緩い推奨順のソフト勾配。固定の次章は指定しない。自由章を全て済ませた場合は第5章の気配を綴じる）。『祭り企画書』の「没」の印が、説明されないまま心に引っかかる形で終章へ繋ぐ。

| 祭り具・提灯・祭りの残り | フレーバー | 各所の拾得物 | 物の残り香——愛されて作られて、使われなかった一齣 |
| プレイヤーの捨て物 | 拾得物（章アフィニティ） | 屋台の宝物棚 | 「あんたが捨てたものがここで飾られている」——個別化の再会 |
| 祭囃子の語り | 住人セリフ | 救出後の村 | 中止の本当の理由を知っている者の言い淀み（深読み層の続き） |
| ノミの反応 | ノミ語り | 拍子・人形・企画書への応答 | 「どこかで聞いた拍子」——彼女の正体の微細な滲み |

**断片数の目安**：書物・文書 8篇（朗読に耐える短さ、docs/26 §6 の分量規範）、落書き・環境文字 十数箇所、章アフィニティ拾得物は不定数。

## 9. 伏線の受け渡し

**この章が撒く伏線**（→ 後の章・終章で回収。全て単体でも意味が通る断片）：

- **『祭り企画書』の「没」の印** → 原案の座への最深接続。「企画は存在前に没になる」をこの章で先に体験させる。単体でも「捨てられた企画書」として読める。
- **ノミが拍子に既視感を示して言い淀む** → 終章・ノミの正体開示（原案の世界で祭りが計画されていた名残の可能性）。単体では「物知りなはずの彼女が黙る」違和感として機能。
- **祭囃子が中止の理由を知っているのに言い淀む** → 「誰が開くことを諦めたのか」の問い → 終章で「選ばれなかった」世界の構造が答える。
- **「延期」の病理**（終わらせないための延命措置） → 落慮王の「集めて終わらせない」支配（docs/24 §4.2）の主題的予行——この章で「終わらせられないもの」を体験した者だけが、終章の王の歪みを構造で理解する。
- **「踊り手のいない指揮者」** → 「臣民を持たなかった王」の鏡。祭囃子の祭りが「みんな」のために用意されたのに客がいなかった構造は、落慮王が棄て物を集めても民を持てない構造の先取り。
- **前任の拾い人の落書き**（この章での彼の行動の痕跡） → 全章共通の副軸として接続。
- **結末の欠片**（章共通収集要素）は本章に**4個**配置する（全章配分＝第1〜5章各4個・序章0個）——クリティカルパス上に3個（広場・楽屋・舞台裏）、寄り道「座らなかった観覧席の最上段」に1個。結末綴じ画面での垣間見せ機能は第4章§8の規定どおり。総数・厳密仕様は Issue #15 の全表へ。

**この章が回収する伏線**（章内・または章非依存で成立——第2〜4章順不同の絶対条件準拠）：

- 到着時の「拍子だけが鳴る」→ ボス戦で「拍子＝彼女の言い切れない合図」と判明（章内完結）。
- 掲示板の延期通知 → 工房・鏡部屋で「貼り続けたのは彼女」と判明（章内完結の三層推理）。
- 座席の「みんな」名札 → 招待状・企画書で「客は用意されていなかった」と判明（章内完結）。
- 章アフィニティ（祭り系の捨て物） → 屋台の宝物棚として回収。ゴミ箱文法の体験的回収、他章に依存しない。
- 踊り損ねた者・屋台遊び → ボス戦の読み合いとして回収（teach-test-twist の内部構造）。

## 10. 配信の切り抜き瞬間

- **無人の祭り広場に拍子だけが鳴っている**——「祭りなのに誰もいない」の映像的な奇妙さ。
- **屋台の宝物棚に自分が捨てた物が飾られている**——「あれ、これ俺が捨てたやつ…」（個別化が配信者本人の反応を直接産む）。
- **客席に座った瞬間に劇が始まる**——「座ったら始まった！？」世界初の観客になる儀式。
- **人形のドタバタ振付**——配信者が素直に笑う見せ場（失敗する芸・絡まる糸・間違える列）。
- **第二幕で自分の攻撃がダンスに組み込まれる**——「え、殴ったのに踊りになった」の違和感の笑い。
- **第三幕：武器を置いて客席で観ると劇が終わる**——「戦わないことが正解」の反転。
- **結末の差分**：小さくても本当の祭りが開く瞬間／飾りが静かに降ろされる畳み——「笑ってたのに泣いた」の着地地点。
- **救出後の村で初めての祭り**——「みんなが踊る日」が遅れて来る。章全体の回収点として、配信者と視聴者が「よかった」を分かち合う場面。
