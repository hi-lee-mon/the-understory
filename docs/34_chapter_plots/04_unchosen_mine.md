## 0. 章の骨格（起承転結×三幕ハイブリッド）

- **起（序）**：掘り止めの採石場〜浅坑。静かな不気味さ。「動く素材」の発見と「拾って使う」の獲得。
- **承（破）**：選別の広場〜（公の）作業場〜隔離区画。恐怖の本格化——蠢きが「恨み」に見え始め、深部へ追い込まれる緊張。
- **転（ミッドポイント）**：隠し工房（＝作業場の床下の私室・必須通過点）の発見。「彼は作れなかった」の認識が崩れる。目的が「倒す」から「届ける・終わらせる」へ変わる。
- **結（急）**：根幹坑道〜炉心の広場。打鍵音の正体＝棄材のゴーレム。「拾って使う」でその「待ち」を終わらせ、結末を綴じる。

## 1. 章の目的（感情・物語機能・配信反応）

### 担う感情：**恐怖→勇気**
序破（1〜3章）の温かさ→切なさ→滑稽の振れ幅の後、感情マップの転調点となるホラー寄りの章（`docs/12` §2.1）。狙うのは「怖いものが実は怖いのではなく、それでも奥へ降りる勇気」——**恐怖を理解で溶かし、行動に変える**アーク。

- **恐怖の源泉**：マイクラで最も身近な場所（坑道＝資源を掘りに行く安心の場所）を反転させる。掘る側だったプレイヤーが「掘られるのを待っていた側」の物語に踏み込む。
- **勇気の意味**：深部へ行くほど日誌が乱れ・素材が蠢き・音が迫る。それでもプレイヤーが降りる理由が「理解」に変わる——蠢きは恨みでなく**渇望**だったと知ったあとでも、危険は本物である（求める刃は、求めるからこそ切る）。理解しても安全にならない、理解したから降りられる。

### 「恨み」の運用規範（v0.3 明記）
本章で「恨み」の語を使うのは**プレイヤー視点の表層的誤認（見え方）としてのみ**。実体は常に**渇望**とする（`docs/24` §3.1「棄てられたものたちは怒ってはいない」・§4.3「悪意ではなく、諦められなかった者」と整合）。日誌・落書き・フレーバー・セリフ・環境演出の本文はすべてこの原則に従う——素材を真の怨敵として書かない（Issue #10 への運用指示）。**正典側の表記**（`docs/12` §2.1 感情マップ表「没素材の恨み」・§2 第4章節「恨みを持って蠢く」）は §11 P2 の参照注記で吸収する（v0.4 明記）。

### 担う物語機能（この章でしかできない仕事）
1. **「棄てられたものの暗い面」**：愛された没案でなく、**恐れられて隔離された物**（呪いの刃・危険すぎた設計）を扱う唯一の章。棄てることの暴力性・棄てられた者が恨みを持つ**に見える**ことの正当性を示す（実体は渇望——上記の運用規範）。
2. **「使われなかった」の物語としての深化**：「使う」をテーマ化する章——鍛冶師の口癖思想「使われねぇ道具は、ただの鉄だ」が、終章の問い「選ばれなかったものに価値はなかったのか」への章固有の対抗軸を立てる（「使われないことは、存在しないことか」）。
3. **拾得鍛錬の深化**：拾った没素材を「本来の用途どおりに使う」原体験を章内で教え、ボス戦の核心機構にする。救出後の鍛冶師による正式な鍛錬（上位の真の姿化・名付け素材の特別鍛錬）へ接続——段位差は §3 の規定で保つ（その場使用は「仮の姿」まで——§3・§11 P4）。
4. **灼熱の埋立て地への橋**：焼却・処理された物の届き先（`docs/23` §8.4）へのロア的橋渡し。深部に「燃やされて届いた者たちの地」への気配を置き、救出後の鍛冶師がその存在を語る案内人になる。
5. **転調点**：前任の拾い人の落書きがここで最も濃くなる（確定一文「おれは帰れなかった。でも、物は届いていた」）。この章から**落慮王の存在が断片で見え始める**（集めて離さない何かの気配）。

### 狙う配信反応
- 「怖い・びっくり」（蠢く素材・隔離区画・打鍵音の正体）
- 「拾ったやつで殴ったら通った！」（核心機構のエウレカ）
- 「中に人がいた」（ゴーレムの殻の下の鍛冶師）
- 「考察班が動く」（前任の落書き・原案素材・下へ吸われる物）

## 2. 到着〜導入

### 環礁への着き方
第2〜4章は同時解放・順不同（`docs/13` §1）。坑道環礁は**唯一「降りる」章**——他環礁が浜から見える水平の島なのに対し、ここは**下に裂けた採石場の島**。沖合から見えるのは堂々とした鉱山ではなく、**掘りかけで止まった段丘と、完成しなかった巻き上げ機の骨組み**だけ（表層情報：「何かが途中で止まった場所」）。

### 最初に見えるもの（非言語の第一印象）
- **掘り止めの採石場**：掘りかけの竪穴・中途で放棄された足場・地面に刺さったままのツルハシ。全てが「作業中の姿」で止まっている——墓ではなく**待機**の風景。
- **灯らなかった松明**：坑道に「置かれたが点かなかった」光源。光があるべき場所に光がない、という形の暗さ（没素材の光源）。
- **輝きかけて止まる鉱脈**（`docs/20` §5）：壁の鉱石が微かに明滅し、近づくと沈む。**見ていると眠り、目を離すと動き出す**——「見られていないときだけ生きている」素材の性質を体で覚える最初の一時間。
- **遠い打鍵音**：到着の瞬間から、規則正しい「鈍い一打ち」が環境音として聞こえ続ける。プレイヤーはこれを坑道の環境音だと思う。**正体は最深部のボス**（§5）——全編を通じたヒッチコック型サスペンスの種。

### ノミの反応（配置と役割のみ）
- 導線：坑道口で「ここは淀んでる」方向だけを示す（核心を説明しない）。
- 感情の鏡：この章で初めてノミが**怖がる**（内的状態の要請、`docs/22`）。普段の皮肉が薄れ、光が揺れる——プレイヤーの緊張を代弁する装置。
- 伏線：前任の落書きに近づくと口を濁す（「知っている者への反応」。§8-9 参照）。

## 3. 探索の流れ（場所の系列——クリティカルパス）

各所は「シーン（目標→葛藤→破局）→シークエル（反応→窮地→決断）」の連鎖で設計（`docs/33` §2）。章ギミックは**「没素材を拾って本来の用途どおりに使う」**——これが進行・戦闘・救いのすべてを貫く唯一の動詞になる。表の第5列に各場所の「破局→決断」を割り当て、連鎖として検証可能にする。

**段位規定（v0.3）**：章内のその場使用で素材が戻るのは**「仮の姿」（仮の役目・限定的な効果）まで**——嵌めた歯車は回り、灯した提灯は点り、拾った刃片は切れるが、**本来の輝き（真の姿）には戻らない**。なお**基本位の「真の姿化」は第1章以降プレイヤーが自前で可能**（正典 `docs/11` §8・`docs/14` §1〜§2 の二値モデルどおり——第1章の最初の鍛錬体験がこれを教える）。救出後の鍛冶師が担うのは**上位の真の姿化・名付け素材の特別鍛錬**（§7 および `docs/15` §2「拾得鍛錬の高級化」報酬の価値を守る段位差）であり、「真の姿化そのものが鍛冶師限定」ではない。なお「仮の姿」は正典の二値モデル（没素材→真の姿）にない**新設の中間状態**のため、その適用範囲・持ち出し時の扱い・「使う＝拾い直し完了」のボス戦ローカル性は **§11 P4 の要承認項目**とする（v0.4 明記）。

| 7 | **根幹坑道**（深部） | 没素材が融合した地形（個物の境界が失われた壁）。日誌篇5（入口側・名付けの続きと「下へ降りる」への言及）〜篇6（炉心手前・日付の消失・反復・走り書き）。前任の落書き最密地帯・**原案素材**（最初の色の結晶）・幻想文字の断片（原案素材のすぐ近くの壁、§8） | 表層：「壁自体が恨みでできている」**と見える**恐怖の頂点（見え方としての恨み——実体は渇望、§1 運用規範）。深層：名を持たなかった者たちの末路（結末Bの意味づけ）・下へ吸われる物・落慮王の断片 | **破局**：足元・壁面の没素材が一斉に下へ吸われ始め退路が絞れる／原案素材と幻想文字の同時発見で「世界の没案」の存在が確度を上げて開示される → **決断**：それでも最奥へ降りる |
| 8 | **炉心の広場**（最深部・アリーナ） | 冷えた大鍛冶場。金床の上に山のように積まれた没素材＝**棄材のゴーレム**の静止した塊 | 表層：打鍵音の正体に辿り着く。深層：ゴーレム＝金床に積まれたまま動けなくなったものの姿 | **破局**：環境音の正体＝待ち続けた者の没腐した姿 → **決断**：殻の素材を拾って使い、彼の「待ち」を終わらせる（§5） |

**隠し工房の必須導線化（v0.2 規定・v0.3 で空間関係を接地）**：「誰にも見せないための私室」は**物語上は隠し部屋だが、構造上は必ず発見する**——選別の広場の縁に建つ（公の）作業場（母屋・#5）の床下/壁裏が私室であり、「使えない」の山が母屋の外壁にまで被さっているため、山の底の裂け目が工房の天井に通じ、工房の床の抜けた先が根幹坑道への**唯一の降り口**になる。つまり**通過は必須・読む/拾うは任意**——「発見の強制」は「書物・断片の取得強制」ではない（`docs/24` §8「拾えなくても章はクリアできる」の層構造と整合）。見逃しで進路を失わせないための非言語導線：作業場の床下から灯りと風が漏れる・裂け目から灯りが漏れる・下へ抜ける風の流れ・ノミが裂け目の前で止まる。

### 道中の推理（主軸の問い）
- **なぜ未完か**：彼の素材はすべて「没」だった → ではなぜ全て没だったのか → **彼の仕事（世界一の道具の発注）自体が没だった**。彼は不良素材の被害者ではなく、世界に「必要ない」と判断された物語の主人公だった。
- **誰の物か**：日誌（鍛冶師）・落書き（前任の拾い人）・漂着した他者の捨て物（見知らぬ誰かの怖い物——第4章アフィニティの実演）・原案素材（誰のでもない＝世界のもの）。

## 4. ミッドポイント——隠し工房

**覆る認識**：「鍛冶師は素材に恵まれず何も作れず壊れた」→「**彼は作れていた。だが『没素材の傑作』を自分の仕事として認められなかった**」。

- **発見の形（必須通過点としての位置づけ）**：選別の広場の縁に建つ（公の）作業場の床下/壁裏の私室——「使えない」の山の底の裂け目から天井の抜けた私室に潜り込み、その床の抜けた先が根幹坑道への唯一の降り口になる（§3 の必須導線化・#5/#6）。そこには**完成した小道具**が並ぶ：名札の付いた小さな刃物、掌サイズの鐘、磨かれた遊び道具。没素材で、丁寧に、愛をもって作られたものたち。名付き小物は**複数個**存在させる（終幕素材の供給経路その1、§5 供給保証参照）。
- **正典との橋渡し（v0.2 明記）**：正典（`docs/12` §2・`docs/28` §7）の「素材が全て没になり、何も作れないまま没腐した」は**表層の記録としては真実**——公開の作業日誌・検品記録・発注書はすべて「（公の仕事としては）作れなかった」を裏付ける。隠し工房の発見がこの読みを覆る構造：**「公の仕事」は作れなかったが、「彼の仕事」は作れていた**。Issue #10 の実作業者はこの二層を前提に執筆すること——日誌の公の面は「作れない者」の筆致で書き、工房の名付け記録だけが「作れた者」の筆跡になる（正典側への反映——`docs/25` §2.4 の弱み限定化・`docs/12` §2 および `docs/28` §7 への参照注記追記は、ユーザー承認項目として §11 に集約した）。
- **情報の重ね方（フェアプレイ）**：伏線は先に全て提示済み——（公の）作業場の異様に綺麗な道具立て（「何も作らない者がなぜ道具を手入れする？」＝§3 #5 で配置済み）、日誌の公私二重記録（公開の仕事記録の合間に混入する私的な頁＝篇3）、「使えない」と弾きながら一部だけ別に置いた素材の記録。読み返すと全部そうなっていた。
- **同時に開く第二の転換**：発注書（隠し工房に配置、§8）——彼の「世界一の道具」は**注文だった**。注文は取り消され（没）、彼の物語ごと棄てられた。彼が検品していた素材は「届いた不良品」でなく、**届くはずのなかった全て**。
- **目的の転換（`docs/33` §3 必須要件）**：ここでプレイヤーの目的が「最深部のボスを倒す」から「**彼に届くものを見つけ、彼の物語を終わらせる**」へ変わる。恐怖が使命に変わる＝「勇気」の起点。
- **ノミの機微**：隠し工房で拾った名付き小物へのノミの反応（名付けられた物への特別な反応——名付け＝物語化の資格、ノミ自身の伏線と響き合う）。

## 5. ボス設計——棄材のゴーレム

### 没腐した正体
**「待ち続けた者の没腐した姿」**（`docs/24` §4.3 の定義通り）。姿は**没素材の巨体**——道具・鉱石・部材が無数に積み重なって形作られた「人の形」。その中心（炉心）に、**虚空を打ち続ける鍛冶師本人**がいる。

- **解釈**：彼が壊れたとき、二度棄てされた素材たちが彼に集まった。恨みでなく**渇望**——「彼に使ってもらうために」。ゴーレムは、使い手を求める素材が、素材を拒んだ鍛冶師を包んだ姿。「待ち続けること」が「待つこと自体」を壊した形。
- **動作**：巨体の全動作が鍛冶の反復——振りかぶって打つ（見得）、掴んで積む、崩れて積み直す。**遠くの打鍵音は、ずっとこの音だった**（到着時からの環境音がボスに回収される）。

### ギミック：拾ったもので戦う（teach-test-twist）
- **Teach（章内）**：積み場〜中層で「没素材を拾って用途どおりに使う」が身体に入っている（歯車→巻き上げ機、提灯→灯り、刃片→武器）。
- **Test（戦闘）**：
  - ゴーレムに通常武器は**ほぼ通じない**（没腐の塊は攻撃を吸収する）。正攻法は「殴る」ではない。
  - 「見得」（鍛冶動作の大振りな予備動作）を読んで躱す→衝撃で**部位が崩れて没素材が落ちる**→それを拾い、**その場で用途どおりに使う**：落ちた刃を振るう・落ちた盾材で受ける・落ちた部材を設置して壁/足場にする・灯る素材を点けて心部を晒す。
  - **剥がれ落ちた部位は拾い上げてもまだ拾得物ではない**（由来が「棄材のゴーレムの一部」のまま残る＝拾い直し未完の状態）。**用途どおりに使った時点で初めて「役目を得た物」として定着し拾得物になる**（`docs/32` §1 の拾い直し制と整合——この戦闘では「使う」が拾い直しの完了条件）。ここで定着するのは**「仮の姿」まで**（仮の役目・限定的な効果）であって真の姿化ではない（§3 段位規定・§11 P4）。使った素材は役目を得て二度と戻らない（渇望が静まる）。
  - **使わず抱えたままの部位はゴーレムに引き戻される**——引き戻されるのは**「拾い直し未完の（ゴーレム由来のままの）部位」のみ**であり、一度でも使用済み・図鑑登録済み・名を持つ素材は対象外。つまりこれは「プレイヤーの拾得物の奪取」ではなく**「まだボスの体である物が体に戻る」**規則——ゴーレムの体力＝**未使用部位の総量**。使い切るほど体が痩せていく。
  - **部位の領域外流出の禁止（v0.3・戦闘整合の担保）**：拾い直し未完の部位は**アリーナ外へ持ち出せない**——「由来がゴーレムの一部」のままの物は拾得物化も没腐遺留物化もしない（`docs/32` §2.1 の遺留物は「プレイヤーの拾得物」が対象であり、部位はまだボスの体なので対象外）。部位を持ったまま**離脱または死亡した場合、その部位はゴーレムの体へ還る**——これにより「体力＝未使用部位の総量」の帳簿が常に閉じ、部位が流出して戦闘の整合が崩れる状態は発生しない。
- **Twist（終盤）**：殻が全て「使われて」剥がれたとき、中に**金床に向かって虚空を打ち続ける鍛冶師**がいる。最後の一手は攻撃ではない——**名を持つ没素材を彼の金床に置く**（供給保証は下記）。彼がそれを**一打ち**する——**虚空を打ち続けてきた音が、初めて素材に届いた一打ちとして坑道に響く**＝**止まっていた物語が動き出す音**。撃破＝理解して救う。
  - **終幕一手の非言語導線（v0.3）**：「置く」は文字で教えない（`docs/24` §8：必読情報は文字に置かない）。殻が全て剥がれた時点で、広場の中央・唯一灯りの差す座に**金床だけが残る**よう地形と照明で視線誘導する（戦闘中はゴーレムの塊が座を覆っていた→崩れたあと金床が露わになる）。鍛冶師は**素材のない金床**の前で虚空を打ち続けている——空の金床自体が「ここに置くべきものがある」という空間の欠けとして読める。動作は章内で教えた「部材を設置して壁/足場にする」と同型の「置く」動作の延長であり、名を持つ素材を手に金床へ近づけば「置ける」ことが配置で分かる。ノミが同行していれば金床へ視線を向ける・光がその方向へ寄る等の最小限の一押しを添えてよいが、必須の教示手段にはしない。

### 終幕条件「名を持つ没素材」の供給保証（v0.2・詰み防止）
ボス撃破＝章クリアの必須条件のため、最後の一手に必要な「名を持つ没素材」は**複数経路のどれか一つで必ず成立**する設計にする：

1. **隠し工房の名付き小物**（経路①）：複数個配置し、宝物枠（`docs/14` §1.1）として素材化・返却・紛失されても他が残るよう数で担保。
2. **戦中の確定供給：「名の残る部位」**（経路②・主フォールバック）：ゴーレムの殻には、彼が私的に名付けた小物が巻き込まれている。**フェーズ終盤（殻の最終層が剥がれる局面）で一度だけ必ず剥がれ落ちる**。**検出は非言語が主（v0.3）**：剥がれた部位は他の没素材と異なる灯りと名札の形で視認でき、拾得時の由来表示とフレーバーに名が残る（「◯◯と呼ばれていた素材」）。ノミが同行していれば指摘で補強する（「あれ…名が、ついてる」——名付けの匂いを嗅ぎ分ける特技の実演）が、戦闘中のノミ同行可否は `docs/15` §5（未決）の正典側の空白のため、**ノミ不在でも成立する設計を主とする**（§11 P3）。
   - この素材は**消費不可・破壊不可・再吸収対象外**（名を持つ物は無名の渇望の塊へは還れない——「名付け＝物語化の資格」との世界観整合）。アリーナ外への落下・紛失時は**金床の上に戻る**演出（「彼に使われたがっている」として世界観内で説明可能）。よって戦中供給が欠ける状態は発生しない。
3. **プレイヤーによる名付け**（経路③・代替）：名札を持ち込んでいれば、拾得物に名を付けて条件を満たせる（`docs/23` §3.3「名付け＝物語化の資格」の文法の実演。必須条件でなく代替経路）。**ただし物への名付け手続（名札の可否・手順・戦闘中の可不可）は正典未定義のため Issue #15 で確定する**（v0.4 明記）——経路③は手続確定を条件とする代替であり、供給保証の主軸は経路①②に置く。

→ どの経路も取れないプレイヤー状態は理論上存在しない：工房品を全喪失していても戦中に確定供給があり、その素材は失えない。

### 恐怖設計上の逆転（章の根幹）
- **進捗を「静けさ」で測る**：使われた素材が眠るにつれ、会場のざわめきが減っていく。恐怖が解けていくことが進行の可視化。
- **敗北の意味**：倒されるのでなく「使い切る」——素材が全て役目を得たとき、ゴーレムは「存在理由」を失い、中の鍛冶師だけが残る。

### 難度・仕様接続
- 読み合い可能な予備動作＝フェアな死に学習（`docs/13` §3・`docs/15` §1）。
- 死亡時は未登録拾得物の一部が没腐遺留物として残り回収可能（`docs/32` §2.1）——深部まで戻る緊張が「拾いに戻る」動機になる。拾い直し未完の部位はこの対象外（上記「領域外流出の禁止」）。
- 報酬（新動詞）：**拾得鍛錬の高級化**（`docs/15` §2 準拠。救出後の鍛冶師が上位の真の姿化を担う——詳細は Issue #15）。

## 6. 結末選択——両方が「最善の悪い選択」

Coyne の危機：善と善の衝突、どちらも代償を持つ。

### 選択肢A：**鉱脈を目覚めさせる**（書き換える系）
- **意味**：坑道の全素材に「使われる機会」を与える。輝きかけて止まっていた鉱脈が脈動し、没素材が自ら使い道を探し始める。
- **善**：棄てられた全てが一度に意味を得る最大の救済。環礁は「生きた鉱山」に変わる。
- **悪い**：**恐れられて封印された物も目覚める**。隔離区画は「誰かが責任を持って閉じた」場所だった——それを一括で解くことは、解放と同時に無責任な解放でもある（呪いの刃・危険すぎた設計が「使われる資格」を得る）。さらに彼自身の物語は「個人の完結」でなく「世界の潮流」に呑まれる——彼が本当に欲しかったのは一つの道具だったはず。
- **残る痕跡**：坑道が生きた鉱山になる（色・動き・生成物が変わる）。隔離区画の開いた扉は残る——「何かが出た」静かな不安を後味として残す。

### 選択肢B：**名を与える**（見届ける系）
- **意味**：選ばれなかった道具に、一つひとつ**名前を与える**。名付け＝物語化の資格（`docs/23` §3.3・D5）。無名の捨て物が「誰かのもの」になる。
- **善**：最も誠実な救い——一つひとつを「見る」。**名を持つ物だけが光る＝救われた数だけ坑道に灯りが増える**視覚対比として、「見た」行為の誠実さがそのまま景色に可視化される。そして彼の物語は「世界の潮流」に呑まれず、**個人の物語のまま完結する**（A の「悪い」面＝個の埋没との対称）。
- **悪い**：**名を持てるのは僅かで、鉱脈の大多数は眠ったまま残る**。棄てられたものの巨大さの前で、救えるのはほんの一部——「救いきれない」を引き受ける選択。
- **残る痕跡**：坑道は静かに輝く鉱脈に（目覚めでなく「灯り」）。名を持つ物だけが光る＝選ばれた数だけ光が増える視覚対比。

### 共通の担保
- どちらでも鍛冶師は救われ、二度と「何も作れない者」ではなくなる——**終幕で金床に置かれた名付き素材は、いずれの結末でも彼の手で「彼の仕事」として打ち上げられる**（一打ちが完成品になる＝彼の物語の最小で確かな完結は両結末に共通、§5）。
- 選ばなかった側の光景は図鑑「結末の記録」に残る（後悔は罰でなく思い出、`docs/22`）。
- マルチ：結末決裁は先着（`docs/32` §6）——「目覚めさせる派／名を与える派」の議論を促す。

## 7. 救出後

### 主の行き先
- **鍛冶師 → 拾い人の村の「拾得鍛錬の名人」**（確定済み）。クラフト強化の中心NPC——「ガラクタを本来の用途に思い出させる」正式な鍛錬を教える役。章内の「拾って使う」原体験が、村での上位鍛錬（真の姿化・名付け素材の特別鍛錬）へと深化する（段位差は §3 段位規定どおり——章内のその場使用は「仮の姿」までで、真の姿化は彼の正式鍛錬でのみ可能。§11 P4 参照）。

### 村への変化
- 鍛錬設備の高度化・拾得物の「真の姿」バリエーション拡大。
- 由来鑑定の教師役：宝物/ガラクタの見分け（`docs/14` §1.1）を彼が「素材を見る目」として教える。
- **名付けの実演**：救出後、彼が没素材に付けた名を住人に話す等、「名付けられた物が個物として存在し続ける」機構の見せ場。

### 灼熱の埋立て地への橋（次コンテンツ導線）
- 鍛冶師は**灼熱の埋立て地を知っている**（確定済み）——隔離区画の更に下、焼却・処理された物が届く場所。彼の口から「燃やされて届いた者たちの地」の存在が語られる（`docs/23` §8.4 のロア接続）。
- ゲーム上の導線：L3ごみ処理場（クレーン・マグマ構造物）の構築動機と、埋立て地への行き方（処理口・帰還は焦げ跡つきの片道 `docs/32` §5）の存在を示唆。**設計確定済み領域への橋**（`docs/23` §8.4・`docs/32` §5 で設計確定、実装自体は Phase 1 以降）であり、本章内では「熱い下層の気配」＋救出後の言及に留める（新規区域の実装対象は別Issue）。

### 次への引き（予告頁）
- 章クリアでノミが予告頁を綴じる。**第2〜4章は順不同のため、予告は「未攻略の順不同章」を指す動的選択**（実装要件：ノミが残り章のうち最も「淀んでいる」方角を語る）。

### 碑文・環境文字
- **隔離区画の封印札**：書き手＝かつての整理者（「集めて離さない」落慮王側の秩序の片鱗として読める古い形式）。「触るな」の警告系。

### ゴミ箱経路（この章での形）
- **漂着した他者の捨て物1つ**（v0.3 用語修正・v0.4 で具体形を明記）：他者が捨てた由来のある「怖い物」が**章アフィニティ配達**（武器/道具/鉱石/呪い付き/怖い物の届き先 `docs/23` §6）としてこの章に届いている実演。**物の形は「宛名の綴じられた呪いの刃」等——名札・巻き紙に差出人と宛名の記しが残り、開かれないままの手紙（巻き紙）を伴う**形とする（捨てた者が「読んでほしい誰か」を宛てたが、国に読む者がいないため届かなかった、という状態を物の姿で示す）。`docs/23` §5.2 の「届け物」（梱包して捨てた開封者指定の荷物）・§7 の「誤配」（プレイヤーのゴミ箱に届く別人宛の便）とは**別機構**——こちらは章アフィニティで章内に配置された他者の捨て物であり、「他者宛ての荷物」ではない。
- **返信の扱い（v0.2 双方向化・v0.4 で「気配」の現れ方を明記）**：返信機構は第2章の灯台守救出で解放される（`docs/23` §7・`docs/25` G5）。**「読む者不在の気配」は、捨て物に伴う手紙が「宛名はあるが封を切られていない」状態として残る**ことで現れる——国にまだ読む者がいないため誰にも開かれていない、という形の痕跡（ノミが同行していれば「まだ誰にも読まれてないな…」類の最小反応を添えてもよい）。**第2章攻略済みなら、この手紙が「読む者（顔の分かる灯台守）に届くはずの文」だと分かる**深みとして機能する双方向断片（§9 順不同耐性と同じ設計）。

### ノミの反応トリガー（配置のみ）
初到着（淀みの案内）／初の蠢く素材（怖がる内的状態）／隔離区画（止める素振り）／（公の）作業場（手入れされた道具への違和感）／隠し工房（名付き物への特別な反応・核心を濁す）／根幹坑道（落書きの前で止まる——知っている者の反応）／炉心（打鍵音への畏怖）／「名の残る部位」剥離時（同行している場合のみ・名付けの嗅ぎ分け——§5 供給保証経路②。不在でも非言語で検出可能）／結末後（安堵＋何かを思い出す素振り——落慮王伏線）。

- [x] **終幕条件の供給保証（v0.2）**：「名を持つ没素材」は工房複数個・戦中の「名の残る部位」確定供給・名札による自作の3経路。戦中供給物は消費・破壊・再吸収不可で紛失時は金床に戻る——**詰み状態は構造上存在しない**（`docs/24` §8・`docs/13` §3 と整合）。隠し工房は「隠し」ながら必須通過点（通過は必須・取得は任意）。経路③は「物への名付け手続（Issue #15 で確定）」を前提とする代替経路（v0.4 明記——供給保証の主軸は経路①②）。
- [x] **拾得物規則との整合**：再吸収は「拾い直し未完の部位」のみ。使用＝拾得物化の完了条件（`docs/32` §1）——なお「使う＝完了条件」は棄材のゴーレム由来部位に限る戦闘ローカルの特例である旨を §11 P4 で明文化（v0.4）。
- [x] **ボス戦の整合（v0.3）**：拾い直し未完の部位はアリーナ外へ持ち出せず・遺留物化せず、離脱・死亡時はゴーレムに還る——「体力＝未使用部位総量」の帳簿が常に閉じる（§5）。終幕一手「金床に置く」は金床の空間的欠け＋設置動作の延長で非言語に導く。「名の残る部位」は灯り・名札の造形と由来表示でノミ不在でも検出可能。
- [x] **終幕の一打ち（v0.4）**：「その音が坑道に初めて響く」は環境音（虚空を打つ音は到着時から鳴り続けている）と字面で矛盾するため、「**虚空を打ち続けてきた音が、初めて素材に届いた一打ちとして響く**」に修正——同じ打鍵音が「届いた音」に質的に変わる瞬間として記述。
- [x] **段位規定（v0.3・v0.4 で承認手続き化）**：章内の「使う」は「仮の役目を与える」（仮の姿・限定的な効果）に留め、真の姿化は救出後の正式鍛錬のみ——拾得鍛錬の高級化の価値を保全（§3・§5）。「仮の姿」は正典の二値モデルにない新設状態のため、適用範囲・持ち出し扱い・ボス戦ローカル性の確定を含めて **§11 P4 の要承認項目に収録**（`docs/14` §1〜§2・`docs/11` §8 への反映と Issue #15 への前提通知を承認手続きに含む）。
- [x] **「恨み」の運用規範（v0.3・v0.4 で正典側吸収を追記）**：恨み＝プレイヤー視点の表層的誤認としてのみ使用、実体は常に渇望——日誌・落書き・フレーバーの本文はこの原則に従う（§1・`docs/24` §3.1/§4.3 と整合）。正典側の「恨み」表記（`docs/12` §2.1・§2 第4章節）は §11 P2 の参照注記対象に追加し、「表層の見え方を指す」旨の注記で吸収する。
- [x] **配置の一意性（v0.3）**：場所系列に「（公の）作業場／検品小屋」を追加し、日誌篇3・フェアプレイ伏線（綺麗な道具立て）・隠し工房「作業場の床下の私室」の空間関係を接地（§3 #5・§4・§8）。発注書＝隠し工房、幻想文字＝根幹坑道の原案素材近くの壁に確定。
- [x] **シーン→シークエル連鎖（v0.4）**：§3 #7 根幹坑道の「破局」を具体的イベントに明記——足元・壁面の没素材の一斉吸収による退路遮断（突発的障害）＋原案素材・幻想文字の同時発見による「世界の没案」の開示（新事実）で Swain 型の「思いもよらない事態」として成立させた。
- [x] **用語の三点区別（v0.3・v0.4 で具体形を明記）**：章内配置の物は「漂着した他者の捨て物」（章アフィニティ配達由来）——具体形は「宛名の綴じられた呪いの刃等・封を切られていない手紙を伴う」形。「読む者不在の気配」は封を切られないままの手紙として現れ、第2章攻略済みなら「読む者に届くはずの文」と読める双方向断片（§8）。`docs/23` §5.2 の届け物（梱包・開封者指定）・§7 の誤配（プレイヤーの箱への別人宛便）とは別機構。
- [x] **結末選択の対称性（v0.4）**：選択肢Bの「善」を B 固有の価値（一つひとつを「見る」誠実さ＝名を持つ物だけが光る可視化・個の物語のまま完結）に絞り、終幕の「一打ち＝彼の仕事の完結」は両結末共通の演出として共通の担保へ移動——A（個が世界の潮流に呑まれる）と対称な二択の重さにした（§6）。

- [x] **感動を狙い撃ちしない**：主軸＝推理（なぜ全て没だったか・誰の物か）と鍛冶師の人物魅力（無骨さ×密かな名付けのギャップ）。
