# 14_アイテム・クラフト設計（v0.1）

## 1. クラフトの思想：「拾得鍛錬」

この世界の素材はすべて「没の素材」——一見ガラクタだが、**「本来の用途を思い出させる」**と真の姿に変わる。クラフトは**「捨てられたものを本物に変える」**行為そのものがテーマになる。

- 思想：**solutionではなくtoolを渡す**（Createの教訓）。没素材は組み合わせで想定外の使い方が生まれる設計。

### 1.1 「拾う≠掠める」：由来鑑定と宝物/ガラクタの区分（Issue #24）

テーマ「捨てられたものを大切に」と報酬ループ「全部拾って素材にする」の矛盾を、**「取る」行為自体を意味のある判断にする**ことで解消する：

- **由来鑑定**：特に価値のある拾得物には「元の主・本来の意味」が記録されている（鑑定・村の住人の反応・図鑑で判明）。拾得物は大きく2種：
  - **ガラクタ**：由来が薄い・消費してよい素材。クラフトの主材料
  - **宝物**：明確な由来を持つ物（誰かの形見・没になった作品・誰かが恐れて棄てた物）。素材にすると戦力を得るが**その物語が消える**（図鑑に「失われた物語」として記録）
- **「返す・譲る・残す」の価値**：宝物は村の住人に返還/譲渡できる（「それは私の…」の機微）→ 絆・特別な話・情報・施設が開く。あえて「その場に返す」選択も記録される
- 掠めることは**できるが、掠めると失われるものがある**＝行為に重みがつき、掠奪が黙認されるのではなくテーマの一部になる。強さだけを追うプレイも許すが、失われた物語は図鑑に残る（強制しない・裁かない・見せる）
- **入手手段のバリエーション（ユーザー方針 2026-09-25）**：「拾う」だけでなく**拾う・見つける（隠し配置）・貰う（住人の贈与・報酬）・届ける（配達・譲渡の楽しさ）・忍んで置く（スニーク的な遊び）**を揃える。住人へのお使い・返し物クエストは「荷物の配達ゲーム」的な届ける喜びを担う
- **「還す」の動詞を加える（Issue #32）**：拾得物・国の物をゴミ箱に入れると国へ還る。由来の分かる物は本来の持ち主/場所へ届く——「拾う」の逆の動詞として設計に組み込む（詳細は `docs/23_discard_grammar.md`）
- **図鑑は「育てる道具」**：拾得図鑑は最初から完成品でなく、クラフトまたは住人からの授与で段階的に綴じられていく。図鑑ページ自体も収集対象
- **図鑑に「あなたが捨てたもの」節を設ける**：プレイヤーが捨てた物の記録（何を・どこへ届いたか）が綴られる。忘れていても世界が覚えている構造
- **鑑定権限の棲み分け（2026-09-27 承認——横断規則9）**：ノミ＝由来の嗅ぎ分け（物の物語）／灯台守＝届きものの宛先・読み取り／鍛冶師＝素材・鍛錬の価値判定——三者は排他でなく層が違う。併せて「掌サイズの鐘」（N-GEAR-4-03：由来のある物に近づくと鳴る由来探知・第4章隠し工房に配置）を採用済み。

### 1.2 拾得鍛錬の段位三層（2026-09-27 承認——P4・横断規則10）

拾得鍛錬の段位は三層で確定する：

1. **基本位の真の姿化**＝第1章以降プレイヤーが自前で可能（拾得鍛錬台 N-DEV-301——§5）。第1章の最初の鍛錬体験がこれを教える
2. **仮の姿**（仮の役目・限定的効果）＝第4章の章ギミック「その場使用」限定の中間状態（「本来の用途を思い出させる」過程の未成段階）。仮の姿のまま拾得物として保持・持ち帰り可能だが、真の姿化は救出後の鍛冶師による正式鍛錬を要する
3. **上位の真の姿化・名付け素材の特別鍛錬**＝救出後の鍛冶師のみ（「拾得鍛錬の高級化」報酬の価値を守る段位差）

なお「使う＝拾い直し完了」の特例は第4章ボス戦・棄材のゴーレム由来部位のみの戦闘ローカル規則とし、`docs/32` §1 の通常の拾い直しは変更しない。`docs/11` §8 に同旨を併記済み。

## 2. 素材の系統（例・要全表化）

| 没素材 | 本来の姿 | 用途 |
|---|---|---|
| 錆びた没の鉱石 | 輝くはずだった鉱石 | 高Tier装備・道具 |
| 読まれなかった手紙 | 届いた手紙 | バフ・エンチャント素材・ロア |
| 止まった提灯 | 灯った提灯 | 光源・導線ギミック |
| 没の楽器 | 鳴る楽器 | 音系ギミック・ボス対策 |
| 欠けた月の結晶 | 満ちた月の結晶 | 第1章系装備 |
| 没の図面 | 実現した図面 | 高度クラフト・建築 |

- **「届いた手紙」の語義（2026-09-27 承認——02 open_questions #2・U1 #16）**：「届いた」は**「宛て先でなくとも読み手に届いた＝読まれた」**と定義する（「届く≠読まれる」の第2章テーマと衝突しないための語義拡張）。変換規則：拾得した「読まれなかった手紙」を読み手が読んだ時点で「届いた手紙」へ変換。**返信で届いた手紙も同格**（ゴミ箱経由の返信手紙は「届いた手紙」として鍛錬素材に使える——U1 #6 採用）。

## 3. アイテム系統

### 武器・道具（「新しい動詞」を渡す）
- **拾い人の鉤（かぎ）**：伸縮して掴む・登る・引く。探索の新動詞。
- **届いた手紙の刃**：「届く」ことを具現化した剣。投げると必ず戻る。
- **没の楽器**：鳴らすと環境・モブに作用（没腐の浄化・特定ボスの対策）。
- **満ちた月の弓**：月齢で効果が変わる。
- **縁（ふち）の羅針盤**：現実で「縁の地」や異物を示す案内。**入手時期＝序盤——現実側で最初の縁の地探索時に入手**（定常往復路の開通より前——U2 #15 承認）。港風セット装備時は死亡時の没腐遺留物も指す（U2 #7 承認——`docs/32` §4.2 併記）。

### 装備（Tierは進行に連動）
- 章ごとの「没素材シリーズ」が見た目も能力も変わる。装備の見た目変化＝成長の可視化。

### 食料・実用品
- **祭りの残り**（中止の祭り由来の食）：珍しいバフ食。
- **拾得の携行品**：拾得物を現実へ持ち帰るための器。**器容量が効くのは「未登録・未加工の収め物」のみ**——一度鑑定・登録済みの拾得物は通常の持ち物として自由に持ち出せる（案A・2026-09-27 承認——U1 #15。器は「未加工品の関税」の役割で、死亡ロストの範囲もこの器の中身に閉じる。`docs/32` §1.2 併記）。

### 収集・ロア
- **結末の欠片**：各章で集めるとその物語の結末に関わる。**全章配分＝総数20個（第1〜5章各4個＝CP3＋寄り道1、序章0個）**で確定（横断規則2・Issue #15 で確定済み）。終章・集積の間で全欠片の回収演出を行う。
- **拾得図鑑の綴じ片**：図鑑を埋める。
- **白紙の名札**（N-ITEM-100）：バニラ名札の供給保証なしに対する MOD 独自の代替経路——名付けの台で没素材に名を与える儀式の素材（U4-18・U2 #17 承認。`docs/23` §3.3 併記）。

### ゴミ箱（棄てる装置・転移経路 — Issue #32）
クラフト可能な「捨てる」装置。入れた物は消えず国に届き、自分を棄てれば転移手段になる（`docs/23_discard_grammar.md` §8 の全仕様）。拾得鍛錬の思想通り「捨てられた素材」で作る。**スケール×精度の2軸**で体系化する：

| スケール | 装置 | できること |
|---|---|---|
| L1 | ゴミ箱 | 物を捨てられる（国に届く）。届きものを受け取れる（ポスト機能） |
| L2 | デカいゴミ箱（ゴミ箱8個でクラフト） | **人が入れる**＝自分を棄てて転移・名付け生物の転移。レシピは国からの**返礼（招待状）**として届く（`docs/23` §5.0） |
| L3 | ごみ処理場（構造物として組む） | 工業規模の文法：クレーンで掴む・マグマ焼却・圧縮・選別。**他人を捨てられる**（灼熱の埋立て地へ届く） |

- **精度軸**：名札を組み込むと全スケールが「名づけられた」版になる（捨て場の定着度・配達精度・住人の記憶UP）——名付け＝物語化の一貫した拡張。
- 没素材を組み込むほど「国に近い箱」になる（届き精度・双方向性の理屈づけ）。詳細レシピ・素材・上限値は Issue #15 で全表化。

## 4. 報酬設計

- 各ボスの固有ドロップは「**新しい動詞**」（テレポート・浄化・変形等）を渡す＝黄昏の森の教訓。
- **由来鑑定の報酬系**：宝物の返還/譲渡は絆・特別ロア・施設解放の報酬。素材化は戦力報酬だが物語を喪失するトレードオフ
- 宝箱は**固定枠＋ランダムレア枠**（変動報酬）。探索の「何が出るか」を維持。**構成比（U4-7 承認）：固定3〜4枠＋レア枠1（レア率15%・寄り道配置は30%）。結末の欠片は宝箱に入れない。宝箱はリスポーンなし**。
- 「拾ったものを鍛え直す」快楽がクラフト動機の中心（未完コレクション動機も併用）。
- **禁則：護石式マラソンを作らない（ユーザー方針）**：レアドロップの周回・延々とした素材集めを進行条件にしない。集める楽しみは報酬であって義務ではない——拾得物は「見つけたら嬉しい」設計にし、進行ゲートは物語・発見・クラフト知識で制する
