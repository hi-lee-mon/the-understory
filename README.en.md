# The Understory

[日本語版 README はこちら](README.md)

A large-scale dimension MOD for Minecraft aiming to be "the second Twilight Forest" — a country where the unchosen and the erased drift ashore, and where you rewrite the endings of discarded stories.

Target audience: YouTubers/VTubers. Each chapter is structured as a streamable episode. Two-way travel between the Overworld and the country. NeoForge / MC 1.21.1 / Java 21 (planned).
